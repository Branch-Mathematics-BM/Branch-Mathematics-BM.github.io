### A. Correlated-input interfaces: criterion, nonexistence, and cost

#### A.1 The promise must be part of the contract

Let \(X_1,\ldots,X_m\) be nonempty finite carriers, and let
\(K\subseteq\prod_iX_i\) be a nonempty set of legal joint inputs. Let
\(T:K\to Y\) be the required task.

Here the receiver is promised an input in \(K\). It is not required to classify
arbitrary tuples outside \(K\). This differs from preserving the definedness
of a partial task on the whole Cartesian product.

Let \(E_i\) be a Branch-local equivalence and let \(q_i:X_i\to X_i/E_i\).
Write \(q(x)=(q_1(x_1),\ldots,q_m(x_m))\).
The exact decoder is required only on \(q(K)\).

**Criterion.** A decoder \(D:q(K)\to Y\) with \(Dq=T\) exists if and only if

$$
\forall s,t\in K,\quad
T(s)\ne T(t)\ \Longrightarrow\
\exists i:\ s_i\not E_i t_i.
$$

**Proof.** Equality of the product codes is equivalent to coordinatewise
\(E_i\)-equivalence. A decoder exists precisely when equal product codes
force equal task values. Taking the contrapositive gives the criterion.
Conversely define \(D(q(s))=T(s)\); the criterion makes it well defined. This
is the foundational fibre-factorization result applied to the legal joint
source \(K\). \(\square\)

Thus every pair of legal inputs with different tasks must be separated by at
least one retained coordinate. The contract does not require every Branch to
retain the distinction.

#### A.2 A two-state counterexample

Take \(X_1=X_2=\{0,1\}\), legal inputs

$$
K=\{(0,0),(1,1)\},\qquad T(a,b)=a\quad\text{on }K.
$$

Both of the following interfaces are exact:

- keep the first bit, forget the second;
- forget the first bit, keep the second.

Both require one Branch-local bit. A family coarser than both must forget both
bits, which gives the same code to the two different task values. It is not
exact. Consequently there is no greatest/coarsest exact Branch-local
equivalence family for this promise-only contract.

This does not eliminate the unique joint task quotient on \(K\): both exact
interfaces induce the same separating joint quotient there. What fails is a
unique coarsest allocation of that quotient to the individual Branches.
Identity local dynamics suffice, so this counterexample requires no
complication from continuation.

#### A.3 An exact greatestness test

Fix initial equivalences \(B_i\) and consider every task-exact family
\(\mathbf E=(E_i)\) with \(E_i\subseteq B_i\).
This finite feasible set \(\mathcal A\) is nonempty because the discrete
equivalences are allowed.

Form the coordinatewise join

$$
J_i=\bigvee_{\mathbf E\in\mathcal A}E_i.
$$

The join is the equivalence generated by the union: add transitive connections
to the union of all feasible \(E_i\). It remains inside \(B_i\).

**Theorem.** A greatest exact family exists if and only if
\(\mathbf J=(J_i)\) passes the task-separation criterion in A.1.
When it passes, \(\mathbf J\) is that greatest family.

**Proof.** If \(\mathbf J\) is feasible, it contains every feasible family and
is therefore greatest. Conversely, a greatest feasible family belongs to
\(\mathcal A\); its coordinates occur among the joined relations. It also
contains every joined relation. Hence it equals \(\mathbf J\). \(\square\)

This is a finite decision procedure, not an efficiency theorem: enumerate the
allowed partitions, keep the task-exact families, form the joins, and test
the resulting family. A failed test gives two legal inputs with different
tasks that the proposed join merges.

#### A.4 Preserving raw-input definedness is a different contract

If the receiver must also distinguish legal from illegal raw tuples, define
the total tagged task

$$
\widehat T(x)=
\begin{cases}
T(x),&x\in K,\\
\bot,&x\notin K,
\end{cases}
$$

where \(\bot\) is different from every task value.

On the full Cartesian product define

$$
u\sim_i v
\iff
uB_iv\ \text{and}\
\widehat T(c_{-i},u)=\widehat T(c_{-i},v)
\quad\text{for every Cartesian context }c_{-i}.
$$

Each relation is an intersection of kernel equivalences. Replacing coordinates
one at a time proves that the product quotients preserve \(\widehat T\).
Every other product-exact family must pass each fixed-context test and is
therefore contained in these relations. This supplies the greatest family
for this stronger task-only contract.

For the diagonal example this stronger contract must keep both bits: changing
one bit can turn a legal tuple into an illegal tuple. The promise-only and
raw-definedness contracts therefore have different retention requirements.
This explains the boundary of the Cartesian finite-interface theorem without
contradicting it.

#### A.5 Exact binary retention includes Set Cover

Specify the following finite decision problem. Every Branch is binary.
Each Branch is either retained exactly or replaced by a constant. Its local
cost is one bit when retained and zero when forgotten. Input data are an
explicit legal-input table \(K\), a binary task \(T\), and an integer budget
\(k\). The question is whether at most \(k\) Branches suffice.

Given a Set Cover instance with sets \(S_1,\ldots,S_m\) covering a finite
universe \(U\), let \(v_u\in\{0,1\}^m\) be the membership vector of element
\(u\). Define

$$
K=\{\mathbf0\}\cup\{v_u:u\in U\},\qquad
T(\mathbf0)=0,\quad T(v_u)=1.
$$

All \(v_u\) are nonzero because the supplied sets cover \(U\). Duplicate
membership vectors can be merged without changing the cover problem.

For a retained coordinate set \(I\), exact decoding is possible if and only if
every \(v_u\) has at least one retained one-coordinate:

$$
\forall u\in U,\quad
\exists i\in I:\ u\in S_i.
$$

**Proof.** The zero input must remain distinguishable from every task-one
input. Task-one inputs may share a code with each other. A task-one input
shares the zero code exactly when all its retained coordinates are zero.
This is exactly the covering condition. \(\square\)

The construction has polynomial size. A proposed coordinate subset can be
verified by checking the legal input table in polynomial time. Using the
classical NP-completeness of Set Cover, this binary promise-retention decision
problem is NP-complete. Local actions may all be identities.

The cost here is the sum of independently retained binary Branch capacities.
It is not the logarithm of the number of joint codes realized on \(K\).
This explicit cost and promise semantics are essential to the complexity
statement. The reduction uses established complexity theory; no historical
priority is claimed for this formulation.

### B. Exact scalar error with a decoder-sensitivity cap

#### B.1 Statement and assumptions

Let \(X\ne\varnothing\), let \((Z,d)\) be a metric space,
let \(R:X\to Z\), and let \(T:X\to\mathbb R\) be bounded.
Fix \(L\ge0\). Define

$$
\varepsilon_L=
\inf_{\operatorname{Lip}(D)\le L}
\sup_{x\in X}|T(x)-D(R(x))|,
$$

where the decoder \(D:Z\to\mathbb R\) must be \(L\)-Lipschitz.
No continuity of \(R\) or \(T\) is assumed.
The code metric and output units are fixed parts of this contract.

**Theorem.** The optimum is attained and is exactly

$$
\boxed{
\varepsilon_L=
\frac12\sup_{x,y\in X}
\left[|T(x)-T(y)|-L\,d(R(x),R(y))\right]_+.
}
$$

Here \([a]_+=\max(a,0)\).
This quantifies both collisions inside a fibre and instability between
different, nearby fibres.

#### B.2 Complete proof

For any admissible decoder with worst-case error \(e\),

$$
|T(x)-T(y)|
\le |T(x)-D(Rx)|+|D(Rx)-D(Ry)|+|D(Ry)-T(y)|
\le 2e+L\,d(Rx,Ry).
$$

Taking the positive part and supremum proves the lower bound.

Let \(e\) be the value on the right of the theorem and define the envelopes

$$
a(z)=\sup_{x\in X}\{T(x)-e-Ld(z,Rx)\},
$$

$$
b(z)=\inf_{x\in X}\{T(x)+e+Ld(z,Rx)\}.
$$

Both are finite: boundedness of \(T\) supplies one side of each bound and any
fixed \(x_0\in X\) supplies the other side. Each cone is \(L\)-Lipschitz, so
taking its supremum or infimum preserves that Lipschitz bound.

For every \(x,y,z\), the defining pair bound and triangle inequality give

$$
T(x)-T(y)\le 2e+L\,d(Rx,Ry)
\le2e+L\,d(z,Rx)+L\,d(z,Ry).
$$

Thus every lower cone is below every upper cone, and \(a(z)\le b(z)\).
Set \(D(z)=(a(z)+b(z))/2\). This decoder is \(L\)-Lipschitz. At \(z=Rx\),

$$
T(x)-e\le a(Rx)\le D(Rx)\le b(Rx)\le T(x)+e.
$$

Its error is at most \(e\), attaining the lower bound. \(\square\)

The envelopes use classical McShane-type Lipschitz constructions. The
formula and proof are supplied here for this BM reconstruction contract;
no claim of historical novelty is made.

#### B.3 Minimum required sensitivity

For a requested error \(\varepsilon\ge0\), first check

$$
R(x)=R(y)\ \Longrightarrow\ |T(x)-T(y)|\le2\varepsilon.
$$

If that fails, no decoder can meet the tolerance.
If it holds, define

$$
L_{\min}(\varepsilon)=
\sup_{\substack{x,y\in X\\R(x)\ne R(y)}}
\frac{[|T(x)-T(y)|-2\varepsilon]_+}{d(R(x),R(y))},
$$

with supremum zero for an empty indexing set.
When this number is finite, a decoder with exactly that sensitivity cap is
feasible by B.1; when it is infinite, no finite Lipschitz cap is feasible.
The formula gives an exact sensitivity/error tradeoff for bounded scalar
tasks. It does not extend automatically to vector, smooth, causal, or quantum
decoder classes.

#### B.4 Rescaled code example

On \(X=[-1,1]\), take \(T(x)=x\), \(R_a(x)=ax\), and Euclidean code distance,
with \(a>0\). The theorem gives

$$
\boxed{\varepsilon_L=(1-La)_+.}
$$

The representation is injective for every \(a>0\), but a decoder constrained
to \(L=1\) has error \(0.99\) when \(a=0.01\).
Perfect recovery requires \(L\ge1/a\).
This quantifies why making code residuals small by rescaling does not establish
stable recovery. Changing the code metric would change the declared contract.

#### B.5 Cubic code example

Let \(T(t)=t\), \(R(t)=t^3\) on \([-1,1]\).
For a fixed input separation \(d_0\in[0,2]\),

$$
u^3-v^3=d_0(3m^2+d_0^2/4)\ge d_0^3/4,
\qquad m=(u+v)/2,
$$

and equality is attained at \(u=-v=d_0/2\).
Consequently

$$
\varepsilon_L=\max_{0\le a\le1}(a-La^3)
=
\begin{cases}
1-L,&0\le L\le1/3,\\
2/(3\sqrt{3L}),&L\ge1/3.
\end{cases}
$$

For \(0<\varepsilon\le2/3\), the required sensitivity is exactly

$$
\boxed{L_{\min}(\varepsilon)=4/(27\varepsilon^2).}
$$

For \(2/3\le\varepsilon\le1\), it is \(1-\varepsilon\);
for \(\varepsilon\ge1\), it is zero.
Exact recovery at \(\varepsilon=0\) has no finite Lipschitz decoder.

| Decoder cap \(L\) | Optimal cubic-code error |
|---:|---:|
| 0 | 1 |
| \(1/3\) | \(2/3\) |
| 1 | approximately 0.384900179460 |
| 10 | approximately 0.121716123890 |
| 100 | approximately 0.038490017946 |

For example, tolerance \(0.1\) requires \(L\ge400/27\), approximately
14.8148148148. The statements follow analytically; the decimal values are
illustrations.

### C. Finite-horizon causal approximation with an explicit error budget

#### C.1 Native model and profile metric

Let \(X\ne\varnothing\), let \(f:X\to X\) be a supplied total deterministic
evolution, and let \(T:X\to(Y,d_Y)\) be a task. Fix a finite horizon \(H\ge0\).
This theorem assumes the native evolution already exists.

Define

$$
P_h(x)=(T(x),T(fx),\ldots,T(f^h x)),
$$

and the future-profile pseudometric

$$
\rho_h(x,y)=
\max_{0\le j\le h}d_Y(T(f^j x),T(f^j y)).
$$

It satisfies

$$
\rho_{h-1}(fx,fy)\le\rho_h(x,y)\qquad(h\ge1).
$$

This follows by dropping the current-time comparison from the maximum.
It requires neither continuity nor a native-state Lipschitz bound on \(f\).

For each remaining horizon \(h\), choose a finite internal profile cover with
native prototypes \(c_{h,1},\ldots,c_{h,N_h}\) and radius \(\delta_h\):

$$
\forall x\in X,\quad
\min_j\rho_h(x,c_{h,j})\le\delta_h.
$$

Choose \(q_h(x)\) to be the first prototype index meeting that inequality.

#### C.2 Construction

Initialize the code by \(j_0=q_H(x_0)\).
Define the update and decoder

$$
F_h(j)=q_{h-1}(f(c_{h,j}))\quad(h\ge1),
\qquad D_h(j)=T(c_{h,j}).
$$

The code at remaining horizon \(h\) uses only its current index to update.
It does not reobserve the unknown native trajectory at each step.

**Error bound.** For every initial state and every \(0\le k\le H\),

$$
d_Y\bigl(D_{H-k}(j_k),T(f^k x_0)\bigr)
\le\sum_{h=H-k}^{H}\delta_h
\le\sum_{h=0}^{H}\delta_h.
$$

**Proof.** Put \(x_k=f^k x_0\), \(h=H-k\), and

$$
e_k=\rho_h(x_k,c_{h,j_k}).
$$

The initial cover gives \(e_0\le\delta_H\).
For \(h\ge1\), triangle inequality, profile nonexpansion, and the next cover
give

$$
\begin{aligned}
e_{k+1}
&=\rho_{h-1}\bigl(fx_k,c_{h-1,F_h(j_k)}\bigr)\\
&\le \rho_{h-1}\bigl(fx_k,f(c_{h,j_k})\bigr)
+\rho_{h-1}\bigl(f(c_{h,j_k}),c_{h-1,q_{h-1}(f(c_{h,j_k}))}\bigr)\\
&\le e_k+\delta_{h-1}.
\end{aligned}
$$

Induction gives the stated sum. The current task distance is one term in
\(\rho_h\), so it obeys the same bound. \(\square\)

Thus any finite covers at the chosen radii, including minimum-cardinality
internal covers, can be equipped with these common updates. At those fixed
radii no larger alphabets are needed for this task-prediction contract.
The price is accumulated error. To meet a single final tolerance, the radii
must share a common error budget.

#### C.3 Exact existence condition at every positive tolerance

**Theorem.** A finite-state deterministic predictor with uniform error at most
\(\varepsilon\) over times \(0,\ldots,H\) exists for every
\(\varepsilon>0\) if and only if \(P_H(X)\) is totally bounded in the sup
product metric. Initialization may inspect the native state or a lawful
observation sufficient to select the required initial code.

**Necessity.** A predictor with finitely many initial codes produces finitely
many output profiles. If every native profile is within \(\varepsilon\)
of its corresponding predicted profile, these profiles form a finite
\(\varepsilon\)-cover. Having such covers at every positive radius is total
boundedness.

**Sufficiency.** Total boundedness of \(P_H(X)\) gives total boundedness of all
shorter profiles by nonexpansive projection. An ambient cover of radius
\(\delta_h/2\) gives an internal cover of radius \(\delta_h\): discard empty
balls and choose one native profile in each remaining ball. Any other native
profile in that ball is within \(\delta_h\) of the chosen one. Set
\(\delta_h=\varepsilon/(H+1)\) and apply C.2. \(\square\)

No compactness or completeness assumption is needed for this finite-cover
existence assertion. Those would matter for stronger limit or attainment
claims of a different kind.

#### C.4 Explicit resource bound

Let \(N_h^{\mathrm{in}}(\delta)\) be the minimum internal cover size, and let
\(N_h^{\mathrm{amb}}(\delta)\) allow centers anywhere in \(Y^{h+1}\).
When finite, the minimum internal cardinality is attained because possible
finite cardinalities are positive integers. The preceding argument gives

$$
N_h^{\mathrm{in}}(\delta)\le N_h^{\mathrm{amb}}(\delta/2).
$$

With radii satisfying \(\sum_h\delta_h\le\varepsilon\), the construction
requires at most

$$
b_h=\left\lceil\log_2N_h^{\mathrm{in}}(\delta_h)\right\rceil
$$

bits for the code at stage \(h\), excluding an externally supplied remaining-
horizon index. Integrated code capacity is bounded by \(\sum_h b_h\).
If the phase must be internal, an autonomous augmented machine can use
states \((h,j)\), with at most \(\sum_hN_h\) states and hence at most
\(\lceil\log_2(\sum_hN_h)\rceil\) bits. Its final states can be absorbing.

Any initial predictor with uniform trajectory error \(\varepsilon\) must
have at least \(N_H^{\mathrm{amb}}(\varepsilon)\) initial codes.
The construction provides an upper bound, not a general globally optimal
resource allocation.

The theorem is about finite alphabets and task prediction. It does not prove
continuous/smooth encoding, computability of arbitrary infinite covers,
physical channel realization, extra interaction descent, or exact native
path lifting. Prototype indices along the quantized path need not form one
exact native trajectory. If initialization receives only an insufficient
legacy code, this construction cannot supply its missing distinctions.

#### C.5 Horizon cost: a fully explicit doubling example

Take \(X=[0,1)\), \(f(x)=2x\bmod1\), and \(T(x)=x\).
For integers \(r\ge1\) and remaining horizon \(h\), define

$$
q_h(x)=\lfloor2^{h+r}x\rfloor,\qquad
F_h(j)=j\bmod2^{h+r-1},\qquad
D_h(j)=j/2^{h+r}.
$$

Direct calculation gives \(q_{h-1}f=F_hq_h\). Starting from \(q_H(x_0)\),
the machine therefore retains the correct current binary prefix at every
stage. Its error is

$$
0\le f^k(x_0)-D_{H-k}(j_k)<2^{-(H-k+r)}\le2^{-r}.
$$

Initial storage is \(H+r\) bits, decreasing to \(r\) bits at the deadline.
This special compatible encoding has no accumulated recompression error.

There is also a horizon-dependent lower bound. Choose the
\(2^{H+1}\) initial points

$$
x_j=(j+1/2)/2^{H+1},\quad 0\le j<2^{H+1}.
$$

For two different indices write \(j-i=2^s u\) with \(u\) odd.
Then \(0\le s\le H\), and at time \(H-s\) the two unwrapped values differ by
\(u/2\). Their fractional parts have distance \(1/2\).
The future profiles of every pair therefore have sup distance at least
\(1/2\).

A common predicted profile cannot be within error
\(\varepsilon<1/4\) of both, by triangle inequality.
Every such predictor consequently needs at least \(2^{H+1}\) initial codes,
or at least \(H+1\) initial bits.

This is a finite-alphabet capacity statement, not a native dimension lower
bound: the original model already evolves in one real coordinate.
It also proves that no one finite-alphabet deterministic predictor can meet
the same error \(\varepsilon<1/4\) for every time without new observations.
Finite horizon is an essential restriction of the positive theorem.

"""Reproducible finite checks for the 14 October BM repair continuation.

Written proofs carry the general claims. Exact finite checks and floating-point

from itertools import combinations, product

import json

import random
import numpy as np
from scipy.optimize import linprog


def exact_interface(states, tasks, retained):
    decoded = {}
    for x, t in zip(states, tasks):
        code = x & retained
        if code in decoded and decoded[code] != t:
            return False
        decoded[code] = t
    return True


def check_promises():
    models = 0
    no_greatest = 0
    for m in range(1, 4):
        ambient = list(range(1 << m))
        for promise_mask in range(1, 1 << len(ambient)):
            states = [x for x in ambient if promise_mask & (1 << x)]
            for tasks in product((0, 1), repeat=len(states)):
                feasible = []
                for retained in range(1 << m):
                    direct = exact_interface(states, tasks, retained)
                    conflict_cover = all(
                        ti == tj or bool((x ^ y) & retained)
                        for x, ti in zip(states, tasks)
                        for y, tj in zip(states, tasks)
                    )
                    assert direct == conflict_cover
                    if direct:
                        feasible.append(retained)
                joined = (1 << m) - 1
                for retained in feasible:
                    joined &= retained
                join_feasible = exact_interface(states, tasks, joined)
                greatest_exists = any(
                    all((r & other) == r for other in feasible)
                    for r in feasible
                )
                assert join_feasible == greatest_exists
                no_greatest += not greatest_exists
                models += 1
    diagonal = [0, 3]
    assert exact_interface(diagonal, [0, 1], 1)
    assert exact_interface(diagonal, [0, 1], 2)
    assert not exact_interface(diagonal, [0, 1], 0)
    return {"models": models, "no_greatest_models": no_greatest,
            "criterion_and_join_test": "passed"}


def check_set_cover_reduction():
    instances = 0
    for patterns in product(range(1, 8), repeat=3):
        # Each pattern lists sets containing one universe element.
        states = [0] + sorted(set(patterns))
        tasks = [0] + [1] * (len(states) - 1)
        decoding = [r for r in range(8) if exact_interface(states, tasks, r)]
        covering = [r for r in range(8) if all(p & r for p in patterns)]
        assert decoding == covering
        assert min(r.bit_count() for r in decoding) == min(
            r.bit_count() for r in covering)
        instances += 1
    return {"incidence_instances": instances, "reduction_check": "passed"}


def scalar_exact(z, t, cap):
    error = max(F(0), max(
        (abs(a - b) - cap * abs(x - y)) / 2
        for x, a in zip(z, t) for y, b in zip(z, t)))
    codes = sorted(set(z))
    decoded = {}
    for code in codes:
        lower = max(a - error - cap * abs(code - x)
                    for x, a in zip(z, t))
        upper = min(a + error + cap * abs(code - x)
                    for x, a in zip(z, t))
        assert lower <= upper
        decoded[code] = (lower + upper) / 2
    assert all(abs(a - decoded[x]) <= error for x, a in zip(z, t))
    assert all(abs(decoded[x] - decoded[y]) <= cap * abs(x - y)
               for x in codes for y in codes)
    return error, decoded


def scalar_lp(z, t, cap):
    codes = sorted(set(z))
    index = {code: i for i, code in enumerate(codes)}
    n = len(codes)
    rows, rhs = [], []
    for code, value in zip(z, t):
        row = [0.] * (n + 1)
        row[index[code]], row[-1] = 1., -1.
        rows.append(row); rhs.append(float(value))
        row = [0.] * (n + 1)
        row[index[code]], row[-1] = -1., -1.
        rows.append(row); rhs.append(-float(value))
    for x in codes:
        for y in codes:
            if x == y:
                continue
            row = [0.] * (n + 1)
            row[index[x]], row[index[y]] = 1., -1.
            rows.append(row); rhs.append(float(cap * abs(x - y)))
    objective = [0.] * n + [1.]
    result = linprog(objective, A_ub=rows, b_ub=rhs,
                     bounds=[(None, None)] * n + [(0, None)], method="highs")
    assert result.success, result.message
    return result.fun


def check_scalar():
    rng = random.Random(20261014)
    max_lp_difference = 0.
    cases = 200
    for _ in range(cases):
        n = rng.randint(2, 9)
        z = [F(rng.randint(-8, 8), 2) for _ in range(n)]
        t = [F(rng.randint(-12, 12), 3) for _ in range(n)]
        cap = rng.choice([F(0), F(1, 4), F(1, 2), F(1), F(3)])
        exact, _ = scalar_exact(z, t, cap)
        numerical = scalar_lp(z, t, cap)
        difference = abs(float(exact) - numerical)
        max_lp_difference = max(max_lp_difference, difference)
        assert difference < 2e-8
    rescaling = []
    for delta in [F(1), F(1, 10), F(1, 100), F(1, 1000)]:
        values = [F(-1), F(0), F(1)]
        error, _ = scalar_exact([delta * x for x in values], values, F(1))
        assert error == max(F(0), 1 - delta)
        rescaling.append({"delta": str(delta), "cap": "1", "error": str(error)})
    cubic = []
    for cap in [0., 1/3, 1., 10., 100.]:
        a = 1. if cap <= 1/3 else 1/math.sqrt(3*cap)
        expected = a-cap*a**3
        z = [-1., -a**3, 0., a**3, 1.]
        t = [-1., -a, 0., a, 1.]
        observed = scalar_lp(z, t, cap)
        assert abs(observed-expected) < 2e-8
        cubic.append({"cap": cap, "error": expected})
    return {"rational_cases": cases, "exact_envelope_witnesses": "passed",
            "independent_lp_max_difference": max_lp_difference,
            "rescaling_examples": rescaling, "cubic_examples": cubic}


def future_profiles(f, t, horizon):
    profiles = []
    for x in range(len(f)):
        y = x
        profile = []
        for _ in range(horizon + 1):
            profile.append(t[y])
            y = f[y]
        profiles.append(tuple(profile))
    return profiles


def profile_distance(a, b):
    return max(abs(x-y) for x, y in zip(a, b))


def minimum_internal_cover(profiles, radius):
    n = len(profiles)
    distances = [[profile_distance(a, b) for b in profiles] for a in profiles]
    balls = [sum(1 << j for j in range(n) if distances[i][j] <= radius)
             for i in range(n)]
    full = (1 << n) - 1
    centers = None
    for k in range(1, n+1):
        for chosen in combinations(range(n), k):
            covered = 0
            for i in chosen:
                covered |= balls[i]
            if covered == full:
                centers = chosen
                break
        if centers is not None:
            break
    assert centers is not None
    q = [min(range(len(centers)), key=lambda j: (distances[x][centers[j]], j))
         for x in range(n)]
    assert all(distances[x][centers[q[x]]] <= radius for x in range(n))
    return centers, q


def check_causal_composition():
    rng = random.Random(20261015)
    systems = 100
    starts = 0
    outputs = 0
    for _ in range(systems):
        n = rng.randint(2, 8)
        horizon = rng.randint(0, 6)
        f = [rng.randrange(n) for _ in range(n)]
        t = [F(rng.randint(-6, 6), 2) for _ in range(n)]
        radii = [rng.choice([F(0), F(1, 2), F(1), F(2)])
                 for _ in range(horizon+1)]
        profiles = [future_profiles(f, t, h) for h in range(horizon+1)]
        covers = [minimum_internal_cover(profiles[h], radii[h])
                  for h in range(horizon+1)]
        for h in range(1, horizon+1):
            assert all(profile_distance(profiles[h-1][f[x]], profiles[h-1][f[y]])
                       <= profile_distance(profiles[h][x], profiles[h][y])
                       for x in range(n) for y in range(n))
        for x0 in range(n):
            native = x0
            code = covers[horizon][1][x0]
            used_budget = F(0)
            for h in range(horizon, -1, -1):
                centers, q = covers[h]
                center = centers[code]
                used_budget += radii[h]
                assert profile_distance(profiles[h][native], profiles[h][center]) <= used_budget
                assert abs(t[native]-t[center]) <= used_budget
                outputs += 1
                if h:
                    code = covers[h-1][1][f[center]]
                    native = f[native]
            starts += 1
    return {"finite_systems": systems, "native_initial_states": starts,
            "decoded_time_points": outputs, "optimal_internal_covers": "exhaustive",
            "causal_error_budget_checks": "passed"}


def doubling(x):
    y = 2*x
    return y-int(y)


def check_doubling():
    separated_pairs = 0
    trajectories = 0
    for horizon in range(8):
        count = 1 << (horizon+1)
        grid = [F(2*j+1, 2*count) for j in range(count)]
        for i in range(count):
            for j in range(i+1, count):
                difference = j-i
                s = 0
                while difference % 2 == 0:
                    s += 1
                    difference //= 2
                k = horizon-s
                left = (1 << k)*grid[i]; left -= int(left)
                right = (1 << k)*grid[j]; right -= int(right)
                assert abs(left-right) == F(1,2)
                separated_pairs += 1
        for r in range(1, 6):
            for denominator in [17, 64, 101]:
                for numerator in range(denominator):
                    x = F(numerator, denominator)
                    q = int((1 << (horizon+r))*x)
                    for h in range(horizon, -1, -1):
                        decoded = F(q, 1 << (h+r))
                        assert F(0) <= x-decoded < F(1, 1 << (h+r))
                        assert x-decoded < F(1, 1 << r)
                        if h:
                            q %= 1 << (h+r-1)
                            x = doubling(x)
                    trajectories += 1
    return {"separation_pairs": separated_pairs, "countdown_trajectories": trajectories,
            "rational_checks": "passed"}

## I. Noise, loss, and calibration

### 59. The scalar decoder theorem does not yet include uncertain codes

**Evidence / parent:** B assumes the decoder receives R(x) exactly; parents 18 and 21. **Kind:** Bound/proof; new noise extension, not a flaw in B.

Let the task values t(x) be bounded real numbers. Instead of one exact code, let the nonempty set Omega(x) contain every code that can reach the decoder. In a common metric code space, for a finite sensitivity cap L, the exact robust worst-case error is

\[
e_{L,\Omega}=\frac12\sup_{x,y}
\bigl[|t(x)-t(y)|-L\,\operatorname{dist}(\Omega(x),\Omega(y))\bigr]_+.
\]

The infimum is attained by an L-Lipschitz real decoder. Distances between sets are infimum pairwise distances, not Hausdorff distances. To prove this, apply B to the source of pairs (x,z) with z in Omega(x), representation (x,z)↦z, and task (x,z)↦t(x). Taking the supremum over two such pairs gives the formula, and B's envelope construction proves attainment even when the closest pair of codes is not attained.

**Remaining gate:** Supply the actual code uncertainty sets and a common metric. A probability variance, unspecified noise amplitude, or error measured only at R(x) does not supply them. This result assumes arbitrary real outputs; entry 61 handles a different receiver class.

### 60. Code rescaling changes the signal-to-noise requirement

**Evidence / parent:** B.4 treats R(x)=a x without code noise; parent 21. **Kind:** Bound/proof.

For x in [−1,1], task t(x)=x, a>0, and observed code a x+e with |e|≤nu, the minimum error with decoder sensitivity at most L is

\[
e^*=\begin{cases}
1,&\nu\ge a,\\
\max\{\nu/a,\;1-L(a-\nu)\},&0\le\nu<a.
\end{cases}
\]

By 59, twice the error is the maximum, for 0≤d≤2, of d−L(a d−2nu)_+. This piecewise linear function has its maximum at d=2nu/a or d=2 when nu<a. If nu≥a, the endpoint code sets overlap and the maximum is two. This proves the value and its attainment through 59.

For nu<a and L≥1/a, the error floor is nu/a. Decreasing a can therefore make an exact noiseless code unusable at a fixed physical noise level. Increasing decoder gain cannot remove overlap of possible codes.

**Remaining gate:** The noise must be specified in code units. Choosing a convenient normalization and then leaving nu unchanged describes a different instrument.

### 61. Native output restrictions can invalidate midpoint decoding

**Evidence / parent:** R, “Optimal error inside a fibre,” and B's real-output hypothesis; parent 18. **Kind:** Counterexample/repair; deployment gate already distinguished from the unrestricted theorem.

Suppose one code represents task values 0 and 2. If all real decoded values are accepted, output 1 attains error one. If the receiver permits only outputs {0,2}, every accepted decoder has error two. The same representation and task diameter therefore have different optimum losses under different output Passports.

The corrected one-fibre quantity is

\[
\inf_{y\in Y_{\mathrm{accepted}}}\sup_{x\in F}|t(x)-y|.
\]

For finite accepted outputs this is computed by evaluating every candidate, and attainment is automatic. It is not generally half the diameter. Across fibres, independent choices still require any declared regularity or common physical implementation to be audited separately.

**Remaining gate:** Identify accepted outputs, including quantization, feasibility, and any joint constraints. R already states a radius rather than a universal midpoint theorem for arbitrary targets; the correction is to applications that silently drop that distinction.

### 62. Good decoders for individual calibrations need not give one usable decoder

**Evidence / parent:** B assumes one specified encoder; F/R T19–T20 retain quantifier order; parent 21. **Kind:** Counterexample/repair.

Let x in [−1,1], task x, and unknown calibration theta in {−1,+1} give R_theta(x)=theta x. If theta is supplied, D_theta(z)=theta z is a gain-one exact decoder. If theta is not supplied and a single decoder must work for both calibrations, code z=1 can mean either task +1 or −1. Every common decoder has error at least one; D=0 attains one.

Thus “for every calibration there is a decoder” does not establish “there is a decoder for every calibration.” One calibration bit suffices to restore exact recovery in this example and is necessary to distinguish the two conventions if otherwise indistinguishable observations are retained.

**Remaining gate:** State which calibration parameters are observed, fixed, estimated, or adversarial. The theorem applies only to the resulting common observation contract.

### 63. A finite numerical sample does not certify a uniform residual

**Evidence / parent:** R, “Uniform quantitative contracts,” requires uniform bounds; parent 21 and the verification obligation in 7. **Kind:** Counterexample/repair.

On [0,1], any finite sample set leaves an open interval between samples. A continuous triangular spike supported in that interval can be zero at every sample and have arbitrarily large peak. Even continuity plus zero sampled residual therefore gives no finite uniform bound without a quantitative regularity assumption.

If the nonnegative residual r is K-Lipschitz and every point lies within rho of a sampled point, then

\[
\sup r\le\max_{\mathrm{samples}}r+K\rho.
\]

Choose a nearest sample up to an arbitrarily small distance slack and apply the Lipschitz inequality; taking the slack to zero proves the estimate. This is a valid sample-to-uniform certificate, provided K and rho themselves are certified.

**Remaining gate:** Establish a native residual modulus and a genuine covering radius. Random tests without a distributional guarantee do not provide this worst-case certificate.

## II. Predictive state, actions, and initialization

### 64. The causal predictor must include every selectable action

**Evidence / parent:** C uses one autonomous map; R, “The future profile of a past,” keeps continuations common; parent 19. **Kind:** Bound/proof; controlled extension.

Let A be a finite action alphabet and f_a:X→X specified total maps. Let W_h be all action words of length at most h, including the empty word. Form

\[
P_h(x)=(T(f_wx))_{w\in W_h},\qquad
\rho_h(x,y)=\max_{w\in W_h}d(T(f_wx),T(f_wy)).
\]

For every action a, rho_(h−1)(f_a x,f_a y)≤rho_h(x,y), because each continued word is a word already tested at horizon h. Native prototype covers of radius delta_h therefore support the construction in C with updates F_(h,a)(j)=q_(h−1)(f_a(c_(h,j))). Its error along **every** admissible action sequence is at most sum_h delta_h.

A finite initialized predictor exists at every positive tolerance exactly when P_H(X) is totally bounded: sufficiency is this construction; necessity unfolds each initial reduced state into its finite action-response tree, giving a finite ambient cover. The tree has sum_(k=0)^H |A|^k response slots.

**Remaining gate:** This does not make discovering the covers efficient. Partial actions require availability tags, and restricted action histories require their own legal-word contract. An autonomous forecast alone is not a control certificate.

### 65. An autonomous deadline has a clock cost even for a constant task

**Evidence / parent:** C.4 separates stage alphabets from an internal phase state; parent 23. **Kind:** Bound/proof.

Consider a system required to issue a constant task for H further transitions and then export “stopped,” without an external clock. Its H+1 remaining-time states are pairwise future-distinguishable: if h<k, after h transitions one is stopped and the other is still available. Any exact autonomous interface preserving the stop event therefore needs at least H+1 states, or ceil(log2(H+1)) fixed-length state bits. A countdown attains this bound.

If stopping is scheduled externally and is not a response exported by the internal state, the constant task can instead use one state with a self-loop. These are different contracts. Charging only the maximum per-stage task alphabet hides the deadline cost in the first contract.

**Remaining gate:** Decide whether the clock is external hardware, part of the reduced state, or a receiver-observed task. The phase sum in C is an upper bound; this calculation establishes a concrete situation in which a separate phase resource is necessary.

### 66. Equal error allocation can overpay when stage costs differ

**Evidence / parent:** C.4 uses delta_h=epsilon/(H+1); parent 23. **Kind:** Bound/proof.

Suppose a declared resource envelope is sum_h a_h delta_h^(−p), with a_h>0 and p>0, and the proved propagation budget is sum_h w_h delta_h≤epsilon, with w_h>0 and epsilon>0. Put

\[
B=\sum_h a_h^{1/(p+1)}w_h^{p/(p+1)}.
\]

The unique minimum of this continuous envelope is B^(p+1)/epsilon^p, attained at

\[
\delta_h=\frac{\epsilon}{B}(a_h/w_h)^{1/(p+1)}.
\]

The cost decreases in every delta_h, so the budget is saturated. Each term is strictly convex. Lagrange differentiation gives a_h delta_h^(−p−1) proportional to w_h; substitution gives the displayed allocation and value, and convexity proves global optimality.

For C's future metric all w_h=1. Stages with larger covering cost receive a larger error allowance. This optimizes the specified envelope; it is not an exact solution for integer covering numbers or a cost law that has not been measured.

**Remaining gate:** Supply the actual covering-cost model and rounding overhead, or use the expression only as a certified upper-envelope design.

### 67. A finite predictive code is not protected against transmission errors

**Evidence / parent:** C's code alphabet is noiseless; parents 19 and 23. **Kind:** Bound/proof.

Suppose M initial states have future profiles separated by more than twice the allowed task error. Their transmitted b-bit words must remain distinguishable after any s bit flips. Hamming balls of radius s around these words must be disjoint, so their minimum distance is at least 2s+1 and

\[
M\sum_{j=0}^{\min(s,b)}\binom bj\le2^b.
\]

Otherwise one received word could stand for two incompatible forecasts. Counting the disjoint balls proves the inequality. A sufficient, deliberately inefficient construction repeats each bit of an ordinary ceil(log2 M)-bit message 2s+1 times; majority decoding corrects any total of s flips.

The ordinary binary indices in C's doubling example have no such separation. They certify a noiseless forecast, rather than an error-correcting communication system.

**Remaining gate:** Supply the communication-error model and protect the code accordingly. Protection against message corruption does not recover information already lost in the native measurement; entry 68 treats that obstruction.

### 68. Initialization uncertainty limits the doubling predictor's horizon

**Evidence / parent:** C.5 initializes from the exact native x; parents 19 and 21. **Kind:** Counterexample/repair with an explicit lower bound.

For f(x)=2x mod 1 and T(x)=x, compare x=0 with x'=2^(−H−1). Their native measurement intervals of radius nu overlap whenever nu≥2^(−H−2). One shared measurement can initialize only one deterministic forecast. At time H the two tasks are 0 and 1/2, so that forecast has worst-case error at least 1/4.

Consequently, a guarantee strictly below 1/4 requires

\[
\nu<2^{-H-2},\quad\text{equivalently}\quad
H<\log_2(1/(4\nu))\quad(\nu>0).
\]

This necessary condition holds even with unlimited internal code states. It is a measurement obstruction, not a failure of C's exact-initialization construction. The example is exact dyadic arithmetic; no asymptotic estimate is involved.

**Remaining gate:** Identify initialization precision and any subsequent observations. Extra code redundancy alone cannot remove the shared initial measurement.

## III. Long-time dynamics and verification domains

### 69. A long-time tolerance needs a contraction margin, not only a small residual

**Evidence / parent:** R, “Propagating approximate defects,” and T55-C4 give finite-horizon recurrences; parents 19 and 21. **Kind:** Bound/proof; sharp uniform budget.

For e_(k+1)≤q e_k+delta with 0≤q<1,

\[
e_k\le q^ke_0+\delta\frac{1-q^k}{1-q},\qquad
\sup_k e_k\le\max\{e_0,\delta/(1-q)\}.
\]

Both bounds follow by expanding the recurrence. They are sharp: true state zero and approximate update F(z)=qz+delta, starting from z=e_0≥0, attain the recurrence and approach delta/(1−q).

Thus an infinite-time task tolerance epsilon needs e_0≤epsilon and delta≤(1−q)epsilon in this worst-case class. If q is known only to lie below q_bar<1, use q_bar. If its uncertainty permits q≥1, this certificate supplies no uniform bound.

**Remaining gate:** Certify the contraction coefficient on the comparison domain. A favorable fitted value without an uncertainty margin does not establish the budget.

### 70. Stable native evolution does not certify its discrete numerical update

**Evidence / parent:** R's evolution maps are supplied native operations; parent 9 for an implementation and 21 for amplification. **Kind:** Counterexample/repair.

The equation x_dot=−lambda x, lambda>0, has exact flow gain exp(−lambda t)<1 for every t>0. Explicit Euler with step h instead has gain |1−h lambda|. It contracts exactly when 0<h lambda<2. At h lambda=2 it alternates without decay; above two a small perturbation grows exponentially.

For x_dot=−A x with symmetric positive-definite A, orthogonal diagonalization gives

\[
\|I-hA\|_2=\max_j|1-h\lambda_j(A)|,
\]

so strict contraction holds exactly for 0<h<2/lambda_max(A). This is an exact numerical-model threshold, not a claim that every integrator must be Euler.

**Remaining gate:** Name the deployed update and certify its step-size or solver stability. A proof for the continuous flow cannot be transferred to an unspecified discretization.

### 71. Expansive steps can be allowed if the full cycle contracts

**Evidence / parent:** R T33 allows varying gains; parent 21. **Kind:** Bound/proof; a more usable periodic certificate.

For a p-step repeating schedule e_(k+1)≤L_k e_k+delta_k, let

\[
Q=\prod_{j=1}^pL_j,\qquad
B=\sum_{j=1}^p\delta_j\prod_{\ell=j+1}^pL_\ell.
\]

At cycle boundaries e_((n+1)p)≤Q e_(np)+B. If Q<1, entry 69 supplies a boundary bound max(e_0,B/(1−Q)); applying the prefix recurrences gives the separate bound for each phase.

For L_1=2, L_2=1/4, and both defects delta, Q=1/2 and B=5delta/4. The limiting boundary error is at most 5delta/2 and the intervening expansive phase at most 6delta. Scalar affine updates with positive defects attain these limiting values. Requiring every L_j<1 would unnecessarily reject this schedule; reporting only the cycle value would hide the larger intermediate error.

**Remaining gate:** Verify the actual order and per-phase domains. The formula assumes the same schedule and constants repeat.

### 72. Residual tests need a reachable comparison tube

**Evidence / parent:** R, “Uniform quantitative contracts,” explicitly demands the needed intermediate domains; parent 21. **Kind:** Gate/procedure with a proof.

Let K be a nonempty exact forward-invariant subset of a metric state space, g:K→K the exact update, and F the deployed update. Suppose sup_(x in K) d(Fx,gx)≤delta and F is q-Lipschitz between all compared points in the r-neighborhood of K, where q<1. Then

\[
\operatorname{dist}(Fz,K)\le q\operatorname{dist}(z,K)+\delta.
\]

Compare z with a point of K arbitrarily close to its distance infimum, and use g(K)⊆K. Therefore the r-tube is forward invariant if r≥delta/(1−q). For a true trajectory x_k in K, d(Fz_k,gx_k)≤q d(z_k,x_k)+delta yields the same error bound.

This proof requires residual certification only on K, while requiring deployed-map regularity on the tube. It avoids evaluating an exact native update at an unlawful approximate state.

**Remaining gate:** Verify K's invariance, F's domain, and its tube modulus. Testing only endpoints or asserting a bounded region without proving it contains the approximate trajectory is insufficient.

### 73. Sampled-time closure can hide a wrong intermediate evolution

**Evidence / parent:** R exactification is relative to the declared contexts; parent 21. **Kind:** Counterexample/repair.

On [−1,1], let the true map be f(x)=x and the reduced update be F(x)=−x, with exact encoding and decoding. Their two-step maps agree everywhere: f^2=F^2=id. A test restricted to even times reports zero residual, while at every odd time the worst task error is two.

Continuous-time frequency has the same sampling issue: rotations at frequencies omega and omega+2pi/tau agree at every multiple of tau but differ between samples. These are exactly equivalent for the sampled contract; they need not be equivalent for a receiver that asks for intermediate responses.

**Remaining gate:** Declare the time set, interpolation requirements, and admissible dynamics. A long sampled horizon is not a substitute for finer temporal coverage.

## IV. Stochastic laws, policies, and statistical evidence

### 74. A small average row error can conceal a completely wrong rare state

**Evidence / parent:** R T41 uses uniform row control, not a training-distribution average; parent 29 only concerns a different complexity question. **Kind:** Counterexample/repair.

Let native row errors be nonnegative epsilon_x≤1 and let an evaluation distribution p assign mass alpha to one state with error one and zero error elsewhere. The average error is alpha, while the worst-case error is one.

If every state has p_x≥p_min>0, then

\[
\max_x\epsilon_x\le\min\{1,\overline\epsilon/p_{\min}\},
\qquad\overline\epsilon=\sum_xp_x\epsilon_x.
\]

Each term p_x epsilon_x is at most the sum, proving the bound; concentrating error on a least-probable state attains the unconstrained ratio. If some state has zero mass, an average supplies no control at that state.

**Remaining gate:** Choose worst-case or distributional performance explicitly. A finite Markov Passport requiring every initial law cannot be certified from average training error without this coverage information.

### 75. Mixing improves the linear-in-time approximate-lumpability bound

**Evidence / parent:** R T41–T42 prove min(1,m epsilon); parent 21. **Kind:** Bound/proof; a stochastic long-time extension.

Let Q be a reduced stochastic matrix with Dobrushin coefficient q=max_(z,z') TV(Q_z,Q_z')<1. Suppose every native state's aggregated row is within delta of the Q row for its current code. If mu_k is the actual observed law and nu_(k+1)=nu_k Q, then

\[
TV(\mu_k,\nu_k)\le q^kTV(\mu_0,\nu_0)
+\delta(1-q^k)/(1-q).
\]

The fresh discrepancy between mu_(k+1) and mu_k Q is at most delta by convexity. Q contracts TV by q: decompose a zero-mass signed difference into equal-mass positive and negative laws and average pairwise row differences. This proves the recurrence and the bound.

If the native chain has a stationary law and pi is its aggregate, while pi_Q is Q's unique stationary law, TV(pi,pi_Q)≤min(1,delta/(1−q)). The observed process need not itself be exactly Markov: uniform native row control suffices for this argument.

**Remaining gate:** Estimate and certify q and delta. Without a strict mixing margin, T42's finite-horizon guarantee remains the available general certificate.

### 76. Sampled transition rows cannot be certified exactly by equality of counts

**Evidence / parent:** R's finite stochastic algorithm assumes supplied rational tables; parents 29 and 7. **Kind:** Gate/procedure with a finite confidence bound.

Suppose N native rows are each sampled independently n times into B observation classes. There are M=NB empirical cell probabilities. Each has variance at most 1/(4n). Chebyshev's inequality and a union bound give

\[
\Pr(\max_{x,b}|\widehat p_{xb}-p_{xb}|>t)
\le M/(4nt^2).
\]

Set t=2epsilon/B. With n≥M B^2/(16 alpha epsilon^2), every row has TV estimation error at most epsilon with probability at least 1−alpha. Thus a true between-row discrepancy is bounded by its empirical discrepancy plus 2epsilon. This conservative bound is explicit and requires no unjustified exact-equality inference.

For any finite sample, Bernoulli parameters p and p+eta in (0,1) assign positive probability to the same sample strings. No zero-error finite-sample test of exact equality is possible without additional structural knowledge.

**Remaining gate:** State the sampling process, row access, confidence level, and tolerance. Correlated samples do not satisfy the variance calculation automatically.

### 77. Closure after averaging actions does not support action selection

**Evidence / parent:** R distinguishes action-labelled closure from a game strategy; parent 29. **Kind:** Counterexample/repair.

Use hidden states x0,x1 with the same current observation, and absorbing outputs g,b with different observations. Action A sends x0 to g and x1 to b. Action B sends x0 to b and x1 to g. Under a fixed policy choosing A and B with equal probability and not exporting their label, both hidden states have the same observed next law: half g, half b.

The policy-averaged quotient is exact for that policy. Under action A, however, the aggregated rows have TV distance one. A controller allowed to choose A therefore cannot use the averaged-law closure certificate. Recording the action also distinguishes the two joint action/output laws.

**Repair:** Compare aggregated rows for every selectable action, or explicitly constrain the policy and exported observations. This is a four-state finite counterexample; it does not dispute fixed-policy lumpability.

### 78. Conditioning on a rare event amplifies model error

**Evidence / parent:** R T41–T42 concern unconditional laws; parent 21. **Kind:** Bound/proof and counterexample.

If TV(P,Q)≤delta, P(E)≥p>delta, and both conditional laws are defined, then

\[
TV(P(\cdot\mid E),Q(\cdot\mid E))
\le\min\{1,2\delta/p\}.
\]

For A⊆E, insert Q(A)/P(E) between the two conditional probabilities. Each unnormalized probability discrepancy is at most delta, and Q(A)≤Q(E), giving 2delta/P(E). Also Q(E)>0 follows from delta<p.

The dependence on event probability is necessary. Give E the same mass alpha in both laws, place its mass on different labels, and let the laws agree outside E. Then TV(P,Q)=alpha while the conditional distance is one. Moving only a fraction theta in (0,1) of that rare mass gives delta=theta alpha<p=alpha and conditional distance theta, also demonstrating the dependence within the bound's strict-probability hypothesis.

**Remaining gate:** Provide a lower bound on the probability of every event on which the receiver conditions. A good global transition estimate alone does not certify rare-event forecasts.

## V. Heat profiles and physical ports

### 79. The heat inverse needs an explicit precision budget

**Evidence / parent:** R, “Positive time in the heat equation,” proves injectivity and an unbounded inverse; parents 21 and 27. **Kind:** Bound/proof; sharp finite-band noise calculation.

Restrict the initial state to the unit ball of the first n orthonormal eigenmodes of a nonnegative self-adjoint heat generator A. Observe z=exp(−tau A)x+e with ||e||≤nu, and request x. The exact unrestricted minimax error is

\[
e_n^*=\min\{1,\nu\exp(\tau\lambda_n)\}.
\]

Inverting the retained modes has norm exp(tau lambda_n), proving the upper bound nu exp(tau lambda_n); projecting its output to the unit ball cannot increase error. The constant zero decoder gives the other upper bound, one. For the lower bound, set x=±c e_n with c=min(1,nu exp(tau lambda_n)). Both can produce observed code zero, so any decoder has error at least c.

For epsilon<1, a necessary and sufficient precision condition in this model is nu exp(tau lambda_n)≤epsilon. Thus exact noiseless distinction preservation does not decide the usable spectral cutoff.

**Remaining gate:** Identify tau, the task norm, code-noise norm, spectral bounds, and the lawful initial-state class.

### 80. A full unforced heat future can cost no more than its earliest retained time

**Evidence / parent:** R defines receiver-profile covering numbers; parents 26–27. **Kind:** Bound/proof; a concrete profile quantification.

Let S(t)=exp(−tA) be the contraction heat semigroup and take the full-state receiver path (S(t)x) for tau≤t≤H, in the sup norm. For any x,y,

\[
\sup_{t\in[\tau,H]}\|S(t)(x-y)\|
=\|S(\tau)(x-y)\|.
\]

The value at tau supplies the lower bound; semigroup contraction supplies the upper. Ambient covering numbers of the path image and the image at tau are also equal. Evaluation at tau maps any path cover into a state cover. Conversely a state center z extends to the path S(t−tau)z, with no larger covering error.

Thus enlarging H adds no approximation width for this particular unforced full-state task. An earliest positive time matters; a longer future interval alone does not necessarily increase width.

**Remaining gate:** Forcing, different observables, noncontractive dynamics, or a time-integrated metric changes the argument. This result does not quantify those contracts.

### 81. Heat smoothing does not compactify every bounded forcing family

**Evidence / parent:** R's heat calculation is for initial states and its Hankel statement fixes an input-space norm; parent 26. **Kind:** Counterexample/repair.

For the forced equation x_dot=−A x+u, x(0)=0, consider the final-state map on the unit ball of L1([0,H];Hilbert space). With eigenvalues lambda_j→infinity, set u_j(s)=lambda_j e_j on [H−1/lambda_j,H] and zero elsewhere. Its L1 norm is one, but

\[
x_j(H)=(1-e^{-1})e_j.
\]

These outputs have a fixed pairwise separation, so this bounded forcing family is not compactified. Pulse amplitudes are unbounded; excluding them is an additional input contract.

For the L2 input unit ball, the j-th response gain instead is

\[
b_j=\left((1-e^{-2H\lambda_j})/(2\lambda_j)\right)^{1/2}\to0.
\]

Cauchy–Schwarz in each temporal mode bounds the omitted output tail by sup_(j>n) b_j times the input norm. Finite output-mode truncations therefore converge in operator norm, proving compactness.

**Remaining gate:** Specify input norms and amplitude/bandwidth restrictions. “Bounded forcing” without its norm leaves the approximation theorem undecided.

### 82. Compact traces followed by an unbounded receiver can lose compactness

**Evidence / parent:** R, “Coupling obligations at a boundary,” explicitly assumes bounded Lambda and L; parent 26. **Kind:** Counterexample/repair; an application gate.

On l2, let T=diag(1/j), a compact operator, and let Lambda=diag(j) with domain {z:sum_j j^2|z_j|^2<infinity}. T maps every input into this domain, yet Lambda T=identity. The composed response is bounded but not compact.

Thus merely knowing that reachable traces are compact in a weak ambient norm is insufficient for an unbounded boundary operator. A sufficient repair is that T be compact into Lambda's graph-norm domain, with norm ||z||_graph=(||z||^2+||Lambda z||^2)^(1/2). Lambda is bounded from that domain into the output space, so composition is compact.

**Remaining gate:** Identify the actual trace and receiver spaces. The source's bounded-operator result remains correct; a derivative or Dirichlet-to-Neumann receiver often needs stronger spaces before it can be applied.

### 83. An uncertain coupling operator needs a resolvent certificate

**Evidence / parent:** R gives g=S^−1 b and receiver Cg for a specified invertible S; parent 21. **Kind:** Bound/proof.

Let a=||S^−1||, ||Delta S||≤zeta, and a zeta<1. The perturbed operator S_hat=S+Delta S is invertible by the convergent geometric series for I+S^−1 Delta S, and

\[
\|\widehat S^{-1}\|\le\frac a{1-a\zeta},\qquad
\|\widehat S^{-1}-S^{-1}\|\le\frac{a^2\zeta}{1-a\zeta}.
\]

If the forcing error is at most eta and C is fixed, then

\[
\|C(\widehat g-g)\|
\le\|C\|\frac{a\eta+a^2\zeta\|b\|}{1-a\zeta}.
\]

The second inverse bound follows from the resolvent identity. Splitting the output error into forcing and inverse errors gives the final expression. For a positive scalar S with a negative perturbation Delta S, the bound can be attained.

**Remaining gate:** Certify the operator-error norm and the inverse margin. If a zeta≥1, closeness of a numerical matrix alone cannot certify invertibility of the intended coupling.

## VI. Receiver geometry and uncertain weights

### 84. Nonnegative weights need not satisfy the SPD theorem's hypotheses

**Evidence / parent:** R LEV 013 assumes S,K positive definite, although task weights can originate as nonnegative sums; parent 22. **Kind:** Bound/proof; PSD extension with corrected equality scope.

For positive-semidefinite S,K, the optimum over rank(M)≤d still is the sum of the discarded eigenvalues of H=S^(1/2) K S^(1/2), including zero eigenvalues. Let A=K^(1/2)S^(1/2). Every feasible M gives a rank-at-most-d matrix N=K^(1/2) M S^(1/2), so the classical low-rank bound remains a lower bound. A truncated singular-value approximation A_d lies in the column support of K^(1/2) and row support of S^(1/2). Therefore

\[
M=K^{\dagger/2}A_dS^{\dagger/2}
\]

attains that bound and has rank at most d. Daggers denote the spectral pseudoinverses.

The SPD characterization of **all** minimizers and its rank-filling assertion do not transfer. With S=diag(1,0), K=I, and d=1, every M=[[1,a],[0,0]] has zero loss, with arbitrarily large a. With S=diag(1,0), K=diag(0,1), even M=0 has zero loss.

**Remaining gate:** Check support, rank, and which task directions have zero weight. A zero weighted loss does not certify unweighted tasks.

### 85. Euclidean projector admissibility changes under nonorthogonal units

**Evidence / parent:** R LEV 014C compares a Euclidean projector Passport with unrestricted linear maps; parents 21–22. **Kind:** Counterexample/repair.

Under a coordinate change x'=A x, with A invertible, transport

\[
S'=ASA^T,\quad K'=A^{-T}KA^{-1},\quad M'=AMA^{-1}.
\]

Substitution into the quadratic loss proves J'(M')=J(M); rank is preserved. Euclidean symmetry, however, is not preserved. For P=(1/2)[[1,1],[1,1]] and A=diag(2,1), the transported map is [[1/2,1],[1/4,1/2]], idempotent but nonsymmetric.

If orthogonality means self-adjointness in a specified metric G, the lawful Passport is M^2=M and M^T G=G M. Transport G'=A^(−T) G A^−1; these equations are then invariant. Resetting G' to identity after changing units chooses a different admissible class and can change the measured projector price.

### 86. A solver certificate does not include uncertainty in S and K

|J_{S,K}(P)-J_{S',K'}(P)|
\le r\{k_{\mathrm{err}}\|S\|+\|K'\|s_{\mathrm{err}}\}=:B.

Split the difference into tr((K−K')Q S Q) and tr(K'Q(S−S')Q). PSD trace bounds give the displayed estimate. Since it is uniform over the same feasible class, the two projector **optimum values** differ by at most B as well.

A certified numerical lower bound l and feasible upper value u for the measured instance therefore give [l−B,u+B] for the intended instance. If only an upper bound for ||K'|| is known, use ||K||+k_err. This is additional to arithmetic/dual-feasibility error in the optimization certificate.

### 87. A stable optimum value does not imply a stable selected subspace

## VII. Experiment objectives and observation semantics

### 89. Maximum quotient width can spend the budget on irrelevant distinctions

**Evidence / parent:** R distinguishes exact quotient width from task pair coverage; parent 38 and the application obligation in 10. **Kind:** Counterexample/repair.

Let X={0,1}×{0,...,7} and let the receiver task be the first coordinate. A unit-cost experiment u reveals that bit and has width one. A unit-cost distractor v reveals the second coordinate and has width three. Greedy maximization of raw quotient width chooses v, which leaves the task completely ambiguous in every resulting class.

For required task pairs, u separates all 64 cross-bit pairs. v separates only the 56 with different second coordinates. Task pair coverage therefore selects u at the same budget. This does not show width is a bad objective for a receiver requesting all distinctions; it shows the task contract must determine the objective.

**Remaining gate:** Enumerate the distinctions the receiver actually needs and their cost or loss. A higher raw width alone is not a demonstrated application improvement.

### 90. Pair-coverage submodularity yields a usable fixed-budget guarantee

**Evidence / parent:** R W15 proves monotone submodularity of required-pair coverage; parent 38. **Kind:** Bound/proof; algorithmic quantification.

For unit-cost tests and a budget of k≥1, greedy pair coverage attains at least

\[
\bigl(1-(1-1/k)^k\bigr)\,\mathrm{OPT}_k
\ge(1-e^{-1})\,\mathrm{OPT}_k.
\]

At a current family S, an optimal k-test family can add at least OPT_k−C(S) coverage. Submodularity bounds that increase by the sum of its k individual current marginals. One available test therefore adds at least (OPT_k−C(S))/k, and greedy adds at least that much. Iterating the remaining-deficit inequality k times proves the factor.

The same argument works for nonnegative weights on required pairs. This is the classical greedy coverage guarantee in the explicit BM task-pair sector, not a novelty claim. It does not apply to the non-submodular quotient-width objective.

**Remaining gate:** A 63% coverage guarantee is not an exact separation certificate. Unequal test costs, adaptive policies, and noisy pair decisions require a separately proved guarantee.

### 91. Repeating a test does not reduce adversarial support ambiguity

**Evidence / parent:** R, “A nerve replaces an invalid quotient,” uses feasible observation sets; parent 38. **Kind:** Bound/proof; a negative result about a proposed remedy.

Let Omega(x) be the possible observations of one test. Under independent set-product uncertainty, r repetitions give Omega(x)^r. For every nonempty state family F,

\[
\bigcap_{x\in F}\Omega(x)^r
=\left(\bigcap_{x\in F}\Omega(x)\right)^r.
\]

The repeated experiment therefore has exactly the same ambiguity nerve for every finite r≥1. If two tasks can produce a common observation once, they can produce its repeated tuple, so no uniform zero-error identification improvement follows from repetition.

This is consistent with statistical averaging improving a high-probability estimate under additional assumptions. Support-based worst-case ambiguity and error probability are different quantities. Independence in the feasible-set product does not supply zero-mean noise or a concentration law.

**Remaining gate:** To claim a repetition benefit, state its statistical law, correlation structure, and confidence target, or a restricted joint feasible set that actually removes the common repeated observations.

### 92. An ambiguity coloring is not an observation-based task decoder

**Evidence / parent:** R explicitly calls nerve coloring a grouping problem; parent 38. **Kind:** Gate/procedure; exact decoder criterion.

A decoder D that receives only observation z and must return T(x) for every z in Omega(x) exists exactly when

\[
\Omega(x)\cap\Omega(y)\ne\varnothing
\quad\Longrightarrow\quad T(x)=T(y).
\]

Necessity follows at a shared observation. Conversely the set of task values compatible with every realized observation is a singleton, so define D by that value. No representative-state choice or observation-independent grouping is needed.

For Omega(1)={a,b}, Omega(2)={b,c}, and different task labels, the two states can form one jointly confusable group, but no decoder can identify the task at b. Sending a group label chosen from the true hidden state presupposes access that an observation-only encoder may not have.

**Remaining gate:** State what the encoder observes. A finite grouping/coloring result becomes a usable decoding certificate only after this observation-access check. The source already warns of the distinction; this entry supplies its explicit acceptance test.

### 93. The four-hypothesis adaptive threshold is specific to worst-case cost

**Evidence / parent:** R W18 uses unit costs and worst-case depth; parent 38. **Kind:** Counterexample/repair for an objective change.

With three hypotheses a,b,c, take the three binary unit-cost tests that isolate each hypothesis. Every fixed separating set needs two tests. An adaptive policy asks “a?” first and, only if necessary, “b?”. Under a positive prior its expected cost is 2−p(a), strictly below two; under the uniform prior it is 5/3. Its worst-case cost is still two.

Three is the minimum number for this strict expected-cost advantage in the positive-prior, unit-cost, exact-identification contract. With two hypotheses, any separating test identifies both in one unit, and exact identification cannot stop before a test when both hypotheses remain possible. With one hypothesis no tests are needed.

**Remaining gate:** Supply the prior and choose expected or worst-case cost. This does not revise W18's four-state worst-case threshold; it prevents exporting that threshold to a different optimization objective.

## VIII. Physical quantum closure and numerical certification

### 94. Unamplified quantum error can understate an entangled receiver's error

**Evidence / parent:** R explicitly distinguishes operator-norm task defect from diamond norm; parents 30 and 33. **Kind:** Counterexample/repair with dimension quantification.

For d≥2, the Werner–Holevo channels are

\[
\Phi_\pm(\rho)=\frac{\operatorname{tr}(\rho)I\pm\rho^T}{d\pm1}.
\]

Their Choi matrices are (I±F)/(d±1), where F swaps the two d-dimensional factors, so they are CPTP. On a normalized maximally entangled input their outputs have orthogonal symmetric and antisymmetric supports. Hence their diamond distance is exactly two.

Yet their adjoint difference obeys

\[
\|\Phi_+^\dagger-\Phi_-^\dagger\|_{\infty\to\infty}
\le\frac{4d}{d^2-1},
\]

because it equals 2(dX^T−tr(X)I)/(d^2−1), with ||X^T||=||X|| and |tr X|≤d||X||. Thus an unamplified discrepancy tending to zero does not certify a small error for an entangled exterior. These are standard channels; the displayed bound is a conservative direct norm calculation.

**Remaining gate:** Declare whether reference systems are part of the task. Use a completely bounded/diamond certificate when they are. This is a norm-scope issue, not a new failure of exact OAQEC.

### 95. Matrix-unit residuals can yield a rigorous channel-error upper bound

**Evidence / parent:** R's Choi closure constraints test a matrix-unit basis; parent 35. **Kind:** Bound/proof; certification conversion.

For any linear map Lambda:M_n→M_m, if max_(i,j)||Lambda(E_ij)||_1≤a, then

\[
\|\Lambda\|_\diamond\le n a.
\]

For an ancillary block matrix X=(X_ij), the trace norm of (Lambda⊗id)(X) is at most a sum_(i,j)||X_ij||_1. A rank-one X=u v* has block norms ||u_i||||v_j||; Cauchy–Schwarz bounds their sum by n||u||||v||. Apply this to a singular-value decomposition of X to obtain sum||X_ij||_1≤n||X||_1, uniformly in ancilla size. This proves the bound.

Apply it to the physical closure residual E Phi−Psi E after certifying that Psi is CPTP. If its unnormalized input-first Choi residual has operator norm at most r, each m×m block has trace norm at most m r, giving the conservative bound n m r.

**Remaining gate:** Certify the residual norms and the decoder's physicality. Small basis residuals without their dimension factor are not a diamond-norm certificate.

### 96. A nearly positive Choi matrix can be repaired to an actual channel

**Evidence / parent:** R rejects a floating-point solver status as an exact channel certificate; parent 35. **Kind:** Gate/procedure with a constructive proof.

Let J be an approximate input-first Choi matrix for a map M_n→M_m. First use its Hermitian part J_H. Put Delta=I_n−Tr_out J_H and

\[
J_0=J_H+\Delta\otimes I_m/m.
\]

Then Tr_out J_0=I_n exactly. Obtain a **certified** epsilon≥0 with J_0≥−epsilon I_(nm), and set

\[
J_{\mathrm{phys}}=\frac{J_0+\epsilon I_{nm}}{1+m\epsilon}.
\]

This matrix is PSD and has partial trace I_n, so it is exactly the Choi matrix of a CPTP map. The trace correction has trace norm ||Delta||_1. The final change has trace norm epsilon||I_(nm)−mJ_0||_1/(1+m epsilon). Recompute the closure residual of this repaired channel and apply 95 for an upper certificate.

**Remaining gate:** The lower eigenvalue bound, partial trace, and residual must use rigorous arithmetic or certified intervals. An approximate eigenvalue alone is not the epsilon certificate. This repairs physical feasibility; it does not certify global optimality or infeasibility.

### 97. The dephasing–Hadamard example has an exact approximate-closure defect

**Evidence / parent:** R, “Explicit range-invariance counterexample,” proves nonexistence for 0<lambda<1 but does not quantify its best physical approximation; parent 30. **Kind:** Bound/proof; exact scalar family.

Let E_lambda attenuate qubit X,Y by lambda and preserve Z, and let Phi be Hadamard conjugation. In R's diamond convention without a factor of one-half,

\[
\min_{\Psi\ \mathrm{CPTP}}
\|E_\lambda\Phi-\Psi E_\lambda\|_\diamond=1-\lambda
\qquad(0\le\lambda\le1).
\]

For rho_±=(I±X)/2, the desired outputs E_lambda Phi(rho_±)=(I±Z)/2 have trace distance two. The encoded inputs have distance 2lambda, and any channel Psi contracts that distance. Triangle inequality therefore gives two ≤2lambda+2delta and delta≥1−lambda.

For the matching upper bound choose Psi=Phi. Write E_lambda=((1+lambda)/2)id+((1−lambda)/2)Ad_Z. The residual is (1−lambda)/2 times the difference of two unitary channels, whose diamond distance is at most two. Thus delta≤1−lambda.

**Remaining gate:** This solves only this specified finite channel family. It does not imply a general dimension-free bound in R's normalized commutator defect.

### 98. Physical channel closure errors compose without inverse gains

**Evidence / parent:** R's physical quantum closure is one-step; parent 19's prior resolution is deterministic prediction. **Kind:** Bound/proof; finite typed quantum extension.

Let Phi_j be native CPTP transitions, E_j the corresponding CPTP encodings, and Psi_j the proposed CPTP reduced transitions, all with matching types. If

\[
\|E_j\Phi_j-\Psi_jE_{j-1}\|_\diamond\le\delta_j,
\]

then

\[
\|E_H\Phi_H\cdots\Phi_1
-\Psi_H\cdots\Psi_1E_0\|_\diamond
\le\min\{2,\sum_{j=1}^H\delta_j\}.
\]

Telescope the difference. Its j-th term has the j-th residual preceded and followed by channels. Channels have diamond norm one, so each term costs at most delta_j. Triangle inequality proves the sum; the final objects are channels, giving the bound by two.

The argument automatically includes an entangled reference and does not invert an encoder. An output decoder that is also CPTP cannot increase this error.

**Remaining gate:** Every reduced transition and decoder must actually be physical, and every one-step residual must concern the same declared encoded process. This is not a uniform infinite-time bound for constant positive defects.

## IX. Finite certificates, weighted paths, and infinite acceptance

### 99. Polynomial table complexity does not mean polynomial oracle complexity in arity

**Evidence / parent:** R bounds runtime in the complete explicit input table; parents 9 and 29, with a different deterministic input model. **Kind:** Bound/proof; an information-theoretic query lower bound.

Consider an Interaction with one candidate-to-merge bit and m−1 independent context bits. The output for input bit zero is known to be zero. For input bit one, an oracle returns zero everywhere, or one at a single unknown context c*. Deciding whether the bit can be merged safely requires 2^(m−1) oracle queries in the zero-output worst case.

After fewer queries, an unqueried context could be c*. The all-zero Interaction and that alternative give identical answers so far but require different interfaces. A deterministic always-correct algorithm cannot decide between them.

This does not contradict polynomial runtime in the explicit table: the table itself has exponentially many entries in m. It exposes a concrete dependence hidden if a headline uses arity or number of branches as its input-size measure.

**Remaining gate:** Report representation size, oracle assumptions, arity, and table access separately. A symbolic formula may permit a faster method, but it needs its own proof.

### 100. The initial partition needs a task-retention preflight

**Evidence / parent:** R T55-C7R assumes B_i already encodes the task/Passport distinctions; parent 9. **Kind:** Gate/procedure; not an observed implementation bug.

On X={0,1}, let the action be identity, task T(x)=x, and incorrectly supplied initial partition B={X}. The action refinement has no split and immediately reports a fixed point, yet the task is not decodable. Refinement does not discover an omitted task if it is absent from its initial constraints.

\[
B_i'=B_i\cap\bigcap_{T\ \mathrm{declared}}\ker\widetilde T
\]

before refinement. This preserves all prior distinctions while adding the missing ones. In a finite explicit model it is a direct task-table scan.

**Remaining gate:** Verify the supplied task list itself. The source theorem's assumption is correct; the preflight makes it an executable acceptance condition rather than a trusted annotation.

### 101. Split witnesses alone do not certify a finished coarsest interface

**Evidence / parent:** R recommends recording split reasons and proves a terminal fixed-point theorem; parents 7 and 9. **Kind:** Gate/procedure.

Use X={0,1,2,3}, f(i)=max(i−1,0), and a task distinguishing zero from the other states. The first lawful refinement is {0},{1},{2,3}. Its split has a valid witness, but states 2 and 3 still have different successor blocks. Stopping there is incomplete. Conversely the discrete partition is always closed, but closure alone does not certify minimality in a model where further merges are legal.

A sufficient finite certificate contains: the checked initial task partition; every complete refinement round, replayable as the exact signature-intersection operator; and a final full check that the terminal relation is unchanged by that operator. Replay proves that every admissible family remains below every stage, using R's monotonicity induction. Terminal closure proves that the output is itself admissible. Together they prove coarsestness.

**Remaining gate:** Pin the tables and replay exact comparisons. A reason for one representative split, an arbitrary extra split, or a solver's “done” flag is not this complete certificate.

### 102. Successor sets erase transition multiplicity

**Evidence / parent:** R T55-C7R is explicitly relational, while T29 uses summed probabilities; no path-count preservation theorem is supplied. **Kind:** Counterexample/repair; weighted finite extension.

If x has two same-label edges to a and y has one, the relational successor-class sets of x and y are identical. A receiver asking the number of one-step paths instead gets two and one. Set-level closure cannot certify multiplicity or weighted path totals.

For a finite weighted matrix W over a semiring, use the signature

\[
\sigma_E(x)=\left(\sum_{y\in B}W(x,y)\right)_{B\in X/E}.
\]

Equality of finer-block sums implies equality after coarsening by associativity of addition. Intersect these signature kernels with tasks and contextual constraints; the same finite termination and greatestness induction applies. With incidence matrix R of the partition, the stable signature equation is W R=R W_bar, hence W^k R=R W_bar^k by induction. Over the natural-number semiring it preserves the specified weighted path counts.

**Remaining gate:** Declare weights, their arithmetic, and the receiver's aggregation rule. Probability, reachability, path count, and minimum cost require their own native algebra; they are not interchangeable labels.

### 103. A reachable infinite trace need not determine its concrete acceptance

**Evidence / parent:** R's relational theorem preserves successor classes and finite paths, not unspecified fairness; parent 20. **Kind:** Counterexample/repair and a finite positive extension.

Take two states x,y, each able to move to either state, and merge them into one class. Give x parity priority zero and y priority one, accepting a run if the minimum priority visited infinitely often is even. The one reduced infinite trace has both the accepted lift x,x,... and rejected lift y,y,.... It does not determine the acceptance of the actual concrete run.

For a finite carrier, require the priority to be constant on every interface class as an additional task. Exact successor-class equality then lifts **every** infinite reduced path from any concrete representative: fix an order on the finite states and recursively select the least successor in the required next class. The lifted priority sequence equals the reduced one, so parity acceptance is preserved.

**Remaining gate:** Specify the receiver's path acceptance and existential/universal quantifier. This proof handles finite exact relations and class-constant parity; arbitrary fairness constraints, strategies, and analytic infinite-history limits remain separate.

## X. Capacity, realizable repair, and definedness

### 104. Integral route capacities sharpen the fractional erasure bound

**Evidence / parent:** R's survivor-capacity bound uses nonnegative real capacities; parent 24. **Kind:** Bound/proof; exact arithmetic refinement.

Let m routes have nonnegative **integer** bit capacities and let every r=m−f survivor subset need capacity at least integer H≥0. The exact minimum total capacity of this arithmetic problem is

\[
H+(m-r)\lceil H/r\rceil.
\]

Sort capacities increasingly. The first r sum to at least H, so the r-th is at least ceil(H/r); each of the remaining m−r is no smaller. This proves the lower bound. Distribute H among the first r as floor(H/r) and ceil(H/r), then give every remaining route ceil(H/r). The smallest-r sum is H, proving attainment of the capacity constraints.

For m=4, f=2, H=1, the real-valued bound is two bits while integer capacities require three. This is not yet a coding existence theorem: it solves the arithmetic constraints, not decentralized access or a particular code alphabet.

**Remaining gate:** Distinguish semantic log-alphabet capacity, whole physical bits, and coding feasibility. The source's fractional inequality remains valid.

### 105. The fractional erasure bound is attainable under a centralized symbol contract

**Evidence / parent:** R states its cut bound is necessary, without constructing a code; parent 24. **Kind:** Bound/proof; a scoped realization.

Over a specified prime field F_p with p≥m, a centralized encoder holds r field symbols a0,...,a_(r−1). Form the polynomial q(z)=sum_(j=0)^(r−1) a_j z^j and send q(alpha_e) on route e at m distinct field points. Any r surviving evaluations recover all coefficients: the difference of two degree-less-than-r polynomials with r distinct zeros is zero, or equivalently the Vandermonde determinant is nonzero.

The receiver quotient has p^r possibilities, so H=r log2 p semantic bits. Each route has log2 p capacity and the total m log2 p equals (m/r)H, attaining the fractional lower bound. Any r−1 routes cannot distinguish all p^r messages by cardinality.

This is the standard polynomial erasure code, proved here in the declared finite contract. It assumes centralized access, classical field symbols, known erasure locations, and no corruption of surviving symbols.

**Remaining gate:** Distributed encoders, binary storage rounding, adversarial corruption, and quantum tasks change the problem. This construction is not a general distributed-realizability theorem.

### 106. An optimum repair cost needs a realizable minimizer

**Evidence / parent:** R, “Perturbation reserve and repair cost,” defines an infimum and leaves attainment conditional; parent 6. **Kind:** Gate/procedure with an explicit solved example.

If the control set U is a compact metric space, the defect delta(u) is continuous, and cost c(u) is lower semicontinuous, every nonempty feasible set {u:delta(u)≤epsilon} is compact and the cost attains its minimum there. A minimizing sequence has a convergent subsequence in that set, and lower semicontinuity proves attainment. Without compactness, even delta(u)=0 and c(u)=u on U=(0,1] have infimum zero with no action attaining it.

For the explicitly declared control family in 97, take U=[0,1], delta(lambda)=1−lambda, and the illustrative cost c(lambda)=lambda^2. Then for epsilon≥0,

\[
J(\epsilon)=(1-\epsilon)_+^2,
\]

attained at lambda=(1−epsilon)_+. This is a complete cost curve for that declared model; the quadratic cost is an assumption, not a measured physical efficiency law.

**Remaining gate:** Supply the actual feasible intervention set, cost, and calibrated channel family. An infimum alone is not an executable intervention or evidence for the experimental EF law.

### 107. One real coordinate does not replace a finite-bit budget

**Evidence / parent:** R separates dimension and covering width; C distinguishes real coordinates from finite alphabets; parent 23. **Kind:** Bound/proof; exact distortion curve.

For identity task T(x)=x on [−1,1], at most M≥1 noiseless messages, arbitrary encoding, and arbitrary real decoded outputs, the exact worst-case error is

\[
e_M^*=1/M.
\]

M decoded centers with error epsilon cover the interval by M intervals of length 2epsilon. Their total length is at most 2M epsilon, so epsilon≥1/M. Equal subintervals of length 2/M and their midpoints attain the bound, including the endpoints.

With a fixed b-bit message, M≤2^b and the sharp error is 2^−b. A real-valued exact coordinate has a continuum alphabet, while its finite-bit implementation lies on this distortion curve. The attaining finite encoder is discontinuous at quantization boundaries; this theorem does not promise a continuous encoder.

**Remaining gate:** State the alphabet, noise, continuity, and implementation constraints. A dimension-one result alone gives none of these bit costs.

### 108. Approximate relational closure needs a loss for empty successors

**Evidence / parent:** R T55-C3–C4 exclude empty sets from their Hausdorff statement; parent 18. **Kind:** Bound/proof; an explicit extension convention.

Choose a declared penalty a>0. On nonempty compact successor sets use d_a(A,B)=min(d_H(A,B),a); adjoin the empty set with d_a(empty,A)=a for every nonempty A and d_a(empty,empty)=0. This is a metric: capping a metric preserves triangle inequality, and the new-point inequalities follow directly from all nonempty distances being at most a.

If one current representation fibre contains both an empty successor set and a nonempty one, its minimum radius over all allowed successor-set centers is **exactly a**, rather than a/2. Every center is either empty or nonempty and therefore has distance a to at least one member; all distances are at most a. Thus any uniform error strictly below a forces availability to be exact on every fibre.

**Remaining gate:** Choose the penalty from the receiver's meaning of nonblocking/termination. This completes a one-step error convention; compactness of unions and Lipschitz propagation under this new metric must be checked before extending T55-C4.

# interval endpoint lying inside each task's interval, not only that interval's
# own endpoints. Piecewise affine interpolation then enforces its whole range.

                         for i in range(n) for j in range(n)])
    zs = sorted(set(z for s in sets for z in s))
    idx = {z:i for i,z in enumerate(zs)}
    A=[]; b=[]; dim=len(zs)+1
    for i,s in enumerate(sets):
        for z in zs:

## 3. An explicit conditioned nonlinear repair

### 3.1 System, encoder, and exact flow

Consider the declared native system on R²

\[
\dot x=\alpha x+\beta y^2,\qquad
\dot y=\gamma y,
\]

with known real parameters. The initial performance set is x²+y²≤1, and the receiver asks for x or its trajectory on [0,T]. Let Delta=2gamma−alpha≠0 and k=beta/Delta. The smooth encoder

\[

\]

is a global submersion and closes exactly: u_dot=alpha u. For every h, its reduced update is u↦exp(alpha h)u. The exact response is

\[
x(t)=e^{\alpha t}u_0+k e^{2\gamma t}y_0^2.
\]

Subtracting k times d(y²)/dt verifies the differential identity; substitution gives the flow formula globally. The unit ball need not be invariant: performance here refers to initial states, and the global flow formula handles their whole finite trajectory.

If |Delta|≥s>0, q=|k|≤|beta|/s. On the unit ball the coordinate correction has magnitude at most q, gradient norm at most 2q, and Hessian norm 2q. This gives a concrete regular repair with explicit conditioning; it is not a general existence theorem for arbitrary nonlinear systems or a proof that this encoder is optimal among all encoders.

### 3.2 Exact trajectory error for this repaired encoder

With no code noise and arbitrary trajectory decoders into Lp(0,T), 1≤p≤infinity, the exact best worst-case error **for this encoder** is

\[
\boxed{e_{R,p}^*=\frac q2 D(q)\,\|e^{2\gamma t}\|_p},
\qquad
D(q)=\begin{cases}1,&0\le q\le1,\\2/q-1/q^2,&q>1.\end{cases}
\]

For a fixed u, put s=y². Its feasible values form a compact interval inside [0,1], defined by (u+k s)²+s≤1. The possible response trajectories are a line segment e^(alpha t)u+k e^(2gamma t)s. The segment's midpoint decoder attains half its diameter in every stated norm; triangle inequality gives the matching lower bound.

It remains to find the maximum feasible s-span d. Two states in one fibre obey |x'−x|=q d and |x'−x|≤sqrt(1−s)+sqrt(1−s−d)≤1+sqrt(1−d). For q≤1, span one is attained by (x,y)=(−k,0) and (0,1). For q>1, qd≤1+sqrt(1−d) gives d≤2/q−1/q². Equality is attained at (−sign(k),0) and (sign(k)(1−1/q),sqrt(d)). Thus D(q) is exact.

Its gain from the scalar code to Lp is ||exp(alpha t)||_p. Its error is at most (q/2)||exp(2gamma t)||_p, and the above fibre attains the lower bound. It therefore gives the exact global error without requiring a pointwise midpoint selector.

## 5. A decoder correction: pointwise optimality can destroy sensitivity

At k=1/2 with no noise, the fibrewise midpoint decoder for the **current** task, on realized codes −1≤u≤1, is

## 6. What happens at exact nonlinear resonance

Let alpha=2gamma, gamma≠0, and beta≠0. The nonresonant coefficient beta/(2gamma−alpha) is undefined and cannot be substituted into any preceding smooth-repair bound.

### 6.1 A fixed-step C2 obstruction without a regularity assumption on the update

Suppose a C2 scalar encoder R near the origin has R_x(0,0)≠0 and closes under one nonzero sampled step h>0 with a single-valued reduced update. Restrict r(x)=R(x,0), which is locally invertible, and put U=r^−1 R. Then U(x,0)=x. Axis closure forces the reduced update in this coordinate to be multiplication by exp(alpha h), so

\[
U(e^{\alpha h}(x+\beta h y^2),e^{\gamma h}y)
=e^{\alpha h}U(x,y)
\]

locally. This conclusion does not assume the original reduced update is differentiable; the axis determines it on a neighborhood of realized codes.

At x=0, write U(0,y)=A y+(B/2)y²+o(y²), with U_x(0,0)=1. Comparing linear terms gives A exp(gamma h)=A exp(2gamma h), hence A=0. Comparing quadratic terms then gives beta h exp(alpha h)=0, because exp(2gamma h)=exp(alpha h). This contradicts beta≠0. Thus no such C2 x-regular scalar repair exists even for this sampled contract.

The x-regular condition matters: retaining y alone is a smooth closed coordinate, but it does not satisfy R_x≠0. This obstruction is not a universal prohibition on one-coordinate nonlinear closure.

### 6.2 A C1 repair and its finite-horizon bound

\[
U=x-(\beta/\gamma)y^2\log|y|,

\[

B=\left\lceil\sqrt{2rnd}\right\rceil,\qquad
q\ge\max\left\{nd,\left\lceil\frac{B\,\mathrm{kbar}\,\mathrm{sbar}}{\varepsilon}\right\rceil\right\},
\]

where epsilon is any positive rational tolerance. Enumerate every n by d matrix V whose entries belong to {i/q:-q <= i <= q}. Discard matrices without full column rank, and compute exactly

\[
P_V=V(V^\top V)^{-1}V^\top.
\]

Let Pbest minimize the rational value J(P_V) over this finite enumeration, and put U=J(Pbest). Then

\[
\boxed{\quad
\max\{0,U-B\,\mathrm{kbar}\,\mathrm{sbar}/q\}
\ \le J_{d,\mathrm{proj}}^*\le U,
\qquad U-J_{d,\mathrm{proj}}^*\le\varepsilon.
\quad}
\]

All computed candidates and bounds are rational. No spectral gap, unique minimizer, numerical stationary point, or rank-one moment assumption is needed. The enumeration contains at most (2q+1)^(nd) matrices. This is a terminating global certificate, with a quantified and potentially enormous cost; it is not an efficient general algorithm.

For d=0 the only projector is zero and the value is tr(KS); for d=n the only projector is I and the value is zero. These endpoint cases require no enumeration.

### Proof: existence, coverage, and objective error

The projector constraints define a closed bounded subset of a finite-dimensional Euclidean space: every such P has Frobenius norm sqrt(d). The set is nonempty, so the continuous polynomial J attains its minimum.

Take any P in this set and choose an n by d orthonormal frame W with P=WW^T. Every entry of W is in [-1,1]. Round its entries to the nearest grid values to obtain V. Then

\[
\|V-W\|_F\le\frac{\sqrt{nd}}{2q}<1.
\]

For every unit a in R^d, ||Va|| >= ||Wa||-||(V-W)a|| > 0. Thus V has full column rank and is among the retained candidates. Write P_V for its orthogonal range projector. Equal-rank projectors satisfy

\[
\|P-P_V\|_F^2
=2d-2\operatorname{tr}(PP_V)
=2\|(I-P_V)W\|_F^2
\le2\|W-V\|_F^2
\le\frac{nd}{2q^2}.
\]

The inequality uses (I-P_V)V=0 and the operator norm of I-P_V being at most one. Consequently the enumerated projectors cover the entire admissible set within radius sqrt(nd/2)/q, including singular coordinate charts and tied optimal subspaces.

For Q=I-P, let A_P=K^(1/2) Q S^(1/2). Its Frobenius norm is at most sqrt(r kbar sbar). Also

\[
\|A_P-A_{P'}\|_F
\le\sqrt{\mathrm{kbar}\,\mathrm{sbar}}\,\|P-P'\|_F.
\]

The difference-of-squares inequality therefore gives

\[
|J(P)-J(P')|
\le2\sqrt r\,\mathrm{kbar}\,\mathrm{sbar}\,\|P-P'\|_F.
\]

Apply this to an attained global optimizer and its rounded frame. That grid candidate has cost at most the optimum plus kbar sbar sqrt(2rnd)/q. The minimum grid cost can only be smaller. Its feasibility provides the upper bound; nonnegativity provides the optional lower bound by zero. The definition of B and q completes the proof.

An individual rational feasible projector certifies only an upper bound. The lower certificate also requires verification of the grid minimum and the coverage/error argument. Checking only the winning candidate or only sampled grid points is insufficient. The supplied implementation exhausts the stated demo grid; for other inputs it must run the corresponding complete enumeration, or use another rigorously justified lower certificate.

### A sharper optional Lipschitz constant

When S and K are near scalar matrices, the preceding bound needlessly charges for the constant part of the objective. Choose rational sigma and kappa, and put

\[
\Delta S=S-\sigma I,\quad \Delta K=K-\kappa I,\quad
A=\kappa\Delta S+\sigma\Delta K.
\]

Since Q is a rank-r projector,

\[
J(P)=\kappa\sigma r+\operatorname{tr}(AQ)
+\operatorname{tr}(\Delta K Q\Delta S Q).
\]

The linear term has Lipschitz constant ||A||_F. Expand the last term's difference as

\[
\operatorname{tr}[\Delta K(Q-Q')\Delta S Q]
+\operatorname{tr}[\Delta K Q'\Delta S(Q-Q')].
\]

Frobenius Cauchy–Schwarz bounds each by sqrt(r)||Delta K||op||Delta S||op||Q-Q'||F. Hence a valid alternative is

\[
L_c=\|A\|_F+2\sqrt r\,\|\Delta K\|_{\rm op}\|\Delta S\|_{\rm op}.
\]

Use certified rational upper bounds for these norms and square roots. The covering error becomes L_c sqrt(nd/2)/q. The smaller of the original error coefficient and this certified coefficient may be used to select q. The implementation's square-root upper bounds use integer arithmetic and explicitly check their squared values, rather than trusting decimal rounding.

\[
S=\operatorname{diag}(11/10,9/10),\qquad

the matrices do not commute. With sigma=kappa=1, L_c=11/50 and the covering factor sqrt(nd/2)=1. At tolerance 1/250, q=55 suffices. All 12,321 integer-grid matrices were visited; 12,320 have full rank. The exact winner is

\]

The globally certified interval is

### Certified input uncertainty

Suppose the intended matrices S' and K' are positive semidefinite and satisfy ||S'-S||op <= deltaS and ||K'-K||op <= deltaK. For every rank-d P, expansion of K'QS'Q-KQSQ gives

\[
|J'(P)-J(P)|\le
\eta=r\{\delta K\,\mathrm{sbar}+(\mathrm{kbar}+\delta K)\delta S\}.
\]

For example, |tr(Delta K Q S Q)| <= deltaK sbar r; the other term is bounded in the same way using ||K'||op <= kbar+deltaK. Taking minima gives the same bound for the optimum values. Thus a nominal interval [L,U] implies the intended interval [max(0,L-eta),U+eta]. The nominal Pbest remains a feasible projector, with intended cost at most U+eta and intended suboptimality at most epsilon+2eta. Smaller solver tolerances alone cannot remove fixed physical input uncertainty.

## 3. An exact noncommuting example with two retained and two discarded dimensions

Set

\[
S_0=\operatorname{diag}(9,1),\qquad
K_0=\begin{pmatrix}17/2&-15/2\\-15/2&17/2\end{pmatrix},
\qquad S=\operatorname{diag}(S_0,S_0),\quad K=\operatorname{diag}(K_0,K_0),\quad d=2.
\]

Let m be the minimum of (v^T K_0 v)(v^T S_0 v) over unit v in R^2. The previous rational Sturm certificate establishes m as the two-dimensional projector value and isolates its minimizing slope t in

[1.133177443571420609339, 1.133177443571420609340].

Every unit w=(w1,w2) in R^4 has (w^T K w)(w^T S w) >= m. Indeed, put a_i=||wi||^2 and normalize each nonzero wi. Their unit quadratic forms k_i,s_i satisfy k_i s_i >= m, so Cauchy–Schwarz gives

\[
\left(\sum_i a_i k_i\right)\left(\sum_i a_i s_i\right)
\ge\left(\sum_i a_i\sqrt{k_i s_i}\right)^2\ge m,
\qquad \sum_i a_i=1.
\]

Now choose an orthonormal basis u1,u2 for any rank-two discarded subspace and rotate that basis to diagonalize its compressed S. Its projector cost is

\[
\operatorname{tr}[(U^T K U)(U^T S U)]
=\sum_{j=1}^2(u_j^T K u_j)(u_j^T S u_j)\ge2m.
\]

Choose u1=(v,0), u2=(0,v), where v=(1,t)/sqrt(1+t^2) is a minimizing vector. The cross-block forms vanish, so equality holds. This proves global optimality across every rank-two subspace, including those that mix the blocks. The retained projector is I-diag(vv^T,vv^T).

#!/usr/bin/env python3
"""Rational finite projector certificates; no floating-point optimization.

The general guarantees follow from the accompanying net-coverage proof.
The enumerated demo, rational matrix checks, and Sturm certificate are exact.
"""
from fractions import Fraction as F
from itertools import product
from math import isqrt, ceil
from random import Random
import json


def eye(n):
    return [[F(i == j) for j in range(n)] for i in range(n)]


def transpose(a):
    return [list(x) for x in zip(*a)]


def mul(a, b):
    bt = transpose(b)
    return [[sum((x*y for x, y in zip(row, col)), F(0))
             for col in bt] for row in a]


def add(a, b, scale=F(1)):
    return [[x+scale*y for x, y in zip(ar, br)] for ar, br in zip(a, b)]


def times(a, t):
    return [[t*x for x in row] for row in a]


def trace(a):
    return sum((row[i] for i, row in enumerate(a)), F(0))


def frob2(a):
    return sum((x*x for row in a for x in row), F(0))


def row_bound(a):
    return max(sum(abs(x) for x in row) for row in a)


def inverse(a):
    n = len(a)
    z = [list(row)+ident for row, ident in zip(a, eye(n))]
    for j in range(n):
        pivot = next((i for i in range(j, n) if z[i][j]), None)
        if pivot is None:
            return None
        z[j], z[pivot] = z[pivot], z[j]
        divisor = z[j][j]
        z[j] = [x/divisor for x in z[j]]
        for i in range(n):
            if i != j:
                c = z[i][j]
                z[i] = [x-c*y for x, y in zip(z[i], z[j])]
    return [row[n:] for row in z]


def is_spd(a):
    if a != transpose(a):
        return False
    z = [list(row) for row in a]
    for j in range(len(z)):
        if z[j][j] <= 0:
            return False
        pivot = z[j][j]
        for i in range(j+1, len(z)):
            for k in range(j+1, len(z)):
                z[i][k] -= z[i][j]*z[j][k]/pivot
    return True


def projector(v):
    vt = transpose(v)
    ginv = inverse(mul(vt, v))
    return None if ginv is None else mul(mul(v, ginv), vt)


def cost(s, k, p):
    q = add(eye(len(s)), p, F(-1))
    return trace(mul(mul(mul(k, q), s), q))


def sqrt_upper(x, places=12):
    scale = 10**places
    value = x*scale*scale
    z = isqrt(value.numerator//value.denominator)
    if F(z*z) < value:
        z += 1
    result = F(z, scale)
    assert result*result >= x
    return result


def ceil_sqrt(x):
    z = isqrt(x)
    return z if z*z == x else z+1


def net_error_coefficient(s, k, d, centers=None):
    n = len(s)
    r = n-d
    coefficient = F(ceil_sqrt(2*r*n*d))*row_bound(s)*row_bound(k)
    if centers is not None:
        sigma, kappa = centers
        ds = add(s, times(eye(n), sigma), F(-1))
        dk = add(k, times(eye(n), kappa), F(-1))
        linear = add(times(ds, kappa), times(dk, sigma))
        lip = sqrt_upper(frob2(linear))
        lip += 2*sqrt_upper(F(r))*row_bound(ds)*row_bound(dk)
        coefficient = min(coefficient, lip*sqrt_upper(F(n*d, 2)))
    return coefficient


def global_grid_certificate(s, k, d, epsilon, centers=None):
    n = len(s)
    assert is_spd(s) and is_spd(k) and 0 < d < n and epsilon > 0
    coefficient = net_error_coefficient(s, k, d, centers)
    q = max(n*d, ceil(coefficient/epsilon))
    best = None
    winner = None
    accepted = 0
    total = (2*q+1)**(n*d)
    # Scaling by 1/q leaves this projector unchanged. The corresponding
    # integer-grid matrix represents the rounded rational frame V.
    for entries in product(range(-q, q+1), repeat=n*d):
        v = [[F(x) for x in entries[i*d:(i+1)*d]] for i in range(n)]
        p = projector(v)
        if p is None:
            continue
        accepted += 1
        value = cost(s, k, p)
        if best is None or value < best:
            best = value
            winner = p
    assert winner == transpose(winner)
    assert mul(winner, winner) == winner and trace(winner) == d
    error = coefficient/q
    assert error <= epsilon
    return {'q': q, 'grid_matrices': total, 'full_rank_matrices': accepted,
            'lower': max(F(0), best-error), 'upper': best,
            'error': error, 'projector': winner, 'coefficient': coefficient}


def decimal(x, upper=False, places=21):
    scale = 10**places
    a = x.numerator*scale
    z = -((-a)//x.denominator) if upper else a//x.denominator
    sign = '-' if z < 0 else ''
    z = abs(z)
    return sign+str(z//scale)+'.'+str(z % scale).zfill(places)


def interval_text(lo, hi):
    return [decimal(lo), decimal(hi, True)]


def rational_matrix(a):
    return [[str(x) for x in row] for row in a]


def trim(p):
    p = list(p)
    while len(p) > 1 and p[-1] == 0:
        p.pop()
    return p


def peval(p, x):
    result = F(0)
    for a in reversed(p):
        result = result*x+a
    return result


def sturm(p):
    seq = [p, [i*p[i] for i in range(1, len(p))]]
    while True:
        rem = list(seq[-2])
        divisor = seq[-1]
        while rem != [F(0)] and len(rem) >= len(divisor):
            j = len(rem)-len(divisor)
            c = rem[-1]/divisor[-1]
            for i, a in enumerate(divisor):
                rem[j+i] -= c*a
            rem = trim(rem)
        if rem == [F(0)]:
            return seq
        seq.append([-x for x in rem])


def variations(seq, x):
    vals = [peval(p, x) for p in seq]
    signs = [1 if v > 0 else -1 for v in vals if v]
    return sum(a != b for a, b in zip(signs, signs[1:]))


def root_count(seq, a, b):
    return variations(seq, a)-variations(seq, b)


def refine(seq, a, b):
    assert root_count(seq, a, b) == 1
    while b-a > F(1, 10**36):
        mid = (a+b)/2
        assert peval(seq[0], mid)
        if root_count(seq, a, mid):
            b = mid
        else:
            a = mid
    return a, b


def imul(a, b):
    vals = [x*y for x in a for y in b]
    return min(vals), max(vals)


def ipoly(p, x):
    value = (F(0), F(0))
    for a in reversed(p):
        lo, hi = imul(value, x)
        value = lo+a, hi+a
    return value


def strict_cost_interval(t):
    numerator = ipoly([F(153, 2), F(-135), F(85), F(-15), F(17, 2)], t)
    denominator = ipoly([F(1), F(0), F(2), F(0), F(1)], t)
    assert denominator[0] > 0
    return imul(numerator, (1/denominator[1], 1/denominator[0]))

                a = [[F(rng.randint(-2, 2)) for _ in range(n)] for _ in range(n)]
                b = [[F(rng.randint(-2, 2)) for _ in range(n)] for _ in range(n)]

# BM nonlinear repair addendum — exact reduction, conditioning, and model uncertainty

Date: 15 October 2026. This is an extension of the Research Edition, addressing review references 12, 19, and 21. It preserves the frozen Foundation and existing canonical identifiers.

The construction corrects a present-time code by following the full system forward and pulling the retained state backward with a chosen reduced model. When the omitted influence fades faster than this backward operation amplifies error, the corrected code converges. It then evolves exactly under the reduced model. The proof quantifies approximation, regularity, sensitivity, uncertainty, and finite evaluation. It extends the earlier quadratic example to a class of nonlinear systems, including feedback in both directions in its continuous version.

This is a sufficient theorem in a specified native class. It does not determine the globally optimal encoder or repair cost for arbitrary nonlinear dynamics. The construction is an asymptotic-phase construction; no historical novelty or independent verification is asserted.

## 1. Declared system and uniform hypotheses

Use Euclidean norms throughout. Let x be in R^d and y in the closed ball of radius rho>0 in R^m. Consider

\[
\dot x=f(x)+b(x,y),\qquad \dot y=g(x,y).
\tag{N1}
\]

Assume the vector fields are C1 on an open neighborhood of this domain. For every relevant x and y, assume

\[
g(x,0)=0,\qquad
\langle y,g(x,y)\rangle\le-\beta\|y\|^2,
\qquad \|b(x,y)\|\le B_0\|y\|^q,
\tag{N2}
\]

where beta>0, B0>=0, and q>=1 is an integer. In particular b(x,0)=0. Suppose f is defined on all of R^d and

\[
-aI\preceq\operatorname{sym}Df(x)\preceq\ell I,
\qquad a\ge0,\quad\ell\ge-a.
\tag{N3}
\]

Let Psi_t be the reference flow generated by x_dot=f(x), and Phi_t the native flow (N1). The reference exists for all positive and negative times: (N3), applied to f and -f, bounds radial growth by a linear Gronwall estimate with the finite constant ||f(0)||. Its variational equation gives

\[
\operatorname{Lip}\Psi_t\le e^{\ell t},\qquad
\operatorname{Lip}\Psi_{-t}\le e^{at},\qquad t\ge0.
\tag{N4}
\]

The native flow exists for every t>=0 on the stated domain. Indeed (N2) gives ||y_t||<=e^(-beta t)||y_0|| and preserves the ball. The x equation has the same radial growth bound as f with the additional uniformly bounded forcing B0 rho^q. Neither component can escape to infinity in finite time, and the fields extend to a neighborhood of the closed y-ball. Local existence therefore continues forward.

The decisive value gap is

\[
\delta=q\beta-a>0.
\tag{N5}
\]

These are uniform native hypotheses, not quantities inferred from a successful sample fit. In particular, a perturbation that fails to vanish to the stated order at y=0 may violate this contract even when its unweighted amplitude is small.

## 2. Exact continuous repair for the coupled system

Write x_t=pi_x Phi_t(x,y). Define the finite and limiting encoders

\[
R_T(x,y)=\Psi_{-T}(x_T),\qquad
R(x,y)=\lim_{T\to\infty}R_T(x,y).
\tag{N6}
\]

**Theorem.** Under (N1)–(N5), this limit exists uniformly on the whole stated domain, is continuous, and satisfies

\[
R(x,0)=x,\qquad
\boxed{R\Phi_t=\Psi_t R\quad(t\ge0)}.
\tag{N7}
\]

Its correction and truncation obey

\[
\boxed{\quad
\|R(x,y)-x\|\le\frac{B_0}{\delta}\|y\|^q,\qquad
\|R-R_T\|(x,y)\le\frac{B_0}{\delta}\|y\|^q e^{-\delta T}.
\quad}
\tag{N8}
\]

This includes x-dependent forcing and x-dependent driver dynamics; no independence between the retained and omitted components is assumed in this continuous theorem.

### Complete proof

The reference flow transports its vector field: D Psi_-t(z) f(z)=f(Psi_-t(z)). Thus differentiating Psi_-t(x_t) cancels the reference part of the native derivative and gives

\[
\frac{d}{dt}R_t(x,y)
=D\Psi_{-t}(x_t)b(x_t,y_t).
\]

Its norm is at most B0 ||y||^q exp[-(q beta-a)t]. Integrating from T to S proves the uniform Cauchy estimate; integrating from zero or from T to infinity proves (N8). Each R_T is continuous, so the uniform limit is continuous. At y=0 native evolution is reference evolution, giving R_T(x,0)=x and hence the normalization.

For s>=0, the native semigroup and reference group identities give

\[
R_T(\Phi_s z)=\Psi_{-T}(x_{T+s})
=\Psi_s R_{T+s}(z).
\]

Take T to infinity and use continuity of Psi_s to obtain (N7). This proves one common exact update for every time, hence for every chosen sampling step, rather than separate independently fitted updates.

The repair is unique within its uniform normalization class. If another map U satisfies the same semiconjugacy and ||U(x,y)-x||<=C||y||^q with a finite uniform C, pull both codes backward along the reference flow:

\[
\|U(z)-R(z)\|
\le e^{at}\|U(\Phi_tz)-R(\Phi_tz)\|
\le(C+B_0/\delta)\|y\|^q e^{-\delta t}\longrightarrow0.
\]

Uniqueness in this class is not a claim of optimality across other reduced dynamics, code dimensions, or receiver tasks.

### Forecast and code-noise bounds

For the retained-state task x_t, use decoder D_t(z)=Psi_t(z). Apply (N8) at the actual current state and use (N7):

\[
\boxed{\quad
\|x_t-\Psi_tR(x_0,y_0)\|
\le\frac{B_0}{\delta}\|y_0\|^q e^{-q\beta t}.
\quad}
\tag{N9}
\]

The error decays at the omitted forcing rate. This sharper statement follows by applying the value bound after evolution; propagating only the initial correction with a forward Lipschitz constant would lose it.

If the observed code has error at most nu, the pointwise forecast error is at most

\[
\frac{B_0}{\delta}\|y_0\|^q e^{-q\beta t}+\nu e^{\ell t}.
\tag{N10}
\]

For 1<=p<=infinity, its Lp trajectory error is bounded by the Lp norm of this scalar envelope. When ell<=0 it supplies a uniform infinite-time upper bound B0 rho^q/delta+nu. No minimax equality is claimed for these general nonlinear systems.

## 3. A quantitative C1 repair theorem

Additional assumptions now restrict (N1) to the triangular class

\[
\dot x=f(x)+b(y),\qquad \dot y=g(y).
\tag{N11}
\]

Let f be C2 with ||D2 f||<=M uniformly, and let g be C1 with sym Dg(y)<=-beta I throughout the y-ball. Suppose

\[
\|Db(y)\|\le B_1\|y\|^{q-1},\qquad
\omega=q\beta-2a-\ell>0.
\tag{N12}
\]

The derivative norms are operator norms; D2 f uses the induced bilinear norm. Define

\[
c=\frac{B_1\rho^{q-1}}{q\beta+\ell},\qquad
\eta_x=\frac{MB_0\rho^q}{\omega(\omega+a)},\qquad
\eta_y=c\eta_x+\frac{B_1\rho^{q-1}}{\delta}.
\tag{N13}
\]

The denominators are positive: ell>=-a and omega>0 imply q beta+ell>0 and delta>0.

**Theorem.** The same limiting R is C1 on R^d times the open y-ball, with uniform bounds

\[
\boxed{\|D_xR-I\|\le\eta_x,\qquad \|D_yR\|\le\eta_y.}
\tag{N14}
\]

If eta_x<1, each map x -> R(x,y) is a global C1 diffeomorphism of R^d. Its inverse has Lipschitz constant at most 1/(1-eta_x). Consequently (x,y)->(R(x,y),y) is a C1 coordinate change on the product domain, R is a submersion, and

\[
\operatorname{Lip}R\le\sqrt{(1+\eta_x)^2+\eta_y^2}.
\tag{N15}
\]

This conditions the repair itself as well as its decoder. The C1 assertion is for the triangular subclass; it is not automatically transferred to the fully coupled continuous theorem.

### Complete derivative and invertibility proof

Driver contraction gives ||D_y phi_t||<=e^(-beta t). Variations of the x equation, using the upper one-sided bound ell, give

\[
\|D_{x_0}x_t\|\le e^{\ell t},\qquad
\|D_{y_0}x_t\|\le c e^{\ell t}.
\tag{N16}
\]

For the latter, integrate the forcing derivative B1 rho^(q-1)e^(-q beta t) against the evolution bound e^(ell(t-s)). The resulting factor is at most B1 rho^(q-1)/(q beta+ell).

The second variation of the backward reference flow satisfies

\[
\|D^2\Psi_{-t}\|
\le M e^{at}\frac{e^{at}-1}{a}\quad(a>0),
\]

with continuous limit Mt when a=0. This follows by integrating the quadratic forcing D2(-f)[D Psi_-s,D Psi_-s] in the second-variation equation, using (N4).

Differentiate the convergent integral for R-x. In the x direction, only the evaluation point of D Psi_-t(x_t) varies. The derivative integrand is bounded, for a>0, by

\[
\frac{MB_0\rho^q}{a}
\{e^{-\omega t}-e^{-(\omega+a)t}\}.
\]

Its integral equals MB0 rho^q/[omega(omega+a)]. For a=0, integrate MB0 rho^q t e^(-omega t) to obtain the same formula. In the y direction, evaluation-point variation costs at most c times this integral. The additional derivative of b(phi_t(y)) has integral at most B1 rho^(q-1)/delta. These bounds prove uniform convergence of the derivative integrals; together with uniform convergence of R_T they justify C1 differentiation and (N14).

For fixed y write R(x,y)=x+h_y(x). The bound on D_xR-I makes h_y globally eta_x-Lipschitz. For any target z, x=z-h_y(x) is a contraction on the complete space R^d when eta_x<1. It has a unique solution. The derivative I+D h_y is invertible with inverse norm at most 1/(1-eta_x); the inverse function theorem gives C1 dependence on z and y. This proves the global triangular coordinate change. The operator bound on the two derivative blocks gives (N15).

**Affine reference improvement.** If f is affine, M=0 and the second-variation term vanishes. The stronger omega condition is then unnecessary: delta>0 alone gives C1 repair, D_xR=I, and ||D_yR||<=B1 rho^(q-1)/delta. The earlier quadratic repair is recovered on its convergent side. Failure of delta>0 does not prove repair impossible; a different construction may still work.

## 4. Model uncertainty, including new feedback

Let R1 be the C1 repair for a triangular baseline (N11), with eta_x and eta_y as above. Define

\[
G_y=\frac{B_1}{\delta}
+\frac{B_1\eta_x}{q\beta+\ell}.
\]

Repeating the derivative proof with ||y|| in place of rho gives the pointwise estimate ||D_yR1(x,y)||<=G_y||y||^(q-1); in particular eta_y=G_y rho^(q-1). For the affine improvement use eta_x=0 in this formula, without any omega denominator.

Now change the native system to

\[
\dot x=f(x)+b(y)+\Delta b(x,y),\qquad
\dot y=g(y)+\Delta g(x,y),
\]

where the perturbations are C1 and uniformly satisfy

\[
\|\Delta b(x,y)\|\le\epsilon_b\|y\|^q,\qquad
\|\Delta g(x,y)\|\le\epsilon_g\|y\|,
\quad\beta'=\beta-\epsilon_g>0,
\quad\delta'=q\beta'-a>0.
\tag{N17}
\]

This permits feedback in both directions. The continuous theorem constructs R2 for the changed system. Its change from the baseline code obeys

\[
\boxed{\quad
\|R_2(x,y)-R_1(x,y)\|
\le\frac{(1+\eta_x)\epsilon_b+G_y\epsilon_g}{\delta'}\|y\|^q.
\quad}
\tag{N18}
\]

To prove this, let z_t follow the changed system and put w_t=R1(z_t). Differentiating baseline semiconjugacy at zero time gives D R1 v1=f(R1). Therefore

\[
\dot w_t=f(w_t)+D_xR_1\Delta b+D_yR_1\Delta g.
\]

The added forcing has norm at most [(1+eta_x)epsilon_b+G_y epsilon_g]||y||^q e^(-q beta' t). Pull w_t backward by Psi_-t and integrate, as in section 2, to obtain (N18). This pullback limit is R2: the difference w_t-x_t is at most B0||y_t||^q/delta, whose backward magnification tends to zero since delta'>0.

The estimate is sharp in an affine subclass. Take scalar f(x)=-a x, g(y)=-beta y, b(y)=kappa y^q with kappa>0. Increase forcing by epsilon_b y^q and reduce decay by epsilon_g y. Then

\[
R_1=x+\frac{\kappa y^q}{q\beta-a},\qquad
R_2=x+\frac{(\kappa+\epsilon_b)y^q}{q(\beta-\epsilon_g)-a}.
\]

Here eta_x=0, G_y=q kappa/(q beta-a), and the absolute coefficient difference equals the right-hand coefficient in (N18). Thus the uncertainty constant is not merely a qualitative continuity assertion. No C1 or inverse bound for the newly coupled R2 is asserted without additional derivative hypotheses.

## 5. Finite evaluation, closure residual, and precision window

The exact code is a limit; a finite evaluated code has a quantified residual. From the identity used in section 2,

\[
\boxed{\quad
\|R_T\Phi_h(z)-\Psi_hR_T(z)\|
\le e^{\ell h}\frac{B_0}{\delta}\|y\|^q
e^{-\delta T}(1-e^{-\delta h}).
\quad}
\tag{N19}
\]

Indeed R_T Phi_h=Psi_h R_(T+h); integrate the encoder derivative only from T to T+h and apply the forward Lipschitz bound. Equality is attained in the scalar affine power-forcing model with positive coupling, so this finite-window residual bound is sharp in that subclass.

If an evaluated code differs from R_T by at most epsilon_eval at both required native inputs, its sampled closure residual has the additional budget (1+e^(ell h))epsilon_eval. Error in the reduced update itself needs its own budget.

Suppose the endpoint x_T is computed within epsilon_x and the backward-flow evaluation at that computed endpoint has error at most epsilon_back. Then

\[
\|\widehat R_T-R\|
\le C e^{-\delta T}+e^{aT}\epsilon_x+\epsilon_{\rm back},
\qquad C=B_0\|y\|^q/\delta.
\tag{N20}
\]

This separates analytic truncation from numerical flow error. Taking T ever larger reduces one and can amplify the other. Under a declared fixed epsilon_x>0 and a>0, the minimizing nonnegative window for this envelope is

\[
T_* =\max\left\{0,\frac1{q\beta}
\log\frac{B_0\|y\|^q}{a\epsilon_x}\right\}.
\tag{N21}
\]

For y=0 or B0=0 choose T*=0. When a=0 the envelope decreases toward epsilon_x+epsilon_back as T tends to infinity. If the flow error budget depends on T, that dependence must instead be included before optimizing. The formula is an optimization of the stated evaluation envelope, not an optimal physical sensor or repair-cost theorem.

An executable numerical certificate requires certified epsilon_x and epsilon_back. The floating-point ODE checks below do not supply rigorous interval enclosures for them.

## 7. Resonance: an obstruction for every forcing order

For integer q>=1, beta>0 and kappa nonzero, consider the scalar retained coordinate in

\[
\dot x=-q\beta x+\kappa y^q,\qquad \dot y=-\beta y.
\tag{N22}
\]

**Obstruction.** There is no local C^q scalar encoder R with R_x(0,0) nonzero that closes under even one fixed step h>0 with any single-valued update F. No regularity of F is assumed.

**Proof.** Write r(x)=R(x,0). Its derivative at zero is nonzero, so its local inverse exists and is C^q. Normalize U=r^-1 R, so U(x,0)=x. On the axis, closure forces the normalized update to be multiplication by exp(-q beta h), and hence locally

\[
U(\Phi_h(x,y))=e^{-q\beta h}U(x,y).
\]

Put lambda=exp(-beta h), so 0<lambda<1. The native step is

\[
\Phi_h(x,y)=(\lambda^q(x+\kappa h y^q),\lambda y).
\]

For q>=2, Taylor expansion at (0,0), U_x(0,0)=1, and x=0 give

\[
\kappa h\lambda^q y^q
+\sum_{j=1}^q c_j\lambda^j y^j+o(|y|^q)
=\lambda^q\sum_{j=1}^q c_j y^j+o(|y|^q).
\]

Mixed terms involving x have degree at least q+1 after substitution; pure x^2 terms have degree at least 2q. For every j<q, lambda^j differs from lambda^q, forcing c_j=0. At degree q the c_q terms cancel and force kappa h lambda^q=0, a contradiction. For q=1, the first-order Taylor expansion directly gives the same contradiction, including its x-derivative term. This proves the obstruction for all q.

The lower-regularity repair

\[
U=x+\frac\kappa\beta y^q\log|y|,
\]

extended by U=x at y=0, still closes exactly. It is C^(q-1) but not C^q at zero: the q-th derivative of y^q log|y| contains q! log|y| and diverges, while all derivatives of lower order extend continuously. For q=1 it is continuous and not locally Lipschitz. This strengthens the earlier example from a nonsmooth chosen formula to a nonexistence result for every C^q scalar encoder preserving the x direction. It does not rule out retaining y alone or using a larger code, and it assumes beta>0.

        'arithmetic': 'fractions.Fraction',
    }

    # At sampled resonance: (x,y) -> (lambda^q*(x+y^q), lambda*y).
    # Lower jet coefficients are forced to zero; the q-th forcing term is
    # nonzero while its decoder coefficient cancels. Check the rational map
    # and its logarithmic repair exactly on dyadic y.
    resonant_cases = 0
    lam = F(1, 2)
    for order in range(1, 13):
        eigenvalue = lam**order
        assert all(lam**j != eigenvalue for j in range(1, order))
        assert eigenvalue != 0
        for j in range(9):
            for sign in (-1, 1):
                y = sign*lam**j
                x = F(j-order, 7)
                # b=log(2), kappa=h=1: log|y|/b=-j exactly.
                r = x-j*y**order
                new_x = eigenvalue*(x+y**order)
                new_y = lam*y
                new_r = new_x-(j+1)*new_y**order
                assert new_r == eigenvalue*r
                resonant_cases += 1
    out['resonance_exact_checks'] = {
        'orders_checked': list(range(1, 13)),
        'dyadic_logarithmic_repair_cases': resonant_cases,
        'arithmetic': 'fractions.Fraction; the dyadic logarithm cancels exactly',
        'general_obstruction': 'The written Taylor-jet proof applies to every integer q>=1',
    }

    # Non-polynomial examples. The second has feedback in both directions;
    # only the continuous theorem is asserted for that example.
    starts = [(x, y) for x in (-20, -3, -1, 0, 1, 3, 20)
              for y in (-1, -.6, -.2, 0, .2, .6, 1)]
    starts += [(rng.uniform(-12, 12), rng.uniform(-1, 1)) for _ in range(15)]
    horizon, h, nu = 5., .37, .001
    roundoff_allowance = 2e-9  # Not a certified solver error budget.
    times = np.array([0., .25, .5, 1., 2., 4.])
    numerical = []
    for coupled in (False, True):
        max_dx, max_dy = 0., 0.
        max_repair_ratio, max_forecast_excess, max_closure_excess = 0., 0., 0.
        for x, y in starts:
            if coupled:
                r = phase(x, y, horizon, coupled)
            else:
                r, dx, dy = phase(x, y, horizon, coupled, True)
                max_dx = max(max_dx, abs(dx-1))
                max_dy = max(max_dy, abs(dy))
                assert abs(dx-1) <= float(eta_x)+roundoff_allowance
                assert abs(dy) <= float(eta_y)+roundoff_allowance
            value_bound = float(b0/gap)*y*y
            if value_bound:
                max_repair_ratio = max(max_repair_ratio, abs(r-x)/value_bound)
            assert abs(r-x) <= value_bound+roundoff_allowance
            finite_tail = value_bound*exp(-float(gap)*horizon)
            native_h = native(x, y, h, coupled)
            encoded_next = phase(*native_h, horizon, coupled)
            reduced_next = reference(r, h)[0]
            defect_bound = exp(float(ell)*h)*finite_tail*(1-exp(-float(gap)*h))
            excess = abs(encoded_next-reduced_next)-defect_bound
            max_closure_excess = max(max_closure_excess, excess)
            assert excess <= roundoff_allowance
            actual = native(x, y, times[-1], coupled, times=times)[0]
            for noise in (-nu, 0., nu):
                predicted = integrate(lambda t, z: [-z[0]+sin(z[0])/4],
                                      [r+noise], times[-1], times=times)[0]
                bounds = value_bound*np.exp(-float(q*beta)*times)
                bounds += (abs(noise)+finite_tail)*np.exp(float(ell)*times)
                excess = float(np.max(np.abs(actual-predicted)-bounds))
                max_forecast_excess = max(max_forecast_excess, excess)
                assert excess <= roundoff_allowance
        numerical.append({
            'model': 'fully coupled continuous repair' if coupled else 'triangular C1 repair',
            'initial_states': len(starts), 'phase_horizon': horizon,
            'forecast_times': times.tolist(), 'code_noise_values': [-nu, 0., nu],
            'max_observed_value_bound_ratio': max_repair_ratio,
            'max_observed_DxR_minus_I': None if coupled else max_dx,
            'max_observed_DyR': None if coupled else max_dy,
            'max_forecast_bound_excess': max_forecast_excess,
            'max_finite_closure_bound_excess': max_closure_excess,
            'solver': 'SciPy DOP853, rtol=3e-13, atol=2e-14',
            'status': 'Numerical consistency only; solver errors are not rigorously enclosed',
        })
    out['nonpolynomial_ODE_checks'] = numerical

    eps_b, eps_g = F(1, 100), F(1, 10)
    perturbed_gap = q*(beta-eps_g)-a
    uncertainty_coefficient = ((1+eta_x)*eps_b+eta_y*eps_g)/perturbed_gap
    maximum_perturbation_excess = 0.
    for x, y in starts[::2]:
        base_r = phase(x, y, horizon)
        changed_r = phase(x, y, horizon, 'perturbed')
        base_tail = float(b0/gap)*y*y*exp(-float(gap)*horizon)
        changed_tail = float((b0+eps_b)/perturbed_gap)*y*y
        changed_tail *= exp(-float(perturbed_gap)*horizon)
        bound = float(uncertainty_coefficient)*y*y+base_tail+changed_tail
        excess = abs(base_r-changed_r)-bound
        maximum_perturbation_excess = max(maximum_perturbation_excess, excess)
        assert excess <= roundoff_allowance
    out['nonlinear_feedback_uncertainty'] = {
        'initial_states': len(starts[::2]), 'epsilon_b': str(eps_b),
        'epsilon_g': str(eps_g), 'remaining_value_gap': str(perturbed_gap),
        'exact_uncertainty_coefficient': str(uncertainty_coefficient),
        'max_observed_bound_excess': maximum_perturbation_excess,
        'status': 'Numerical consistency; the general bound has a written proof',
    }

    # Check the analytic evaluation-window optimizer independently against a
    # dense set of alternative horizons, under a fixed error-envelope model.
    flow_error, back_error = 1e-10, 1e-12
    c0 = float(b0/gap)
    optimum = max(0., log(float(b0)/(float(a)*flow_error))/float(q*beta))
    def envelope(t):
        return c0*exp(-float(gap)*t)+flow_error*exp(float(a)*t)+back_error
    best = envelope(optimum)
    assert all(envelope(t) >= best-1e-20 for t in np.linspace(0, 12, 2401))
    derivative = -float(gap)*c0*exp(-float(gap)*optimum)
    derivative += float(a)*flow_error*exp(float(a)*optimum)
    assert abs(derivative) < 1e-20
    out['finite_precision_window'] = {
        'assumed_forward_state_error': flow_error,
        'assumed_backflow_evaluation_error': back_error,
        'best_horizon_display': optimum, 'minimum_envelope_display': best,
        'comparison_horizons': 2401,
        'scope': 'Optimization of a declared error envelope; the ODE solver is not certified to meet these error assumptions',
    }
    out['scope'] = {
        'general_guarantees': 'Written proofs under stated decay, curvature, and regularity assumptions',
        'exact_computation': 'Rational constants, affine identities, and sampled resonant dyadic identities',
        'numerical_computation': 'Non-polynomial ODE examples and evaluation-window display',
        'not_claimed': 'Independent review, formal verification, optimal encoder cost, or physical-model validation',
    }
    print(json.dumps(out, indent=2))
