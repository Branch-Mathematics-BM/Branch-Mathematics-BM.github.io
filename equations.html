1. Purpose of the Equation Registry

Equations in this encyclopedia are not included merely to make the framework appear mathematical.

Each important relation should identify:

mathematical objects · domain and codomain · assumptions · interpretation · derivation or proof status · limitations · related definitions · related theorems · numerical behavior when applicable

Some expressions below are exact mathematical equations. Others are explicitly identified as structural schemas, definitions, conditions, diagnostics, or worked examples.

2. Structural BM Schema

Classification: structural schema

\[ \boxed{ \text{lawful Branches} \longrightarrow \text{lawful Interactions} \longrightarrow \text{combined computation} \longrightarrow \text{Response} \longrightarrow \begin{cases} \text{terminal mathematical result},\\[4pt] \text{Root if downstream admissible}. \end{cases} } \]

This summarizes the broad structural direction of Branch Mathematics.

It is not a numerical equation and does not imply that every BM construction is a linear sequence.

3. Interaction Equation

Classification: formal typed structure

For participating Branches \(B_1,\ldots,B_n\),

\[ \boxed{ I: D_I \subseteq X_{B_1}\times\cdots\times X_{B_n} \longrightarrow Z_I. } \]

\(D_I\) is the actual admissible Interaction domain.

Formal membership in the ambient product does not by itself imply membership in \(D_I\).

4. Leaf Extraction Equation

Classification: canonical BM structural equation

If

\[ z = I(x_1,\ldots,x_n) \in Z_I \]

and

\[ \ell_j: Z_I \longrightarrow \mathcal L_j, \]

then the individual Leaf value is

\[ \boxed{ \lambda_j = \ell_j(z) = \ell_j \left( I(x_1,\ldots,x_n) \right) \in \mathcal L_j. } \]

The notation deliberately distinguishes:

  • \(\mathcal L_j\): Leaf codomain;
  • \(\ell_j\): Leaf-extraction map;
  • \(\lambda_j\): extracted Leaf value.

5. Tree Response Map

Classification: formal BM structural equation

\[ \boxed{ \mathcal R_T: D_T \longrightarrow Y_T. } \]

For admissible Tree input \(x\in D_T\),

\[ r = \mathcal R_T(x) \in Y_T. \]

The Response may be a value, state, function, law, relation, operator, classification, structured object, or another typed mathematical output.

6. Passport Observation Family

Classification: formal definition

\[ b_c: X \longrightarrow Y_c, \qquad c\in\mathcal C. \]

Each \(b_c\) records one observation, invariant, test, distinction, law component, or Passport requirement.

7. Combined Passport Map

Classification: formal construction

\[ B_P: X \longrightarrow \prod_{c\in\mathcal C}Y_c \] \[ \boxed{ B_P(x) = \left( b_c(x) \right)_{c\in\mathcal C}. } \]

The product map collects the active Passport observations when the required product exists in the relevant mathematical sector.

8. Passport Equivalence

Classification: exact equivalence relation in deterministic equality-based semantics

\[ \boxed{ x\sim_Px' \Longleftrightarrow b_c(x)=b_c(x') \quad \forall c\in\mathcal C. } \]

Equivalently,

\[ x\sim_Px' \Longleftrightarrow B_P(x)=B_P(x'). \]

9. Passport Completion Fibre

Classification: exact set construction

\[ \boxed{ \mathfrak C_P(\ell) = \bigcap_{c\in\mathcal C} b_c^{-1}(\ell_c). } \]

The completion fibre contains every underlying state compatible with all active Passport observations.

10. Exact Task Sufficiency

Classification: exact deterministic factorization criterion

Let

\[ T: X \longrightarrow W. \]

Passport \(P\) is sufficient for \(T\) when there exists

\[ \widetilde T: B_P(X) \longrightarrow W \]

such that

\[ \boxed{ T = \widetilde T\circ B_P. } \]

The factor map is required on the realized image \(B_P(X)\).

11. Fibre Criterion for Sufficiency

Classification: equivalent exact deterministic criterion

\[ \boxed{ B_P(x)=B_P(x') \Longrightarrow T(x)=T(x'). } \]

Equivalently,

\[ \boxed{ x\sim_Px' \Longrightarrow T(x)=T(x'). } \]

A distinction may be discarded only when the declared Task does not require it.

12. Equivalence Inclusion Criterion

Classification: exact deterministic relational criterion

Define Task equivalence by

\[ x\sim_Tx' \Longleftrightarrow T(x)=T(x'). \]

Then exact sufficiency is

\[ \boxed{ \sim_P \subseteq \sim_T. } \]

13. Structured Quotient Compatibility

Classification: operation-compatibility condition

For an \(n\)-ary algebraic Operation

\[ \sigma: X^n \longrightarrow X, \]

a Passport quotient preserves \(\sigma\) only when

\[ \boxed{ x_i\sim_Py_i \quad \forall i \Longrightarrow \sigma(x_1,\ldots,x_n) \sim_P \sigma(y_1,\ldots,y_n). } \]

In the finitary algebraic setting, this is the congruence requirement.

14. Quotient Operation

Classification: induced Operation conditional on congruence

\[ \boxed{ \overline{\sigma} \left( [x_1]_P,\ldots,[x_n]_P \right) = \left[ \sigma(x_1,\ldots,x_n) \right]_P. } \]

This expression is well-defined only when its equivalence class does not depend on the chosen representatives.

15. Exact Interface Compatibility

Classification: exact coherence equation

For

\[ F: X_1\to X_2, \qquad P_1: X_1\to Q_1, \] \[ P_2: X_2\to Q_2, \qquad G: Q_1\to Q_2, \]

exact Interface compatibility is

\[ \boxed{ P_2\circ F = G\circ P_1. } \]

16. Approximate Interface Defect

Classification: quantitative diagnostic

Given a mathematically justified metric or discrepancy \(d\), define

\[ \boxed{ \Delta_F(x) = d \left( P_2(F(x)), G(P_1(x)) \right). } \]

Exact coherence corresponds to

\[ \Delta_F(x)=0. \]

Approximate compatibility may require

\[ \Delta_F(x) \le \varepsilon. \]

Such a defect is meaningful only after a valid comparison structure has been supplied.

17. GURF Observation Map

Classification: formal response-system observation

\[ r: X \longrightarrow Y, \qquad y=r(x). \]

The map may represent measurement, coarse-graining, compression, projection, filtering, feature extraction, or another retained representation.

18. GURF Completion Fibre

Classification: exact compatible-state construction

\[ \boxed{ \mathfrak C_A(\ell) = \bigcap_{\alpha\in A} r_\alpha^{-1}(\ell_\alpha). } \]

This is the set of underlying states compatible with the complete active observation family.

19. GURF Future Continuation Criterion

Classification: exact deterministic dynamic sufficiency condition

Let

\[ \Phi_t: X \longrightarrow X \]

be the relevant evolution.

Observation \(r\) remains sufficient for future Task \(T\) when there exists

\[ \widetilde T_t: r(X) \longrightarrow W \]

satisfying

\[ \boxed{ T\circ\Phi_t = \widetilde T_t\circ r. } \]

20. Continuation Failure

Classification: deterministic obstruction condition

Continuation fails when there exist \(x,x'\in X\) such that

\[ r(x)=r(x') \]

but

\[ \boxed{ T(\Phi_t(x)) \neq T(\Phi_t(x')). } \]

The present representation has merged states whose future Task-relevant behavior differs.

21. Task Diameter of a Fibre

Classification: quantitative GURF diagnostic

Let \(y\in r(X)\), and suppose the Task space \(W\) has metric \(d_W\).

\[ \boxed{ D_{r,T}(y) = \sup_{ x,x'\in r^{-1}(y) } d_W \left( T(x), T(x') \right). } \]

Exact sufficiency requires

\[ D_{r,T}(y)=0 \]

for every realized observation value.

Approximate sufficiency may require

\[ D_{r,T}(y) \le \varepsilon. \]

22. GURF Repair

Classification: refinement condition

Add an observation

\[ q: X \longrightarrow Z. \]

The refined representation is

\[ (r,q): X \longrightarrow Y\times Z. \]

Repair succeeds for deterministic Task \(T\) when

\[ \boxed{ (r,q)(x) = (r,q)(x') \Longrightarrow T(x)=T(x'). } \]

23. Minimal Repair Optimization

Classification: optimization template

\[ \boxed{ \inf_{q\in\mathcal Q_{\mathrm{adm}}} \operatorname{Cost}(q) } \]

subject to

\[ T = \widetilde T \circ (r,q). \]

The admissible repair class \(\mathcal Q_{\mathrm{adm}}\) and the meaning of cost are application-dependent.

An infimum is used because a minimizing repair need not exist.

24. Joint Feasibility

Classification: exact feasibility condition

If condition \(c\) has feasible set

\[ P_c \subseteq X, \]

then one common witness requires

\[ \boxed{ \bigcap_{c\in\mathcal C} P_c \neq \varnothing. } \]

Separate nonempty feasible sets do not guarantee one common solution.

25. Stochastic Response Kernel

Classification: stochastic response structure

\[ M: X \longrightarrow \mathcal P(Y). \]

For an appropriate measurable and integrable test function \(\varphi:Y\to\mathbb R\),

\[ \boxed{ M^\dagger\varphi(x) = \mathbb E \left[ \varphi(Y) \mid X=x \right]. } \]

Stochastic equality, sufficiency, coupling, and factorization require stochastic semantics rather than automatic reuse of deterministic fibre arguments.

26. Nondeterministic Existential Response

Classification: nondeterministic reachability

\[ \boxed{ \Diamond_R(U) = \left\{ x: \exists y\in U \text{ with } xRy \right\}. } \]

27. Nondeterministic Universal Response

Classification: nondeterministic safety

\[ \boxed{ \Box_R(U) = \left\{ x: \forall y,\; xRy \Rightarrow y\in U \right\}. } \]

Existential and universal quantifiers must not be interchanged.

28. General Root Chain

Classification: general Root-sequence structure

A Root chain may use changing state spaces and changing maps:

\[ R_n\in X_n, \] \[ F_n: D_n \subseteq X_n \longrightarrow X_{n+1}, \] \[ \boxed{ R_{n+1} = F_n(R_n), \qquad R_n\in D_n. } \]

This is more general than ordinary iteration by a single map.

29. Repeated Root Iteration

Classification: conditional repeated-Root dynamical model

To apply ordinary discrete iteration directly, one requires a Root state space \(X_R\) and a map

\[ \boxed{ F: X_R \longrightarrow X_R. } \]

More generally, if \(A_R\subseteq X_R\) is the actual admissible iteration domain, one requires

\[ \boxed{ F(A_R) \subseteq A_R. } \]

For

\[ R_0\in A_R, \]

the recurrence

\[ \boxed{ R_{n+1} = F(R_n) } \]

defines an ordinary iterated system only while the required iterates remain admissible.

Thus repeated Rooting is not automatically a dynamical system.

30. Fixed Root

Classification: fixed-point condition

\[ \boxed{ R_* = F(R_*). } \]

A fixed Root is invariant under the specified Root map.

Fixed-point existence must be established from the mathematics of \(F\) and its domain.

31. Local Root Stability

Classification: standard discrete dynamical-systems criterion

Let

\[ F: U \subseteq \mathbb R^n \longrightarrow \mathbb R^n \]

be continuously differentiable near fixed point \(R_*\), with the required local iteration domain preserved.

A standard sufficient condition for local asymptotic attraction is

\[ \boxed{ \rho \left( J_F(R_*) \right) < 1. } \]

Here \(\rho\) denotes spectral radius.

If the Jacobian has an eigenvalue with modulus greater than one, the fixed point is locally unstable under the standard hypotheses.

The borderline case

\[ \rho(J_F(R_*))=1 \]

is generally inconclusive from linearization alone.

Figure 1 — Convergence of \(R_{n+1}=\frac12R_n+1\)

Starting from \(R_0=0\), the iterated Root value approaches the fixed value \(R_*=2\).

A quantitative plot should show \(R_n\) against iteration \(n\), together with a horizontal reference line at \(R=2\).

This is a worked dynamical-systems example used to illustrate one repeated-Root model. It is not a universal law of Branch Mathematics.

34. Closed Form of the Worked Example

For

\[ R_{n+1} = \frac12R_n+1 \]

with \(R_0=0\),

\[ \boxed{ R_n = 2 \left( 1-2^{-n} \right). } \]

Hence

\[ \boxed{ \lim_{n\to\infty}R_n = 2. } \]

The absolute error is

\[ \boxed{ |R_*-R_n| = 2^{1-n}. } \]

35. General Affine Root Iteration

Classification: exact solution of a general worked dynamical model

\[ \boxed{ R_{n+1} = \alpha R_n+\beta. } \]

Assume

\[ R_n\in\mathbb R \]

and \(\alpha,\beta\in\mathbb R\).

If

\[ \alpha\neq1, \]

the unique fixed point is

\[ \boxed{ R_* = \frac{\beta}{1-\alpha}. } \]

Subtracting the fixed point gives

\[ R_{n+1}-R_* = \alpha(R_n-R_*), \]

and therefore

\[ \boxed{ R_n-R_* = \alpha^n(R_0-R_*). } \]

Equivalently,

\[ \boxed{ R_n = R_* + \alpha^n(R_0-R_*). } \]

Global Convergence

Because this affine scalar relation is exact on all of \(\mathbb R\),

\[ \boxed{ |\alpha|<1 \Longrightarrow R_n\longrightarrow R_* \quad \text{for every finite } R_0\in\mathbb R. } \]

This is global convergence for the stated affine model, not merely local convergence.

36. Affine Parameter Interpretation

Condition Behavior
\(0<\alpha<1\) Global non-oscillatory convergence toward \(R_*\), with the side of approach determined by \(R_0-R_*\).
\(-1<\alpha<0\) Global alternating convergence toward \(R_*\).
\(\alpha=0\) \(R_1=\beta\), after which the sequence remains at the fixed point \(R_*=\beta\).
\(\alpha=-1\) The fixed point is \(R_*=\beta/2\). Unless \(R_0=R_*\), the sequence alternates with period two.
\(|\alpha|>1\) Deviations from \(R_*\) grow geometrically unless \(R_0=R_*\).
\(\alpha=1,\ \beta\neq0\) No finite fixed point; \(R_n=R_0+n\beta\).
\(\alpha=1,\ \beta=0\) Every \(R_0\in\mathbb R\) is fixed.

37. Root Production Rate

Classification: model-dependent event-rate definition

If distinct Root events occur at times \(t_n\), define

\[ \Delta t_n = t_{n+1}-t_n. \]

When

\[ \Delta t_n>0, \]

define

\[ \boxed{ \nu_n = \frac{1}{\Delta t_n}. } \]

This quantity is meaningful only when the model genuinely contains identifiable discrete Root events and an applicable time variable.

BM has no universal Root-production rate.

38. Continuous Root-State Rate

Classification: model-dependent continuous-state rate

For a differentiable Root trajectory in a normed vector space,

\[ \boxed{ \dot R(t) = \frac{dR}{dt}. } \]

If an appropriate norm exists,

\[ \|\dot R(t)\| \]

measures the magnitude of Root-state change.

On a differentiable manifold, the corresponding derivative is a tangent vector

\[ \dot R(t) \in T_{R(t)}X_R. \]

39. Root Event Accumulation Criterion

Classification: finite-time event-accumulation condition

\[ \boxed{ \sum_{n=0}^{\infty} \Delta t_n < \infty. } \]

If this holds, infinitely many modeled events accumulate before a finite limiting time.

Whether such Zeno-like behavior is admissible or physically meaningful depends entirely on the underlying mathematical or physical model.

40. Invariant Preservation

Classification: exact preservation equation

For

\[ F: X \longrightarrow Y \]

with invariant representations

\[ C_X: X\to V, \qquad C_Y: Y\to V, \]

preservation means

\[ \boxed{ C_Y(F(x)) = C_X(x). } \]

BM may track or audit such preserved information but does not create the invariant itself.

41. Dynamic Closure

Classification: exact deterministic reduced-dynamics compatibility

Let

\[ R: X \longrightarrow Z \]

be a reduced representation and

\[ \Phi_t: X \longrightarrow X \]

the full evolution.

Exact reduced closure requires a reduced evolution

\[ \widetilde\Phi_t: R(X) \longrightarrow R(X) \]

satisfying

\[ \boxed{ R\circ\Phi_t = \widetilde\Phi_t\circ R. } \]

Equivalently,

\[ R(x)=R(x') \Longrightarrow R(\Phi_t(x)) = R(\Phi_t(x')). \]

The reduced state can then determine its own reduced future without requiring hidden information from the original full state.

42. Sensitivity

Classification: standard differential diagnostic

For

\[ F: \mathbb R^n \longrightarrow \mathbb R^m, \]

the Jacobian is

\[ \boxed{ J_F(x) = \frac{\partial F}{\partial x}. } \]

Large derivative directions indicate strong local sensitivity of the output to perturbations in the corresponding input directions.

Sensitivity is not the same thing as instability unless a theorem connects the two in the model being studied.

43. HDE Extended-State Schema

Classification: working GURF-HDE structural model

When an extended response domain is required,

\[ D \subseteq D_{\mathrm{ext}}, \]

one may write

\[ H = D_{\mathrm{ext}}\setminus D \]

in a Set-like decomposition.

An extended response state may then be represented by

\[ \boxed{ x_{\mathrm{ext}} = (x_D,x_H). } \]

A local observation can be insufficient whenever

\[ x_D=x_D' \]

but

\[ \boxed{ T(x_D,x_H) \neq T(x_D',x_H'). } \]

44. GHSE Joined-State Schema

Classification: working GURF-GHSE structural model

For components with state spaces

\[ X_A, \qquad X_B, \]

an admissible joined-state region may be

\[ \boxed{ \mathcal H \subseteq X_A\times X_B. } \]

A glue Operation may be represented by

\[ J: D_J \subseteq X_A\times X_B \longrightarrow X_{AB}. \]

A binary hold predicate may be represented by

\[ h: X_A\times X_B \longrightarrow \{0,1\}. \]

These are working forms rather than universal GHSE equations.

45. UKE Kernel-Type Equations

Classification: standard mathematical forms organized within UKE

Nullspace Kernel

\[ \boxed{ \ker F = \{x:F(x)=0\}. } \]

Integral Kernel

\[ \boxed{ (Tf)(x) = \int K(x,y)f(y)\,dy. } \]

Green Kernel

\[ \boxed{ L_xG(x,x') = \delta(x-x'). } \]

Resolvent

\[ \boxed{ R(z) = (L-zI)^{-1} } \]

where the inverse exists.

Memory Response

\[ \boxed{ y(t) = \int_{-\infty}^{t} K(t,s)x(s)\,ds. } \]
These equations represent mathematically different meanings of the word kernel. They must not be treated as interchangeable merely because the same word is used.

46. Equation Status Classes

Class Meaning
Definition Introduces a mathematical object or quantity.
Exact identity Equality following exactly from stated mathematics.
Derived relation Relation derived from stated assumptions or previous equations.
Conditional relation Valid only when specified hypotheses hold.
Approximation Includes an explicitly defined error, asymptotic regime, probability statement, or tolerance.
Structural schema Expresses mathematical architecture rather than a numerical law.
Worked example Demonstrates mathematical behavior without asserting a universal BM/GURF law.
Candidate model Proposed mathematical model still under active investigation.

47. Equation Publication Standard

An equation is not accepted as a law merely because it can be written, numerically plotted, or fit to data.

A mature equation entry should identify:

  • all mathematical objects;
  • domains and codomains;
  • required hypotheses;
  • units or dimensions where applicable;
  • derivation or proof status;
  • sector semantics;
  • failure conditions;
  • limiting cases;
  • numerical behavior where relevant;
  • related definitions and theorems;
  • and whether the equation is exact, approximate, or model-specific.

48. Scientific Visualization Standard

Quantitative figures are included only when they expose real mathematical behavior.

Preferred figure types include:

convergence plots · parameter sweeps · phase portraits · spectra · surfaces · vector fields · heatmaps · stability regions · bifurcation plots · error curves · response curves · uncertainty bands · residual plots · PDE fields · operator spectra

Every scientific figure should identify the equation, parameter range, initial or boundary conditions, numerical method where applicable, units where relevant, and interpretation of the axes.

49. Structural Diagram Policy

Equation-driven scientific plots and formal structural diagrams are different artifacts.

BM and GURF structural diagrams remain separate and will not be invented or reconstructed for presentation until their canonical mathematical versions are formally recovered and approved.

50. Registry Development

As the formal research corpus expands, important equations can receive stable anchors and approved internal identifiers.

Mature equation entries should link to:

definitions · assumptions · derivations · proofs · numerical tests · scientific figures · applications · revisions · external references

Canonical internal equation identifiers will not be invented solely for the website when an approved project identifier has not yet been assigned.

51. Central Equation Rule

\[ \boxed{ \text{An equation inherits its validity from its mathematical objects, domain, assumptions, derivation, and sector semantics.} } \]

BM and GURF may organize that equation and its role in a larger mathematical structure.

They do not remove the conditions under which the equation is true.
