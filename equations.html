1. How to Read an Equation in BM

No displayed formula is valid because it appears on a Branch Mathematics page. Its validity comes from its mathematical objects, domain, assumptions, derivation, and native semantic sector.

\[ \boxed{ \text{equation validity} = \text{objects} + \text{domain} + \text{hypotheses} + \text{derivation} + \text{sector semantics}. } \]
Before using any equation, ask: What are the objects? What is the domain? Which semantic sector is active? What assumptions are required? What exactly follows from the equation?

2. Equation Classes

\[ \boxed{ \text{equation class} \neq \text{novelty claim}. } \]

4. Core Branch Mathematics Equations

E01 — BM Structural Principle
Classification: Core structural schema
\[ \boxed{ \text{one problem} \longrightarrow \text{multiple lawful Branches} \longrightarrow \text{lawful combined mathematics} \longrightarrow \text{mathematical consequences}. } \]

This is organizational structure, not a numerical physical law.

E02 — Problem Scope
Classification: Core BM object
\[ \boxed{ \mathfrak S_P = \text{declared mathematical scope of problem }P. } \]

Scope controls which distinctions must be preserved.

E03 — Obligation Closure
Classification: Core BM structural definition
\[ \boxed{ \mathscr Q_P = \operatorname{ReqCl}_{\mathfrak D_C} (\mathscr T_P). } \]

The active obligations are the semantic dependency closure of the terminal requirements.

E04 — Branch Specification
Classification: Core organizational definition
\[ \boxed{ B= \left( \mathsf S_B, \tau_B, X_B, A_B, \mathcal L_B, \mathcal O_B, \mathcal P_B \right). } \]
The tuple is an organizational specification, not a universal ontology.
E05 — Branch Essentiality Witness
Classification: Active BM decomposition criterion
Sector: deterministic common-source form

Let \(q\) collapse a proposed Branch distinction. Essentiality is witnessed when some required obligation \(T\) cannot descend:

\[ \boxed{ \nexists\widetilde T \quad\text{such that}\quad T = \widetilde T \circ q \circ R_{\mathcal B}. } \]
\[ \boxed{ \text{Branch separation must make a mathematical difference somewhere.} } \]
E06 — Operation
Classification: Core BM typed form
\[ \boxed{ O: D_O \subseteq X \to Y. } \]

This is the deterministic specialization. Other sectors use their native transformation objects.

E07 — Interaction
Classification: Core BM joint-participation form
\[ \boxed{ I: D_I \subseteq A_{B_1} \times\cdots\times A_{B_n} \to Z_I. } \]

Interaction is an Operation or native relation carrying a declared joint-participation role.

E08 — Interaction Non-Inheritance
Classification: Core firewall
\[ \boxed{ \text{input structure} \not\Rightarrow \text{output structure}. } \]

Structure transfers only through an explicit mathematical construction or theorem.

E09 — Composite Domain
Classification: Classical partial-map mathematics
\[ F: D_F \subseteq X \to Y, \qquad G: D_G \subseteq Y \to Z, \]
\[ \boxed{ D_{G\circ F} = \{ x\in D_F: F(x)\in D_G \}. } \]
E10 — Leaf Extraction
Classification: Core structural equation
\[ z = I(x_1,\ldots,x_n), \qquad \boxed{ L_j = \ell_j(z). } \]
Not every intermediate expression becomes a formal Leaf.
E11 — Lawful Leaf Propagation
Classification: Typed composite relation
\[ L = \ell(I(x)), \qquad J: D_J \subseteq X_L\times X_C \to W, \]
\[ \boxed{ L' = \ell' \big( J(L,c) \big), \qquad (L,c)\in D_J. } \]

Leaf status does not waive the receiving domain.

5. Contract and Passport Equations

E12 — Contract Instantiation
Classification: Core BM obligation equation
\[ \mathcal C^\rho = (\Sigma^\rho,\Phi^\rho), \]
\[ \boxed{ \mathcal P^\rho_{\theta,c} = \operatorname{Inst}_{\theta,c} (\mathcal C^\rho). } \]

Contract is the reusable schema; Passport is the operative instantiation.

E13 — Passport Applicability and Acceptance
Classification: Core BM firewall
\[ \boxed{ \operatorname{Acc}(\mathcal P) \subseteq D_{\mathcal P}. } \]
\[ \boxed{ x\notin D_{\mathcal P} \neq x\in D_{\mathcal P} \setminus \operatorname{Acc}(\mathcal P). } \]
E14 — Combined Exact Passport Representation
Classification: Deterministic product construction
\[ b_c: X \to Y_c, \qquad c\in\mathcal C, \]
\[ \boxed{ B_{\mathcal P}(x) = \big( b_c(x) \big)_{c\in\mathcal C}. } \]
Marginal stochastic information does not automatically define a joint stochastic Passport.
E15 — Passport Fibre
Classification: Exact Set construction
\[ \boxed{ \mathfrak C_{\mathcal P}(\ell) = B_{\mathcal P}^{-1}(\ell) = \bigcap_{c\in\mathcal C} b_c^{-1}(\ell_c). } \]
E16 — Exact Task Sufficiency
Classification: Classical factorization theorem
\[ T: X \to W, \qquad \boxed{ T = \widetilde T \circ B_{\mathcal P}. } \]

Equivalently:

\[ \boxed{ B_{\mathcal P}(x) = B_{\mathcal P}(x') \Longrightarrow T(x) = T(x'). } \]
E17 — Exact Task Quotient
Classification: Classical quotient construction
\[ x \sim_T x' \iff T(x) = T(x'), \]
\[ \boxed{ X/{\sim_T}. } \]
This is only the coarsest exact Set-level Task quotient. Native structure may require a finer quotient.
E18 — Structured Quotient Compatibility
Classification: Classical congruence condition
\[ \boxed{ x_i\sim y_i \ \forall i \Longrightarrow \sigma(x_1,\ldots,x_n) \sim \sigma(y_1,\ldots,y_n). } \]

When this holds:

\[ \boxed{ \overline\sigma ([x_1],\ldots,[x_n]) = [\sigma(x_1,\ldots,x_n)]. } \]
E19 — Exact Interface Compatibility
Classification: Exact factorization / transport condition
\[ F: X_1 \to X_2, \qquad P_1: X_1 \to Q_1, \qquad P_2: X_2 \to Q_2, \]
\[ \boxed{ P_2 \circ F = G \circ P_1. } \]
E20 — Approximate Interface Defect
Classification: Quantitative diagnostic
\[ \boxed{ \Delta_F(x) = d_Q \left( P_2(F(x)), G(P_1(x)) \right). } \]

Exact:

\[ \Delta_F(x)=0. \]

Approximate:

\[ \Delta_F(x) \le \varepsilon. \]

6. Configuration and Realization Equations

E21 — Configuration Well-Formedness
Classification: Core BM status predicate
\[ \boxed{ \mathrm{WF}(C). } \]

Well formed means the declared types, domains, Interfaces, Passports, and comparison semantics are syntactically and semantically coherent.

\(\mathrm{WF}(C)\) does not imply a solution exists.
E22 — Local Admissibility
Classification: Core realization condition
\[ \boxed{ \mathfrak F(U_i;C,c) \neq \varnothing \qquad \forall U_i\in\mathcal U. } \]
This is relative to the declared local cover/decomposition.
E23 — Global Realizability
Classification: Core BM semantic condition
\[ \boxed{ \mathrm{GR}(C;c) \iff \mathfrak F(C;c) \neq \varnothing. } \]

This asserts existence, not uniqueness or constructibility.

E24 — Tree Realization Record
Classification: Core BM structural definition
\[ \boxed{ T = (C,\xi,\Pi,\omega,\Lambda), \qquad \xi \in \mathfrak F(C;c). } \]

Tree therefore contains a selected lawful realization, not merely an organizational graph.

E25 — Response Map
Classification: Core BM output equation
\[ \boxed{ \mathcal E: D_{\mathcal E} \subseteq \mathsf{Tree} \to \mathcal Y, \qquad Y = \mathcal E(T). } \]

The Response type is determined by the native computation.

E26 — Export
Classification: Core receiver-directed transformation
\[ \boxed{ E_r: D_{E_r} \subseteq \mathcal Y \to \mathcal R_r, \qquad r = E_r(Y). } \]
E27 — Root Gate
Classification: Core receiver-relative condition
\[ \boxed{ r \text{ is Root for }B_r \iff r \in \operatorname{Acc} (\mathcal P_R^{B_r}). } \]

This condition is evaluated only after

\[ r \in D_{\mathcal P_R^{B_r}}. \]
\[ \boxed{ \text{Root}_{B_1}(r) \not\Rightarrow \text{Root}_{B_2}(r). } \]
E28 — Re-entry Domain
Classification: Core typed composition
\[ E: X \to Y_E, \qquad R: D_R \subseteq Y_E \to Z, \]
\[ \boxed{ D_{R\circ E} = \{ x\in X: E(x)\in D_R \}. } \]

7. Law Space and Selection

E29 — Law Assignment
Classification: Active specialized BM equation
\[ \boxed{ \Lambda: \Omega_{\mathscr L} \rightrightarrows \mathscr L. } \]

If

\[ |\Lambda(C)| > 1, \]

downstream mathematics must preserve the multiplicity or provide an explicit selector.

E30 — Selection Firewall
Classification: Core non-uniqueness rule
\[ \boxed{ \exists x\in S \not\Rightarrow \text{canonical }x. } \]

Applies to realizations, laws, Roots, minimizers, repairs, reconstructions, and witnesses.

8. Coherence Equations

E31 — Exact Path Coherence
Classification: Core BM comparison condition
\[ x \in D_{P_1} \cap D_{P_2}, \]
\[ q_1: Y_1 \to Q, \qquad q_2: Y_2 \to Q, \]
\[ \boxed{ q_1P_1(x) = q_2P_2(x). } \]
E32 — Approximate Path Coherence
Classification: Quantitative diagnostic
\[ \boxed{ d_Q \left( q_1P_1(x), q_2P_2(x) \right) \le \varepsilon. } \]
\(Q\), \(d_Q\), and \(\varepsilon\) are part of the mathematical claim.

9. Dynamic Closure and Continuation

E33 — Exact Dynamic Closure
Classification: Core exact deterministic compatibility
\[ \Phi: A \to A, \qquad R: A \to Y, \qquad Y_R = R(A), \]
\[ \boxed{ \widetilde\Phi: Y_R \to Y_R, \qquad R\circ\Phi = \widetilde\Phi \circ R. } \]

Equivalent fibre condition:

\[ \boxed{ R(x)=R(x') \Longrightarrow R(\Phi(x)) = R(\Phi(x')). } \]
E34 — Future-Task Continuation
Classification: GURF response specialization
\[ \Phi_t: X \to X, \qquad T: X \to W, \]
\[ \boxed{ T\circ\Phi_t = \widetilde T_t \circ r. } \]

This asks whether the current representation is sufficient for one declared future Task.

E35 — Continuation Failure Witness
Classification: Deterministic obstruction
\[ \boxed{ r(x) = r(x') \quad\text{but}\quad T(\Phi_t(x)) \neq T(\Phi_t(x')). } \]
E36 — Feedback Realization Family
Classification: Core BM realization schema
\[ \boxed{ \mathfrak F(C_f) = \{ \xi: \xi \text{ satisfies all native feedback equations and constraints} \}. } \]

In a fixed-point specialization:

\[ x = \Theta(x). \]
Fixed points are one feedback sector, not the universal definition.

10. Local-to-Global Equation

E37 — Finite Tree-Gluing Realization
Classification: Classical tree/CSP structure used by BM

Let \(H=(V,E)\) be a finite rooted tree with local realization sets \(F_v\) and compatibility relations

\[ C_{uv} \subseteq F_u\times F_v. \]

Exact global factorization:

\[ \boxed{ \mathfrak F_H = \left\{ (x_v): x_v\in F_v,\; (x_u,x_v)\in C_{uv} \ \forall uv\in E \right\}. } \]

Parent-surjectivity:

\[ \boxed{ \forall(u\to v), \forall x_u\in F_u, \exists x_v\in F_v: (x_u,x_v)\in C_{uv}. } \]

Then:

\[ \boxed{ \mathfrak F_H \neq \varnothing. } \]
Hidden global constraints invalidate this factorization.

11. Defect and Repair Equations

E38 — General Defect
Classification: Active specialized BM object
\[ \boxed{ \operatorname{Def}_{\Psi}. } \]

The defect is indexed by the actual failed mathematical condition \(\Psi\).

E39 — Task-Labelled Fibre
Classification: GURF-linked Defect-Calculus specialization
\[ F_C(c) = C^{-1}(c), \]
\[ \boxed{ \mathfrak D_T(C;c) = \left( F_C(c), T|_{F_C(c)} \right). } \]

Exact ambiguity image:

\[ \boxed{ \mathfrak A_T(C;c) = T(F_C(c)). } \]
E40 — Admissible Repair Relation
Classification: Active BM repair structure
\[ \boxed{ \mathscr R_{\mathrm{adm}} \subseteq \mathsf{Conf} \times \mathsf{Conf}. } \]

Repair \(C'\) of \(C\) must satisfy:

\[ (C,C') \in \mathscr R_{\mathrm{adm}}. \]
E41 — Exact Information Repair
Classification: Deterministic GURF/BM repair construction
\[ F: X \to Y, \qquad q: X \to Z, \]
\[ \boxed{ F'(x) = (F(x),q(x)). } \]

Exact repair for Task \(T\) requires:

\[ \boxed{ F'(x)=F'(x') \Longrightarrow T(x)=T(x'). } \]
E42 — Repair Dependency Closure
Classification: Certification firewall
\[ \boxed{ \operatorname{Cl}_{\mathfrak D_C}(S) } \]

is the region whose prior certification may depend on repaired region \(S\).

\[ \boxed{ \text{repair}(S) \not\Rightarrow \text{old certificates remain valid on } \operatorname{Cl}_{\mathfrak D_C}(S). } \]

12. Refinement and Information Equations

E43 — Deterministic Refinement
Classification: Active BM comparison relation
\[ R_1: X_P \to Y_1, \qquad R_2: X_P \to Y_2, \]
\[ \boxed{ R_1 = A_{21} \circ R_2. } \]

This may witness:

\[ \boxed{ \mathcal B_1 \preceq_{P,\mathcal T} \mathcal B_2. } \]
E44 — Exact Deterministic Information Persistence
Classification: Scoped model axiom / preservation criterion
\[ \widehat F: X \to Y\times H, \]
\[ \boxed{ \widehat F(x_1) = \widehat F(x_2) \Longrightarrow x_1 \sim_{\mathcal I} x_2. } \]
This is not a universal definition of information conservation across all semantic sectors.
E45 — Convergence Firewall
Classification: Core semantic requirement
\[ \boxed{ x_n \xrightarrow{\tau} x } \]

where \(\tau\) denotes the actual declared topology, norm, weak topology, probabilistic mode, operator topology, order structure, or other native convergence semantics.

\[ \boxed{ x_n\to x \text{ is incomplete until }\to\text{ is defined}. } \]
E46 — Approximation Firewall
Classification: Core quantitative requirement
\[ \boxed{ d_Q(x,y) \le \varepsilon. } \]

Approximation requires an explicit comparison object \(Q\), discrepancy \(d_Q\), and tolerance \(\varepsilon\).

13. Witness and Coupling Equations

E47 — Shared Witness
Classification: Quantifier-scope condition

Independent:

\[ \exists w_1\, \varphi_1(w_1), \qquad \exists w_2\, \varphi_2(w_2). \]

Shared:

\[ \boxed{ \exists w \left[ \varphi_1(w) \land \varphi_2(w) \right]. } \]
\[ \boxed{ \text{independent witnesses} \not\Rightarrow \text{shared witness}. } \]
E48 — Coupled Witnesses
Classification: Active relational/CSP form
\[ \boxed{ \exists w_1\exists w_2: R_1(x,w_1) \land K(w_1,w_2) \land R_2(x,w_2). } \]

\(K\) carries the required witness coupling.

15. Stochastic, Relational, and Privacy Semantics

E53 — Markov Kernel
Classification: Classical stochastic semantics
\[ \boxed{ K: X \rightsquigarrow Y, \qquad x \mapsto K(x,\cdot). } \]

The output at \(x\) is a probability law.

E54 — Markov Kernel Composition
Classification: Classical stochastic identity
\[ K: X \rightsquigarrow Y, \qquad L: Y \rightsquigarrow Z, \]
\[ \boxed{ (L\circ K)(x,A) = \int_Y L(y,A)\, K(x,dy). } \]
E55 — Markov Test-Function Action
Classification: Classical expectation identity
\[ \boxed{ (K\varphi)(x) = \int_Y \varphi(y) K(x,dy). } \]

Composition gives:

\[ \boxed{ ((L\circ K)\phi)(x) = K(L\phi)(x). } \]
No adjoint notation is assumed unless an actual adjoint structure has been defined.
E56 — Nondeterministic May / Must Semantics
Classification: Classical relational semantics
\[ \boxed{ \Diamond_R(U) = \{ x: \exists y\in U, \ xRy \}. } \]
\[ \boxed{ \Box_R(U) = \{ x: \forall y, \ xRy \Rightarrow y\in U \}. } \]
\[ \boxed{ \Diamond_R \neq \Box_R. } \]
E57 — Probability Coupling
Classification: Classical probability construction
\[ \boxed{ \pi \in \Pi(\mu,\nu). } \]

with marginals:

\[ \pi(A\times Y) = \mu(A), \qquad \pi(X\times B) = \nu(B). \]
The marginals alone do not determine \(\pi\).
E58 — Differential Privacy
Classification: Classical privacy inequality
\[ \boxed{ \Pr[M(x)\in S] \le e^\varepsilon \Pr[M(x')\in S] + \delta } \]

for adjacent \(x,x'\).

\[ \boxed{ \text{privacy indistinguishability} \neq \text{exact equivalence}. } \]

Ordinary Root reuse does not require this attachment structure.

E60 — Candidate Seed Update

The update \(G\) belongs to the native mathematics. “Seed” is only the candidate BM role.

Example quantitative realization:

\[ \|F(S_n)\| \le \varepsilon. \]

17. Ordinary Mathematics Applied to Root-Carrying Values

These equations are deliberately not called intrinsic Root laws. They are ordinary mathematics applied when an object occupying a Root role participates in the relevant native system.

E62 — Stage-Varying Root Reuse Chain
Classification: Ordinary typed sequential mathematics
\[ R_n \in X_n, \qquad F_n: D_n \subseteq X_n \to X_{n+1}, \]
\[ \boxed{ R_{n+1} = F_n(R_n), \qquad R_n \in D_n. } \]

The spaces and maps may change at every stage.

E63 — Ordinary Self-Map Iteration
Classification: Classical dynamics
\[ F: S \to S, \qquad \boxed{ R_{n+1} = F(R_n). } \]

A fixed point satisfies:

\[ R_* = F(R_*). \]
Roothood does not imply that this self-map exists, that a fixed point exists, or that iteration converges.
E64 — Invariant Preservation
Classification: Native preservation equation
\[ F: X \to Y, \qquad C_X: X \to V, \qquad C_Y: Y \to V, \]
\[ \boxed{ C_Y(F(x)) = C_X(x). } \]

BM may audit an invariant; BM terminology does not create one.

E65 — Lipschitz Error Propagation
Classification: Classical quantitative bound
\[ d_Z \big( G(y), G(y') \big) \le L d_Y(y,y'), \]

so if:

\[ d_Y \big( F(x), F(x') \big) \le \varepsilon, \]

then:

\[ \boxed{ d_Z \big( G(F(x)), G(F(x')) \big) \le L\varepsilon. } \]

18. Classical Information and Geometry Carriers

E66 — Local Gaussian Fisher Carrier
Classification: Classical local Gaussian result

For scalar parameter \(\theta\), locally parameter-independent covariance \(V\), and mean \(\mu(\theta)\):

\[ g = V^{-1/2} \frac{d\mu}{d\theta}, \qquad I_{\mathrm{full}} = \|g\|^2. \]

For orthogonal projection \(P\) in whitened coordinates:

\[ \boxed{ I(P) = \|Pg\|^2 \le \|g\|^2. } \]
This is local Gaussian information geometry, not a universal BM compression law.
E67 — Finite-Hypothesis Mahalanobis Carrier
Classification: Classical whitened Euclidean geometry
\[ D = [ z_2-z_1, \ldots, z_M-z_1 ], \]
\[ \boxed{ \dim (\text{smallest exact linear carrier}) = \operatorname{rank}(D). } \]
Finite hypotheses and linear whitened geometry are required.

19. Classical Applied Identities

E68 — Periodic Incompressible Navier–Stokes Energy Identity
Classification: Classical applied PDE identity
\[ \partial_tu + (u\cdot\nabla)u = -\nabla p + \nu\Delta u + f, \qquad \nabla\cdot u = 0. \]
\[ E(t) = \frac12 \int_\Omega |u|^2 \,dx, \]
\[ D(t) = \nu \int_\Omega |\nabla u|^2 \,dx, \qquad F(t) = \int_\Omega f\cdot u \,dx. \]
\[ \boxed{ \frac{dE}{dt} = -D + F. } \]
Requires the standard regularity/boundary assumptions. It does not solve three-dimensional Navier–Stokes regularity.
E69 — Three-Dimensional Vorticity / Enstrophy Identity
Classification: Classical applied PDE identity
\[ \omega = \nabla\times u, \]
\[ \partial_t\omega + (u\cdot\nabla)\omega = (\omega\cdot\nabla)u + \nu\Delta\omega + \nabla\times f. \]
\[ \boxed{ \frac12 \frac{d}{dt} \int_\Omega |\omega|^2 dx = \int_\Omega \omega\cdot (\omega\cdot\nabla)u \,dx - \nu \int_\Omega |\nabla\omega|^2 \,dx + \int_\Omega \omega\cdot (\nabla\times f) \,dx. } \]
This identity does not imply global regularity.
E70 — Wilson-Loop Gauge Invariance
Classification: Classical gauge-theory identity
\[ U_{xy} \mapsto \Omega_x U_{xy} \Omega_y^{-1}. \]
\[ U(C) = U_{x_0x_1} \cdots U_{x_{m-1}x_0}, \]
\[ \boxed{ W(C) = \operatorname{tr} U(C), \qquad W(C) \mapsto W(C). } \]
Gauge invariance of a Wilson loop does not establish four-dimensional Yang–Mills existence or a mass gap.
E71 — Quantum Dephasing
Classification: Classical quantum-channel identity
\[ \rho = \begin{pmatrix} a & c\\ c^* & 1-a \end{pmatrix}, \]
\[ \boxed{ \mathcal D_\lambda(\rho) = \begin{pmatrix} a & \lambda c\\ \lambda c^* & 1-a \end{pmatrix}, \qquad 0\le\lambda\le1. } \]

Population Tasks may survive while phase-sensitive Tasks do not.

20. GURF Extension Schemas

E72 — HDE Extended-State Schema
Classification: GURF-HDE structural specialization
\[ D \subseteq D_{\mathrm{ext}}, \qquad H = D_{\mathrm{ext}} \setminus D, \]
\[ \boxed{ x_{\mathrm{ext}} = (x_D,x_H). } \]

Local representation failure may be witnessed by:

\[ x_D = x_D' \quad\text{but}\quad \boxed{ T(x_D,x_H) \neq T(x_D',x_H'). } \]
This product decomposition is one HDE realization, not a universal HDE equation.
E73 — GHSE Joined-State Schema
Classification: GURF-GHSE structural specialization
\[ \boxed{ \mathcal H \subseteq X_A\times X_B, } \]
\[ J: D_J \subseteq X_A\times X_B \to X_{AB}. \]

A Boolean hold specialization may use:

\[ h: X_A\times X_B \to \{0,1\}. \]
Joining, holding, release, or persistence may require geometric, stochastic, dynamical, or relational semantics instead.

26. Scientific Visualization Standard

A quantitative figure belongs beside an equation only when it displays actual mathematical behavior governed by that equation.

Useful scientific figures include:

  • curves;
  • surfaces;
  • phase portraits;
  • vector fields;
  • spectra;
  • heatmaps;
  • parameter sweeps;
  • bifurcation diagrams;
  • residual plots;
  • error propagation;
  • admissibility regions;
  • coherence-defect fields;
  • realization regions;
  • convergence diagnostics.

A figure should state:

  • the governing equation;
  • parameter values;
  • initial or boundary conditions;
  • units where applicable;
  • numerical method where applicable;
  • meaning of all axes;
  • what mathematical feature the figure demonstrates.
\[ \boxed{ \text{visual metaphor} \neq \text{mathematical visualization}. } \]

27. Central Equation Rule

\[ \boxed{ \begin{gathered} \text{An equation inherits validity from its native mathematics.}\\[4pt] \text{BM may assign the equation a structural role without changing that mathematics.}\\[4pt] \text{Domains, codomains, applicability, and semantic sectors remain explicit.}\\[4pt] \text{Exact, approximate, stochastic, relational, and quantum equations}\\ \text{are not silently interchanged.}\\[4pt] \text{Structural equations do not become physical laws merely by appearing in BM.}\\[4pt] \text{Classical equations remain credited as classical mathematics.}\\[4pt] \text{Candidate formulas remain candidate.}\\[4pt] \text{Recovery-required names supply no equations until formally recovered.}\\[4pt] \text{No equation obtains theorem status from formatting or terminology alone.} \end{gathered} } \]
