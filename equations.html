1. Purpose of the Equation Registry

Equations in this encyclopedia are not included merely to make the framework appear mathematical.

Each important equation should identify:

mathematical objects · domain and codomain · assumptions · interpretation · derivation or proof status · limitations · related definitions · related theorems · numerical behavior when applicable

Some expressions below are exact mathematical equations. Others are explicitly identified as structural schemas or worked examples.

2. Structural BM Schema

Classification: structural schema

\[ \boxed{ \text{lawful Branches} \longrightarrow \text{lawful Interaction} \longrightarrow \text{combined mathematical response} \longrightarrow \text{Root or law result} } \]

This summarizes the broad structural direction of Branch Mathematics.

It is not a numerical equation and should not be interpreted as one.

3. Passport Observation Family

Classification: formal definition

\[ b_c: X \longrightarrow Y_c, \qquad c\in\mathcal C. \]

Each \(b_c\) records one observation, invariant, test, or distinction belonging to a Passport.

4. Combined Passport Map

Classification: formal construction

\[ B_P: X \longrightarrow \prod_{c\in\mathcal C}Y_c \] \[ \boxed{ B_P(x) = \left( b_c(x) \right)_{c\in\mathcal C}. } \]

The product map collects all active Passport observations.

5. Raw Passport Equivalence

Classification: exact equivalence relation

\[ \boxed{ x \sim_P x' \quad\Longleftrightarrow\quad b_c(x)=b_c(x') \quad \forall c\in\mathcal C. } \]

States are Passport-equivalent exactly when every active Passport observation gives the same result.

6. Passport Completion Fibre

Classification: exact set construction

\[ \boxed{ \mathfrak C_P(\ell) = \bigcap_{c\in\mathcal C} b_c^{-1}(\ell_c). } \]

The completion fibre contains every underlying state compatible with all active Passport observations.

The same construction appears naturally in GURF when several observations constrain the possible underlying states.

7. Exact Task Sufficiency

Classification: exact factorization criterion

Let

\[ T: X \longrightarrow W. \]

Passport \(P\) is sufficient for \(T\) when there exists

\[ \widetilde T: B_P(X) \longrightarrow W \]

such that

\[ \boxed{ T = \widetilde T \circ B_P. } \]

8. Fibre Criterion for Sufficiency

Classification: equivalent exact criterion

\[ \boxed{ B_P(x)=B_P(x') \Longrightarrow T(x)=T(x'). } \]

Equivalently,

\[ \boxed{ x\sim_P x' \Longrightarrow T(x)=T(x'). } \]

A distinction may be discarded only when the task does not require it.

9. Equivalence Inclusion Criterion

Classification: exact relational criterion

Define

\[ x \sim_T x' \quad\Longleftrightarrow\quad T(x)=T(x'). \]

Then exact sufficiency is

\[ \boxed{ \sim_P \subseteq \sim_T. } \]

10. Structured Quotient Compatibility

Classification: operation-compatibility condition

For an \(n\)-ary operation

\[ \sigma: X^n \longrightarrow X, \]

a Passport quotient preserves \(\sigma\) only when

\[ x_i\sim_P y_i \quad \forall i \] \[ \Longrightarrow \] \[ \boxed{ \sigma(x_1,\ldots,x_n) \sim_P \sigma(y_1,\ldots,y_n). } \]

In the algebraic setting, this is the congruence requirement.

11. Quotient Operation

Classification: induced operation, conditional on congruence

\[ \boxed{ \overline{\sigma} \left( [x_1]_P,\ldots,[x_n]_P \right) = \left[ \sigma(x_1,\ldots,x_n) \right]_P. } \]

This expression is well-defined only when the result is independent of the chosen representatives.

12. Exact Interface Compatibility

Classification: exact coherence equation

For

\[ F:X_1\to X_2, \qquad P_1:X_1\to Q_1, \] \[ P_2:X_2\to Q_2, \qquad G:Q_1\to Q_2, \]

exact interface compatibility is

\[ \boxed{ P_2\circ F = G\circ P_1. } \]

13. Approximate Interface Defect

Classification: quantitative diagnostic

Given metric \(d\), define

\[ \boxed{ \Delta_F(x) = d \left( P_2(F(x)), G(P_1(x)) \right). } \]

Exact coherence corresponds to

\[ \Delta_F(x)=0. \]

Approximate compatibility may require

\[ \Delta_F(x) \le \varepsilon. \]

This type of defect is naturally suitable for future parameter sweeps and heatmaps.

14. GURF Observation Map

Classification: formal system observation

\[ r: X \longrightarrow Y, \qquad y=r(x). \]

The map may represent measurement, coarse-graining, compression, projection, filtering, or another information-reducing operation.

15. GURF Completion Fibre

Classification: exact compatible-state set

\[ \boxed{ \mathfrak C_A(\ell) = \bigcap_{\alpha\in A} r_\alpha^{-1}(\ell_\alpha). } \]

This is the set of states compatible with the complete active observation family.

16. GURF Future Continuation Criterion

Classification: exact dynamic sufficiency condition

Let evolution be

\[ \Phi_t: X \longrightarrow X. \]

Observation \(r\) remains sufficient for future task \(T\) when

\[ \boxed{ T\circ\Phi_t = \widetilde T_t \circ r. } \]

17. Continuation Failure

Classification: obstruction condition

\[ r(x)=r(x') \] \[ \text{but} \] \[ \boxed{ T(\Phi_t(x)) \neq T(\Phi_t(x')). } \]

The present representation has merged states whose future task-relevant behavior differs.

18. Task Diameter of a Fibre

Classification: quantitative GURF diagnostic

\[ \boxed{ D_{r,T}(y) = \sup_{ x,x'\in r^{-1}(y) } d_W \left( T(x), T(x') \right). } \]

Exact sufficiency requires

\[ D_{r,T}(y)=0. \]

Approximate sufficiency may require

\[ D_{r,T}(y) \le \varepsilon. \]

19. GURF Repair

Classification: refinement condition

Add an observation

\[ q: X \longrightarrow Z. \]

Repair succeeds when

\[ (r,q)(x) = (r,q)(x') \] \[ \Longrightarrow \] \[ \boxed{ T(x)=T(x'). } \]

20. Minimal Repair Optimization

Classification: optimization template

\[ \boxed{ \min_q \operatorname{Cost}(q) } \] \[ \text{subject to} \] \[ T = \widetilde T \circ (r,q). \]

The meaning of cost is application-dependent.

21. Joint Feasibility

Classification: exact feasibility condition

If each condition has feasible set \(P_c\), then one common solution requires

\[ \boxed{ \bigcap_{c\in\mathcal C} P_c \neq \varnothing. } \]

Separate nonempty feasible sets do not guarantee a common witness.

22. Stochastic Response Kernel

Classification: stochastic response structure

\[ M: X \longrightarrow \mathcal P(Y). \]

For a test function \(\varphi:Y\to\mathbb R\),

\[ \boxed{ M^\dagger\varphi(x) = \mathbb E [ \varphi(Y) \mid X=x ]. } \]

23. Nondeterministic Existential Response

Classification: nondeterministic reachability

\[ \boxed{ \Diamond_R(U) = \left\{ x: \exists y\in U \text{ with } xRy \right\}. } \]

24. Nondeterministic Universal Response

Classification: nondeterministic safety

\[ \boxed{ \Box_R(U) = \left\{ x: \forall y, \; xRy \Rightarrow y\in U \right\}. } \]

Existential and universal quantifiers must not be interchanged.

25. Root Iteration

Classification: repeated Root model

\[ \boxed{ R_{n+1} = F(R_n). } \]

When a Root-generating process has this form, ordinary discrete dynamical-systems mathematics applies.

26. Fixed Root

Classification: fixed-point condition

\[ \boxed{ R_* = F(R_*). } \]

A fixed Root reproduces itself under the specified Root-generating map.

27. Local Root Stability

Classification: standard discrete dynamical-systems criterion

For differentiable

\[ F: \mathbb R^n \longrightarrow \mathbb R^n, \]

local attraction near fixed point \(R_*\) is associated with

\[ \boxed{ \rho \left( J_F(R_*) \right) < 1. } \]

Here \(\rho\) denotes spectral radius.

30. Closed Form of the Worked Example

For

\[ R_{n+1} = \frac12R_n+1, \]

with \(R_0=0\), the sequence has closed form

\[ \boxed{ R_n = 2 \left( 1-2^{-n} \right). } \]

Hence

\[ \lim_{n\to\infty} R_n = 2. \]

The error from the fixed Root is

\[ \boxed{ |R_*-R_n| = 2^{1-n}. } \]

31. General Affine Root Iteration

Classification: general worked dynamical model

\[ \boxed{ R_{n+1} = \alpha R_n+\beta. } \]

If

\[ \alpha\neq1, \]

the fixed Root is

\[ \boxed{ R_* = \frac{\beta}{1-\alpha}. } \]

Local convergence occurs when

\[ \boxed{ |\alpha|<1. } \]

32. Parameter Interpretation

Condition Behavior of affine iteration
\(0<\alpha<1\) monotone-type convergence depending on initial position
\(-1<\alpha<0\) alternating or oscillatory convergence
\(|\alpha|>1\) fixed point is unstable
\(\alpha=1\) no finite fixed point unless \(\beta=0\)

33. Root Production Rate

Classification: event-rate definition

If Root events occur at times \(t_n\),

\[ \Delta t_n = t_{n+1}-t_n \]

and

\[ \boxed{ \nu_n = \frac{1}{\Delta t_n}. } \]

This quantity is meaningful only when the model genuinely contains identifiable Root events.

34. Continuous Root-State Rate

Classification: continuous-state rate

\[ \boxed{ \dot R(t) = \frac{dR}{dt}. } \]

If a suitable norm exists,

\[ \left\| \dot R(t) \right\| \]

measures the rate of Root-state change.

35. Root Accumulation Criterion

Classification: finite-event accumulation condition

\[ \boxed{ \sum_{n=0}^{\infty} \Delta t_n < \infty. } \]

If this holds, infinitely many modeled events accumulate before a finite limiting time.

Whether such behavior is admissible depends entirely on the underlying mathematics or physics.

36. Invariant Preservation

Classification: exact preservation equation

For transformation

\[ F: X \longrightarrow Y, \]

with invariant representations \(C_X\) and \(C_Y\),

\[ \boxed{ C_Y(F(x)) = C_X(x). } \]

BM may track such preserved information but does not create the invariant.

37. Dynamic Closure

Classification: exact reduced-dynamics compatibility

For reduction

\[ R: X \longrightarrow Z \]

and full evolution \(\Phi_t\), exact reduced closure requires

\[ \boxed{ R\circ\Phi_t = \widetilde\Phi_t \circ R. } \]

The reduced state can then evolve without needing hidden information from the original full state.

38. Sensitivity

Classification: standard differential diagnostic

For

\[ R: \mathbb R^n \longrightarrow \mathbb R^m, \]

the Jacobian is

\[ \boxed{ J_R(x) = \frac{\partial R}{\partial x}. } \]

Large derivative directions indicate strong local response sensitivity.

Worked example used to demonstrate behavior but not asserted as a universal law
Candidate model proposed mathematical model still under investigation

40. Equation Publication Standard

An equation is not accepted as a law merely because it can be written, numerically plotted, or fit to data.

Its assumptions, derivation, domain, units where relevant, and mathematical status must be explicit.

41. Scientific Visualization Standard

Quantitative figures are included only when they expose real mathematical behavior.

Preferred figure types include:

convergence plots · parameter sweeps · phase portraits · spectra · surfaces · vector fields · heatmaps · stability regions · bifurcation plots · error curves · response curves · uncertainty bands

Structural BM and GURF diagrams remain separate and will not be recreated until their formal versions are recovered and approved.
