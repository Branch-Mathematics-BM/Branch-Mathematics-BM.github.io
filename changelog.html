1. Purpose of the Changelog

This changelog records substantive changes to the mathematics, framework architecture, research status, ownership, and formal public presentation of Branch Mathematics and GURF.

It is not a conversation archive.

The intended record answers questions such as:

What definition changed? · What assumption was strengthened? · Which theorem was corrected? · What object changed ownership? · What failed? · Which result was promoted or downgraded? · Which equation was generalized? · What research status changed? · Which public registry was synchronized?

2. Revision Principles

\[ \boxed{ \text{correction} \neq \text{erasure}. } \]

A substantive revision should preserve enough information to show:

previous form · reason for revision · corrected form · affected dependencies · resulting status

\[ \boxed{ \text{truth} \neq \text{novelty} \neq \text{external validation}. } \]

5. Interaction Arity Clarified

September 3, 2026
BM DEFINITION CORRECTION

Earlier public wording described Interaction as involving two or more Branches.

Current wording is:

\[ \boxed{ \text{Interaction} = \text{lawful typed mathematical action involving one or more Branches, with multi-Branch interaction central.} } \]

This allows unary Branch participation without weakening the central multi-Branch use of Interaction.

6. Leaf Notation and Provenance Corrected

September 3, 2026
BM LEAF NOTATION

Earlier notation reused \(L_j\) for both a Leaf codomain and an extracted Leaf value.

The corrected notation is:

\[ \ell_j: Z_I \longrightarrow \mathcal L_j, \] \[ \boxed{ \lambda_j = \ell_j \left( I(x_1,\ldots,x_n) \right) \in \mathcal L_j. } \]

\(\mathcal L_j\) is the Leaf space, \(\ell_j\) is the extraction map, and \(\lambda_j\) is the Leaf value.

A derived quantity is no longer called a formal BM Leaf merely because it arose during BM-guided research.

7. Tree, Response, and Root Roles Separated

September 3, 2026
BM STRUCTURES CORRECTION

The earlier public schema could be read as placing Tree after Leaf in a universal linear sequence.

The corrected structural distinction is:

\[ \boxed{ \text{Tree} \xrightarrow{\text{combined computation}} \text{Response}. } \] \[ \boxed{ \text{Response} \longrightarrow \begin{cases} \text{terminal result},\\[4pt] \text{Root if downstream admissible}. \end{cases} } \]

Tree is the organized computational structure. Response is its typed output. Root is a downstream role available only after admissibility is established.

8. Response Generalized Beyond Law-Valued Output

September 3, 2026
BM RESPONSE GENERALIZATION

Earlier public wording described Response too narrowly as a law-valued output.

Response is now defined as a typed mathematical output and may be:

September 3, 2026

15. Root Definition Tightened

September 3, 2026
BM ROOT

Root status is now explicitly a downstream role:

\[ \boxed{ \text{Root role} = \text{Response} + \text{verified downstream admissibility}. } \]

Root does not imply:

invertibility · conservation · recursion · physical realization · compatibility with every receiver

16. Rooting Attachment Site Generalized

September 3, 2026
BM ROOTING CORRECTION

Earlier Rooting language could be read as requiring attachment to an interior point.

Rooting is now defined through a compatible mathematical attachment site:

\[ \mathcal A: D_{\mathcal A} \subseteq X_A\times X_R \longrightarrow X'. \]

Attachment may be terminal or nonterminal. Interior attachment is permitted when the native mathematics admits it, but is not universally required.

17. Rebranching Kept Separate From Rooting

September 3, 2026
BM CANDIDATE

Rooting and Rebranching remain distinct candidate structures.

\[ \boxed{ \text{lawful Rooting} \not\Rightarrow \text{Rebranching}. } \]

A lawful attachment may terminate without producing any additional Branch development.

18. Repeated Rooting Closure Requirement Added

September 3, 2026
ROOT DYNAMICS CORRECTION

Earlier wording connected

\[ R_{n+1}=F(R_n) \]

directly to standard iteration.

The corrected condition requires closure:

\[ \boxed{ F: X_R \longrightarrow X_R } \]

or an invariant admissible domain

\[ A_R\subseteq X_R, \qquad \boxed{ F(A_R)\subseteq A_R. } \]

Only then may ordinary iteration and dynamical-systems results be applied directly.

19. General Root Chain Distinguished From Iteration

September 3, 2026
ROOT GENERALIZATION

A more general Root chain may use changing spaces and maps:

\[ R_n\in X_n, \qquad F_n: D_n\subseteq X_n \longrightarrow X_{n+1}, \] \[ \boxed{ R_{n+1} = F_n(R_n). } \]

Such a chain is not automatically iteration of a single endomorphism.

20. Affine Repeated-Root Convergence Corrected

September 3, 2026
EQUATIONS ROOT CORRECTION

For

\[ R_{n+1} = \alpha R_n+\beta, \qquad \alpha\neq1, \]

the fixed point is

\[ R_* = \frac{\beta}{1-\alpha}, \]

and

\[ \boxed{ R_n-R_* = \alpha^n(R_0-R_*). } \]

Therefore, for the scalar affine model on \(\mathbb R\),

\[ \boxed{ |\alpha|<1 \Longrightarrow R_n\to R_* \text{ for every finite }R_0\in\mathbb R. } \]

The result is global for this affine model, not merely local.

21. Nonlinear Root Stability Kept Local

September 3, 2026
ROOT STABILITY

For a differentiable nonlinear Root map, the Jacobian criterion remains a local statement.

\[ \boxed{ \rho(J_F(R_*))<1 } \]

is used under standard hypotheses as a sufficient local asymptotic-attraction condition.

This local result is not conflated with the global affine result.

23. Passport Dynamic Closure Added

September 3, 2026
PASSPORT DYNAMICS

Static Task sufficiency is now explicitly distinguished from autonomous reduced evolution.

For Passport representation

\[ B_P: X \longrightarrow Q \]

and full evolution

\[ \Phi: X \longrightarrow X, \]

dynamic closure requires

\[ \boxed{ B_P\circ\Phi = \widetilde\Phi_P\circ B_P } \]

for some

\[ \widetilde\Phi_P: B_P(X) \longrightarrow B_P(X). \]
\[ \boxed{ \text{Task sufficiency} \not\Rightarrow \text{dynamic closure}. } \]

24. Minimal Repair Optimization Corrected

September 3, 2026
GURF PASSPORT OPTIMIZATION CORRECTION

Earlier public formulas used an unconditional minimum:

\[ \min_q\operatorname{Cost}(q). \]

Because existence of a minimizing repair need not be known, the general formulation is now

\[ \boxed{ \inf_{ q\in\mathcal Q_{\mathrm{adm}} } \operatorname{Cost}(q) } \]

subject to the required repair condition.

The symbol \(\min\) is reserved for cases where attainment is established.

25. Passport Re-entry Made Explicitly Partial

September 3, 2026
PASSPORT RE-ENTRY CORRECTION

Export does not automatically imply re-entry.

If

\[ E: X \longrightarrow Y_E \]

exports Passport information and the receiver accepts only

\[ R: D_R \subseteq Y_E \longrightarrow Z, \]

then

\[ \boxed{ D_{R\circ E} = \{x\in X:E(x)\in D_R\}. } \]

Re-entry is lawful only on this actual composite domain and under all additional receiving constraints.

26. BM-SQ-01 Structured Quotient Result

BM-SQ-01 PROVED FINITARY ALGEBRA

In the finitary algebraic sector, a Passport equivalence supports descended Operations only when it is compatible with those Operations:

\[ \boxed{ x_i\sim_Py_i \quad \forall i \Longrightarrow \sigma(x_1,\ldots,x_n) \sim_P \sigma(y_1,\ldots,y_n). } \]

Under this condition,

\[ \overline\sigma ([x_1]_P,\ldots,[x_n]_P) = [\sigma(x_1,\ldots,x_n)]_P \]

is well-defined.

27. Structured Quotient Counterexample Preserved

COUNTEREXAMPLE BM

On

\[ X=\mathbb R^2, \]

define

\[ (x_1,x_2)\sim_P(y_1,y_2) \Longleftrightarrow x_1=y_1. \]

Coordinate swapping can distinguish classes that the raw equivalence had identified.

The example remains an explicit demonstration that:

\[ \boxed{ \text{equivalence relation} \not\Rightarrow \text{operation-compatible quotient}. } \]

28. Stochastic Semantics Firewall

STOCHASTIC CORRECTION

Stochastic transformations are represented using appropriate kernels rather than deterministic function semantics.

\[ M: X \longrightarrow \mathcal P(Y), \] \[ \boxed{ M^\dagger\varphi(x) = \mathbb E [ \varphi(Y)\mid X=x ]. } \]

Measurability, probability-law equality, and coupling remain explicit.

29. Nondeterministic Quantifier Firewall

NONDETERMINISTIC CORRECTION
\[ \Diamond_R(U) = \{x:\exists y\in U,\ xRy\}, \] \[ \Box_R(U) = \{x:\forall y,\ xRy\Rightarrow y\in U\}. \]

Existential reachability and universal safety remain distinct.

30. Joint Feasibility Firewall

QUANTIFIERS CORRECTION

The distinction

\[ \forall c\;\exists x_c \]

versus

\[ \exists x\;\forall c \]

is now explicit.

Common feasibility requires

\[ \boxed{ \bigcap_{c\in\mathcal C} P_c \neq \varnothing. } \]

31. Differential Privacy Representation Corrected

PRIVACY STOCHASTIC CORRECTION

Differential privacy was separated from ordinary exact Passport equivalence.

For neighboring inputs

\[ x\sim_{\mathrm{adj}}x' \]

and randomized mechanism \(M\),

\[ \boxed{ \Pr[M(x)\in S] \le e^\varepsilon \Pr[M(x')\in S] + \delta. } \]

Privacy therefore requires probabilistic comparison of output laws rather than exact equality classes.

46. Failure Preservation Policy

RESEARCH METHOD FAILURE

Failed arguments, counterexamples, invalid generalizations, and broken assumptions are preserved when they constrain future research.

\[ \boxed{ \text{failed derivation} \Longrightarrow \text{new mathematical constraint}. } \]

Corrections should identify why the earlier route failed rather than silently removing it from the formal record.

47. Novelty Policy

RESEARCH METHOD PRIOR ART

Mathematical derivation determines whether a claimed consequence follows from stated assumptions.

Literature review determines whether an equivalent result was already known.

\[ \boxed{ \text{mathematical truth} \neq \text{historical novelty}. } \]
