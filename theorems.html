1. Theorem Standard

A result is labeled a theorem only when its conclusion follows mathematically from explicitly stated assumptions.

The registry distinguishes:

Classification Meaning
Theorem proved result under stated assumptions
Proposition proved mathematical statement used within the framework
Lemma proved supporting result
Corollary result following directly from an earlier proved statement
Conditional theorem theorem whose assumptions include additional structural hypotheses
Counterexample explicit construction showing that a stronger claim is false

2. Novelty and Proof Are Separate

A valid proof establishes mathematical truth under its assumptions.

It does not by itself establish historical novelty, priority, independent validation, or physical realization.

Many supporting results used by BM and GURF are instances of established mathematics.

Their role in this registry is to make the logical architecture explicit.

3. Passport Equivalence Theorem

Project identifier: not yet assigned

Status: proved

Let \(X\) be a set and let

\[ b_c: X \longrightarrow Y_c, \qquad c\in\mathcal C \]

be a family of functions.

Define

\[ x\sim_P x' \quad\Longleftrightarrow\quad b_c(x)=b_c(x') \quad \forall c\in\mathcal C. \]

Then \(\sim_P\) is an equivalence relation on \(X\).

Proof

Reflexivity follows because

\[ b_c(x)=b_c(x) \]

for every \(c\).

Symmetry follows because

\[ b_c(x)=b_c(x') \Longrightarrow b_c(x')=b_c(x). \]

For transitivity, if

\[ x\sim_P x' \quad\text{and}\quad x'\sim_P x'', \]

then for every \(c\),

\[ b_c(x) = b_c(x') = b_c(x''), \]

so

\[ x\sim_P x''. \]

Therefore \(\sim_P\) is reflexive, symmetric, and transitive. \(\square\)

4. Exact Recoverability Theorem

Project identifier: not yet assigned

Status: proved

Let

\[ r: X \longrightarrow Y \]

be an observation and

\[ T: X \longrightarrow W \]

a task.

The following are equivalent:

(i) There exists

\[ \widetilde T: r(X) \longrightarrow W \]

such that

\[ \boxed{ T = \widetilde T \circ r. } \]

(ii)

\[ \boxed{ r(x)=r(x') \Longrightarrow T(x)=T(x') } \]

for all \(x,x'\in X\).

Proof

Assume (i). If

\[ r(x)=r(x'), \]

then

\[ T(x) = \widetilde T(r(x)) = \widetilde T(r(x')) = T(x'). \]

Hence (ii).

Conversely, assume (ii).

For \(y\in r(X)\), choose any \(x\in X\) satisfying

\[ r(x)=y. \]

Define

\[ \widetilde T(y) = T(x). \]

Condition (ii) guarantees that this does not depend on the chosen representative \(x\).

Thus \(\widetilde T\) is well-defined and

\[ T(x) = \widetilde T(r(x)). \]

Hence (i). \(\square\)

5. Passport Sufficiency Corollary

Status: proved corollary

Let \(B_P\) be the combined Passport observation map.

Passport \(P\) is sufficient for task \(T\) if and only if

\[ \boxed{ x\sim_P x' \Longrightarrow T(x)=T(x'). } \]

Equivalently,

\[ \boxed{ \sim_P \subseteq \sim_T. } \]

6. Completion-Fibre Sufficiency Theorem

Project identifier: not yet assigned

Status: proved

Let

\[ r_\alpha: X \longrightarrow Y_\alpha, \qquad \alpha\in A, \]

and let

\[ \mathfrak C_A(\ell) = \bigcap_{\alpha\in A} r_\alpha^{-1}(\ell_\alpha). \]

A task

\[ T: X \longrightarrow W \]

factors through the combined observation exactly when \(T\) is constant on every nonempty completion fibre.

Equivalently,

\[ \boxed{ \left| T \left( \mathfrak C_A(\ell) \right) \right| \le 1 } \]

for every observation value \(\ell\).

Proof

Define the combined observation

\[ r_A(x) = (r_\alpha(x))_{\alpha\in A}. \]

The fibre of \(r_A\) over \(\ell\) is exactly

\[ r_A^{-1}(\ell) = \mathfrak C_A(\ell). \]

The result therefore follows immediately from the Exact Recoverability Theorem. \(\square\)

7. Parallel Observation Refinement Theorem

Project identifier: not yet assigned

Status: proved

Let

\[ F: X\longrightarrow Y \]

and

\[ G: X\longrightarrow Z. \]

Define the joint observation

\[ H=(F,G): X\longrightarrow Y\times Z. \]

Then

\[ \boxed{ \sim_H = \sim_F \cap \sim_G. } \]

Moreover,

\[ \boxed{ H^{-1}(y,z) = F^{-1}(y) \cap G^{-1}(z). } \]

Proof

By definition,

\[ H(x)=H(x') \]

if and only if

\[ F(x)=F(x') \quad\text{and}\quad G(x)=G(x'). \]

This is exactly

\[ x\sim_F x' \quad\text{and}\quad x\sim_G x'. \]

The fibre identity follows from the same coordinatewise condition. \(\square\)

8. Deterministic Serial Information-Loss Theorem

Project identifier: not yet assigned

Status: proved

Let

\[ F: X\longrightarrow Y \]

and

\[ G: Y\longrightarrow Z. \]

Then

\[ \boxed{ F(x)=F(x') \Longrightarrow (G\circ F)(x) = (G\circ F)(x'). } \]

Equivalently,

\[ \boxed{ \sim_F \subseteq \sim_{G\circ F}. } \]

Proof

If

\[ F(x)=F(x'), \]

applying \(G\) to both sides gives

\[ G(F(x)) = G(F(x')). \]

Therefore the composite cannot distinguish the two states. \(\square\)

Consequence

A deterministic downstream operation cannot reconstruct a distinction already erased by an upstream deterministic map unless additional information enters through another channel.

9. BM-SQ-01 — Structured Quotient Theorem

Project identifier: BM-SQ-01

Sector: finitary algebraic

Status: proved / canonical BM structured-quotient result

Let

\[ A=(X,\Sigma) \]

be a finitary algebra.

Let \(\sim_P\) be the raw equivalence relation induced by a Passport.

For every \(n\)-ary operation

\[ \sigma: X^n \longrightarrow X, \]

define the candidate quotient operation by

\[ \overline{\sigma} \left( [x_1]_P,\ldots,[x_n]_P \right) = \left[ \sigma(x_1,\ldots,x_n) \right]_P. \]

Then the induced \(\Sigma\)-operations are well-defined on

\[ X/{\sim_P} \]

if and only if \(\sim_P\) is a \(\Sigma\)-congruence:

\[ \boxed{ x_i\sim_P y_i \quad \forall i \Longrightarrow \sigma(x_1,\ldots,x_n) \sim_P \sigma(y_1,\ldots,y_n) } \]

for every \(\sigma\in\Sigma\).

Proof

First assume \(\sim_P\) is a \(\Sigma\)-congruence.

Suppose

\[ [x_i]_P = [y_i]_P \qquad \forall i. \]

Then

\[ x_i\sim_P y_i \qquad \forall i. \]

Congruence gives

\[ \sigma(x_1,\ldots,x_n) \sim_P \sigma(y_1,\ldots,y_n). \]

Hence

\[ \left[ \sigma(x_1,\ldots,x_n) \right]_P = \left[ \sigma(y_1,\ldots,y_n) \right]_P. \]

Therefore the quotient operation is independent of representatives and is well-defined.

Conversely, assume every candidate quotient operation is well-defined.

Let

\[ x_i\sim_P y_i \qquad \forall i. \]

Then

\[ [x_i]_P = [y_i]_P. \]

Since \(\overline{\sigma}\) is well-defined,

\[ \overline{\sigma} ([x_1]_P,\ldots,[x_n]_P) = \overline{\sigma} ([y_1]_P,\ldots,[y_n]_P). \]

Therefore

\[ \left[ \sigma(x_1,\ldots,x_n) \right]_P = \left[ \sigma(y_1,\ldots,y_n) \right]_P, \]

so

\[ \sigma(x_1,\ldots,x_n) \sim_P \sigma(y_1,\ldots,y_n). \]

Thus \(\sim_P\) is a congruence. \(\square\)

10. Raw Observation Is Not Enough — Counterexample

Let

\[ X=\mathbb R^2 \]

and define

\[ (x_1,x_2) \sim_P (y_1,y_2) \quad\Longleftrightarrow\quad x_1=y_1. \]

Consider the swap operation

\[ \sigma(x_1,x_2) = (x_2,x_1). \]

Take

\[ x=(1,2), \qquad y=(1,9). \]

Then

\[ x\sim_P y. \]

But

\[ \sigma(x) = (2,1), \qquad \sigma(y) = (9,1), \]

and therefore

\[ \sigma(x) \not\sim_P \sigma(y). \]

Thus observational equivalence alone does not guarantee an operation-compatible quotient.

11. Interface Factorization Theorem

Project identifier: not yet assigned

Status: proved

Let

\[ P_1: X \longrightarrow Q_1 \]

and let

\[ H: X \longrightarrow Q_2. \]

There exists

\[ G: P_1(X) \longrightarrow Q_2 \]

satisfying

\[ \boxed{ H = G\circ P_1 } \]

if and only if

\[ \boxed{ P_1(x)=P_1(x') \Longrightarrow H(x)=H(x'). } \]

Proof

This is the Exact Recoverability Theorem applied with task \(H\). \(\square\)

BM Interface Corollary

If

\[ H=P_2\circ F, \]

then a compatible represented map \(G\) satisfying

\[ P_2\circ F = G\circ P_1 \]

exists exactly when \(P_2\circ F\) is constant on the fibres of \(P_1\).

12. Dynamic Continuation Theorem

Project identifier: not yet assigned

Status: proved

Let

\[ r: X\longrightarrow Y \]

be an observation,

\[ \Phi_t: X\longrightarrow X \]

an evolution, and

\[ T: X\longrightarrow W \]

a future task.

Then the future task is exactly recoverable from the present observation if and only if

\[ \boxed{ r(x)=r(x') \Longrightarrow T(\Phi_t(x)) = T(\Phi_t(x')). } \]

Equivalently, there exists

\[ \widetilde T_t: r(X) \longrightarrow W \]

with

\[ \boxed{ T\circ\Phi_t = \widetilde T_t \circ r. } \]

Proof

Apply the Exact Recoverability Theorem to the task

\[ T_t = T\circ\Phi_t. \]

\(\square\)

13. Repair Refinement Proposition

Project identifier: not yet assigned

Status: proved proposition

Let

\[ r: X\longrightarrow Y \]

be an existing observation and

\[ q: X\longrightarrow Z \]

an added repair observation.

Then

\[ \boxed{ \sim_{(r,q)} \subseteq \sim_r. } \]

Thus adding an observation can refine equivalence classes but cannot make them coarser.

Proof

If

\[ (r,q)(x) = (r,q)(x'), \]

then in particular

\[ r(x)=r(x'). \]

Therefore

\[ x\sim_r x'. \]

\(\square\)

14. Sufficiency Is Preserved Under Refinement

Status: proved corollary

Suppose observation \(r\) is sufficient for task \(T\).

If another observation \(s\) is at least as informative in the sense

\[ \sim_s \subseteq \sim_r, \]

then \(s\) is also sufficient for \(T\).

Proof

Sufficiency of \(r\) gives

\[ \sim_r \subseteq \sim_T. \]

Therefore

\[ \sim_s \subseteq \sim_r \subseteq \sim_T. \]

Hence \(s\) is sufficient for \(T\). \(\square\)

15. Separate Feasibility Does Not Imply Joint Feasibility

Status: proved by counterexample

From

\[ P_c\neq\varnothing \qquad \forall c \]

it does not follow that

\[ \bigcap_c P_c \neq \varnothing. \]

Counterexample

Let

\[ X=\{0,1\}, \]

and choose

\[ P_1=\{0\}, \qquad P_2=\{1\}. \]

Both sets are nonempty, but

\[ \boxed{ P_1\cap P_2 = \varnothing. } \]

16. Quantifier-Scope Non-Equivalence

Status: exact logical distinction

In general,

\[ \boxed{ \forall c\, \exists x_c \; P(c,x_c) } \]

does not imply

\[ \boxed{ \exists x\, \forall c \; P(c,x). } \]

Take \(c\in\{0,1\}\) and define

\[ P(c,x) \quad\Longleftrightarrow\quad x=c. \]

For every \(c\), there exists \(x_c=c\).

But no single \(x\) equals both \(0\) and \(1\).

17. Stochastic Response-Law Factorization

Status: proved at the response-law set level; measurable realization requires the appropriate measurable factorization conditions

Let

\[ r: X \longrightarrow Y \]

and let

\[ M: X \longrightarrow \mathcal P(Z) \]

assign a probability law to each state.

There exists a map

\[ \widetilde M: r(X) \longrightarrow \mathcal P(Z) \]

satisfying

\[ M = \widetilde M \circ r \]

if and only if

\[ \boxed{ r(x)=r(x') \Longrightarrow M(x,\cdot)=M(x',\cdot). } \]

Proof

Treat \(M\) as an ordinary map whose codomain is the set of probability laws on \(Z\).

The statement is then exactly the Exact Recoverability Theorem. \(\square\)

If \(\widetilde M\) is required to be a measurable Markov kernel on a specified measurable space, additional measurable-structure hypotheses must be checked.

18. Existential and Universal Nondeterministic Responses Differ

Status: exact distinction

For relation

\[ R\subseteq X\times Y \]

and target set \(U\subseteq Y\), define

\[ \Diamond_R(U) = \{x:\exists y\in U,\ xRy\}, \]

and

\[ \Box_R(U) = \{x:\forall y,\ xRy\Rightarrow y\in U\}. \]

In general,

\[ \boxed{ \Diamond_R(U) \neq \Box_R(U). } \]

Let one state \(x\) have two possible outputs:

\[ xR0, \qquad xR1. \]

Let

\[ U=\{1\}. \]

Then

\[ x\in\Diamond_R(U) \]

because output \(1\) is possible.

But

\[ x\notin\Box_R(U) \]

because output \(0\notin U\) is also possible.

19. Affine Repeated-Root Theorem

Classification: supporting standard dynamical-systems theorem

Not a universal BM law.

Consider

\[ R_{n+1} = \alpha R_n+\beta, \qquad \alpha\neq1. \]

Define

\[ R_* = \frac{\beta}{1-\alpha}. \]

Then

\[ \boxed{ R_n-R_* = \alpha^n (R_0-R_*). } \]

Equivalently,

\[ \boxed{ R_n = R_* + \alpha^n (R_0-R_*). } \]

Proof

Since

\[ R_* = \alpha R_*+\beta, \]

subtracting \(R_*\) from the recurrence gives

\[ R_{n+1}-R_* = \alpha(R_n-R_*). \]

Iterating,

\[ R_n-R_* = \alpha^n(R_0-R_*). \]

\(\square\)

20. Affine Root Convergence Corollary

Status: proved

If

\[ |\alpha|<1, \]

then

\[ \boxed{ \lim_{n\to\infty} R_n = R_*. } \]

Proof

Since

\[ |\alpha|<1, \]

one has

\[ \alpha^n\to0. \]

Therefore

\[ R_n-R_* = \alpha^n(R_0-R_*) \to0. \]

\(\square\)

21. Worked Root Example Corollary

For

\[ R_{n+1} = \frac12R_n+1, \qquad R_0=0, \]

the fixed point is

\[ R_*=2, \]

and

\[ \boxed{ R_n = 2 \left( 1-2^{-n} \right). } \]

The error is

\[ \boxed{ |R_*-R_n| = 2^{1-n}. } \]

The corresponding numerical convergence figure appears in the Equation Registry.

22. Invariant-Transfer Criterion

Classification: exact condition for a represented invariant

Let

\[ F: X \longrightarrow Y, \]

and let

\[ C_X: X \longrightarrow V, \qquad C_Y: Y \longrightarrow V. \]

The invariant represented by \(C_X\) is exactly preserved under \(F\) through \(C_Y\) if

\[ \boxed{ C_Y\circ F = C_X. } \]

This equation does not create a conservation law.

It states what exact preservation means once the relevant invariant has already been mathematically established.

23. Dynamic Closure Theorem

Status: exact factorization statement

Let

\[ R: X \longrightarrow Z \]

be a reduced representation and

\[ \Phi: X \longrightarrow X \]

a one-step evolution.

There exists a reduced evolution

\[ \widetilde\Phi: R(X) \longrightarrow R(X) \]

satisfying

\[ \boxed{ R\circ\Phi = \widetilde\Phi \circ R } \]

if and only if

\[ \boxed{ R(x)=R(x') \Longrightarrow R(\Phi(x)) = R(\Phi(x')). } \]

Proof

Apply the Exact Recoverability Theorem to the task

\[ T = R\circ\Phi. \]

\(\square\)

24. Exact Versus Approximate Results

The theorems above involving equality are exact.

Replacing equality by

\[ d(a,b)\le\varepsilon \]

creates a different mathematical statement.

Approximate versions require their own assumptions, metrics, stability bounds, and proofs.
