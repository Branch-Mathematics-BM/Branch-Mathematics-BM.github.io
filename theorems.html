1. How to Read the Registry

A theorem can be correct without being new, and a useful BM or GURF specialization can rely on classical mathematics. This registry says which is which directly on every result.

Label Meaning in this registry
Classical infrastructure Established mathematics used directly: factorization, congruence, projection, Markov composition, relational composition, PDE identities, and similar results.
BM structural result A proved statement formulated in BM roles or interfaces. This label does not assert external historical novelty.
GURF response result A proved response/task/observation specialization used by GURF. Again, framework use and historical novelty are separate questions.
Conditional result The conclusion is proved only under additional hypotheses stated in the entry.
Applied identity A domain-specific established identity carried through BM/GURF structure without being relabeled as a new theorem of that domain.
Counterexample / firewall An explicit construction showing why a stronger transport, quotient, closure, quantifier, privacy, or semantic claim is invalid.
\[ \boxed{ \text{proof status} \quad\text{and}\quad \text{mathematical provenance} \quad\text{are recorded separately}. } \]

2. Proof, Framework Role, and Novelty Are Different Questions

The registry uses a result only for what its proof establishes. A classical theorem can be central to BM or GURF without becoming a new theorem merely because the framework gives it a new role.

\[ \boxed{ \text{proved} \not\Rightarrow \text{historically novel} \not\Rightarrow \text{physically realized}. } \]

Conversely, a result formulated naturally in BM can be mathematically useful even while external priority remains a separate literature question.

4. Passport Equivalence Theorem

Classification: Theorem
Provenance: Classical infrastructure used as a BM Passport specialization
Sector: deterministic Set semantics

Statement

Let \(b_c:X\to Y_c\) be a family of functions indexed by \(c\in\mathcal C\). Define

\[ x\sim_Px' \iff b_c(x)=b_c(x') \quad\forall c\in\mathcal C. \]

Then \(\sim_P\) is an equivalence relation on \(X\).

Proof

Reflexive. For every \(c\), \(b_c(x)=b_c(x)\).
Symmetric. Equality of each \(b_c(x)\) and \(b_c(x')\) is symmetric.
Transitive. If \(b_c(x)=b_c(x')\) and \(b_c(x')=b_c(x'')\) for every \(c\), then \(b_c(x)=b_c(x'')\) for every \(c\).

Hence \(\sim_P\) is reflexive, symmetric, and transitive. \(\square\)

Limits
  • This is the kernel equivalence of a family of deterministic observations. It is not a universal model of stochastic, metric, privacy, quantum, or relational indistinguishability.
Reading note

The theorem is elementary but important because every later exact Set-level quotient argument depends on knowing exactly which equivalence is being used.

Definitions: Passport · Passport equivalence
Worked examples: Finite fibres

5. Exact Recoverability / Fibre-Factorization Theorem

Classification: Theorem
Provenance: Classical factorization criterion central to GURF exact sufficiency
Sector: deterministic Set semantics

Statement

Let \(r:X\to Y\) and \(T:X\to W\). The following are equivalent:

  1. there exists \(\widetilde T:r(X)\to W\) with \(T=\widetilde T\circ r\);
  2. \(T\) is constant on every fibre of \(r\):
\[ \boxed{ r(x)=r(x') \Longrightarrow T(x)=T(x'). } \]

Proof

(1) \(\Rightarrow\) (2). If \(r(x)=r(x')\), then \[ T(x)=\widetilde T(r(x)) =\widetilde T(r(x')) =T(x'). \]
(2) \(\Rightarrow\) (1). For \(y\in r(X)\), choose any \(x\) with \(r(x)=y\) and define \[ \widetilde T(y)=T(x). \] Fibre constancy makes this independent of the chosen representative. Therefore \(T=\widetilde T\circ r\).

\(\square\)

Consequences

  • Exact Task sufficiency can be tested fibre by fibre.
  • The factor map is required only on \(r(X)\); extension to all of \(Y\) is a separate question.
Definitions: Exact sufficiency · Fibre
Worked examples: Exact sufficiency · Finite fibre audit

6. Passport Sufficiency Corollary

Classification: Corollary
Provenance: GURF response specialization of Exact Recoverability
Sector: deterministic Set semantics

Statement

Let \(B_P:X\to Q_P\) be a combined Passport map. A Task \(T:X\to W\) is exactly recoverable from the Passport exactly when

\[ x\sim_Px' \Longrightarrow T(x)=T(x'). \] Equivalently, \[ \boxed{\sim_P\subseteq\sim_T.} \]

Proof

Apply Exact Recoverability to \(r=B_P\). The fibres of \(B_P\) are exactly the Passport-equivalence classes. \(\square\)

Limits
  • Sufficiency is relative to the declared Task.
  • The result is exact and deterministic.
Definitions: Passport · Task
Worked examples: Task-specific Passport · Passport failure

7. Completion-Fibre Sufficiency Theorem

Classification: Theorem
Provenance: GURF exact-set specialization of fibre factorization
Sector: deterministic Set semantics with a valid joint product

Statement

Let \(r_\alpha:X\to Y_\alpha\) and define the joint observation \(r_A(x)=(r_\alpha(x))_{\alpha\in A}\). For \(\ell=(\ell_\alpha)_{\alpha\in A}\), define

\[ \mathfrak C_A(\ell) = \bigcap_{\alpha\in A} r_\alpha^{-1}(\ell_\alpha). \]

A Task \(T:X\to W\) factors through \(r_A\) exactly when \(T\) is constant on every nonempty Completion Fibre. Equivalently,

\[ \boxed{ \left|T(\mathfrak C_A(\ell))\right|\le1 \quad\text{for every }\ell. } \]

Proof

By construction \(r_A^{-1}(\ell)=\mathfrak C_A(\ell)\). Apply Exact Recoverability to \(r_A\). \(\square\)

Limits
  • The Set product is not automatically the correct joint object in measurable, topological, categorical, or quantum settings.
  • A nonempty collection of marginal fibres does not itself specify a probabilistic coupling.
Definitions: Completion fibre · Combined Passport
Worked examples: Finite completion fibre · Coupling

8. Minimal Exact Task-Quotient Proposition

Classification: Proposition
Provenance: GURF structural use of a classical quotient fact
Sector: deterministic Set semantics

Statement

For \(T:X\to W\), define \(x\sim_Tx'\iff T(x)=T(x')\). Among equivalence relations \(E\) on \(X\) whose quotient representation is exactly sufficient for \(T\), \(\sim_T\) is the coarsest allowable identification:

\[ E\subseteq\sim_T. \]

The quotient \(X/{\sim_T}\) therefore merges every pair that can be merged without destroying exact determination of \(T\).

Proof

If the quotient by \(E\) is sufficient for \(T\), equal quotient classes must imply equal Task values. Thus \(xEx'\Rightarrow T(x)=T(x')\), so \(E\subseteq\sim_T\). Conversely the quotient by \(\sim_T\) is sufficient, because \(T\) is constant on its own equivalence classes. \(\square\)

Consequences

  • The exact Task itself generates a canonical maximal compression at the level of Set partitions.
Limits
  • Additional algebraic, topological, smooth, measurable, privacy, or dynamic structure can forbid this quotient or require more information.
Definitions: Task equivalence · Structured quotient
Worked examples: Parity Task

9. Finite Exact Carrier Cardinality Bound

Classification: Theorem
Provenance: GURF information bound from elementary finite-set factorization
Sector: finite deterministic Set semantics

Statement

Let \(X\) be finite, \(r:X\to Y\), and \(T:X\to W\). If \(r\) is exactly sufficient for \(T\), then

\[ \boxed{|r(X)|\ge |T(X)|.} \]

The lower bound is attained by \(r=T\), or by any representation whose realized states are in bijection with \(T(X)\).

Proof

Sufficiency gives \(T=\widetilde T\circ r\) for \(\widetilde T:r(X)\to W\). Because every value in \(T(X)\) is \(\widetilde T(y)\) for some \(y\in r(X)\), the restriction \(\widetilde T:r(X)\to T(X)\) is surjective. A surjection between finite sets requires \(|r(X)|\ge|T(X)|\). \(\square\)

Consequences

  • Exact finite compression cannot use fewer realized carrier states than there are distinct Task values.
Limits
  • This is a cardinality bound, not a bit-complexity, rate-distortion, statistical sufficiency, or computational-complexity theorem.
Definitions: Exact sufficiency
Worked examples: Finite fibres

10. Parallel Observation Refinement Theorem

Classification: Theorem
Provenance: Classical product-map identity used by GURF
Sector: deterministic Set semantics

Statement

For \(F:X\to Y\), \(G:X\to Z\), and \(H=(F,G):X\to Y\times Z\),

\[ \boxed{\sim_H=\sim_F\cap\sim_G} \] and \[ \boxed{H^{-1}(y,z)=F^{-1}(y)\cap G^{-1}(z).} \]

Proof

\(H(x)=H(x')\) holds exactly when both coordinates agree. The fibre identity is the same coordinatewise condition. \(\square\)

Consequences

  • Adding a genuinely independent exact observation can refine ambiguity.
  • Parallel observations cannot make the exact equivalence coarser.
Limits
  • A pair of marginal stochastic laws is not automatically a joint observation without a coupling.
Definitions: Information refinement
Worked examples: Parallel Tree · Sensor fusion

11. Deterministic Serial Information-Loss Theorem

Classification: Theorem
Provenance: Classical composition fact used as a GURF data-processing firewall
Sector: deterministic Set semantics

Statement

Let \(F:X\to Y\) and \(G:Y\to Z\). Then

\[ F(x)=F(x') \Longrightarrow (G\circ F)(x)=(G\circ F)(x'), \] hence \[ \boxed{\sim_F\subseteq\sim_{G\circ F}.} \]

Proof

Apply the single-valued map \(G\) to the equality \(F(x)=F(x')\). \(\square\)

Consequences

  • A deterministic downstream Operation cannot recover a distinction already erased upstream unless additional information enters by another channel.
Limits
  • The theorem does not say downstream processing cannot improve noise, stability, calibration, or a different Task.
  • Other semantic sectors need their own data-processing statements.
Definitions: Transformation · Information refinement
Worked examples: Serial loss

12. BM-SQ-01 — Structured Quotient Criterion

Classification: Theorem
Provenance: Classical congruence criterion organized as BM structured-quotient result
Sector: finitary algebra
Project identifier: BM-SQ-01

Statement

Let \(A=(X,\Sigma)\) be a finitary algebra and let \(\sim_P\) be a Passport-induced equivalence relation. For each \(n\)-ary operation \(\sigma\in\Sigma\), define

\[ \overline\sigma([x_1]_P,\ldots,[x_n]_P) = [\sigma(x_1,\ldots,x_n)]_P. \]

These quotient Operations are well-defined for every \(\sigma\in\Sigma\) if and only if \(\sim_P\) is a congruence:

\[ x_i\sim_Px_i'\ \forall i \Longrightarrow \sigma(x_1,\ldots,x_n) \sim_P \sigma(x_1',\ldots,x_n'). \]

Proof

Congruence implies well-defined quotient. Different representatives of the same classes are coordinatewise equivalent; compatibility sends them to equivalent outputs, so the output class is independent of representatives.
Well-defined quotient implies congruence. If \(x_i\sim_Px_i'\), then \([x_i]_P=[x_i']_P\). Equality of the quotient Operations on these equal input classes gives equality of the output classes, which is the congruence condition.

\(\square\)

Consequences

  • A Passport equivalence suitable for observation is not automatically suitable for algebraic quotienting.
Limits
  • This is universal-algebra mathematics. The BM contribution here is the structural use of the criterion, not a claim to have discovered congruences.
  • Topology, probability, operator theory, geometry, and quantum structures require their native quotient conditions.
Definitions: Structured quotient · Congruence
Worked examples: Structured quotient · False quotient

14. Interface Factorization Theorem

Classification: Theorem
Provenance: BM structural specialization of Exact Recoverability
Sector: deterministic Set semantics

Statement

Let \(P_1:X\to Q_1\), \(F:X\to Y\), and \(P_2:Y\to Q_2\). A map \(G:P_1(X)\to Q_2\) satisfying

\[ \boxed{P_2\circ F=G\circ P_1} \]

exists exactly when \(P_2\circ F\) is constant on the fibres of \(P_1\).

Proof

Apply Exact Recoverability with \(r=P_1\) and \(T=P_2\circ F\). \(\square\)

Consequences

  • The theorem tests whether the receiving Passport can be computed from the sending Passport without reconstructing the full source state.
Limits
  • The result certifies only the declared Set-level Passport factorization; native structural compatibility of \(F\), \(P_1\), and \(P_2\) is separate.
Definitions: Interface · Passport

15. Typed Composite-Domain Theorem

Classification: Theorem
Provenance: BM structural statement of the exact domain of composition
Sector: partial deterministic maps

Statement

Let \(F:D_F\subseteq X\to Y\) and \(G:D_G\subseteq Y\to Z\). Then the composite \(G\circ F\) is defined exactly on

\[ \boxed{ D_{G\circ F} = \{x\in D_F:F(x)\in D_G\}. } \]

Proof

For \(G(F(x))\) to be meaningful, first \(x\) must lie in \(D_F\), and then the produced value \(F(x)\) must lie in \(D_G\). These conditions are also sufficient. \(\square\)

Consequences

  • A declared codomain \(Y\) does not mean every \(F(x)\) is admissible for the next Operation.
  • Composite admissibility can be strictly smaller than the source domain.
Definitions: Composition · Admissibility
Worked examples: Domain shrink · Reciprocal singularity

16. Dynamic Continuation Theorem

Classification: Theorem
Provenance: GURF response specialization of fibre factorization
Sector: deterministic dynamics

Statement

Let \(r:X\to Y\), let \(\Phi_t:X\to X\) be a declared evolution, and let \(T:X\to W\) be a future Task. The future Task \(T\circ\Phi_t\) is determined exactly by the current observation \(r\) if and only if

\[ r(x)=r(x') \Longrightarrow T(\Phi_t(x))=T(\Phi_t(x')). \]

Proof

Apply Exact Recoverability to the Task \(T_t=T\circ\Phi_t\). \(\square\)

Consequences

  • A present representation can be sufficient for a future Task even if it does not reconstruct the entire future state.
Limits
  • One time \(t\) does not imply all-time closure.
  • Stochastic and nondeterministic evolution require sector-correct continuation semantics.
Definitions: Continuation · Task
Worked examples: Dynamic closure example

17. Repair Refinement Proposition

Classification: Proposition
Provenance: GURF response result from the joint-observation identity
Sector: deterministic Set semantics

Statement

Let \(r:X\to Y\) be an observation and \(q:X\to Z\) an added repair observation. Then

\[ \boxed{\sim_{(r,q)}\subseteq\sim_r.} \]

Proof

If \((r,q)(x)=(r,q)(x')\), then in particular \(r(x)=r(x')\). \(\square\)

Consequences

  • Adding exact observation information cannot enlarge a deterministic ambiguity class.

  • A refinement may still fail the actual Task or may worsen numerical stability, cost, privacy, or other objectives.

21. Stochastic Response-Law Factorization at the Law-Value Level

Classification: Theorem with measurable-realization caveat
Provenance: Set-level factorization applied to probability-law-valued responses
Sector: map into a space of probability laws

Statement

Let \(r:X\to Y\) and let \(M:X\to\mathcal P(Z)\) assign a probability law to each source state. There exists a Set map \(\widetilde M:r(X)\to\mathcal P(Z)\) with \(M=\widetilde M\circ r\) if and only if

\[ r(x)=r(x') \Longrightarrow M(x)=M(x') \] as probability laws.

Proof

Regard \(\mathcal P(Z)\) simply as a Set and apply Exact Recoverability. \(\square\)

22. Markov Test-Pullback Composition Theorem

Classification: Theorem
Provenance: Classical Markov-kernel composition identity used by BM/GURF
Sector: measurable stochastic semantics

Statement

Let \(K:X\rightsquigarrow Y\) and \(L:Y\rightsquigarrow Z\) be Markov kernels. Define

\[ (L\circ K)(x,A) = \int_Y L(y,A)\,K(x,dy). \]

For every bounded measurable test function \(\phi:Z\to\mathbb R\),

\[ \boxed{ (L\circ K)^\dagger\phi = K^\dagger(L^\dagger\phi). } \]

Proof

By definition, \[ (L\circ K)^\dagger\phi(x) = \int_Z\phi(z)(L\circ K)(x,dz). \]
Substitute the composed kernel and use Tonelli/Fubini under the bounded measurable hypotheses: \[ = \int_Y \left[ \int_Z\phi(z)L(y,dz) \right]K(x,dy). \]
The inner integral is \(L^\dagger\phi(y)\), hence the result is \(K^\dagger(L^\dagger\phi)(x)\).

\(\square\)

Consequences

  • Stochastic composition propagates test observables by nested expectation, not by ordinary point substitution.
Definitions: Stochastic semantics
Worked examples: Kernel multiplication

24. Existential and Universal Nondeterministic Responses Differ

Classification: Exact distinction with counterexample
Provenance: Classical relational semantics used as a BM/GURF sector firewall
Sector: relations

Statement

For a relation \(R\subseteq X\times Y\) and \(U\subseteq Y\), define

\[ \Diamond_R(U)=\{x:\exists y\in U,\ xRy\}, \] \[ \Box_R(U)=\{x:\forall y,\ xRy\Rightarrow y\in U\}. \]

In general \(\Diamond_R(U)\neq\Box_R(U)\).

If one state \(x\) satisfies \(xR0\) and \(xR1\), and \(U=\{1\}\), then \(x\in\Diamond_R(U)\) but \(x\notin\Box_R(U)\).

Proof

The counterexample proves the distinction. \(\square\)

Definitions: Existential reachability · Universal safety
Worked examples: Finite relation

25. Relational May/Must Composition Theorem

Classification: Theorem
Provenance: Classical relational composition identity used by BM/GURF
Sector: relations

Statement

Let \(R\subseteq X\times Y\), \(S\subseteq Y\times Z\), and \(U\subseteq Z\). Then

\[ \boxed{ \Diamond_{S\circ R}(U) = \Diamond_R(\Diamond_S(U)) } \] and \[ \boxed{ \Box_{S\circ R}(U) = \Box_R(\Box_S(U)). } \]

Proof

\(x\in\Diamond_{S\circ R}(U)\) exactly when there exist \(y,z\) with \(xRy\), \(ySz\), and \(z\in U\). This is exactly \(x\in\Diamond_R(\Diamond_S(U))\).
\(x\in\Box_{S\circ R}(U)\) exactly when every \(z\) reachable through some \(y\) lies in \(U\). Equivalently, every \(R\)-successor \(y\) has all of its \(S\)-successors in \(U\), i.e. \(y\in\Box_S(U)\). Hence \(x\in\Box_R(\Box_S(U))\).

\(\square\)

Consequences

  • The may/must quantifier is preserved through relational composition instead of being silently interchanged.
Definitions: Nondeterministic semantics

Let a Root value \(R_n\) be proposed for re-entry through a partial update \(F:D_F\subseteq X\to X\). The iteration

is lawful only while \(R_n\in D_F\) and every required receiving Passport and admissibility condition remains satisfied at each step.

28. Affine Repeated-Root Formula

Classification: Theorem
Provenance: Classical affine iteration used as a Root example
Sector: scalar deterministic dynamics

Statement

Let \(R_{n+1}=\alpha R_n+\beta\) with \(\alpha\neq1\). Define \(R_*=\beta/(1-\alpha)\). Then

\[ \boxed{ R_n = R_*+\alpha^n(R_0-R_*). } \]

Proof

Subtract the fixed-point equation \(R_*=\alpha R_*+\beta\):

\[ R_{n+1}-R_*=\alpha(R_n-R_*). \]

Iterating gives \(R_n-R_*=\alpha^n(R_0-R_*)\). \(\square\)

Limits
  • The affine formula does not generalize unchanged to nonlinear or state-dependent updates.
Worked examples: Fixed-point Seed · Repeated Root

29. Affine Root Global-Convergence Corollary

Classification: Corollary
Provenance: Classical contraction of an affine scalar map
Sector: scalar deterministic dynamics

Statement

Under the affine formula, if \(|\alpha|<1\), then for every finite \(R_0\in\mathbb R\),

\[ \boxed{\lim_{n\to\infty}R_n=R_*.} \]

Proof

Since \(|\alpha|<1\), \(\alpha^n\to0\). Substitute into the affine formula. \(\square\)

Limits
  • Global convergence here belongs to this scalar affine system; local Jacobian criteria for nonlinear systems are different results.

32. Dynamic Closure Theorem

Classification: Theorem
Provenance: GURF response specialization of Exact Recoverability
Sector: deterministic dynamics

Statement

Let \(\Phi:X\to X\) be an evolution and \(R:X\to Y\) a reduced representation. A reduced map \(\widetilde\Phi:R(X)\to R(X)\) satisfying

\[ \boxed{R\circ\Phi=\widetilde\Phi\circ R} \]

exists if and only if

\[ R(x)=R(x') \Longrightarrow R(\Phi(x))=R(\Phi(x')). \]

Proof

Apply Exact Recoverability with observation \(R\) and Task \(R\circ\Phi\). \(\square\)

Consequences

  • Dynamic closure is exact factorization of future reduced state through present reduced state.
Limits
  • One-step closure does not by itself establish regularity, stability, accuracy under perturbation, or a physical reduced model.

33. Task Sufficiency Does Not Imply Dynamic Closure

Classification: Counterexample
Provenance: Exact GURF distinction
Sector: deterministic dynamics

Statement

Let \(X=\mathbb R^2\), \(R(x_1,x_2)=x_1\), and \(T(x_1,x_2)=x_1\). Then \(R\) is exactly sufficient for the current Task \(T\). Define

\[ \Phi(x_1,x_2)=(x_2,x_2). \]

For \(x=(0,1)\) and \(x'=(0,2)\),

\[ R(x)=R(x')=0, \qquad R(\Phi(x))=1, \qquad R(\Phi(x'))=2. \]

Hence no \(\widetilde\Phi\) can satisfy \(R\circ\Phi=\widetilde\Phi\circ R\).

Proof

The two states have equal reduced present state but unequal reduced next state, violating the closure criterion. \(\square\)

34. Leaf Propagation Admissibility Theorem

Classification: Theorem
Provenance: BM structural result
Sector: typed partial deterministic Interactions

Statement

Let \(I:D_I\to Z\), let \(\ell:Z\to L\) extract a Leaf, and let a later Interaction be \(J:D_J\subseteq L\times C\to W\). Then the derived composite

\[ K(x,c)=J(\ell(I(x)),c) \]

is defined exactly on

\[ \boxed{ D_K = \{(x,c):x\in D_I,\;(\ell(I(x)),c)\in D_J\}. } \]

Proof

The first condition is necessary and sufficient to form \(I(x)\) and the Leaf \(\ell(I(x))\); the second is necessary and sufficient for the receiving Interaction \(J\). Together they are exactly the composite domain. \(\square\)

Consequences

  • Being a Leaf records provenance; it does not waive later domain, type, unit, or Passport checks.

35. Serial Passport-Defect Localization Theorem

Classification: Theorem
Provenance: BM structural result
Sector: deterministic predicate Passports on a two-stage chain

Statement

Let \(f:A\to B\) and \(g:B\to C\) be composable Operations. Let \(P_A,P_B,P_C\) be Boolean Passport predicates. Define local defects

\[ D_f = \{a:P_A(a)\land\neg P_B(f(a))\}, \] \[ D_g = \{b:P_B(b)\land\neg P_C(g(b))\}, \]

and the composite defect

\[ D_{g\circ f} = \{a:P_A(a)\land\neg P_C(g(f(a)))\}. \]

Then

\[ \boxed{ D_{g\circ f} \subseteq D_f\cup f^{-1}(D_g). } \]

Proof

Take \(a\in D_{g\circ f}\). Then \(P_A(a)\) holds and \(P_C(g(f(a)))\) fails.

If \(P_B(f(a))\) fails, then by definition \(a\in D_f\).
If \(P_B(f(a))\) holds, then \(f(a)\in D_g\), because its \(P_B\) predicate holds while the final \(P_C\) predicate fails. Hence \(a\in f^{-1}(D_g)\).

These two cases are exhaustive, proving the inclusion. \(\square\)

Consequences

  • A failed final Passport can be localized to an earlier Interface failure or to a later defect pulled back through the upstream map.
  • The same case-splitting argument extends inductively to finite chains.
Limits
  • The inclusion can be strict: an early Passport failure may later map to a state satisfying the final predicate, so not every local defect is necessarily a final defect.
  • Non-Boolean Passports require an appropriate defect semantics.
Definitions: Interface defect · Passport
Worked examples: Composition Passport failure · Full-system repair

36. Path-Coherence Transitivity Proposition

Classification: Proposition
Provenance: BM structural result from transitivity of the destination equivalence
Sector: parallel deterministic paths

Statement

Let \(F_p,F_q,F_r\) be three paths into a common destination \(D\), defined on a common subset \(U\), and let \(\simeq_D\) be an equivalence relation. If for every \(x\in U\),

\[ F_p(x)\simeq_DF_q(x) \quad\text{and}\quad F_q(x)\simeq_DF_r(x), \]

then \(F_p(x)\simeq_DF_r(x)\) for every \(x\in U\).

Proof

Apply transitivity of \(\simeq_D\) pointwise on \(U\). \(\square\)

Limits
  • The common domain matters; pairwise coherence on unrelated domains does not create a global comparison.
  • The destination relation must actually be transitive.
Definitions: Path coherence
Worked examples: Parallel coherence · Shared-domain case

37. Finite Deterministic Network Evaluation Theorem

Classification: Theorem
Provenance: Finite DAG induction formulated as a BM Network evaluation result
Sector: finite deterministic acyclic Network

Assumptions

  • The dependency graph is finite and acyclic.
  • Every source node has one specified admissible value.
  • Every non-source node \(v\) has a single-valued Operation \(F_v\) on the tuple of predecessor outputs.
  • For the actual predecessor tuple, \(F_v\) is defined and maps into the node's admissible domain.

Statement

Under these assumptions, the Network has a unique evaluation at every node. Moreover every computed node value is admissible.

Proof

A finite DAG admits a topological ordering \(v_1,\ldots,v_N\). Evaluate source nodes first. Suppose all nodes before \(v_k\) have unique admissible values. Every predecessor of \(v_k\) occurs earlier in the topological order, so its predecessor tuple is already uniquely known. The declared single-valued Operation \(F_{v_k}\) therefore gives one unique value, and the admissibility hypothesis puts it in \(A_{v_k}\). Induction completes the evaluation. \(\square\)

Consequences

  • Local deterministic Operations plus an acyclic dependency structure are enough for unique finite evaluation.
  • Cycles, nondeterminism, implicit equations, or multiple fixed points require additional mathematics.
Definitions: Network · Configuration
Worked examples: Full system · Navigation network

38. Exact Task-Diameter Criterion

Classification: Theorem
Provenance: GURF metric reformulation of exact fibre constancy
Sector: deterministic representation with metric Task space

Statement

Let \(r:X\to Y\), \(T:X\to(W,d)\). For a nonempty fibre \(C_y=r^{-1}(y)\), define

\[ \operatorname{diam}_T(C_y) = \sup_{x,x'\in C_y}d(T(x),T(x')). \]

Then \(r\) is exactly sufficient for \(T\) if and only if

\[ \boxed{ \operatorname{diam}_T(C_y)=0 \quad\forall y\in r(X). } \]

Proof

If \(r\) is sufficient, \(T\) is constant on every fibre, so every diameter is zero. Conversely, in a metric space, diameter zero implies all Task values in the fibre coincide. Apply Exact Recoverability. \(\square\)

Definitions: Task diameter · Exact sufficiency

39. Approximate Fibre-Diameter Reconstruction Proposition

Classification: Proposition
Provenance: GURF approximate response bound
Sector: metric Task space with a chosen section

Assumptions

  • A section \(s:r(X)\to X\) is chosen with \(r(s(y))=y\).
  • Every nonempty fibre has Task diameter at most \( arepsilon\).

Statement

Define \(\widehat T(y)=T(s(y))\). Then for every \(x\in X\),

\[ \boxed{ d\!\left(T(x),\widehat T(r(x))\right) \le\varepsilon. } \]

Proof

The points \(x\) and \(s(r(x))\) lie in the same fibre. By the fibre-diameter hypothesis, the distance between their Task values is at most \(\varepsilon\). \(\square\)

41. Gaussian Local Fisher-Carrier Theorem

Classification: Theorem
Provenance: Classical Gaussian Fisher-information / orthogonal-projection result used by current GURF task-aware compression
Sector: finite-dimensional Gaussian inference

Assumptions

  • Observation \(y\in\mathbb R^n\) has covariance \(V>0\) independent of the scalar parameter \(\theta\) locally.
  • The mean \(\mu(\theta)\) is differentiable.
  • Compression in whitened coordinates is an orthogonal projection \(P=P^T=P^2\).

Statement

Define the whitened local Task direction

\[ g = V^{-1/2}\frac{d\mu}{d\theta}. \]

The full local Fisher information is \(I_{\rm full}=\|g\|^2\). After projection \(P\),

\[ \boxed{ I(P)=\|Pg\|^2\le\|g\|^2. } \]

Equality holds exactly when \(g\in\operatorname{ran}(P)\). For any nonzero \(g\), the one-dimensional subspace \(\operatorname{span}\{g\}\) therefore preserves all local Fisher information for the scalar Task.

Proof

Because \(P\) is an orthogonal projection,

\[ g=Pg+(I-P)g, \qquad Pg\perp(I-P)g. \]

Pythagoras gives \[ \|g\|^2 = \|Pg\|^2+\|(I-P)g\|^2 \ge\|Pg\|^2. \] Equality holds iff \((I-P)g=0\), i.e. \(g\in\operatorname{ran}(P)\). \(\square\)

Consequences

  • A variance-maximizing compression such as generic PCA need not preserve the parameter direction \(g\).
  • The theorem identifies the minimal local linear carrier for one Gaussian scalar parameter.
Limits
  • This is local, Gaussian, and covariance-frozen. Nonlinear, non-Gaussian, parameter-dependent-covariance, global, or multi-parameter problems require different analysis.
Definitions: Task · Approximate sufficiency

42. Finite-Hypothesis Mahalanobis-Carrier Theorem

Classification: Theorem
Provenance: Classical linear algebra used by GURF task-aware finite-hypothesis compression
Sector: finite-dimensional whitened Euclidean geometry

Statement

Let whitened model points be \(z_1,\ldots,z_M\in\mathbb R^n\). Define

\[ D= [\,z_2-z_1,\ldots,z_M-z_1\,]. \]

An orthogonal projection \(P\) preserves every pairwise Euclidean distance among the \(z_a\) exactly if and only if

\[ \operatorname{col}(D)\subseteq\operatorname{ran}(P). \]

Hence the smallest exact linear carrier has dimension

\[ \boxed{\operatorname{rank}(D).} \]

Proof

Every pairwise difference \(z_a-z_b\) is a linear combination of the columns \(z_j-z_1\), so all pairwise differences lie in \(\operatorname{col}(D)\).
Orthogonal projection preserves the norm of a vector \(v\) exactly iff \(v\in\operatorname{ran}(P)\). Therefore all pairwise distances are preserved iff all pairwise difference vectors lie in the projection range, equivalently iff \(\operatorname{col}(D)\subseteq \operatorname{ran}(P)\).

The minimal dimension is the dimension of that column space, \(\operatorname{rank}(D)\). \(\square\)

Limits
  • This is an exact finite-hypothesis linear result in whitened Euclidean geometry, not a universal nonlinear compression theorem.

43. Periodic Incompressible Navier–Stokes Energy Identity

Classification: Applied identity
Provenance: Classical PDE identity carried as a BM Leaf derivation
Sector: smooth incompressible Navier–Stokes on a periodic domain

Assumptions

  • \(u,p,f\) are sufficiently smooth for the integrations by parts.
  • \( abla\cdot u=0\).
  • The spatial domain is periodic, so boundary flux integrals vanish.

Statement

For

\[ \partial_tu+(u\cdot\nabla)u = -\nabla p+\nu\Delta u+f, \qquad \nabla\cdot u=0, \]

define

\[ E(t)=\frac12\int_\Omega|u|^2dx, \quad D(t)=\nu\int_\Omega|\nabla u|^2dx, \quad F(t)=\int_\Omega f\cdot u\,dx. \]

Then

\[ \boxed{\frac{dE}{dt}=-D+F.} \]

Proof

Take the \(L^2\) inner product with \(u\). The time term gives \(dE/dt\). The convective term is the integral of a divergence plus a term proportional to \(\nabla\cdot u\), so it vanishes. The pressure term also vanishes by incompressibility and periodicity. Integration by parts gives \(\int u\cdot\Delta u=-\int|\nabla u|^2\). The forcing term remains as \(F(t)\). \(\square\)

Limits
  • This identity does not solve the three-dimensional regularity problem.
Worked examples: Full derivation

44. Three-Dimensional Vorticity / Enstrophy Identity

Classification: Applied identity
Provenance: Classical PDE identity carried as a distinct BM Leaf family
Sector: smooth 3D incompressible Navier–Stokes on a periodic domain

Statement

With \(\omega=\nabla\times u\),

\[ \partial_t\omega+(u\cdot\nabla)\omega = (\omega\cdot\nabla)u+\nu\Delta\omega+\nabla\times f. \]

Therefore

\[ \boxed{ \frac12\frac{d}{dt}\int_\Omega|\omega|^2dx = \int_\Omega\omega\cdot(\omega\cdot\nabla)u\,dx - \nu\int_\Omega|\nabla\omega|^2dx + \int_\Omega\omega\cdot(\nabla\times f)\,dx. } \]

Proof

Take curl of the incompressible equation, dot the vorticity equation with \(\omega\), integrate, use incompressibility and periodicity to remove transport, and integrate the Laplacian term by parts. \(\square\)

Limits
  • The stretching term is one reason the 3D problem differs sharply from the 2D enstrophy structure.
  • The identity is not a regularity theorem.
Worked examples: Vorticity derivation

45. Lattice Wilson-Loop Gauge-Invariance Identity

Classification: Applied identity
Provenance: Classical lattice gauge-theory identity
Sector: finite lattice gauge theory

Statement

Let link variables transform as

\[ U_{xy}\mapsto \Omega_xU_{xy}\Omega_y^{-1}. \]

For a closed loop \(C=(x_0x_1)(x_1x_2)\cdots(x_{m-1}x_0)\), define

\[ W(C)= \operatorname{tr} \left( U_{x_0x_1}\cdots U_{x_{m-1}x_0} \right). \]

Then \(W(C)\) is gauge invariant.

Proof

After transformation, adjacent factors \(\Omega_{x_j}^{-1}\Omega_{x_j}\) cancel. The loop product becomes \(\Omega_{x_0}U(C)\Omega_{x_0}^{-1}\). Trace is invariant under conjugation, so \(W(C)\) is unchanged. \(\square\)

Limits
  • This finite identity does not establish four-dimensional quantum Yang–Mills existence or a mass gap.

46. Qubit Dephasing Population/Coherence Identity

Classification: Applied identity
Provenance: Classical quantum-information channel calculation
Sector: qubit density operators

the computational-basis populations are preserved while the off-diagonal coherence is multiplied by \(\lambda\).

47. Exact and Approximate Results Must Stay Separate

Equality-based theorems above are exact. Replacing equality by a metric, divergence, risk, confidence interval, operator norm, probability bound, or tolerance creates a different mathematical claim.

\[ \boxed{ \text{exact equality} \neq \text{approximate control} } \]

Approximate results therefore state the comparison structure, assumptions, constants, error propagation, and probability semantics when relevant.

48. Privacy Is Not an Exact-Equivalence Corollary

Differential privacy is governed by inequalities between output laws, not by ordinary exact Passport-equivalence classes. A typical requirement is

\[ \Pr[M(x)\in S] \le e^\varepsilon \Pr[M(x')\in S] +\delta \] for adjacent inputs \(x\sim_{\rm adj}x'\).

Exact Set-level recoverability or quotient theorems must therefore not be transported into privacy semantics without rebuilding the probabilistic hypotheses.
