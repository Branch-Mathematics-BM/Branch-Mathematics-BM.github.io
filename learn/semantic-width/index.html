Semantic Width Explained

Semantic width measures how much distinction a system must preserve for a declared receiver and tolerance. It is task-specific complexity, not simply native state size.

Short version: two native states count as different only when the declared task, context, dynamics, or receiver still needs to tell them apart.

Why raw dimension is not enough

A system can have a huge state space while a receiver cares about only one bit of behavior. Another receiver may require nearly the full state.

Raw dimension therefore answers a different question from task-specific complexity.

Semantic width asks how many receiver-distinct behaviors must survive, not how many native coordinates the system originally had.

Exact semantic width

Start with a finite native state space X and an exact task equivalence E. Two states are equivalent when the declared response treats them identically.

The exact quotient is:

X / E

If the quotient has N classes, then a natural exact width is:

w(0) = log₂ |X / E|

This is not Shannon entropy. It is a log-cardinality measure of how many exact receiver-distinct classes must remain available.

BM firewall: log-cardinality is not automatically thermodynamic information, Shannon entropy, or Landauer cost.

A simple parity example

Many native states, one semantic bit

Suppose the native state is an n-bit string:

x ∈ {0,1}n

The native state space has:

2n states

But the receiver asks only for parity:

T(x) = x₁ ⊕ x₂ ⊕ ··· ⊕ xₙ

There are only two task-distinct response classes: even parity and odd parity.

|X / ET| = 2

Therefore:

w(0) = log₂ 2 = 1 bit

Native state size grows with n. Exact task width stays at one bit.

But locality can make the implementation wider

The parity example also shows an important distinction between centralized semantic complexity and distributed realization cost.

If all bits are already aggregated centrally, parity is one bit. If n separate sources must send enough information across separate cuts before aggregation, the distributed architecture may require much more total communication.

centralized semantic width ≠ distributed realization width

BM calls this kind of gap a locality or realization surcharge.

Approximate semantic width

Exact equality is often too strict. Suppose the receiver tolerates error ε.

Instead of asking how many exact response classes exist, we ask how many response representatives are needed so that every admissible response lies within tolerance ε of one of them.

N(ε) = covering number of the receiver-visible profile set
w(ε) = log₂ N(ε)

As tolerance grows, fewer distinct representatives may be needed.

Small tolerance
Moderate tolerance
Large tolerance

The picture is conceptual: tolerance trades representation width against approximation error.

Behavioral distance

To define approximate distinction, BM compares states through their declared receiver-visible behaviors.

For a family of responses Bj with output metrics dj, one behavioral pseudometric is:

DP(x,x′) = maxj dj(Bj(x), Bj(x′))

Native states can be far apart in their original geometry and still be semantically close if the receiver sees almost the same behavior.

Conversely, two states that are close natively can be semantically far apart if a sensitive task amplifies their difference.

Finite systems and graph coloring

In finite exact or thresholded problems, semantic width can become a graph-coloring problem.

Build a graph whose vertices are native states and connect two vertices whenever they are too different to share one representation cell.

{x,x′} is an edge when D(x,x′) > ε

Then an admissible representation corresponds to coloring incompatible states differently.

N(ε) = χ(Gε)
w(ε) = log₂ χ(Gε)

In scalar-output radius semantics, the threshold can shift to 2ε; the precise graph rule depends on the declared cell-radius semantics.

This matters because approximate representation can be combinatorially hard even when the underlying state description is simple.

Not every metric behaves like a tree

If the behavioral distance is ultrametric, tolerance classes are naturally nested. In that special case, threshold partitions behave canonically across scales.

In general metrics, threshold neighborhoods need not form a partition. That is why graph coloring or covering geometry is needed instead of simply declaring “states within ε are equivalent.”

ordinary metric thresholding need not be transitive

Dynamic semantic width

A distinction may be invisible now and become important later. Dynamic semantic width therefore compares entire finite-horizon task histories.

Dh(x,x′) = max0≤j≤h d(TΦjx, TΦjx′)

As the horizon grows, the receiver can potentially distinguish more states.

longer horizon ⇒ at least as many required distinctions

In exact finite systems, the horizon equivalences form a nested chain:

Eh+1 ⊆ Eh

Semantic width can grow with time

Suppose two states produce the same task output for the first five steps and then diverge on step six. A short-horizon model may lawfully merge them. A longer-horizon model may not.

This creates a time-dependent complexity profile:

h ↦ wh(ε)

BM uses this to study distinction latency, memory, causal scheduling, and spacetime semantic width.

Infinite-dimensional systems

Semantic width becomes especially useful when native state dimension is infinite.

Consider a PDE state u and a finite-horizon receiver-visible profile:

Pτ,H(u) = (TΦtu)t∈[τ,τ+H]

The approximate semantic width is:

wτ,H(ε) = log₂ N(Pτ,H(K), ε)

If the profile set is relatively compact in the declared profile metric, then the covering number is finite at every positive tolerance.

Infinite native dimension does not imply infinite approximate semantic width.

Heat equation intuition

Positive-time heat evolution smooths high-frequency structure. For suitable bounded initial sets and receiver norms, this can make the visible profile family compact at positive time.

That gives finite positive-tolerance semantic width even though the underlying PDE state space is infinite-dimensional.

The full unsmoothed unit ball at time zero can still have infinite covering number at small tolerance.

t = 0: width may be infinite
t > 0: width may become finite

This is a semantic compression effect caused by the dynamics and the declared observation—not a statement that the PDE has become finite-dimensional.

Wave-like systems can behave differently

Conservative or weakly smoothing dynamics may preserve high-frequency distinctions rather than suppressing them.

Therefore, the heat-equation conclusion cannot simply be transferred to a wave equation or other conservative system.

BM firewall: smoothing in one dynamical sector does not imply compressibility in another.

Semantic width is receiver-relative

The same native system can have radically different semantic widths under different Passports.

Receiver task Possible semantic burden
Parity only One bit in the centralized exact finite example
Count of ones About log₂(n+1) bits
Full reconstruction n bits for an n-bit state

There is therefore no single semantic width of a system independent of receiver, task, context, horizon, and tolerance.

Width versus construction complexity

A small semantic interface does not automatically mean it is easy to discover.

The minimal quotient may be tiny while deciding which native states belong to the same contextual class is computationally hard.

representation width ≠ complexity of constructing the representation

BM keeps those notions separate.

Width versus realization

A low-width abstract quotient may also fail to admit the implementation class the system requires.

For example, a quotient may exist as a set but fail to admit a smooth Euclidean realization of the desired dimension. A quantum task quotient may exist algebraically but fail to admit the required CPTP physical channel without extra structure.

semantic compression ≠ automatic admissible implementation

Why BM uses the word “semantic”

The word is meant in a precise task-relative sense: width is measured after asking what differences change the declared response.

It is not intended to mean linguistic meaning or subjective interpretation.

Semantic width is the width of distinctions that still matter to the declared mathematics of the receiver.

What semantic width is good for

The concept becomes useful whenever the full native description is larger than the distinctions the receiver actually needs.

Area Semantic-width question
Model reduction How many task-distinct reduced states are truly necessary?
PDEs How complex is the receiver-visible profile family at tolerance ε?
Networks How much distinction must cross a cut?
Control How much state must remain observable for the declared control task?
Quantum systems How large a carrier is required for the declared operator system or algebra?
Distributed systems How much semantic content exists centrally, and what locality surcharge appears when it must be realized?

The main distinction

Native complexity

How large, high-dimensional, detailed, or difficult is the underlying system description?

Semantic complexity

How many distinctions must remain visible for the declared response, context, horizon, and tolerance?

Branch Mathematics needs both. It does not replace native complexity with semantic complexity; it distinguishes them.

Where this leads

Once width is task-relative, a new set of questions becomes natural:

How does width change under dynamics? How much extra width is caused by locality? How does tolerance change the required representation? When does coupling create new distinctions? How much width must cross an interface? How much of it can be recovered later?

Those questions lead into approximate model reduction, PDE semantic width, distributed cuts, spacetime width, many-body locality, and quantum carriers.
