Recovery

Recovery After Compression

Once a representation merges two native states, can the missing distinction ever come back? Branch Mathematics separates what deterministic memory can preserve, what later observations can reacquire, and what is permanently unavailable relative to the declared sources.

Short version: deterministic computation cannot recreate a distinction that its current state no longer contains. A discarded distinction can become available again only if some later source supplies new distinguishing information.

Compression changes what the system can know

Suppose two native states x and x′ are mapped to the same reduced state:

R(x) = R(x′)

Any later deterministic computation that depends only on R(x) must treat those two cases identically, because it receives exactly the same input in both cases.

Once two states become identical inside the retained representation, deterministic processing of that representation alone cannot tell them apart again.

The basic no-recreation principle

Let M be retained memory derived only from the current representation. If:

R(x)=R(x′)

then every deterministic update of that retained state must remain identical for the two cases until some external distinction enters.

This is not a thermodynamic claim and not a universal physical information law. It is a statement about distinguishability under deterministic maps.

BM firewall: deterministic memory cannot recreate a distinction that the retained state has already merged.

Three different notions of memory

BM keeps several forms of memory separate because they have different mathematical power.

1
Latent native memory The system secretly retains distinctions not visible in the coarse output.
2
Autonomous coarse memory The system stores only variables generated from its already-compressed state.
3
Observation or history memory The system stores distinctions supplied by earlier measurements or external inputs.

The first can preserve hidden distinctions. The second cannot recreate them after loss. The third can contain distinctions because observations supplied them before or after the compression event.

A simple example

Two native states become one coarse state

Suppose:

R(a)=R(b)=q

The coarse system now stores only q.

Any deterministic function F of that stored state satisfies:

F(R(a)) = F(q) = F(R(b))

So no later deterministic transformation of q alone can answer the question “was the original state a or b?”

What can make the distinction return?

A distinction can become available again if a later source produces different observations for the formerly merged possibilities.

Suppose at a later time the system receives an observation:

O(x)

If:

O(a) ≠ O(b)

then the new observation reacquires the distinction.

No new observation

The distinction remains unavailable because every deterministic update starts from the same retained state.

New distinguishing observation

The distinction can re-enter the retained state because the system receives genuinely different new data.

The causal transition condition

Let Et describe which native states are still identified by the retained state at time t. Let Ot+1 be the new observation.

A lawful next retained equivalence must satisfy:

Et ∩ ker(Ot+1) ⊆ Et+1

In plain language: if two states were already merged and the new observation still cannot distinguish them, the next retained state cannot legitimately separate them.

New distinctions require new distinguishing provenance.

Reacquisition is not the same as recovery from memory

The words can sound similar, but BM separates them carefully.

Mechanism What happens
Retention The distinction was never discarded.
Latent memory The distinction survives internally even if not visible at the output.
Reacquisition A later external observation supplies the distinction again.
Impossible recreation No retained variable or later observation distinguishes the merged cases.

Keep or reacquire?

If a distinction matters now, then becomes irrelevant for a while, then matters again later, the system has a design choice.

Needed distinction is live
Gap temporarily not needed
Choice keep or discard
Reacquire? new observation may restore it
Needed again future deadline

If holding the distinction through the gap costs H, while reacquiring it later costs R, then under additive independent assumptions the local choice is:

keep if H ≤ R

But multiple distinctions can interact nonlinearly through shared state or graph-coloring constraints, so the many-distinction problem need not decompose into independent choices.

Why many distinctions can couple

Two distinctions may each be cheap to discard separately, while discarding both forces a more expensive representation later.

This is one reason the correct state variable for exact causal scheduling is often the retained partition:

Πt = X / Et

rather than a collection of independent yes/no flags.

Path lifting: can a coarse history come from one native history?

Recovery also has a trajectory-level form.

Suppose the coarse system records a path:

π = (q₀,q₁,…,qk)

BM asks whether there exists a single native initial state whose evolution produces that entire coarse history.

C(π) = ⋂j=0k Φ-j(R-1(qj))

The path is realizable exactly when:

C(π) ≠ ∅

This blocks a subtle error: using one native witness for the first part of the path and a different native witness for a later part.

BM firewall: compatible coarse states at each time do not guarantee that one native trajectory realizes the entire coarse history.

No witness switching

If a coarse path is supposed to represent one evolving native system, the underlying witness must remain consistent across time.

A sequence of separately possible coarse transitions can still fail to correspond to any single native trajectory.

This is important in reduced models, hidden-state systems, PDE histories, and any architecture where future validity depends on one coherent underlying state.

Finite hidden memory versus finite sliding-window memory

A system may admit an exact finite hidden-state realization even when no fixed-length recent observation window is sufficient.

The hidden state can summarize arbitrarily old history in a finite latent variable, while a raw sliding window may need unbounded length.

BM firewall: finite hidden-state memory does not imply finite sliding-window memory.

Pre-revelation storage

Sometimes future context will reveal which task matters, but that context arrives only after the system must decide what to store.

Then the storage must preserve every distinction that could matter under any future allowed context.

ker(S) ⊆ EY

Conceptually, pre-revelation storage must be fine enough for the whole family of possible later tasks.

Context revelation does not restore discarded distinctions

Learning which question will be asked is not the same as learning the answer.

If two states were merged before the context was revealed, and the new context tells the system only which task to perform, that context alone does not recreate the missing state distinction.

task identity ≠ state identity
BM firewall: context revelation does not automatically recover distinctions discarded before the revelation.

Recovery across a causal cut

Suppose information crosses a cut at time t. If a future task depends on a distinction and no later observation can distinguish the relevant states, then the cut must preserve that distinction now.

no later distinguishing source ⇒ distinction must cross the cut

This gives BM's Last-Chance viewpoint: some distinctions have a final moment at which they can still be retained before they become unrecoverable relative to the declared architecture.

Approximate reacquisition

At positive tolerance, reacquisition does not require perfect identification. It requires enough margin to restore the task distinction robustly.

If a sensor's nominal separation margin is m and sensor uncertainty is ν, a robust reacquisition condition takes the form:

m - 2ν > threshold

A later measurement may therefore reset accumulated model uncertainty if it supplies a sufficiently strong new observation.

Reacquisition can sometimes be better than retention

Approximate models accumulate propagation error. If the system can take a fresh, accurate observation later, discarding and reacquiring a distinction can sometimes be better than carrying a noisy approximation for a long interval.

Retain

Keep the distinction continuously, but allow modeling or propagation error to accumulate.

Reacquire

Drop the distinction and later reset it using a fresh sufficiently accurate observation.

So “never discard anything” is not generally the optimal architecture.

Recovery in quantum systems

The same receiver-relative idea appears in quantum information, but the physical rules are different.

A noise process can destroy full-state recoverability while leaving a smaller observable algebra exactly recoverable.

BM therefore asks what task algebra survives, not merely whether the entire state can be reconstructed.

full-state failure does not imply failure of every weaker quantum task

But quantum recovery must still be realized by an admissible physical channel such as a CPTP map. Algebraic recoverability and physical recoverability remain distinct tests.

Recovery in PDE and distributed systems

In PDEs, a discarded interior distinction may become visible later through a boundary observation if the dynamics transport it to the measured region.

In distributed networks, a distinction lost on one route may still be available through another route if that route retained an independent witness.

Recovery therefore depends on provenance:

where did the distinguishing evidence survive, and when can it reach the receiver?

The BM recovery test

When asking whether a lost distinction can return, BM checks:

1
Was it truly discarded? Or does latent state still retain it?
2
What new sources arrive later? Measurements, context, peer messages, routes, or environmental observations.
3
Do those sources actually distinguish the merged cases? If not, no deterministic update can separate them.
4
Does the distinction arrive before the deadline? Eventual observability is not enough for a time-constrained task.
5
Is the reacquired distinction robust enough? Approximate recovery must survive declared uncertainty and tolerance.

The key idea

A distinction can be retained, hidden, or reacquired—but it cannot be conjured from a deterministic state that no longer contains it.

This principle connects BM's work on causal memory, interface design, retention versus reacquisition, distributed cuts, path lifting, and task-relative recovery.
