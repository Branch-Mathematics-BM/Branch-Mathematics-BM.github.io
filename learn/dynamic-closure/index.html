Dynamic Closure Explained

Dynamic closure asks whether a reduced state can determine its own lawful future evolution without secretly depending on distinctions that were discarded during compression.

Short version: a reduced model is dynamically closed only when any two native states represented as the same reduced state also produce the same reduced successor.

Why dynamic closure matters

A reduced representation can be perfectly adequate for answering a task at the current moment and still fail as a dynamical model.

The reason is simple: the representation may have merged native states that look identical now but evolve differently later.

A reduced state is not dynamically complete merely because it is currently correct.

This is one of the cleanest examples of why Branch Mathematics tracks distinctions through time rather than judging a compression only at the instant it is created.

Static sufficiency first

Suppose a native state space X is compressed by a representation R : X → Q, and the current task is T : X → Y.

The representation is statically sufficient for the task if the task factors through the representation:

T = T̄R

Equivalently:

ker(R) ⊆ ker(T)

If R(x)=R(x′), then the task must also give T(x)=T(x′).

That says nothing yet about what happens after the system evolves.

Now add dynamics

Let the native dynamics be f : X → X.

We want a reduced evolution f̄ : Q → Q satisfying:

Rf = f̄R

This commuting condition means that evolving first and then compressing gives the same result as compressing first and then evolving entirely inside the reduced state space.

The exact criterion is:

Rf = f̄R   ⇔   ker(R) ⊆ ker(Rf)

In plain language:

If two native states look identical to the reduced model now, they must still look identical to the reduced model after one native update.

A tiny example

Four native states

Let the native states be:

X = {a, b, c, d}

Suppose the reduction merges them into two coarse states:

R(a)=R(b)=0,    R(c)=R(d)=1

Now define the native dynamics:

Native state Successor Reduced successor
a c 1
b a 0
c c 1
d d 1

States a and b are represented identically because both map to 0. But after one native step:

R(f(a)) = 1,    R(f(b)) = 0

So there is no single reduced update rule that knows what state 0 should do. The reduced model is not dynamically closed.

Why the reduced update does not exist

A reduced update rule would need to assign one successor to the reduced state 0.

But 0 stands for both a and b, and those states demand different reduced successors.

0 → 1   because of a
0 → 0   because of b

The problem is not numerical error. It is structural ambiguity created by the quotient.

Static sufficiency and dynamic closure are different tests

Static test

If two states are merged, do they give the same answer to the current task?

Dynamic test

If two states are merged, do they produce the same reduced successor after evolution?

A representation can pass the first test and fail the second.

Permanent BM firewall: static sufficiency does not imply dynamic closure.

Successor fibres make the failure visible

For a reduced state q, define its successor fibre:

SR(q) = { R(Φx) : R(x)=q }

The reduced model is exactly closed at q if this set contains only one element.

Exact dynamic closure therefore becomes:

every successor fibre is a singleton

This viewpoint is useful because it also leads naturally to approximate closure.

Approximate closure

In many systems, exact equality is too strict. Instead, we ask how widely the possible reduced successors can spread.

One natural quantity is the maximum successor-fibre diameter:

α(R) = supq diam SR(q)

Another is the smallest worst-case one-step prediction radius:

δ*1 = supq rad SR(q)

These satisfy:

α(R)/2 ≤ δ*1 ≤ α(R)

Exact closure is the special case where the successor fibres collapse to singletons.

Dynamic closure is receiver-relative

The full native state may evolve differently even when the receiver does not care about those differences.

BM therefore does not require native-state equality after evolution. It requires equality only at the level that the declared reduced representation and Passport demand.

native successors may differ
while receiver-relevant successors remain identical

This is why task-relative dynamics can sometimes close even when full-state dynamics do not.

Closure over longer horizons

One-step closure is only the beginning. A system can also be examined through finite temporal horizons.

For a task T and evolution Φ, BM uses horizon response maps of the form:

βh(x) = (Tx, TΦx, …, TΦhx)

Two states are equivalent at horizon h only if their task responses agree throughout that horizon.

Eh+1 ⊆ Eh

Longer horizons can only preserve or reveal more distinctions; they cannot erase distinctions already required by shorter horizons.

Memory enters when closure fails

If a coarse state cannot evolve autonomously, additional state may be needed.

That extra state can come from several very different sources:

1
Latent native memory Keep hidden distinctions that the coarse output itself does not expose.
2
Observation-derived memory Use a history of visible outputs or measurements to disambiguate the future.
3
Contextual input Allow later information from the environment or another subsystem to restore distinctions.

BM keeps these mechanisms separate because they are not mathematically interchangeable.

Dynamic closure in model reduction

Reduced-order models often seek a lower-dimensional state that can be updated without returning to the full system.

Dynamic closure gives a direct structural test for whether that ambition is even exact at the declared level.

If closure fails, one of several things must change:

A
Refine the representation Keep more distinctions so the reduced successor becomes single-valued.
B
Add memory Use additional state to carry distinctions that the visible reduction omitted.
C
Relax exactness Accept bounded prediction error and move into approximate closure.
D
Change the Passport Require less only if the receiver contract genuinely permits it.

Dynamic closure does not guarantee physical realization

Even if the exact quotient exists mathematically, a required realization may fail to exist in the desired category.

A set-theoretic reduced state may fail to admit a continuous, smooth, local, quantum-CPTP, or otherwise admissible implementation.

Another permanent BM firewall: exact quotient does not imply admissible realization.

Why this matters across fields

Field Dynamic-closure question
Control Can the chosen reduced state be propagated without hidden variables?
PDE reduction Does a reduced interface remain sufficient after the PDE evolves?
Networks Do coarse node states determine the next coarse network state?
Stochastic systems Do aggregated states determine the next aggregated law?
Quantum systems Does the retained operator system remain sufficient under the channel dynamics?

The BM viewpoint

Dynamic closure is not a claim that every system should admit a reduced autonomous model. Sometimes it does not.

BM treats that failure as useful information. It tells us that some discarded distinction still has future consequences.

Failure of closure is evidence that the current representation is too coarse for the declared future task.

The next natural question is then: how much additional distinction must be preserved?

That leads directly to semantic width.
