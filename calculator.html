Three possible statement statuses
  • COMPUTABLE: the native symbolic engine can operate directly on it.
  • SYMBOLIC: the notation parses, but contains undefined maps/functions or other data preventing complete solution.
  • FORMAL: mathematically meaningful notation is retained even when the current CAS cannot safely infer its semantics.

This means symbols such as λ, π, ∑, ⊗, ∖, and ± no longer cause the entire Configuration to be rejected.

Calculator Semantics

Input → Classification → Dependency → Branches → Native computation → Leaves → Realization audit

Formal mathematics is not an error

\[ \boxed{ \text{unsupported by current CAS} \not\Rightarrow \text{mathematically invalid}. } \]

A formal statement remains part of the Configuration. If that statement is required for the current Branch realization, the calculator reports the realization as unresolved.

No silent deletion

\[ \boxed{ \text{unresolved obligation} \neq \text{permission to erase the obligation}. } \]

Partial reductions are not complete solutions

The calculator may simplify a computable subset while explicitly stating that formal or symbolic obligations remain.

\[ \boxed{ \text{partial native reduction} \neq \text{global realization}. } \]

Tree status

\[ \boxed{ T=(C,\xi,\Pi,\omega,\Lambda), \qquad \xi\in\mathfrak F(C;c). } \]

A Tree is certified only when the required Configuration has a lawful realization under the mathematics actually supplied.
