Semantic Width: Task-Specific Complexity

Semantic width measures the size of the receiver-visible distinction structure rather than the raw native state space. Exact width counts task-distinct classes. Approximate width measures how many tolerance-scale behavior representatives are required.

Volume II developmentUses classical metric entropy and graph theory
Abstract

Given a declared Passport, Branch Mathematics induces a behavioral pseudometric on native states by comparing only receiver-visible responses. Exact semantic width is determined by the resulting zero-distance quotient. Approximate semantic width is determined by the covering complexity of the induced profile space at tolerance ε. In finite settings, diameter semantics reduce to graph coloring; radius semantics admit sharp graph sandwiches but can require higher-order compatibility. This page develops exact and approximate width, contextual profile geometry, ultrametric structure, dynamic width, hierarchical error propagation, locality surcharge, and computational complexity.

1. Native size and task size are different quantities

Let X be a native state space. Raw dimension, cardinality, state complexity, and description length all measure properties of X itself. A receiver may need far less.

native complexity ≠ receiver-visible complexity

Semantic width is intended to quantify the latter.

2. Receiver-visible profiles

Let the Passport declare a context set C and a response map:

B : S × C → Y.

The semantic profile of a state s∈S is:

P(s)(c) = B(s,c).

Two states are exactly semantically equivalent when their profiles agree for every allowed context:

s ∼ s′ ⇔ P(s)=P(s′).

The exact task quotient is therefore S/∼.

3. Exact semantic width

In a finite system, define:

N(0)=|S/∼|,    w(0)=log₂N(0).

This is a worst-case label-capacity quantity.

Firewall: exact semantic width is not automatically Shannon entropy, mutual information, thermodynamic entropy, or Landauer cost.

4. Behavioral pseudometric

Suppose each declared response component has metric dj. Define:

DP(x,x′)=maxjdj(Bj(x),Bj(x′)).

For contextual profiles one can use:

D(x,x′)=supc∈Cd(B(x,c),B(x′,c)).

This is a pseudometric because distinct native states can have zero receiver-visible distance.

Zero-Distance QuotientBM placement of classical pseudometric structure

The relation D(x,x′)=0 is an equivalence relation. The quotient by this relation is the exact receiver-visible state space induced by the Passport.

5. Approximate semantic width

At tolerance ε>0, ask how many receiver-profile representatives are needed so every admissible state lies within tolerance of one representative.

N(ε)=𝒩(P(S),d∞,ε),    w(ε)=log₂N(ε).

This is the central approximate semantic-width quantity.

7. Finite diameter semantics and graph coloring

Require every representation cell to have behavioral diameter at most ε. Build the incompatibility graph:

{x,x′}∈E(Gε) ⇔ D(x,x′)>ε.
Finite Diameter WidthVolume II
Ndiam(ε)=χ(Gε),    wdiam(ε)=log₂χ(Gε).
Reason.

A valid cell cannot contain an incompatible edge, so every cell is an independent set. A partition into admissible cells is exactly a proper coloring.

8. Radius semantics

Decoder semantics are naturally expressed by cell radius:

rad(A)=infysupx∈Ad(P(x),y).

Define Nrad(η) as the minimum number of cells with radius at most η.

Radius–Coloring SandwichVolume II
χ(G2η) ≤ Nrad(η) ≤ χ(Gη).

The lower bound follows because radius-η implies diameter at most 2η. The upper bound follows because diameter at most η implies radius at most η.

9. Scalar-output finite contexts

For scalar output with the sup metric over a finite context set, radius feasibility reduces to a 2ε pairwise threshold, giving:

N(ε)=χ(G2ε).

10. Pairwise compatibility can be insufficient in general metrics

Equilateral-triangle obstruction

Three points can have all pairwise distances ≤2ε while requiring a common covering radius greater than ε. Thus pairwise admissibility does not imply joint decoder admissibility.

Firewall: pairwise approximate compatibility does not imply global radius-cell realizability.

11. Hypergraph formulation for radius semantics

An exact finite formulation uses a hypergraph whose forbidden hyperedges are subsets with radius greater than tolerance:

A is forbidden ⇔ rad(P(A))>ε.

An admissible semantic partition is a coloring whose color classes avoid all forbidden hyperedges.

12. Ultrametric special case

In an ultrametric:

D(x,z)≤max{D(x,y),D(y,z)}.

Threshold balls are nested or disjoint, and threshold equivalence becomes transitive.

Canonical Threshold PartitionsSpecial case

In the ultrametric case, tolerance thresholding yields canonical nested partitions across scales.

Firewall: ordinary metric thresholding need not define an equivalence relation.

13. Computational complexity

General finite diameter semantics contain graph coloring, so exact minimal-width computation is NP-hard in graph-realizable cases.

small optimal width ≠ easy optimal synthesis.

14. Dynamic semantic width

Let Φ be native evolution and T a receiver task. Define:

Dh(x,x′)=max0≤j≤hd(TΦjx,TΦjx′).

The corresponding width:

wh(ε)=log₂Nh(ε)

measures how many states must remain distinguishable through horizon h. Exact horizon equivalences satisfy Eh+1⊆Eh, so exact dynamic width is nondecreasing with horizon.

15. Distinction latency

The earliest horizon at which two states become task-distinguishable can be written:

ℓ(x,x′)=min{h:βh(x)≠βh(x′)}.

This gives a task-relative notion of when a distinction becomes operationally necessary.

16. Temporal capacity profile

In finite exact systems:

ch=log₂|X/Eh|,    Δh=ch-ch-1.

Carrying full long-horizon state too early creates:

ΓHtime=Σj=1HjΔj.

17. Contextual semantic width

For interface e, define:

Pe(s)(c)=Be(s,c),    De(s,s′)=supc∈Cd(Be(s,c),Be(s′,c)).

Then:

Ne(ε)=𝒩(Pe(Se),d∞,ε),    we(ε)=log₂Ne(ε).

This is the portable approximate interface width for the declared context family.

18. Locality surcharge

For finite exact product interfaces:

Γloc=Σilog₂|Qi|-log₂|im(B)|≥0.

This is extra capacity caused by requiring components to preserve distinctions separately before global aggregation.

Parity

A centralized parity task has one bit of exact semantic output. Under local product interfaces, the locality surcharge can reach:

m-1 bits.

19. Hierarchical approximate width

If node v contributes local error εvloc with downstream gain Gv, then:

εroot ≤ ΣvGvεvloc.

This supports architecture-aware allocation of approximation budgets.

20. Robust semantic width

Width alone does not record how close a representation is to failure. For a cell with radius r under tolerance ε:

reserve=ε-r.

Robust design trades cell count against reserve, decoder sensitivity, and propagation gain.

21. Width can jump under weak coupling

Exact width can change discontinuously with coupling. At positive tolerance, a distinction may remain hidden until its response separation exceeds ε. If the first nonzero distinction term is order m, a transition scale can behave like:

λc ~ (ε/||Vm||)1/m.
Exact semantic structure can split immediately under infinitesimal coupling, while approximate semantic structure can remain stable over a nonzero coupling interval.

22. Perturbation of behavioral distance

If coupling changes behavioral distances by at most 2δ:

|Dλ-D0|≤2δ,

then covering numbers satisfy the tolerance-shift sandwich:

N0(ε+δ) ≤ Nλ(ε) ≤ N0(ε-δ),

whenever the shifted tolerances remain meaningful.

23. Width is not Euclidean dimension

Semantic width counts receiver-distinct behavior at a declared scale. Euclidean dimension asks whether the representation embeds into ℝd with required regularity.

Firewall: small semantic width does not imply low-dimensional smooth Euclidean realizability.

24. Width is not construction complexity

An interface can have tiny optimal width but be computationally hard to synthesize.

optimal representation size ≠ complexity of discovering the optimum.

25. Width is not automatically physical information

Semantic width is defined relative to mathematical tasks and receivers. Translating it into energy, entropy, thermodynamic cost, or physical channel capacity requires additional native assumptions and theorems.

Firewall: no universal physical interpretation follows from the width definition alone.

27. The BM contribution and the classical ingredients

Covering numbers, pseudometrics, chromatic number, ultrametrics, compactness, and metric entropy are classical mathematics. The BM development is their task-relative organization around Passports, contextual profiles, dynamics, interfaces, locality, causal horizons, robustness, and realization.

Classical ingredients should remain explicitly credited. The research question is whether the BM synthesis yields useful new theorems, obstruction principles, or cross-sector deductions beyond renaming.

28. Open directions

Important open directions include scalable width computation, useful approximation guarantees for hard coloring instances, width under nonlinear dynamics, dimension-aware realization bounds, many-body scaling laws, and stability of width under physically structured perturbations.

The next natural step is the continuum case, where native dimension can be infinite while positive-tolerance receiver width remains finite.
