Spacetime Semantic Width

A causal state should remember exactly the past distinctions that can still change the declared future response. Spacetime semantic width measures the complexity of those residual future-response states across space, time, context, and deadlines.

Volume II developmentUses classical automata, quotient, and causal-state ideas
Abstract

Given a past p and current state s, define the residual response ρp(s) as the complete future task map remaining after that past. Two states are equivalent when they induce the same residual response for every allowed continuation. In the exact deterministic sector this relation is a right congruence and yields a canonical causal machine. Approximate covers differ: independently optimal covers at successive times can be efficient yet causally incompatible. Spacetime semantic width therefore joins residual-state complexity, deadlines, cut obligations, retain-or-reacquire decisions, and approximation stability.

1. State should depend on the future task

A native state can contain distinctions that will never affect the declared receiver again. A causal task state should preserve only distinctions that can still change an allowed future response.

past history → remaining future-response map → causal semantic state

2. Residual response

Let p denote an admissible past and s the current native state. Define the residual response

ρp(s)=T̂(p,s)

as the complete map from allowed future continuations to future receiver-visible outputs. Exact equivalence is

s Ep s′ ⇔ ρp(s)=ρp(s′).

The exact spacetime semantic state is the quotient Sp/Ep.

3. Right congruence and causal update

Residual Right-Congruence Principle

If two states have identical residual response after past p, then after the same admissible next continuation a their successor states have identical residual response for the shortened future problem.

ρp(s)=ρp(s′) ⇒ ρpa(sa)=ρpa(s′a)

The exact quotient therefore carries an induced transition.

4. Canonical exact causal machine

Exact Causal Machine

In the declared exact deterministic sector, residual equivalence yields a canonical causal quotient whose update is induced by continuation itself. Because the quotient is defined by complete future response, there is no extra exact stage-compatibility surcharge between successive residual quotients.

This is closely related to residual-state and Myhill–Nerode constructions in automata theory; BM uses that pattern inside a broader Passport and multi-sector architecture.

5. Horizon residuals and countdown

For a finite deadline H, only futures inside the remaining horizon matter.

ρp,H(s)=remaining task behavior through H.

As the deadline approaches, some distinctions can cease to matter. This is the spacetime form of countdown descent.

6. Distinction latency

Two states can be identical to the receiver now but become distinguishable later. Their distinction latency is the earliest horizon at which the future task separates them.

ℓ(s,s′)=min{h : βh(s)≠βh(s′)}.

Latency tells the architecture when a distinction first becomes operationally necessary.

7. Last-chance cuts

If a future task will require a distinction and no later observation, route, or external input can reacquire it, the current causal cut must preserve it.

no later distinguishing source ⇒ current cut must preserve the distinction.

8. Keep or reacquire

Keep

Carry the distinction in memory or communication until its final use.

Reacquire

Drop it now and obtain genuinely new distinguishing information later before the deadline.

Permanent firewall: later context revelation does not recover a discarded distinction unless the later context actually carries new distinguishing information.

9. Pre-revelation storage

If a future context Y will be revealed later, let EY identify states that remain indistinguishable after all allowed values of that context. Any storage map S used before revelation must satisfy

ker(S) ⊆ EY.

Otherwise the architecture can merge states that the later reveal cannot separate.

10. Approximate residual distance

At tolerance ε>0, define a residual pseudometric over future continuations:

Dp(s,s′)=supf∈Fpd(T̂(p,s;f),T̂(p,s′;f)).

The approximate spacetime width is

wp(ε)=log₂ 𝒩(ρp(Sp),d∞,ε).

11. Approximate covers are not automatically causal

An optimal ε-cover at time t and an optimal ε-cover at time t+1 can fail to map consistently into one another.

Permanent firewall: independently optimal approximate stage covers do not imply a compatible causal reduced dynamics.

12. Compatibility defect

For encoders Rt and Rt+1, a one-step compatibility defect can be written as

δt=sup{d(Rt+1Φx,Rt+1Φx′):Rtx=Rtx′}.

Zero defect recovers exact stage compatibility.

13. Error propagation

If the reduced transition has amplification factor Lt, then a typical bound is

et+1≤Ltet+δt.

Small local covers alone are therefore insufficient; the causal transitions must also be compatible and stable.

14. Spacetime width profile

A causal system naturally has a width profile rather than one fixed number:

t ↦ wt(ε),    or    (t,H) ↦ wt,H(ε).

This records how much task-relevant distinction must remain live at each point in the architecture.

15. Memory and communication are cut costs

Memory

Carries a distinction across a temporal cut.

Communication

Carries a distinction across a spatial or network cut.

A spacetime design can trade one against the other, subject to causality and reacquisition constraints.

16. Causal locality surcharge

If a centralized residual state has width w* but a distributed architecture requires several local memories and channels, the realized total can be larger:

Γcausal=realized spacetime width−centralized residual width ≥ 0

whenever the local states collectively refine the centralized residual state.

17. Finite propagation speed and light cones

In local systems, native locality theorems can confine influence to a backward task light cone over finite time.

outside the backward task light cone ⇒ no effect before the deadline.

In bounded-depth circuits this can be exact. In local Hamiltonian systems, Lieb–Robinson-type estimates can supply approximate collars when their hypotheses apply.

BM uses those native theorems to bound task-specific causal width; it does not replace them.

18. Coupling can split residual equivalence

At coupling λ=0, two states can have identical future task response. Any nonzero coupling can create an exact distinction immediately, while positive tolerance can delay the transition until the induced difference exceeds ε.

exact transition may occur at λ=0; approximate transition occurs at finite λc(ε).

19. Perturbation stability

If behavioral distances satisfy

|Dλ−D0|≤2δ,

then covering numbers obey the tolerance-shift sandwich

N0(ε+δ)≤Nλ(ε)≤N0(ε−δ)

when the shifted tolerances remain valid.

20. Exact residual states are more canonical than approximate covers

Exact

Equality of full residual response defines a canonical quotient once the Passport is fixed.

Approximate

Different equally small covers may cross, differ in robustness, and fail causal compatibility.

22. What BM contributes here

The BM synthesis is to define state by remaining future distinctions; treat memory and communication as spacetime cut obligations; permit lawful reacquisition; separate exact canonical residual quotients from approximate noncanonical covers; and track locality, realization, robustness, and provenance explicitly.

23. Open directions

Open directions include scalable approximate causal-state synthesis, memory-versus-communication tradeoffs, continuous-time residual geometry, PDE spacetime width, stochastic future-law residuals, quantum causal Passports, and dimension-aware bounds for approximate stage compatibility.
