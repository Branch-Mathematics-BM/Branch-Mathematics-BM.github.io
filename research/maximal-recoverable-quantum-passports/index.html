Exact quantum capability

Maximal Recoverable Quantum Passports

For a fixed quantum channel and code, there is a largest exact observable algebra that survives the noise. A receiver Passport selects a required subalgebra inside that capability. The gap between the two tells you exactly what survives, what fails, and what can be downgraded without ambiguity.

Volume II development Uses established operator-algebra quantum error correction
Abstract

Let P be the code projector and {E_a} Kraus operators of a finite-dimensional channel N. The compressed error algebra 𝔈_N=C*(P E_a†E_b P) determines the maximal exactly recoverable algebra A_max(N)=𝔈_N′. A receiver requiring task algebra A_req succeeds exactly when A_req⊂A_max(N); the exact surviving requested capability is A_req∩A_max(N). Under additional erasure, A_max is antitone, yielding an exact degradation order. BM interprets A_max as the channel's maximal recoverable quantum Passport and keeps it distinct from one receiver's chosen Passport, approximate recoverability, and implementation cost.

1. Channel capability and receiver demand are different

A noisy quantum system has a physical capability determined by its code and channel. A receiver has a task requirement determined by the Passport.

Channel capability

The largest observable algebra that can be exactly recovered.

Receiver demand

The observable algebra the current task actually requires.

BM keeps these objects separate.

2. The compressed error algebra

Let P be the code projector and Ea Kraus operators of the channel N.

Define:

𝔈N=C*(P Ea†EbP).

This algebra records how the noise acts inside the code through the compressed error products.

3. Maximal exactly recoverable algebra

Exact Maximal Recoverable Algebra
Amax(N)=𝔈N′.

The maximal exactly recoverable observable algebra is the commutant of the compressed error algebra.

This is established operator-algebra QEC. BM uses it as the exact quantum capability object for the channel.

4. Why it is maximal

Every exactly correctable observable must commute with every element of the compressed error algebra.

Therefore any exactly correctable task algebra A satisfies:

A⊂Amax(N).

No larger exact task algebra can exist outside that commutant.

5. A maximal recoverable Passport

BM interprets:

Amax(N)

as the maximal exact quantum Passport supported by the code and channel.

It is not a chosen receiver task. It is the envelope of all exact task algebras physically available under that noise model.

6. Receiver-required Passport

Let the receiver require:

Areq.

Exact success requires:

Areq⊂Amax(N).

If this inclusion fails, some required observable is not exactly recoverable.

7. Surviving requested capability

Even when the full required algebra fails, part of it can remain exactly recoverable.

Asurvive=Areq∩Amax(N).

This is the exact portion of the requested Passport that survives the channel.

8. Failure is therefore structured

Rather than saying only “recovery failed,” one can state:

required algebra − surviving intersection = exact lost capability.

This identifies which distinctions have failed rather than collapsing everything to one binary label.

9. Full-state recovery is one endpoint

Full logical-state recovery corresponds to:

Areq=B(HL).

If:

Amax(N)=B(HL),

the full logical system is exactly recoverable.

If Amax is smaller, only a restricted task family survives.

10. Proper noncommutative capability

The maximal recoverable algebra can be a proper noncommutative subalgebra.

Then full-state QEC has failed, but genuinely quantum task recovery remains possible.

Firewall: “not full-state recoverable” does not mean “only classical information survives.”

11. Commutative surviving capability

If the maximal surviving algebra is commutative, the remaining exact task content is jointly measurable classical information.

Amax commutative ⇒ exact surviving task is classical in algebraic type.

This changes the access geometry because no-broadcasting constraints no longer apply in the same way.

12. Scalar endpoint

If:

Amax=C·I,

then no nontrivial logical observable remains exactly recoverable.

The channel has reached the trivial exact capability endpoint for that code.

13. Damage order

For erasure patterns F₁⊂F₂, the second removes at least as much physical support as the first.

Antitone Degradation
Amax(F₂)⊂eq Amax(F₁).

More erasure cannot increase exact recoverable capability.

14. Exact degradation chain

Along a nested sequence of damage patterns:

F₀⊂F₁⊂···⊂Fr,

one obtains:

Amax(F₀)⊃eqAmax(F₁)⊃eq···⊃eqAmax(Fr).

This is a clean exact capability chain.

15. Damage patterns need not be totally ordered

Two erasure patterns can be incomparable by inclusion.

Their maximal recoverable algebras can also be incomparable.

exact degradation is naturally a partial order, not always one line.

16. Task success across a damage poset

For a fixed receiver task Areq, define the successful damage patterns:

Good(Areq)={F : Areq⊂Amax(F)}.

This family is downward closed in damage: if a task survives a larger erasure, it also survives every smaller nested erasure.

17. Authorized sets from maximal Passports

A surviving subset S is authorized for task A exactly when:

A⊂Amax(S).

Thus access geometry can be read directly from the maximal recoverable Passport of each surviving subsystem.

18. Minimal authorized sets

The minimal subsets satisfying:

A⊂Amax(S)

form MinAuth(A).

These determine the task-relative erasure hitting number:

dA=τ(MinAuth(A)).

19. No-broadcasting from maximal Passports

If A is noncommutative and two disjoint subsets both have maximal recoverable algebras containing A, then both disjoint subsets recover the same genuine quantum task.

No-broadcasting forbids this exact configuration.

A noncommutative ⇒ exact authorized family must be intersecting.

20. Maximal Passport and task downgrading

If the original requirement fails, one lawful response is to replace it with a weaker algebra:

Areq′⊂Areq∩Amax.

This is an explicit contract change.

BM treats task downgrading as a declared Passport revision, not as a silent reinterpretation of failure.

21. Exact recoverable algebras form a structured family

Every exactly recoverable task algebra lies inside Amax.

Thus exact task capabilities inherit a clean inclusion structure.

A exact-recoverable ⇔ A⊂Amax.

This makes exact capability synthesis comparatively simple once Amax is known.

22. Approximate Passports are different

At positive tolerance, define:

Capε(N)={A : δA(N)≤ε}.

This family is downward closed, but it need not have one unique greatest element.

Permanent firewall: the exact maximal-Passport theorem does not automatically extend to a unique maximal approximate Passport.

23. Why approximate maximality can fail

Two different task algebras can each be recoverable within tolerance ε while the algebra generated by both exceeds the error budget.

A₁,A₂∈Capε does not imply C*(A₁∪A₂)∈Capε.

Approximate capability can therefore be genuinely multi-objective.

24. Capability frontiers

Instead of one approximate maximal algebra, one can study maximal elements of:

Capε(N)

under inclusion.

Several incomparable maximal elements may coexist.

This produces a quantum capability frontier rather than one exact envelope.

25. Maximal Passport and carrier dimension

Once the surviving contextual operator system is identified, any exact carrier must have enough operator-space dimension to represent it.

log₂k ≥ ½log₂ dim(Ssurvivectx).

As damage shrinks the recoverable Passport, minimum carrier requirements can shrink as well.

26. Maximal Passport and locality

If native dynamics prove that certain remote degrees of freedom cannot affect the task before the deadline, they need not enter the contextual operator system.

Thus:

native locality → smaller task operator system → potentially smaller recoverable Passport burden.

This links many-body locality to exact quantum capability.

27. Maximal Passport and spacetime evolution

A future task can be pulled backward in the Heisenberg picture:

At=Φt,T*(AT).

The relevant recoverable Passport at time t is therefore the intersection of the channel's current exact capability with the future task algebra transported back to t.

Aneeded,t∩Amax,t.

28. Dynamic recovery and static recoverability differ

A task algebra can be statically recoverable after one noise event while a compressed carrier still fails to admit an autonomous CPTP evolution through time.

Permanent firewall: static exact task recoverability does not imply exact quantum dynamic closure.

29. Provenance from noise to lost task

A useful audit trail is:

noise model → Kraus family → compressed error algebra → commutant → maximal Passport → receiver intersection → surviving task.

This exposes exactly where capability was lost.

30. Comparing two channels

For channels N and M, exact capability comparison can be made by inclusion:

Amax(N)⊂Amax(M).

If so, every exact task recoverable under N is also recoverable under M.

If neither inclusion holds, the channels support different incomparable task families.

31. Channel ordering is receiver-sensitive

Even if two channels have incomparable maximal recoverable algebras, one receiver may prefer one channel because its required algebra lies inside that channel's capability.

channel superiority can depend on Areq.

This is a direct example of BM's receiver-relative comparison principle.

32. A reusable exact-capability workflow

choose code → specify channel → form 𝔈N → compute Amax=𝔈N′ → compare with Areq → derive authorized sets → compute task distance → record surviving intersection → decide downgrade or repair.

33. What BM contributes here

The maximal recoverable algebra, commutant construction, OAQEC, access structures, and no-broadcasting are established quantum mathematics.

The BM synthesis is to interpret the maximal exact recoverable algebra as the channel's maximal quantum Passport, keep it distinct from one receiver's required Passport, use intersections to express surviving capability, connect damage order to access geometry, and preserve exact/approximate separation rather than inventing a nonexistent unique approximate maximal Passport.

34. Open directions

Important next problems include efficient maximal-Passport computation for structured many-body channels, local-to-global capability synthesis, approximate capability frontiers, dimension-aware conversion from algebraic defect to physical recovery defect, and dynamic versions in which the maximal recoverable Passport evolves through spacetime.
