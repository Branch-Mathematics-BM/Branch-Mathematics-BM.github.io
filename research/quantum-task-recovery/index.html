Quantum error correction

Quantum Error Correction for Observables Instead of Full States

A quantum code can fail to preserve an arbitrary logical state while still preserving exactly the observable algebra the receiver actually needs. Task-relative QEC treats that weaker requirement as a first-class mathematical object.

Volume II development Uses established OAQEC and quantum information theory
Abstract

Let P project onto a code space and let {E_a} describe a noise channel. For a declared task algebra A, exact operator-algebra quantum error correction is characterized by [P E_a†E_b P,X]=0 for every X∈A. Branch Mathematics uses this established criterion to define task-relative authorized sets, erasure distance, access geometry, and graceful degradation. A subset of physical shares is authorized when some CPTP recovery fixes the declared task algebra, even if full-state recovery fails. This page develops exact task correction, erasure distance, the two-qubit repetition example, authorized-set geometry, antitone degradation under erasure, and the separation between algebraic and physical approximate recovery.

1. Full-state correction can be more than the task requires

Standard quantum error correction is often presented as preserving an arbitrary logical state in a code subspace. That is the strongest natural task.

But a receiver may only need a smaller observable algebra:

A ⊂ B(Hcode).

Examples include one classical logical bit, a commuting family of measurements, or a restricted noncommutative subsystem.

task-relative correction = preserve A, not automatically all of B(Hcode).

2. Exact correctability criterion

Let P be the code projector and let Ea be Kraus operators for the noise.

Operator-Algebra QEC Criterion

A finite-dimensional task algebra A is exactly correctable when

[P Ea†EbP, X]=0   for all X∈A and all a,b.

This is established operator-algebra quantum error correction, used by BM as a native quantum theorem.

3. Full-state QEC is the special case A=B(Hcode)

If the task algebra is the full logical algebra, the criterion reduces to the ordinary Knill–Laflamme structure.

Full logical algebra

Preserve arbitrary logical superpositions, coherences, and observables.

Task algebra

Preserve only the observable structure explicitly required by the Passport.

4. Authorized subsets

Suppose a logical encoding is distributed across physical subsystems indexed by:

{1,…,m}.

A subset S is authorized for task algebra A when there exists a CPTP recovery acting on S that restores every observable in A.

Auth(A)={S : A is exactly recoverable from S}.

This can be strictly larger than the authorized family for full-state recovery.

5. Upward closure

If a set S is authorized and S⊂T, then T is also authorized: the larger set can discard its extra systems and run the recovery available on S.

S∈Auth(A), S⊂T ⇒ T∈Auth(A).

Thus exact task authorization is naturally upward closed.

6. Task-relative erasure distance

Define:

dA=min{|F| : Fc∉Auth(A)}.

This is the smallest erasure size whose complement can no longer recover the declared task algebra.

Task-relative erasure distance can exceed or differ from what one would infer by asking for full logical-state recovery.

7. Two-qubit repetition code

Logical Z survives one erasure

Encode:

|0L⟩=|00⟩,   |1L⟩=|11⟩.

If one physical qubit is erased, the remaining qubit still distinguishes the two code-basis states. Therefore the logical Z observable remains recoverable from either single qubit.

But an arbitrary logical superposition:

α|0L⟩+β|1L⟩

does not survive one erasure as a recoverable full qubit.

logical Z recoverable   but   full qubit not recoverable.

8. Why this matters

The code is not simply “good” or “bad.” Its capability depends on the declared task.

TaskOne-qubit erasure
Logical ZRecoverable
Classical code-basis bitRecoverable
Full logical qubitNot recoverable
Logical X coherenceNot recoverable

9. Minimal authorized sets

The most informative part of an access structure is often the family of minimal authorized sets:

MinAuth(A).

Every authorized set contains at least one minimal authorized set.

These sets describe the smallest physical coalitions capable of restoring the task.

10. Erasure distance as a hitting number

An erasure set F destroys recovery exactly when it intersects every minimal authorized set.

Hitting-Set Form of Erasure Distance

For the exact task access structure,

dA = τ(MinAuth(A)),

where τ is the minimum hitting-set size.

This turns task-relative erasure tolerance into a finite combinatorial invariant of the authorized hypergraph.

11. No-broadcasting constrains noncommutative tasks

If two disjoint subsets can each exactly recover the same genuinely noncommutative task algebra, one could effectively broadcast that algebra.

Disjoint-Recovery Constraint

Two disjoint exact recoveries of the same finite-dimensional C*-algebra force the recoverable algebra to be commutative.

This is a classical no-broadcasting consequence placed into BM access geometry.

12. Threshold access structures

Suppose every subset of size at least k is authorized for the same genuinely quantum task, among m shares.

To prevent two disjoint authorized subsets:

2k>m.

This is the task-algebra version of the familiar quantum threshold constraint.

13. Maximal exactly recoverable algebra

Let:

E = C*(P Ea†EbP)

be the C*-algebra generated by the compressed error products.

Then the maximal exactly recoverable algebra is:

Amax(N)=E′,

the commutant of the error algebra.

This is established operator-algebra structure. BM uses it as the exact surviving quantum Passport after a noise or erasure pattern.

14. Required task versus surviving task

Let Areq be the task algebra required by the receiver, and let Amax(F) be the maximal algebra surviving erasure pattern F.

The exactly surviving required capability is:

Asurvive(F)=Areq∩Amax(F).

This gives a precise algebraic notion of graceful degradation.

15. More erasure cannot increase exact capability

If erasure pattern F₂ removes at least as much as F₁, then the exactly recoverable algebra cannot become larger.

F₁⊂F₂ ⇒ Amax(F₂) ⊂eq Amax(F₁).

This antitone structure gives an exact degradation partial order.

16. Exact recoverable algebras form a lattice

For a fixed finite-dimensional noise channel, exact recoverable observable algebras inherit lattice structure from subalgebras inside the maximal recoverable algebra.

This makes the exact capability landscape comparatively clean.

exact task capability: ordered, composable, algebraic.

17. Approximate recovery is less canonical

At positive tolerance, several incomparable task algebras can each be approximately recoverable without one containing the other.

approximate capability can be downward closed without a unique greatest algebra.
Firewall: the exact maximal-algebra theorem does not automatically extend to a unique maximal approximate algebra.

18. Algebraic commutator defect

Define the compressed error operator system:

K = span{P Ea†EbP}.

For a candidate task algebra A, an approximate algebraic defect can be based on commutators with K.

κ = sup ||[K,X]||

over appropriately normalized K and X.

19. Distance to the exact commutant

Let η measure operator-norm distance of the candidate task observables to the exact commutant K′. In finite dimension, the project development uses the comparison:

η≤κ≤2η.

This is an algebraic stability statement.

20. Physical recovery defect is different

The receiver ultimately needs a physical recovery channel. Define:

δA(N)=optimal CPTP recovery error for task algebra A.

This is not identical to κ or η.

Permanent firewall: approximate algebraic closeness does not by itself determine optimal physical recovery error.

21. Perturbation stability

For channels N and M, the physical task-recovery defect satisfies the Lipschitz bound:

|δA(N)-δA(M)| ≤ ||N-M||⋄.

Thus small diamond-norm channel perturbations cannot change the optimal task-recovery defect by more than the perturbation size.

22. Task recovery and semantic carriers

A carrier or surviving subsystem is sufficient only if the declared task algebra factors through it physically.

task algebra → carrier → CPTP recovery → receiver.

This ties quantum semantic carriers directly to task-relative QEC.

23. Authorized geometry under erasure

For each erasure pattern F, define the surviving subsystem Fc. The family:

Auth(A)={Fc : A recoverable after erasing F}

encodes the full exact access geometry of the task.

Minimal authorized sets reveal the essential physical coalitions. Minimal hitting sets reveal the smallest erasures that defeat the task.

24. Task-specific protection can save resources

If the receiver only needs a commuting algebra, fewer shares or weaker redundancy may suffice than for a fully noncommutative logical system.

weaker quantum task ⇒ potentially larger authorized family.

This is one of the main practical motivations for task-relative QEC.

25. But weaker task does not mean classical task

A proper task algebra can still be noncommutative.

Such a task remains genuinely quantum and remains subject to no-broadcasting and nonclassical access constraints.

Firewall: “not full-state” does not mean “classical.”

26. Graceful degradation

Instead of classifying a noisy code as simply correctable or uncorrectable, one can track which task algebras survive as damage increases.

Damage levelPossible surviving capability
LowFull logical algebra
ModerateProper noncommutative subalgebra
HigherCommutative observable algebra
SevereOnly scalars

This yields a structured degradation ladder instead of a binary failure label.

27. Exact task distance versus code distance

Standard code distance is tied to preserving the full logical system. Task-relative erasure distance is tied to preserving one declared algebra.

dA can differ from full-code erasure distance.

Different tasks on the same physical code can therefore have different effective distances.

28. A reusable analysis workflow

declare task algebra → compute compressed error products → test commutant criterion → derive Amax → build authorized sets → compute erasure distance → analyze approximate defect → test CPTP recovery.

29. What BM contributes here

Knill–Laflamme theory, operator-algebra QEC, C*-algebras, no-broadcasting, access structures, and CPTP recovery are established quantum mathematics.

The BM synthesis is to treat the receiver's observable algebra as the Passport, distinguish task recovery from full-state recovery, organize erasure tolerance through authorized sets and hitting numbers, track maximal surviving algebras under damage, and connect exact algebraic degradation to approximate physical recovery without conflating them.

30. Open directions

Important open problems include tight dimension-aware bounds from algebraic commutator defect to physical CPTP recovery defect, approximate access-structure geometry, efficient computation of task-relative authorized families for large codes, adaptive task downgrading under noise, and many-body locality bounds for task-specific QEC.
