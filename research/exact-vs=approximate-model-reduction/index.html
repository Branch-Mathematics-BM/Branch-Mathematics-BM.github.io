Exact vs Approximate Model Reduction

Exact reduction identifies states only when every declared response agrees. Approximate reduction allows positive error, but that changes the structure from exact equivalence classes to metric cells, covers, compatibility constraints, and robustness tradeoffs.

Exact foundation Approximate developments Uses classical approximation theory
Abstract

Branch Mathematics separates exact task quotients from positive-tolerance representations. Exact sufficiency is governed by factorization through a representation. Approximate sufficiency is governed by the geometry of receiver-visible response profiles. This page develops behavioral pseudometrics, cell-radius conditions, covering numbers, graph and hypergraph formulations, exact and approximate horizon reduction, SVD-based linear approximations, compatibility defects, error propagation, robustness reserve, and the separation between abstract semantic compression and admissible realization.

1. Exact reduction begins with the task

Let X be a native state space, R:X→Q a representation, and T:X→Y a declared task.

T = T̄R ⇔ ker(R) ⊆ ker(T).

This condition is exact: any two states merged by R must produce exactly the same task response.

Exact Task Sufficiency Canonical foundation

A representation R is sufficient for T if and only if the task factors through R.

Interpretation.

Exact reduction is not defined by low dimension alone. It is defined by the equivalence relation induced by the declared response.

2. The coarsest exact task quotient

For one exact task, the coarsest exact representation is the quotient by:

ET = ker(T).

For a family of tasks and admissible continuations, the exactification relation becomes:

E* = ⋂T∈Q, m∈M ker(T∘m).

Two native states can be merged exactly only when no declared task after any declared admissible continuation distinguishes them.

Exactification asks for the most aggressive compression that remains exact for the whole declared contract.

3. Positive tolerance changes the mathematical object

At tolerance ε>0, equality is no longer the right relation.

The receiver permits different outputs as long as one decoder representative can serve all states in the same cell within tolerance.

Exact

Representation cells are equivalence classes.

Approximate

Representation cells are sets whose receiver-visible responses fit inside admissible error radius.

Approximate reduction is therefore a covering problem rather than merely a quotient problem.

4. Behavioral pseudometric

Let the Passport declare responses Bj:X→Yj, each equipped with a metric dj.

Define:

DP(x,x′) = maxj dj(Bj(x),Bj(x′)).

This is a receiver-relative behavioral pseudometric.

Native states can be far apart in the original geometry and still have zero behavioral distance if the declared receiver cannot distinguish them.

5. Diameter and radius semantics

Approximate cells can be constrained in at least two natural ways.

Semantics Condition on a cell A
Diameter diam(A) ≤ ε
Decoder radius rad(A) ≤ ε

The radius condition is the direct decoder condition because one representative must serve the whole cell.

rad(A) = infz supy∈A d(y,z).

General metric spaces satisfy:

½ diam(A) ≤ rad(A) ≤ diam(A).

6. Why pairwise thresholding can fail

Three-point obstruction

Place three task outputs at the vertices of an equilateral triangle of side length 2ε.

Every pair fits inside some radius-ε ball, but the whole triple requires circumradius:

2ε/√3 > ε.

Pairwise admissibility therefore does not imply joint decoder admissibility.

Permanent firewall: pairwise approximate compatibility does not imply global cell realizability.

7. Graph and hypergraph formulations

Under diameter semantics in a finite system, define a conflict graph:

{x,x′}∈E(Gε) ⇔ DP(x,x′)>ε.

Then the minimum number of admissible cells is:

N(ε)=χ(Gε).

Under general radius semantics, pairwise conflicts can be insufficient. One can instead use a hypergraph whose hyperedges are subsets that fail the radius constraint.

A is a forbidden hyperedge ⇔ rad(P(A))>ε.

This distinction matters because approximate representation can be combinatorially harder than exact quotienting.

8. Semantic width

The approximate semantic width is:

w(ε)=log₂ N(ε).

For exact finite representations:

w(0)=log₂|X/E*|.

This is a log-cardinality or covering quantity, not automatically a Shannon entropy.

Permanent firewall: semantic width is not automatically Shannon entropy, thermodynamic entropy, or Landauer cost.

9. Exact dimension and approximate width need not track one another

A system can require infinitely many exact receiver-distinct states while having finite positive-tolerance covering number.

Conversely, a finite exact quotient can have awkward or high-dimensional realization requirements.

exact quotient size ≠ approximate covering width ≠ Euclidean realization dimension.

10. Infinite-dimensional systems

Let a bounded admissible state set K be mapped into a receiver-profile space by:

P:K→Y.

Positive-tolerance semantic width is finite for every ε>0 exactly when the profile image is relatively compact:

Compact Profile Criterion Classical compactness + BM placement
N(P(K),ε)<∞ for every ε>0 ⇔ P(K) is relatively compact.

Thus an infinite-dimensional native system can have finite approximate task width.

11. Linear compact operators and singular values

Suppose the receiver profile is generated by a compact linear operator:

T:H→Y

between Hilbert spaces, with singular values:

σ₁≥σ₂≥···→0.

Truncating after n singular directions yields an operator-norm error:

||T-Tn|| = σn+1.

Singular-value decay therefore controls finite-dimensional approximation of the receiver-visible profile set.

This is classical approximation theory. BM's use is to apply it to the task-filtered profile rather than automatically to the full native state.

12. Free linear horizon approximation

For a linear dynamical system:

xt+1=Axt,   yt=Cxt,

define the horizon observability operator:

Oh = [C;CA;···;CAh].

The best unconstrained rank-d approximation in operator norm is:

Ehfree(d) = σd+1(Oh).

But this is only a stagewise approximation result.

13. Stagewise optimality is not dynamic compatibility

Let Ph project onto a horizon-h reduced subspace and Rh-1 encode the next shorter horizon.

A compatibility defect can be measured by:

δh = ||Rh-1A(I-Ph)||.

Even if each Ph is independently optimal for its horizon, the sequence can fail to support a coherent reduced dynamics.

Permanent firewall: independent stage optimum does not imply compatible dynamics.

14. Error propagation

Approximate reduction must control how local defects accumulate.

A typical recurrence is:

et+1 ≤ LH-tet + δH-t.

Here L captures reduced update amplification and δ captures local incompatibility.

Regime Consequence
L<1 Errors can contract.
L=1 Errors can accumulate roughly additively.
L>1 Errors can amplify geometrically.
Permanent firewall: small local defect does not imply small global defect without conditioning.

15. Backward error budgets

If a final receiver tolerance is known, the admissible local budget can be propagated backward.

Bt = (Bt+1-δt)/Lt.

A negative budget is an infeasibility certificate: the architecture cannot meet the declared final tolerance under the current local defects and amplification factors.

16. Robustness reserve

Two approximate reductions can have the same width and nominal tolerance but different safety margins.

If a cell has current radius r and tolerance ε, define:

reserve = ε-r.

A slightly wider representation can have much larger robustness reserve.

Minimum width and maximum robustness need not coincide.

17. Pareto structure

Approximate design can involve competing objectives:

width, error, robustness, locality, memory, cost.

There need not be one representation that is simultaneously best in every coordinate.

The natural object can therefore be a Pareto frontier rather than a unique optimum.

18. Approximate quotients need not be nested canonically

Exact equivalence relations often admit a refinement order.

Positive-tolerance optimal covers can cross one another: two different optimal cellings may have the same size but neither refines the other.

approximate optimality need not form one canonical chain.

This is one reason approximate BM must use geometric and optimization language rather than exact quotient language alone.

19. Realization remains a separate stage

A small abstract cover or quotient does not guarantee an admissible realization.

The required representation may need to be:

Category Possible obstruction
Continuous Topology of the quotient or profile set
Smooth Bundle or rank obstruction
Distributed Locality surcharge or incompatible product structure
Causal Required future information is not yet available
Quantum No CPTP realization of the desired abstract recovery
Permanent firewall: set-theoretic or algebraic reduction does not imply admissible physical realization.

20. Exact versus approximate smooth realization

Exact quotienting can force a nontrivial quotient space that does not embed in a desired low-dimensional Euclidean target.

Approximation can sometimes bypass the exact topological obstruction by allowing controlled deformation or merging.

But positive tolerance does not automatically remove every obstruction. The required tolerance, regularity, locality, and decoder conditioning still matter.

21. A linear repair viewpoint

Suppose a nominal invariant splitting is perturbed by off-diagonal coupling of size Δ, and the relevant spectral separation is s>0.

A Sylvester-type correction can produce an invariant graph with a bound of the form:

r = 2Δ/s.

The induced squared error surcharge can then scale like:

O(Δ²/s²).

The lesson is that repair cost depends not only on defect magnitude but also on conditioning or separation.

22. Why rescaling can hide instability

A representation can be numerically small in its encoded coordinates while its decoder is highly sensitive.

Rescaling can therefore make encoded error look arbitrarily small without improving the recovered native or task error.

Permanent firewall: robust-width claims require decoder sensitivity or an equivalent normalization condition.

23. Exact and approximate reduction in stochastic systems

In stochastic sectors, equality of support is weaker than equality of law.

Exact aggregation must preserve the declared transition probabilities or laws, not merely the set of possible successors.

Permanent firewall: support equality does not imply law equality.

Approximate stochastic reduction then needs a declared metric on probability laws, such as total variation, Wasserstein distance, or another native probabilistic metric.

24. Exact and approximate reduction in quantum systems

In the quantum sector, an abstract algebraic quotient is not enough.

Exact physical closure requires a completely positive trace-preserving reduced channel:

ΨE = EΦ.

Approximate physical closure can be quantified by:

δQ = minΨ CPTP ||EΦ-ΨE||⋄.

This minimum is attained in finite dimension.

Permanent firewall: algebraic or operator recovery does not imply CPTP recovery.

25. Exact versus approximate PDE reduction

For a PDE, exact state compression can be impossible at low continuous Euclidean dimension while positive-time, positive-tolerance receiver profiles can still be compact.

exact low-dimensional closure may fail while approximate task width is finite.

This makes the exact/approximate distinction especially important in continuum systems.

26. What a reduction certificate should contain

A serious reduction claim should state:

Item Question
Task What response must be preserved?
Context Under which environments or peer systems?
Horizon How far into the future?
Metric How is error measured?
Tolerance What deviation is allowed?
Dynamics How does local error propagate?
Realization What implementation category is required?
Robustness How much perturbation reserve remains?

27. The BM distinction

Branch Mathematics does not define model reduction by dimension alone.

It separates:

what may be merged exactly, what may be blurred approximately, how errors propagate, whether local reductions compose, and whether the abstract reduction can actually be realized.

That distinction is what connects exactification, semantic width, dynamic closure, robustness, PDE reduction, distributed interfaces, and quantum recovery.
