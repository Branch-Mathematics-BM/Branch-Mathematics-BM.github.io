1. What GURF Is

Class: Core identity
Status: Canonical / stable

GURF is the response-specialized mathematical framework used when a problem contains genuine response semantics: a system has states, produces responses, is observed or compressed, is asked to support Tasks, can be constrained or intervened upon, and may need to preserve information for future continuation.

The framework asks not merely what a system outputs, but which distinctions in the underlying state must remain available for the particular responses, decisions, interventions, reconstructions, safety questions, and future evolutions that matter.

\[ \boxed{ \text{Which distinctions in the underlying state must survive for the responses, Tasks, interventions, or future continuations that matter?} } \]

Mathematical objects

  • source or system state;
  • native response law or response relation;
  • Observation / retained representation;
  • Task or Task family;
  • admissibility and active constraints;
  • Regime / law context;
  • Intervention or control;
  • continuation / evolution;
  • uncertainty, coupling, and quantifier scope;
  • obstruction, repair, and certification.
Limits
  • GURF is not required for every mathematical problem.
  • GURF does not replace the native mathematics governing the system.
Definitions: GURF
Research: GURF foundations

2. GURF Under Branch Mathematics

Class: architecture ownership
Status: Canonical

Branch Mathematics is the broader meta-structural mathematics governing lawful representation, distinction preservation, transformation, quotienting, composition, realization, Interfaces, export, and re-entry. GURF specializes that architecture when the mathematics is genuinely about response.

\[ \boxed{ \mathrm{BM} \supset \text{response-specialized GURF use}. } \]
Limits
  • A BM problem need not invoke GURF.
  • GURF may go quiet when response semantics add no mathematical leverage.
Definitions: BM/GURF distinction

4. Extension Principle

Class: governance rule
Status: Canonical

Extensions do not repeatedly redefine the Core. Each extension adds specialized response mathematics only when its semantic trigger is present.

\[ \boxed{ \text{Core response contract} + \text{specialized response requirement} \longrightarrow \text{extension activation}. } \]
Response audit
  • Name the Core response question first.
  • Identify the specialized semantic trigger.
  • Activate only the extensions that answer a real additional question.
  • Do not use an extension label as a substitute for its mathematics.

5. Minimal Response System

Class: Core response object
Status: Canonical working object

A compact deterministic Core system can be recorded as

\[ \boxed{ \mathfrak G = \left( X,Y,\mathfrak R,\mathcal O,\preceq,\mathcal A \right). } \] \[ \begin{aligned} X&=\text{source/system state object},\\ Y&=\text{native response space},\\ \mathfrak R&=\text{response law or relation},\\ \mathcal O&=\text{Observation map/family},\\ \preceq&=\text{declared information/degradation order},\\ \mathcal A&=\text{admissibility structure}. \end{aligned} \]
Limits
  • This is a minimal deterministic working object, not a claim that all response systems have six intrinsic components.
  • Task, Regime, Intervention, noise, memory, coupling, and extension data may be added when the problem requires them.

6. Extended Response Contract

Class: Core working configuration
Status: Active formalization

For a richer problem it is useful to expose the response contract without changing the definition of the minimal Core.

\[ \boxed{ \mathfrak G^\star = \left( X,\Lambda,U,Y, \mathfrak R, \mathcal O, \mathcal A, \mathcal T, \mathcal N, \mathcal P \right). } \] Here \(\Lambda\) carries Regimes/laws, \(U\) interventions, \(\mathcal T\) a Task family, \(\mathcal N\) uncertainty/noise structure, and \(\mathcal P\) the active response Passports.
What it allows
  • Expose exactly which extra objects are active in a complicated response problem.
  • Separate the stable Core from application-specific enrichment.
Limits
  • The tuple is an organizational configuration, not a new primitive ontology.

7. Response and Observation Must Remain Distinct

Class: Core semantic separation
Status: Canonical

A physical or mathematical response and what an observer records from it are different objects. Detection, compression, projection, calibration, and inference may all change what is retained.

\[ x \xrightarrow{\mathfrak R} y \xrightarrow{\mathcal O} z, \qquad \boxed{ F_{\mathfrak G} = \mathcal O\circ\mathfrak R. } \]
Failure / obstruction tests
  • Identifying detector output with the underlying response.
  • Treating an inferred parameter as though it were directly observed.
  • Suppressing calibration or compression in the response history.

8. Task

Class: Core response target
Status: Canonical

A Task states what the retained response representation must support.

\[ \boxed{ T:X\to W. } \]

Mathematical objects

  • prediction;
  • classification;
  • reconstruction;
  • control decision;
  • future continuation;
  • parameter inference;
  • safety decision;
  • physical observable.
Definitions: Task

9. Task Families

Class: Core multi-Task semantics
Status: Active

Many real systems must support more than one downstream question. A response representation should therefore be audited against a Task family rather than against an unnamed generic notion of information.

\[ \mathcal T=\{T_\beta:X\to W_\beta\}_{\beta\in B}. \] Exact joint Task sufficiency requires \[ \boxed{ F(x)=F(x') \Longrightarrow T_\beta(x)=T_\beta(x') \quad\forall\beta\in B. } \]
Limits
  • Separate sufficiency for each Task does not automatically imply one shared witness, strategy, or coupling when those objects are part of the Task.

10. Observable Equivalence

Class: Core exact deterministic semantics
Status: Classical infrastructure used by GURF

For an exact deterministic retained representation \(F:X\to Z\), states are observationally equivalent when the representation gives the same realized value.

\[ \boxed{ x\sim_Fx' \iff F(x)=F(x'). } \]
Limits
  • This exact equality relation is not the universal semantics for stochastic, approximate, privacy, relational, or quantum response.

11. Fibre

Class: Core ambiguity object
Status: Classical infrastructure

The fibre over a realized observation value is the set of source states that remain indistinguishable after the declared representation.

\[ \boxed{ \mathcal F_F(z) = F^{-1}(z) = \{x\in X:F(x)=z\}. } \]
Reading note

A fibre is not automatically a defect. It becomes a Task obstruction only when the Task varies inside it.

12. Completion Fibre

Class: Core multi-observation ambiguity object
Status: Canonical GURF use

For an active family of observations \(r_\alpha:X\to Y_\alpha\), the Completion Fibre records the states compatible with all declared retained information.

\[ \boxed{ \mathfrak C_A(\ell) = \bigcap_{\alpha\in A} r_\alpha^{-1}(\ell_\alpha). } \]
What it allows
  • Expose exact ambiguity after several observation channels.
  • Make inconsistency visible when the intersection is empty.
  • Support Task-relative sufficiency and repair analysis.
Theorems: Completion-fibre sufficiency
Passports: Passport fibre

13. Exact Task Sufficiency

Class: Core factorization criterion
Status: Mathematically established

The retained response representation is exactly sufficient for Task \(T\) when the Task can be computed from the realized retained representation alone.

\[ \boxed{ F(x)=F(x') \Longrightarrow T(x)=T(x') } \] if and only if there exists \[ \widetilde T:F(X)\to W \] such that \[ \boxed{ T=\widetilde T\circ F. } \]
Limits
  • The natural factor domain is the realized image \(F(X)\).
  • Exact sufficiency for one Task does not imply full-state recovery or Dynamic Closure.
Theorems: Exact Recoverability
Passports: Exact Passport sufficiency

14. Full-State Recovery Is Stronger

Class: Core identifiability firewall
Status: Canonical

Task recovery can succeed even when many source states remain indistinguishable. Full state identification is a stronger requirement.

\[ F(x)=F(x') \not\Rightarrow x=x' \] may coexist with \[ \boxed{ F(x)=F(x') \Longrightarrow T(x)=T(x'). } \]
Failure / obstruction tests
  • Equating Task identifiability with full physical-state identifiability.

15. Approximate Sufficiency

Class: Core quantitative semantics
Status: Active / sector-dependent

When exact equality is too strong, the Task space must carry an explicit metric, divergence, risk, or other discrepancy.

\[ F(x)=F(x') \Longrightarrow \boxed{ d_W(T(x),T(x'))\le\varepsilon. } \]
Limits
  • The discrepancy, tolerance, and domain are part of the claim.
  • Approximate similarity is not automatically an equivalence relation.
Passports: Approximate Passport conditions

16. Task Diameter

Class: Core quantitative ambiguity diagnostic
Status: Mathematically established

Task diameter measures the variation of the downstream Task inside one retained-information fibre.

\[ \boxed{ D_{F,T}(z) = \sup_{x,x'\in F^{-1}(z)} d_W(T(x),T(x')). } \]
What it allows
  • Zero diameter exactly characterizes exact metric Task sufficiency.
  • Positive diameter quantifies Task-relevant ambiguity.
Theorems: Task-diameter criterion
Passports: Task diameter

17. Response Defect

Class: Core diagnostic family
Status: Active formalization

A response defect is any explicitly typed failure quantity or set measuring departure from a required response condition.

\[ \boxed{ \Delta_{\mathcal R}(x) = d\!\left( \text{actual response object}, \text{required response object} \right) } \] when a justified discrepancy exists.

Mathematical objects

  • Task defect;
  • Interface defect;
  • constraint defect;
  • closure defect;
  • coherence defect;
  • invariant drift;
  • recovery residual.
Limits
  • Different defects live in different mathematical spaces and cannot be added or compared without a justified common scale.

18. Obstruction

Class: Core failure object
Status: Canonical

A deterministic response obstruction occurs when retained information merges states that a required Task must distinguish.

\[ \boxed{ F(x)=F(x') \quad\text{but}\quad T(x)\neq T(x'). } \]
What it allows
  • Provide a precise reason the current representation cannot solve the declared Task.
  • Identify which distinction a repair must restore.

19. Repair

Class: Core information refinement
Status: Canonical

A repair augments or changes the retained response information so the failed Task or Interface condition can become satisfiable.

\[ q:X\to Q, \qquad (F,q):X\to Z\times Q, \] \[ \boxed{ (F,q)(x)=(F,q)(x') \Longrightarrow T(x)=T(x'). } \]
Theorems: Repair refinement theorem
Passports: Passport repair

20. Minimal or Least-Cost Repair

Class: Core optimization
Status: Conditional

Minimality requires an admissible repair class and an explicit cost or order.

\[ \boxed{ \inf_{q\in\mathcal Q_{\rm adm}} \operatorname{Cost}(q) } \] subject to exact or declared approximate Task recovery.
Limits
  • A literal minimum is justified only when attainment is established.
  • Minimal information, minimal measurement cost, minimal computational cost, and minimal physical intervention are different optimization problems.
Passports: Minimal Passport repair

21. Dependency-Aware Repair

Class: Core/SOE repair discipline
Status: Active

In a serial response chain, repairing the earliest failed obligation is usually necessary before trusting downstream calculations.

\[ \boxed{ D_{g\circ f} \subseteq D_f\cup f^{-1}(D_g). } \]
What it allows
  • Localize an invalid response handoff.
  • Prevent downstream Leaves or inferences from being reused after an upstream Passport failure.
Theorems: Passport-defect localization
Passports: Defect localization

22. Continuation

Class: Core future-Task semantics
Status: Canonical

A representation that is adequate now may fail after evolution. GURF asks whether present retained information still determines the required future Task.

\[ \Phi_t:X\to X, \] \[ \boxed{ T\circ\Phi_t = \widetilde T_t\circ F } \] for some \[ \widetilde T_t:F(X)\to W. \]
Theorems: Dynamic continuation
Equations: Continuation equation

23. Dynamic Closure

Class: Core reduced-dynamics semantics
Status: Canonical

Dynamic Closure is stronger than one future Task being recoverable. The retained representation must determine its own exact future.

\[ F:X\to Z, \qquad \Phi:X\to X, \] \[ \boxed{ F\circ\Phi = \widetilde\Phi\circ F. } \]
Limits
  • Static Task sufficiency does not imply Dynamic Closure.
  • Closure does not imply stability, numerical accuracy, or physical adequacy.
Theorems: Dynamic Closure theorem · Task-vs-closure counterexample
Passports: Passport Dynamic Closure

24. Approximate Dynamic-Closure Defect

Class: Core quantitative dynamic diagnostic
Status: Active

When the retained space carries a justified discrepancy, a candidate reduced evolution can be tested by its failure to reproduce the reduced image of the full evolution.

\[ \boxed{ \Delta_{\rm cl}(x) = d_Z\!\left( F(\Phi(x)), \widetilde\Phi(F(x)) \right). } \]
Limits
  • Small one-step defect does not automatically give small long-time error.

25. Regime and Law Passport

Class: Core law-context semantics
Status: Canonical

Equal-looking states can respond differently under different active laws or Regimes. When future behavior depends on law context, the law index belongs in the effective response state or Passport.

\[ \lambda\in\Lambda, \qquad \mathfrak R_\lambda:X\to Y, \] \[ \boxed{ (x,\lambda)\in X\times\Lambda. } \]
Passports: Law Passports

26. Intervention

Class: Core controlled-response semantics
Status: Canonical

An Intervention changes which response is produced or which future state is reached.

\[ \mathfrak R:X\times U\to Y, \qquad \Phi_t:X\times U\to X. \]
Limits
  • Task sufficiency must be checked relative to the Intervention family actually allowed.
  • An uncontrolled observational representation can become insufficient once control actions are introduced.

27. Intervention Families

Class: Core/SOE control scope
Status: Active

A Task may depend on the response under a family of possible interventions, not just one fixed action.

\[ \mathcal U=\{u_\gamma\}_{\gamma\in\Gamma}, \] \[ \boxed{ F(x)=F(x') \Longrightarrow T(\Phi_t(x,u_\gamma)) = T(\Phi_t(x',u_\gamma)) \quad\forall\gamma } \] for uniform exact sufficiency.
Limits
  • The quantifier order changes if the control may adapt to the hidden state or observation history.

28. Joint Feasibility

Class: Core/ACE common-witness semantics
Status: Canonical

Several individually feasible response requirements may be mutually incompatible.

\[ P_c\subseteq X, \qquad \boxed{ \bigcap_{c\in\mathcal C}P_c\neq\varnothing. } \]
Theorems: Joint feasibility firewall
Passports: Joint feasibility

29. Quantifier Firewall

Class: Core logical semantics
Status: Canonical

Witness reuse, strategy reuse, and quantifier order are response information. They cannot be dropped when the Task depends on them.

\[ \forall c\,\exists x_c \not\Rightarrow \boxed{ \exists x\,\forall c } \] and \[ \boxed{ \exists\pi\,\forall\omega \neq \forall\omega\,\exists\pi_\omega. } \]
Theorems: Quantifier-scope firewall
Passports: Quantifier firewall

30. Stochastic Response

Class: Core stochastic semantics
Status: Canonical

A stochastic response maps a state to a probability law rather than a single deterministic output.

\[ \boxed{ M:X\rightsquigarrow Y, \qquad x\mapsto M(x,\cdot). } \] For an admissible test function, \[ \boxed{ M^\dagger\varphi(x) = \int_Y\varphi(y)M(x,dy). } \]
Limits
  • Equality of one mean is generally weaker than equality of laws.
  • Measurability and integrability remain native requirements.
Passports: Stochastic Passports

31. Exact Stochastic Response Equivalence

Class: Core stochastic equality
Status: Canonical

Exact stochastic response equivalence means equality of the entire output law.

\[ \boxed{ x\sim_Mx' \iff M(x,\cdot)=M(x',\cdot). } \]
Limits
  • A finite family of moments determines the law only under additional assumptions.

32. Stochastic Composition

Class: Core/SOE probabilistic composition
Status: Mathematically established

Stochastic response composition integrates over the intermediate law.

\[ K:X\rightsquigarrow Y, \qquad L:Y\rightsquigarrow Z, \] \[ \boxed{ (L\circ K)(x,A) = \int_YL(y,A)\,K(x,dy). } \] At the test level, \[ \boxed{ (L\circ K)^\dagger\phi = K^\dagger(L^\dagger\phi). } \]
Theorems: Markov composition

33. Stochastic Coupling Firewall

Class: Core joint-law semantics
Status: Canonical

Separate marginal response laws do not determine their joint dependence. When a joint response is required, a coupling must be supplied or proved to exist.

\[ \boxed{ \gamma\in\Gamma(\mu,\nu). } \]
Limits
  • Separate marginal feasibility does not imply one coupling satisfying several joint Tasks.
Passports: Coupling Passports

34. Differential-Privacy Firewall

Class: Core privacy semantics
Status: Canonical firewall

Differential privacy is a probabilistic comparison between output laws for neighboring inputs, not an exact response equivalence.

\[ x\sim_{\rm adj}x', \] \[ \boxed{ \Pr[M(x)\in S] \le e^\varepsilon\Pr[M(x')\in S]+\delta. } \]
Limits
  • Exact equivalence, approximate metric similarity, and differential privacy are different structures.
Theorems: Privacy firewall
Passports: Differential privacy

35. Nondeterministic Response

Class: Core relational semantics
Status: Canonical

A nondeterministic response is naturally relational or set-valued. GURF keeps possibility and guarantee semantics separate.

\[ R\subseteq X\times Y, \] \[ \Diamond_R(U)=\{x:\exists y\in U,\ xRy\}, \] \[ \Box_R(U)=\{x:\forall y,\ xRy\Rightarrow y\in U\}. \]
Limits
  • May and must semantics cannot be merged.

36. Relational Response Composition

Class: Core/SOE relational composition
Status: Mathematically established

The may and must operators compose with their own quantifier semantics.

\[ \boxed{ \Diamond_{S\circ R} = \Diamond_R\circ\Diamond_S, } \] \[ \boxed{ \Box_{S\circ R} = \Box_R\circ\Box_S. } \]
Theorems: Relational composition

37. Serial Information Loss

Class: Core deterministic information theorem
Status: Mathematically established

A deterministic downstream map cannot recreate distinctions already collapsed by an upstream deterministic representation unless genuinely new information enters.

\[ F(x)=F(x') \Longrightarrow \boxed{ (G\circ F)(x)=(G\circ F)(x'). } \]
Theorems: Serial loss

38. Parallel Refinement

Class: Core parallel observation structure
Status: Mathematically established

Parallel exact observation can refine ambiguity because the joint fibre is the intersection of the component fibres.

\[ F\parallel G=(F,G), \] \[ \boxed{ [x]_{F\parallel G} = [x]_F\cap[x]_G. } \]
Theorems: Parallel refinement

39. Core Versus Extensions

Class: governance separation
Status: Canonical

The Core asks what response information exists, what has been retained, and which Tasks or continuations it supports. Extensions answer specialized questions about how the response system operates.

\[ \boxed{ \text{Core} = \text{response-information question}, } \qquad \boxed{ \text{extension} = \text{specialized response mathematics}. } \]

40. SOE — Structured Operations Extension

Class: canonical GURF extension
Status: Stable canonical

SOE governs how Operations act on response systems: typing, partial domains, order, composition, localization, filtering, differentiation, reconstruction, Intervention, handoff, rebinding, and feedback.

Mathematical objects

  • typed Operations;
  • operation domains;
  • operation history/provenance;
  • serial/parallel structure;
  • handoff and REBIND Interfaces;
  • adaptive or feedback policy.

41. SOE Operation Contract

Class: SOE core contract
Status: Stable canonical

Every Operation must expose the information required to decide whether it is lawful and what it preserves.

\[ \boxed{ O: D_O \subseteq X_1\times\cdots\times X_n \to Y. } \]
Response audit
  • input/output types;
  • actual admissible domain;
  • active Regime;
  • required response information;
  • preserved/destroyed information;
  • Operation order;
  • failure conditions.
Equations: Composite-domain equation

42. SOE Composition Domain

Class: SOE partial composition
Status: Mathematically established

SOE inherits the true domain of partial composition.

\[ F:D_F\subseteq X\to Y, \qquad G:D_G\subseteq Y\to Z, \] \[ \boxed{ D_{G\circ F} = \{x\in D_F:F(x)\in D_G\}. } \]
Theorems: Typed composite domain

43. SOE Operation Order

Class: SOE order semantics
Status: Canonical

Filtering, differentiation, projection, localization, measurement, reconstruction, constraint activation, and Intervention need not commute.

\[ \boxed{ F\circ G \neq G\circ F } \] when the common domains exist.
Examples: Operation-order example

44. SOE Order Defect

Class: SOE quantitative order diagnostic
Status: Active

When outputs lie in a common linear space, an order defect can be measured by a commutator-like quantity.

\[ \boxed{ \Delta_{F,G}(x) = (F\circ G)(x)-(G\circ F)(x) } \] or \[ \boxed{ \|\Delta_{F,G}(x)\|. } \]
Limits
  • The subtraction/norm form requires the appropriate linear/normed structure.
  • Nonlinear or non-vector outputs need a sector-correct discrepancy.

45. SOE Parallel and Serial Algebra

Class: SOE composition pattern
Status: Canonical

Parallel Operations retain both outputs; serial Operations pass one output into the next.

\[ F\parallel G=(F,G), \qquad G\circ F. \]
Limits
  • Unrestricted distributivity between serial and parallel Operations is not assumed.

46. SOE Product-Separable Compatibility

Class: SOE exact identity
Status: Conditional

When the target map itself separates across the two output coordinates, the parallel observation can be transformed componentwise.

\[ \boxed{ (T_Y\times T_Z)\circ(F\parallel G) = (T_Y\circ F)\parallel(T_Z\circ G). } \]
Limits
  • This is narrower than unrestricted distributivity.

47. SOE Adaptive Systems

Class: SOE adaptive response
Status: Active

A recorded adaptive policy can make the second Operation depend on the first response.

\[ \boxed{ A(x) = \left( F(x), G_{F(x)}(x) \right). } \]
Limits
  • A feedback system reduces to an ordinary deterministic function only when the closed-loop response is single-valued.
  • Otherwise stochastic, relational, or game semantics may be required.

55. ACE — Admissibility and Constraint Extension

Class: canonical GURF extension
Status: Stable canonical

ACE governs when response states, Operations, trajectories, interventions, and inferences are allowed by hard constraints, soft constraints, positivity, boundary conditions, viability, coercivity, convexity, and stability gates.

56. ACE Admissible Set

Class: ACE state admissibility
Status: Canonical

A response theorem asserted only on an admissible set does not automatically extend to the entire ambient state space.

\[ \boxed{ \mathcal A\subseteq X. } \]

57. ACE Constraint Intersection

Class: ACE joint constraint structure
Status: Canonical

When several hard constraints must hold simultaneously, the admissible region is their joint intersection.

\[ \boxed{ \mathcal A = \bigcap_{j=1}^{m}K_j. } \]
Limits
  • Each \(K_j\) being nonempty does not imply their intersection is nonempty.

58. ACE Constraint Activation

Class: ACE Regime-dependent constraint
Status: Active

Some constraints exist only under particular states, laws, modes, or Interventions.

\[ \boxed{ a_j:X\times\Lambda\to\{0,1\}. } \]
What it allows
  • Represent mode-dependent safety limits and law-dependent admissibility.

59. ACE Soft Constraints

Class: ACE optimization constraint
Status: Active

A soft constraint contributes a penalty or risk rather than an absolute feasibility gate.

\[ g_j(x)\le 0 \quad\text{hard}, \qquad \boxed{ J_\rho(x) = J(x)+\rho\,\psi(g_j(x)) } \quad\text{soft}. \]
Limits
  • Penalty minimization does not prove hard feasibility unless an exact-penalty theorem or limiting argument supplies it.

60. ACE Coercivity

Class: ACE analytic gate
Status: Standard mathematics used by ACE

Coercive estimates can support boundedness, compactness, or existence arguments when the relevant native theorem applies.

\[ \boxed{ E(x)\ge c\|x\|^p-C, \qquad c>0. } \]
Limits
  • The norm, exponent, domain, constants, and theorem using the estimate must be specified.

61. ACE Convexity

Class: ACE optimization geometry
Status: Standard mathematics used by ACE

Convexity can simplify response optimization or feasible-set geometry.

\[ \boxed{ E(\theta x+(1-\theta)y) \le \theta E(x)+(1-\theta)E(y), \qquad 0\le\theta\le1. } \]
Limits
  • Convexity does not imply physical dynamical stability.

62. ACE Static/Dynamic Firewall

Class: ACE claim firewall
Status: Canonical

A static positive or convex energy-like condition is not automatically a dynamical stability theorem.

\[ \boxed{ \text{static admissibility} \not\Rightarrow \text{hyperbolicity / spectral stability / nonlinear stability}. } \]
Failure / obstruction tests
  • Calling positivity 'stability' without specifying the stability notion.
  • Treating an energy lower bound as a proof that every trajectory remains admissible.

63. ACE Viability

Class: ACE trajectory admissibility
Status: Standard control/viability mathematics used by ACE

A trajectory is viable when the dynamics keep it inside the declared admissible region over the interval of interest.

\[ \boxed{ \Phi_t(x)\in K \qquad \forall t\in I. } \]
Limits
  • Starting in \(K\) does not imply remaining in \(K\).

64. ACE Feasibility Margin

Class: ACE quantitative safety diagnostic
Status: Active

When constraints admit a signed slack or distance-to-failure interpretation, ACE can track how close the response is to an admissibility boundary.

\[ g_j(x)\le0, \qquad \boxed{ m_j(x)=-g_j(x). } \]
Limits
  • A margin is meaningful only relative to the chosen normalized constraint representation.

65. ACE Boundary and Tangency

Class: ACE continuous-time viability audit
Status: Sector-dependent

For differential dynamics \(\dot x=f(x)\) and a smooth constraint \(g(x)\le0\), an outward-pointing vector field at the boundary can violate viability.

\[ g(x)=0, \qquad \boxed{ \nabla g(x)\cdot f(x)\le0 } \] is a familiar sufficient local tangency condition in the smooth scalar-constraint case.
Limits
  • General viability theory uses tangent cones and sector-specific hypotheses.

66. ACE Chance Constraints

Class: ACE stochastic admissibility
Status: Active

A stochastic response may be admissible only with sufficiently high probability.

\[ \boxed{ \Pr(g(X)\le0)\ge1-\alpha. } \]
Limits
  • Chance constraints are not hard guarantees.
  • The probability model and uncertainty law are part of the constraint.

67. ACE Constraint Conflict

Class: ACE infeasibility diagnosis
Status: Active

ACE should distinguish 'bad response' from 'no response can satisfy all declared constraints.'

\[ \boxed{ \bigcap_jK_j=\varnothing } \] is structural infeasibility.
What it allows
  • Identify a minimal or near-minimal conflicting constraint subset when the native optimization problem allows it.

68. ACE Regime-Switched Constraints

Class: ACE law-dependent admissibility
Status: Active

If constraints depend on the active Regime, admissibility belongs to the combined state-law object.

\[ \boxed{ \mathcal A_\lambda = \{x:g_j(x,\lambda)\le0\ \forall j\}. } \]
Response audit
  • Was \(\lambda\) retained in the Passport?
  • Can a Regime switch make a previously admissible response inadmissible?

69. IRE — Inference and Recovery Extension

Class: canonical GURF extension
Status: Stable canonical

IRE studies what can be inferred from retained response information: feasible inverse sets, Task-relative identifiability, ambiguity, uncertainty, stable recovery, regularization, certificates, and observation design.

70. IRE Historical Lineage

Class: project lineage
Status: Historical / superseded naming

Earlier project material used GURE for much of the inverse-recovery program. That lineage is consolidated into IRE rather than maintained as another active extension.

\[ \boxed{ \mathrm{GURE} \longrightarrow \mathrm{IRE}. } \]

71. IRE Feasible Inverse Set

Class: IRE exact inverse object
Status: Canonical

Inference begins from every admissible state compatible with the datum, not from the assumption that one fitted estimate is automatically the truth.

\[ F:X\to Y, \qquad \boxed{ \mathcal C(y) = \{x\in\mathcal A:F(x)=y\}. } \]
What it allows
  • Separate existence, multiplicity, and Task-identifiability.

72. IRE Task-Relative Identifiability

Class: IRE target recovery
Status: Canonical

A target may be uniquely determined even when the full state is not.

\[ \boxed{ x,x'\in\mathcal C(y) \Longrightarrow T(x)=T(x'). } \]
Reading note

IRE therefore treats identifiability as Task-relative unless full-state recovery is explicitly requested.

73. IRE Local Versus Global Identifiability

Class: IRE scope distinction
Status: Active

A model can be locally identifiable near one state while admitting distant states with the same observation.

\[ \boxed{ F^{-1}(F(x_*))\cap U=\{x_*\} } \] for a neighborhood \(U\) is local uniqueness; global uniqueness requires \[ \boxed{ F^{-1}(F(x_*))=\{x_*\}. } \]

74. IRE Stable Recovery

Class: IRE inverse stability
Status: Sector-dependent

Exact uniqueness does not guarantee that nearby data produce nearby recovered states.

\[ \boxed{ d_X(x,x') \le \omega\!\left( d_Y(F(x),F(x')) \right). } \]
Limits
  • The modulus, domain, and inverse-problem class must be specified.

75. IRE Uncertainty Fibre

Class: IRE approximate feasible set
Status: Canonical quantitative structure

With observational tolerance \(\delta\), inference should propagate the entire admissible data-consistent set.

\[ \boxed{ \mathcal C_\delta(y) = \{x\in\mathcal A:d_Y(F(x),y)\le\delta\}. } \] The Task uncertainty set is \[ \boxed{ T(\mathcal C_\delta(y)). } \]

76. IRE Conditioning

Class: IRE numerical/inverse sensitivity
Status: Active

A recovery problem can be theoretically identifiable yet numerically fragile. For differentiable local inverses, conditioning is tied to the local sensitivity of the forward map.

\[ J_F(x)=\frac{\partial F}{\partial x}. \] Small singular values of \(J_F\) can indicate locally weakly observed directions.
Limits
  • Local Jacobian conditioning does not settle global identifiability.

77. IRE Sensitivity

Class: IRE response-to-parameter differential
Status: Active

Sensitivity records how observed response changes under perturbations of state, parameter, control, or Regime.

\[ \boxed{ S_{ij}(x) = \frac{\partial F_i}{\partial x_j}(x). } \]
What it allows
  • Identify weakly observed directions.
  • Guide measurement selection and uncertainty propagation.

78. IRE Regularization Firewall

Class: IRE selection-vs-identifiability firewall
Status: Canonical

A regularizer can choose one preferred solution from a broad feasible set. That does not prove the underlying physical or mathematical state was uniquely identified by the data.

\[ \boxed{ \text{unique regularized optimizer} \neq \text{unique data-identifiable source}. } \]

79. IRE Recovery Certificate

Class: IRE evidence object
Status: Canonical

A recovery certificate must state exactly what has been established.

Mathematical objects

  • existence;
  • full uniqueness;
  • Task uniqueness;
  • stability;
  • uncertainty radius;
  • admissibility;
  • numerical approximation accuracy;
  • model dependence.
Limits
  • These certificate strengths must not be silently merged.

80. IRE Certificate Hierarchy

Class: IRE claim-order structure
Status: Active

It is useful to distinguish progressively stronger claims rather than using one word such as 'recovered.'

\[ \boxed{ \text{feasible} \prec \text{Task-identifiable} \prec \text{full-state identifiable} } \] and separately \[ \boxed{ \text{unique} \not\Rightarrow \text{stable}. } \]

81. IRE Bayesian / Structural Identifiability Firewall

Class: IRE inference semantics
Status: Canonical firewall

A sharply concentrated posterior may reflect strong prior information as well as informative data. IRE keeps data identifiability and posterior concentration separate.

\[ p(x\mid y)\propto p(y\mid x)p(x). \]
Failure / obstruction tests
  • Calling prior-driven posterior concentration 'data identification'.
  • Treating a MAP estimate as proof that the compatible physical state is unique.

82. IRE Observation Design

Class: IRE experimental design
Status: Active

If several observations are available, IRE can search for a measurement family that shrinks Task ambiguity rather than merely increasing raw data volume.

\[ \boxed{ A^\star \in \operatorname*{arg\,min}_{A\in\mathcal A_{\rm obs}} \sup_{\ell} \operatorname{diam}_T \mathfrak C_A(\ell) } \] when the optimization is well-defined.
Limits
  • Measurement cost, noise, feasibility, and experimental disturbance can change the optimum.

Class: IRE local statistical information
Status: Conditional classical result used by GURF

For a scalar parameter in a locally Gaussian fixed-covariance model, the whitened score direction is the local one-dimensional carrier of Fisher information.

\[ g = V^{-1/2}\frac{d\mu}{d\theta}, \qquad I_{\rm full}=\|g\|^2, \] \[ \boxed{ I(P)=\|Pg\|^2\le\|g\|^2. } \]
Theorems: Gaussian Fisher carrier

84. IRE Ambiguity Geometry

Class: IRE geometric diagnostic
Status: Active

Inverse ambiguity can have dimension, curvature, disconnected components, anisotropy, and boundaries. Treating the compatible set as one scalar uncertainty radius can erase useful structure.

\[ \boxed{ \mathcal C(y) = F^{-1}(y)\cap\mathcal A } \] may be a manifold, stratified set, discrete collection, convex set, or other native geometric object.

Status: Stable canonical

Spectral response represents the system through eigenmodes, spectral measures, or frequency components when the native operator supports that decomposition.

\[ L\phi_n=\lambda_n\phi_n, \qquad f=\sum_n\langle f,\phi_n\rangle\phi_n \] in a discrete spectral setting.
Limits
  • Completeness, self-adjointness, boundary conditions, and spectral type must be established by the native operator theory.

  • Support Green/resolvent representations when justified.

92. UKE-RK — Reproducing Kernel Sector

Status: Stable canonical

\[ \boxed{ f(x) = \langle f,K_x\rangle_{\mathcal H}. } \]
Limits
  • Positive-definite reproducing kernels, integral kernels, and nullspace kernels are distinct notions.
