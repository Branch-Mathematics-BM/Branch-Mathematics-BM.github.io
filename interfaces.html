Finite interface synthesis

The finite synthesis problem asks for the coarsest branch-local exact interfaces that preserve the distinctions already required by receiver tasks and Passports while also preserving declared local continuation and declared Interactions. The construction refines all Branch interfaces simultaneously until every required local and cross-Branch behavior descends exactly.

Principal theorem family: T55-C1 through T55-C7, with T55-C7R the finite relational extension. The ingredients belong to the stable-partition / congruence / finite-fixed-point tradition; historical novelty over general refinement methods is not asserted.

1 · Why static compression is not enough

Mathematical objective

A static task quotient can preserve every task required now and still fail after one local step. Even if every Branch is individually reduced in a way that is stable under its own local dynamics, two or more such reduced Branches can still fail when they enter a declared Interaction.

Static task requirement

States merged by a branch interface must agree on every distinction already required by its initial tasks and Passport.

Local continuation requirement

Equivalent current states must induce the same reduced successor information under every declared local action.

Interaction requirement

Replacing one Interaction input by an interface-equivalent state must preserve definedness and the receiver output class in every declared context.

\[ \boxed{ \text{task sufficiency} + \text{local closure} + \text{Interaction descent} \Longrightarrow \text{exact finite interface family} } \]

The simultaneous-refinement theorem enforces those requirements together and records why each additional split was necessary.

3 · Supplied finite model

Exact finite model

Let \(X_1,\ldots,X_n\) be nonempty finite sets. Branch \(i\) begins with an equivalence \(B_i\) that already encodes every distinction required by its current tasks and Passport.

Interface refinement order

A candidate interface \(E_i\subseteq B_i\) is a refinement of the initial equivalence. Because larger equivalence relations merge more states, the coarsest admissible interface is the largest equivalence relation satisfying all requirements while remaining below \(B_i\).

Each Branch has finitely many declared local action relations

\[ L_{i,a}\subseteq X_i\times X_i. \]

A partial deterministic action is represented by its graph. An empty successor set is therefore retained as a mathematically different outcome from any nonempty successor set.

Partial Interactions

Every declared Interaction has the form

\[ G_b: D_b\subseteq X_{i_1}\times\cdots\times X_{i_m} \longrightarrow X_{r(b)}. \]

The theorem uses all Cartesian contexts: each input slot can be replaced independently while the other slots are held fixed.

Product-context hypothesis

If the application imposes shared-variable aliasing, correlated admissibility, or only a restricted family of reachable contexts, that restricted context family requires its own substitution-closure argument. The theorem’s minimality is relative to the declared product-form obligations.

Preserving definedness

Introduce an output tag \(\bot\), totalize \(G_b\) to \(\widehat G_b\), and extend the receiver equivalence by a singleton undefined class:

\[ \{\bot\} \quad\text{is a separate }E_{r(b)}^\bot\text{-class}. \]

This prevents a reduced Interaction from silently identifying “undefined” with an ordinary defined output.

4 · Local exact closure

Successor signatures

For a local relation \(L\) and candidate equivalence \(E_i\), define

\[ \boxed{ S_{L,E_i}(x) = \{[y]_{E_i}:xLy\} }. \]

Two current states can remain equivalent only if they have exactly the same set of successor equivalence classes. Equality here is exact set equality; overlap is not enough.

Local refinement kernel

\[ \ker S_{L,E_i} = \{(x,x'):S_{L,E_i}(x)=S_{L,E_i}(x')\}. \]

This is an equivalence relation because it is the kernel of a specified signature map.

Why collision overlap is not used

A relation defined only by overlapping successor sets need not be transitive. The refinement construction therefore uses equality of successor signatures, not overlap.

5 · Cross-Branch exactness

Interaction contextual equivalence

For input slot \(p\) of Interaction \(b\), two candidate states \(u,v\) are contextually equivalent relative to the current receiver equivalence when replacing one by the other never changes the tagged receiver output class:

\[ \boxed{ u\ C_{b,p}(E_{r(b)})\ v \iff \widehat G_b(c_1,\ldots,u,\ldots,c_m) \ E^\bot_{r(b)}\ \widehat G_b(c_1,\ldots,v,\ldots,c_m) } \] for every choice of the other input entries \(c\).

Because the tagged outputs are compared by equality of receiver classes, each \(C_{b,p}(E_{r(b)})\) is again a kernel equivalence.

Defined / undefined mismatch

If one fixed context makes \(G_b\) defined at \(u\) and undefined at \(v\), the pair must split.

Receiver-class mismatch

If both are defined but their outputs lie in different receiver classes in any context, the pair must split.

6 · Principal theorem

T55-C7R — Finite simultaneous refinement theorem

Statement proved

Start with the family \(\mathbf E^0=\mathbf B\), and define recursively

\[ \boxed{ E_i^{k+1} = E_i^k \cap \bigcap_a \ker S_{L_{i,a},E_i^k} \cap \bigcap_{b,p:i_p=i} C_{b,p}(E_{r(b)}^k) }. \]

The iteration terminates at a family \(\mathbf E^*\) with all of the following properties:

  1. Every task and initial Passport distinction represented by \(B_i\) factors through \(X_i/E_i^*\).
  2. Every local relation has an exact reduced successor relation, including exact preservation of dead ends.
  3. Every declared Interaction descends to a partial map on the product of reduced interfaces, preserving both definedness and receiver output class.
  4. If another equivalence family \(\mathbf H\subseteq\mathbf B\) satisfies the same requirements, then \(H_i\subseteq E_i^*\) for every Branch. Therefore \(\mathbf E^*\) is uniquely coarsest in the declared class.
  5. The number of strict-refinement rounds is at most \[ \sum_i\left(|X_i|-|X_i/B_i|\right). \] 
initialize E[i] := B[i]

repeat
    for each Branch i:
        keep only pairs equivalent under:
            1. the current E[i]
            2. every local successor-signature kernel
            3. every Interaction contextual-equivalence test
    replace E by the intersections
until no Branch partition changes

return E*

The round bound is a bound on strict partition refinements, not a runtime bound and not a bound on the size of the Interaction context tables.

7 · Proof

Termination and preservation of equivalence structure

Proof

Step 1 — every update is still an equivalence

Each successor-signature kernel is an equivalence. Each contextual Interaction relation is also an equivalence. Their intersection with \(E_i^k\) is therefore an equivalence relation contained in \(E_i^k\).

Step 2 — strict refinement increases class count

A strict decrease of an equivalence relation splits at least one equivalence class, increasing the number of classes by at least one.

Step 3 — the total number of possible splits is finite

Initially the total number of classes is \(\sum_i |X_i/B_i|\). It can never exceed \(\sum_i|X_i|\). Hence there can be no more than

\[ \sum_i\left(|X_i|-|X_i/B_i|\right) \]

strict refinement rounds.

Therefore the descending chain stabilizes after finitely many strict rounds. \(\square\)

8 · Proof

Exactness at the fixed point

Task preservation

Because \(E_i^*\subseteq B_i\), no distinction already encoded by the initial task/Passport equivalence is lost by the final interface.

Local relational closure

At the fixed point, \(xE_i^*x'\) implies equality of successor-class sets for every local action:

\[ S_{L,E_i^*}(x)=S_{L,E_i^*}(x'). \]

Therefore the reduced successor set of an interface class can be defined by \[ \overline L[[x]_{E_i^*}] := S_{L,E_i^*}(x), \] independently of which representative \(x\) is chosen. Empty successor sets remain empty.

Interaction descent

Consider two Interaction input tuples \((u_1,\ldots,u_m)\) and \((v_1,\ldots,v_m)\) satisfying \(u_pE_{i_p}^*v_p\) in every slot.

Replace the slots one at a time. Contextual equivalence gives equality of the tagged receiver class after every single replacement. By transitivity, the original tuple and final tuple have the same tagged receiver class.

Because \(\bot\) is its own class, one tuple is in the Interaction domain if and only if the other is. When both are defined, their outputs lie in the same receiver class. Thus \(G_b\) descends to a well-defined partial Interaction on reduced interfaces.

\(\square\)

9 · Proof

Coarsestness

Competitor family

Let \(\mathbf H\subseteq\mathbf B\) be any other family that preserves the same initial tasks, has exact local relational closure, and makes every declared Interaction descend exactly.

We prove by induction on \(k\) that

\[ H_i\subseteq E_i^k \qquad\text{for every }i,k. \]

Base case

\(\mathbf H\subseteq\mathbf B=\mathbf E^0\) by assumption.

Local-action induction step

Suppose \(H_i\subseteq E_i^k\). If \(xH_ix'\), exact \(H_i\)-closure gives equality of the sets of successor \(H_i\)-classes. Each \(H_i\)-class sits inside one \(E_i^k\)-class, so mapping those successor classes into the coarser \(E_i^k\)-classes yields equal \(E_i^k\)-successor signatures.

Interaction induction step

Changing one \(H_i\)-equivalent Interaction input while holding all other inputs fixed gives the same tagged receiver \(H\)-class because the Interaction descends through \(\mathbf H\). That tagged \(H\)-class lies inside one tagged \(E^k\)-class, so the pair passes every contextual equivalence test used to define \(E_i^{k+1}\).

Hence \(H_i\subseteq E_i^{k+1}\). Induction gives \(\mathbf H\subseteq\mathbf E^*\).

Because the terminal family \(\mathbf E^*\) itself satisfies the requirements, it is the greatest admissible equivalence family below \(\mathbf B\), equivalently the uniquely coarsest exact interface family in the declared class. \(\square\)

10 · T55-C7

Deterministic specialization

For a total deterministic action \(f_{i,a}\), the relational successor signature contains exactly one class:

\[ S_{L,E}(x)=\{[f_{i,a}(x)]_E\}. \]

Therefore the local refinement term reduces to

\[ (f_{i,a}\times f_{i,a})^{-1}E. \]

This is the deterministic simultaneous-refinement theorem T55-C7. For partial deterministic maps, the relational formulation additionally distinguishes the empty successor signature from singleton successor signatures, which is exactly the required availability distinction.

11 · T55-C1

Finite trace lifting

Suppose one relation \(L\) has exact closure through quotient map \(q\). Every finite reduced path beginning at \(q(x)\) can be lifted to a native path beginning at that specific state \(x\).

At each reduced edge, equality of successor-class sets supplies a concrete successor in the required next class. Repeating the argument from the selected successor gives, for every finite \(m\ge0\),

\[ \boxed{ q(L^m[x]) = \overline L^{\,m}[q(x)] }. \]

The same finite induction applies to a declared finite word of action labels.

What trace lifting does not imply

It does not infer a game strategy from reachable sets, erase action scheduling, guarantee an infinite path, or supply an analytic limit merely because every finite trace lifts.

12 · T55-C5

Sufficient finite composition certificate

For product-independent local relations followed by an Interaction that descends through the final interfaces, match each Branch coordinate to the required successor class independently and then apply the descending Interaction.

\[ \text{exact local class matching} + \text{Interaction descent} \Longrightarrow \text{exact product-form composition}. \]

Correlated transitions are outside this certificate

If local transitions are coupled by a shared joint law or restricted joint transition relation, the joint transition itself requires a closure audit. Independent coordinate certificates do not automatically certify a correlated joint transition.

13 · Receiver-relative repair

T55-C6 — Minimal receiver repair

Sometimes an existing branch interface \(R_i\) must be kept, while the only new requirement is a receiver task \(T\) of an Interaction output. Totalize both Interaction applicability and the task so that definedness is itself retained.

Coarsest branch-local repair

For input Branch \(i\), define

\[ \boxed{ u\equiv_i v \iff R_i(u)=R_i(v) \ \text{and}\ \widehat T\!\left(\widehat G(u,c)\right) = \widehat T\!\left(\widehat G(v,c)\right) \quad\forall c }. \]

This is an intersection of kernels and therefore an equivalence relation. Coordinate-by-coordinate substitution shows that the receiver task of the Interaction factors through the product of these branch quotients.

Conversely, any branch-local refinement that keeps \(R_i\) and makes the same receiver task factor through the Interaction must identify only pairs that agree in every fixed context. Therefore its equivalence is contained in \(\equiv_i\).

Hence \(\equiv_i\) is the uniquely coarsest branch-local repair relative to the declared receiver task and context family.

Enlarging the task family or the context family adds kernel intersections, so the admissible equivalence can only refine.

Restricted context families

If only certain correlated contexts are legal, coordinate-by-coordinate substitution must stay inside that declared family. An arbitrary context restriction does not automatically have this closure property.

14 · Operational certificate

Why each split happened

The finite calculator can store each refinement round and a concrete reason for every split. Those reasons are replayable certificates for the supplied finite model.

Successor-signature witness Two currently equivalent states reach different sets of current interface classes.
Definedness witness A fixed Interaction context makes one candidate input defined and the other undefined.
Receiver-class witness A fixed Interaction context produces outputs lying in different current receiver classes.

These are certificates of the supplied finite tables. They are not physical measurements, hardware-cost proofs, or automatically minimal coordinate encodings.

15 · Interaction example

XOR forces distinctions that local dynamics do not

Model

Let source Branch \(A=\{0,1\}\) and input Branch \(B=\{0,1\}\) both have identity local evolution and initially constant observations. Let receiver Branch \(C=\{0,1\}\) have the identity task, and define

\[ G(a,b)=a\mathbin{\mathrm{xor}}b. \]

Local dynamics alone allow the constant interfaces on both \(A\) and \(B\).

But with context \(b=0\), \[ G(0,0)=0,\qquad G(1,0)=1, \] so the two \(A\)-states must split at the receiver. Similarly, context \(a=0\) distinguishes the two \(B\)-states.

The simultaneous refinement therefore makes both source interfaces injective.

If the receiver task is changed to a constant task and no domain-acceptance distinction is imposed, those splits are no longer required.

What this example demonstrates

Independent local stability is not enough for coupled exactness. Receiver requirements carried through an Interaction can force additional Branch distinctions.

16 · Dynamic example

Present task sufficiency can fail after one step

Four-state cycle

Let

\[ X=\{0,1,2,3\}, \qquad f=(1,2,3,0), \]

with present task values

\[ T=(0,0,1,1). \]

The initial task partition is \[ \{0,1\}\mid\{2,3\}. \] It is exactly sufficient for the present task.

Yet \(0\) and \(1\) move into different present-task blocks, as do \(2\) and \(3\). Their successor signatures are therefore different, so the first refinement splits every pair.

\[ \{0\}\mid\{1\}\mid\{2\}\mid\{3\}. \]

Thus exact present task sufficiency did not imply one-step Dynamic Closure.

17 · T55-C3

Approximate relational closure

Let \(Z\) be a metric space and let every \(Q(x)\) be a nonempty compact subset of \(Z\). For one nonempty observation fibre \(R^{-1}(z)\), define the family

\[ \mathscr Q_z = \{Q(x):R(x)=z\}. \]

Let its Hausdorff diameter be

\[ \Delta(z) = \sup_{A,B\in\mathscr Q_z} d_H(A,B), \]

and define the best unrestricted compact-center radius

\[ \rho(z) = \inf_{\varnothing\ne C\subseteq Z\ \mathrm{compact}} \sup_{A\in\mathscr Q_z}d_H(A,C). \]

Radius bounds

\[ \boxed{ \frac12\Delta(z) \le \rho(z) \le \Delta(z) }. \]

The lower bound follows from the Hausdorff triangle inequality. The upper bound follows by choosing any member of \(\mathscr Q_z\) as the candidate center.

In particular, \(\rho(z)=0\) if and only if \(\Delta(z)=0\), which is exactly equality of all successor-image sets in that fibre and hence exact relational closure.

Approximate equality is not a quotient

No equivalence relation is formed by simply thresholding a distance with \(d\le\varepsilon\); such threshold relations need not be transitive. Empty successor sets are also excluded from this Hausdorff statement unless a separate dead-end convention is supplied.

18 · T55-C4

Finite-horizon error propagation

Suppose the reduced set-valued update \(\overline Q\) is \(L\)-Lipschitz in Hausdorff distance:

\[ d_H\!\left(\overline Q(z),\overline Q(z')\right) \le L\,d(z,z'). \]

Suppose also that the one-step concrete/reduced mismatch is uniformly bounded by

\[ d_H\!\left(Q(x),\overline Q(Rx)\right) \le \varepsilon. \]

Under the compactness assumptions stated in the edition, the error recurrence satisfies

\[ e_{k+1}\le\varepsilon+Le_k. \]

Starting from \(e_0=0\), induction gives

\[ \boxed{ e_m \le \varepsilon \sum_{j=0}^{m-1}L^j }. \]

Finite-horizon statement only

No infinite-time estimate follows from this formula unless the constants and the native model supply one. The theorem also assumes the relevant current sets, their images, and the unions used in the proof remain nonempty compact sets.

19 · Scope boundary

What finite interface synthesis does not prove

The theorem is strong inside its declared finite exact setting, but it does not silently solve problems belonging to other mathematical sectors.

Not established Why not
Global Configuration realizability Exact interfaces can preserve all supplied operations while additional global constraints still make the full Configuration unrealizable.
Continuous or smooth quotient structure The proof is finite and set-theoretic; native topology or smoothness needs separate hypotheses.
Stochastic reduction Markov closure requires equality of aggregated transition probabilities, not only equality of relational supports.
Minimal coordinate dimension Coarsest equivalence is not automatically a minimum-dimensional coordinate realization.
Minimal bit or hardware cost Implementation cost requires its own declared optimization problem.
Availability of missing distinctions The algorithm can prove a distinction is necessary even when the physical or computational system has no lawful source that can supply it.
Infinite-time or analytic continuation Finite legal refinement and trace lifting do not extend a native solution through singular endpoints or supply analytic limits.

Interpretation of “coarsest”

“Coarsest exact interface” means greatest admissible equivalence relation under inclusion. It should not be renamed “cheapest representation” unless a cost model has been defined and optimized.

20 · Historical position

Prior-art crosswalk

Established mathematical neighborhood

The finite refinement theorem belongs to the established stable-partition and bisimulation tradition. Its mathematical ingredients include partition refinement, congruence-style compatibility, and finite fixed-point stabilization.

The BM development packages receiver requirements, partial Interaction domains, exact dead-end preservation, and explicit contextual witnesses into one simultaneous Branch-local interface construction. That integration is part of the BM development, but it is not by itself evidence of historical novelty over general refinement methods.

The edition specifically identifies the Paige–Tarjan partition-refinement tradition and later abstract-interpretation generalizations as relevant prior art.

For the theorem-level historical statement and wider crosswalk, see Audit and sources.
