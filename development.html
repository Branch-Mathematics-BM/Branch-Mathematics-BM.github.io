Quantum recovery: formulation and verification

The latest note gives an exact physical recovery formulation for a supplied finite observable algebra, a real-algebraic procedure for optima and defect envelopes, and a common-recovery capability budget set. Endpoint attainment is tested explicitly because normalized-defect slices need not be closed.

Implementation status. The general quantifier-elimination procedure is proved but has not been implemented or run. The calculator implements exact real-rational verification for classical labels carried by quantum signal states.

For that native class, δ = 2(1 − p*), where p* is optimal worst-case measurement success. Matching primal and dual witnesses certify 15 example optima. Two specified nonorthogonal pure signals have exact recovery error 1/5.

BM23-I1–I2

Infinite carriers: a construction and a limit

A supplied effective uniform task-decay bound permits a finite response-tree predictor without compactness of the initial carrier or commutation of its actions. The note proves a noncommuting shift example on the infinite-dimensional Hilbert unit ball and gives a sufficient state bound. Initialization may have several valid codes for the same native state.

For M=1, L=1/2, ε=1/8, two task coordinates and two actions, forecast depth K=4 gives guaranteed error at most 1/16. The browser computes the exact state bound; the Python file constructs the initialized response tree.

The unrestricted problem has a negative result: a universal algorithm cannot approximate optimal infinite-horizon one-state error to additive accuracy 1/5 for all computable infinite systems. The proof already uses a fixed update on the natural numbers and binary rational task values.
