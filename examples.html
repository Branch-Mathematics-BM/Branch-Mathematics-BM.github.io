1. How to Learn BM from These Examples

Branch Mathematics is easiest to learn when the native mathematics is visible first. Each example therefore begins with a familiar mathematical problem, carries out the calculation, and only then identifies the BM roles that organize it.

The early examples are deliberately small. Their job is to isolate one structural idea at a time. Later sections reuse the same ideas in linear algebra, probability, dynamical systems, control, operator mathematics, PDEs, quantum theory, gauge structure, and multi-physics systems. The vocabulary stays the same while the mathematical load grows.

\[ \boxed{ \text{Branch} \to \text{Transformation} \to \text{Interaction} \to \text{Passport} \to \text{Composition} \to \text{Coherence} \to \text{Root} \to \text{Mixed Semantics} \to \text{Network} \to \text{Research Scale} } \]

A reader can therefore enter at the simplest level and watch the need for additional structure emerge rather than being asked to accept a large vocabulary all at once.

Each level now contains multiple worked cases. The intention is to show not only a successful formula, but the intermediate arithmetic, admissibility tests, domain pullbacks, competing Tasks, failed candidates, and repairs that justify the BM structure being activated.

Interpretation rule. BM does not make a simple problem complicated merely to use BM. When ordinary mathematics already solves the problem cleanly, the BM description should remain correspondingly simple. Complexity enters only when multiple structures, interfaces, information requirements, partial domains, competing paths, or semantic sectors make it necessary.

5. The Core BM Roles Before the Examples Begin

The easiest way to learn BM is to separate the mathematical thing from the mathematical role it is playing. A real number is not automatically a Branch, Leaf, Response, Root, or Seed. Its role depends on where it came from, what structure it carries, and what the next mathematics requires.

BM role Working meaning used on this page What it is not
Branch A typed mathematical carrier together with its admissibility, laws, operations, distinctions, and interface information. Not merely “a variable.” Two variables with the same numerical carrier may belong to different Branches.
Interaction A lawful joint mathematical action on a declared admissible domain involving participating Branches. Not every expression that can be typed into a calculator.
Leaf Information extracted from an Interaction result. One Interaction may expose several Leaves. Not every intermediate symbol. Its origin and extraction are part of its meaning.
Tree The organized structure coordinating Branches, Interactions, Leaves, Passports, Interfaces, and intermediate computation. Not necessarily a literal botanical tree or a simple binary graph.
Response The typed mathematical output produced by the organized computation. Not automatically reusable downstream.
Root A Response or resulting structure whose required downstream admissibility has been verified. Not synonymous with recurrence, conservation, invertibility, or a zero of an equation.
Seed An optional candidate primitive for information undergoing lawful generative evolution before a declared Root-export condition is reached. Not merely “the first input.” Initial data is a Seed only when the generative role and export condition are actually present.
A useful student habit Do the native mathematics first. Then ask which BM roles are genuinely present. BM should clarify the structure of the calculation, not force every problem to use every BM object.

6. Leaves Do Work — They Can Feed Later Mathematics

A common misunderstanding is to treat a Leaf as a decorative name for an answer. The more useful picture is that a Leaf exposes a piece of information from one Interaction. If another mathematical operation lawfully accepts that information, the Leaf can participate in a later Interaction.

\[ \boxed{ \text{Branches} \xrightarrow{\text{Interaction}} \text{Leaf} \xrightarrow{\text{new lawful Interaction}} \text{new Leaf} \xrightarrow{} \cdots } \]
Leaf Example A — Electrical Power → Energy → Temperature Change
Branch · Interaction · Leaf · Tree · Response · Root

Start with two Branches: \[ B_V:\text{voltage}, \qquad B_I:\text{current}. \] Take \[ V=24\text{ V}, \qquad I=5\text{ A}. \]

Interaction 1 — electrical power

\[ \mathcal I_P(V,I)=VI \] gives \[ P=(24)(5)=120\text{ W}. \]

The power value \[ L_P=120\text{ W} \] is a Leaf extracted from the voltage-current Interaction.

Interaction 2 — use the power Leaf with a time Branch

Introduce \[ B_t:\text{elapsed time}, \qquad t=30\text{ s}. \] The new Interaction is \[ \mathcal I_E(L_P,t)=L_Pt. \]

\[ E=(120\text{ W})(30\text{ s}) =3600\text{ J}. \]

The extracted energy \[ L_E=3600\text{ J} \] is now a new Leaf. It did not come directly from the first Interaction. It came from a second Interaction that used the first Leaf lawfully.

Interaction 3 — use the energy Leaf in a thermal calculation

Let a thermal-capacitance Branch carry \[ C_{\mathrm{th}}=900\text{ J/K}. \] If the simplified native law is \[ \Delta T=\frac{E}{C_{\mathrm{th}}}, \] then

\[ \Delta T = \frac{3600}{900} = 4\text{ K}. \]

The thermal change is another extracted result: \[ L_{\Delta T}=4\text{ K}. \]

What is the Tree?

\[ (B_V,B_I) \xrightarrow{\mathcal I_P} L_P \xrightarrow{\mathcal I_E\text{ with }B_t} L_E \xrightarrow{\mathcal I_T\text{ with }B_{C_{\rm th}}} L_{\Delta T}. \]

The Tree is the organized calculation containing those Branches, Interactions, Interfaces, and Leaves. If the purpose of the Tree was to predict the temperature increase, then \[ R=4\text{ K} \] is its Response.

Does the Response become a Root?

Suppose a receiving safety Branch accepts predicted rises only when \[ \Delta T\le5\text{ K}. \] Since \[ 4\le5, \] the Response passes that receiving condition and may function as a Root for the next safety calculation, subject to any other declared Passport requirements.

In plain language: one interaction gave us power. Power was useful, so we carried it forward. Power plus time gave energy. Energy plus thermal capacity gave a predicted temperature change. BM keeps the origin and lawful use of each piece visible instead of flattening the whole chain into one unexplained formula.
Leaf Example B — One Vector Interaction Produces Several Useful Leaves
Multiple Leaves from one Interaction

Let \[ a=(3,0), \qquad b=(2,2). \] Define one Interaction record containing quantities needed later:

\[ \mathcal I(a,b) = \left( a\cdot b,\; \|a\|,\; \|b\| \right). \]
Leaf 1 — dot product \[ L_{\cdot}=a\cdot b =3(2)+0(2) =6. \]
Leaf 2 — first magnitude \[ L_a=\|a\|=3. \]
Leaf 3 — second magnitude \[ L_b=\|b\| =\sqrt{2^2+2^2} =2\sqrt2. \]

These Leaves can now be combined to derive the angle:

\[ \cos\theta = \frac{L_{\cdot}}{L_aL_b} = \frac{6}{(3)(2\sqrt2)} = \frac1{\sqrt2}, \] so \[ \theta=\frac{\pi}{4}. \]

The same Leaves can also help derive the scalar projection of \(b\) onto \(a\):

\[ \operatorname{comp}_a b = \frac{a\cdot b}{\|a\|} = \frac63 = 2. \]

And the vector projection is

\[ \operatorname{proj}_a b = \frac{a\cdot b}{\|a\|^2}a = \frac{6}{9}(3,0) = (2,0). \]
Why this matters One Interaction can expose several Leaves, and different downstream mathematics may use different subsets of them. BM does not require every Leaf to be used by every later Task.
Leaf Example C — Residual Leaf Drives a Correction
Linear algebra · Leaf used to generate the next state

Consider \[ A= \begin{pmatrix} 4&0\\ 0&2 \end{pmatrix}, \qquad b= \begin{pmatrix} 8\\ 2 \end{pmatrix}, \] and a trial state \[ x_0= \begin{pmatrix} 1\\ 0 \end{pmatrix}. \]

The matrix-state Interaction produces \[ Ax_0= \begin{pmatrix} 4\\ 0 \end{pmatrix}. \] A residual extraction gives

\[ L_r = b-Ax_0 = \begin{pmatrix} 8\\2 \end{pmatrix} - \begin{pmatrix} 4\\0 \end{pmatrix} = \begin{pmatrix} 4\\2 \end{pmatrix}. \]

A second Leaf records its norm: \[ L_{\|r\|} = \sqrt{4^2+2^2} = \sqrt{20}. \]

In a chosen iterative method, the residual Leaf can lawfully feed a correction rule. For illustration, take \[ x_1=x_0+\alpha L_r \] with \(\alpha=\tfrac14\).

\[ x_1 = \begin{pmatrix} 1\\0 \end{pmatrix} + \frac14 \begin{pmatrix} 4\\2 \end{pmatrix} = \begin{pmatrix} 2\\0.5 \end{pmatrix}. \]

Recompute: \[ Ax_1= \begin{pmatrix} 8\\1 \end{pmatrix}, \qquad r_1= \begin{pmatrix} 0\\1 \end{pmatrix}. \] The new residual is smaller: \[ \|r_1\|=1<\sqrt{20}. \]

The Leaf did not merely summarize the previous Interaction. It became mathematically active in the next one.

Leaf Example D — Posterior Probability Leaf Feeds a Decision Branch
Probability · Leaf → downstream decision

Suppose a Bayesian Interaction produces \[ L_{\mathrm{post}} = P(H\mid D) = 0.82. \] A decision Branch may accept a positive action only when \[ P(H\mid D)\ge0.75. \]

\[ 0.82\ge0.75. \]

The posterior Leaf is therefore sufficient for this simple threshold decision. If a later Task instead requires the full posterior distribution over several hypotheses, the scalar \(0.82\) may be insufficient. What a Leaf enables depends on what information it actually carries.

Leaf Example E — Spectral Leaves Reconstruct an Energy Diagnostic
Fourier analysis · Many Leaves → one diagnostic

Let a discrete signal have Fourier coefficients \[ \widehat u_0=1, \qquad \widehat u_1=2, \qquad \widehat u_2=-1. \] Suppose the spectral Interaction exposes mode-energy Leaves \[ L_k=|\widehat u_k|^2. \]

Mode Leaves \[ L_0=1, \qquad L_1=4, \qquad L_2=1. \]

A later diagnostic Interaction sums those Leaves:

\[ E_{\mathrm{spec}} = \sum_{k=0}^{2}L_k = 1+4+1 = 6. \]

This is a simple model of how many local Leaves can feed one aggregate diagnostic. In larger PDE work the same structural idea scales to many modes, shells, derivatives, or localized quantities.

Leaf Example F — When a Leaf May Enter the Next Interaction
Abstract BM audit · Domain and Passport conditions

Let an Interaction \[ I:D_I\to Z \] expose a Leaf through \[ L=\ell(I(x)). \] Suppose a later Interaction wants \[ J:D_J\subseteq X_L\times X_C\to W, \qquad L\in X_L. \]

The fact that \(L\) exists does not by itself authorize \(J(L,c)\). The next step must verify at least

\[ (L,c)\in D_J, \]

together with the relevant type, law, Interface, and Passport conditions. If those checks pass, a new Leaf may be extracted:

\[ L' = \ell' \bigl( J(L,c) \bigr). \]
\[ x \xrightarrow{I} z \xrightarrow{\ell} L \xrightarrow[\text{only if admissible}]{J(\,\cdot\,,c)} w \xrightarrow{\ell'} L'. \]

This is the abstract pattern behind the earlier power, residual, posterior, and spectral examples.

7. Trees in Different Mathematical Situations

A Tree is the organized BM structure carrying the computation. Students should not assume that every Tree has the same shape. Here are four common patterns.

Tree Example A — Sequential Tree
A result from one stage becomes input to the next
\[ (V,I) \to P \to (P,t) \to E \to (E,C_{\mathrm{th}}) \to \Delta T. \]

This is the power-energy-temperature example above. The structural organization is predominantly sequential.

Tree Example B — Branching Use of One Interaction
One Interaction exposes several Leaves used differently

From vectors \(a,b\), one Interaction exposes \[ L_{\cdot}=a\cdot b, \qquad L_a=\|a\|, \qquad L_b=\|b\|. \]

\[ (a,b) \xrightarrow{\mathcal I} \begin{cases} L_{\cdot}\\ L_a\\ L_b \end{cases} \Longrightarrow \begin{cases} \theta\\ \operatorname{comp}_a b\\ \operatorname{proj}_a b \end{cases} \]

The Tree branches because the same extracted information supports several lawful downstream calculations.

Tree Example C — Parallel Paths with a Coherence Check
Two lawful routes reach a common destination

Convert \(20^\circ\mathrm C\) to Kelvin by two routes.

Route 1 — direct

\[ T_K=20+273.15=293.15\text{ K}. \]

Route 2 — through Fahrenheit

\[ T_F=\frac95(20)+32=68^\circ\mathrm F, \] \[ T_K=\frac59(68-32)+273.15 =20+273.15 =293.15\text{ K}. \]

The Tree contains parallel paths and a coherence requirement: \[ F_{\mathrm{direct}}(20) = F_{\mathrm{via}\ F}(20). \]

Tree Example D — Coupled Feedback Tree
Output changes a state that participates again

Let \[ e_n=T_\star-T_n, \qquad u_n=K_pe_n, \] and a simplified thermal update be \[ T_{n+1}=T_n+\alpha u_n. \]

With \[ T_\star=100, \qquad T_0=80, \qquad K_p=0.5, \qquad \alpha=0.2, \] we obtain

\[ e_0=100-80=20, \] \[ u_0=0.5(20)=10, \] \[ T_1=80+0.2(10)=82. \]

On the next pass, \[ e_1=100-82=18, \] \[ u_1=0.5(18)=9, \] \[ T_2=82+0.2(9)=83.8. \]

The Tree is coupled because the Response of one stage changes a Branch that re-enters later computation.

What to remember “Tree” names the organized calculation, not one specific graph shape. The mathematics determines whether the organization is sequential, branching, parallel, coupled, or something more specialized.

8. Seeds — Generative Information Before Root Export

Seed is an optional BM primitive. Use it only when information is supposed to undergo a lawful generative process before it is eligible to export a Root.

\[ S_0 \xrightarrow{G} S_1 \xrightarrow{G} S_2 \xrightarrow{G} \cdots \xrightarrow{\text{export condition}} R. \]

The important distinction is the export gate. Before the gate is satisfied, the evolving information remains Seed-state information. Once the declared condition is satisfied, the generated result may be tested for Root status at the receiving Interface.

Initial data versus Seed: \(x_0\) is not a Seed just because it appears first. It becomes a Seed only when the problem assigns it a generative role, a lawful update, and a condition that determines when its generated state may be exported.
Seed Example A — Fixed-Point Generation
Scalar Seed · Iteration · Export tolerance · Root test

Let \[ G(s)=\frac12s+1 \] and start with Seed state \[ S_0=0. \] Declare the export condition \[ |G(S_n)-S_n|<0.05. \]

\[ S_1=G(0)=1, \] \[ S_2=G(1)=1.5, \] \[ S_3=G(1.5)=1.75, \] \[ S_4=G(1.75)=1.875, \] \[ S_5=G(1.875)=1.9375, \] \[ S_6=G(1.9375)=1.96875. \]

At \(S_5\), \[ |G(S_5)-S_5| = |1.96875-1.9375| = 0.03125 <0.05. \]

So \(S_5\) satisfies the declared Seed export condition. The exported Response is \[ R=1.9375. \] If the receiving numerical Branch accepts this tolerance, the Response can function as a Root there.

Notice the distinction: \[ S_0,S_1,\ldots,S_5 \] are not all Roots. They are Seed states participating in generation until the export condition is met.

Seed Example B — Newton Generation for \(\sqrt2\)
Numerical Seed · Nonlinear update · Residual-controlled export

Solve \[ f(x)=x^2-2=0 \] with Newton's update \[ G(x) = x-\frac{x^2-2}{2x} = \frac12\left(x+\frac2x\right). \] Choose \[ S_0=1 \] and declare that export is allowed when \[ |S_n^2-2|<10^{-6}. \]

First generated Seed state \[ S_1 = \frac12\left(1+\frac21\right) = 1.5. \] Residual: \[ |1.5^2-2| = 0.25. \]
Second generated Seed state \[ S_2 = \frac12\left(1.5+\frac2{1.5}\right) = 1.4166666667. \] Residual: \[ |S_2^2-2| \approx0.00694444. \]
Third generated Seed state \[ S_3 = \frac12\left( 1.4166666667+ \frac2{1.4166666667} \right) \approx1.4142156863. \] Residual: \[ |S_3^2-2| \approx6.0073\times10^{-6}. \]
Fourth generated Seed state \[ S_4\approx1.4142135624. \] Then \[ |S_4^2-2| <10^{-6}. \]

The Seed generation may now export \[ R\approx1.4142135624. \] Whether this exported value is a Root depends on the receiving tolerance and type requirements.

Seed Example C — A Vector Generates a Krylov Subspace
Vector Seed · Linear-algebraic generation · Structural stopping condition

Let \[ A= \begin{pmatrix} 2&1\\ 0&3 \end{pmatrix}, \qquad S_0=v= \begin{pmatrix} 1\\1 \end{pmatrix}. \]

The generative rule applies \(A\): \[ S_{n+1}=AS_n. \]

First generated vector \[ S_1 = Av = \begin{pmatrix} 2(1)+1(1)\\ 3(1) \end{pmatrix} = \begin{pmatrix} 3\\3 \end{pmatrix}. \]

But \[ S_1=3S_0. \] Therefore \[ \operatorname{span}\{S_0,S_1\} = \operatorname{span}\{S_0\} \] and no new direction was generated.

If the declared export condition is “the generated Krylov subspace has stopped increasing in dimension,” then the condition is already met after this step. The generated subspace \[ K=\operatorname{span}\{(1,1)^\top\} \] may be exported for downstream spectral or approximation work.

Why this is a Seed example The starting vector is being used as a generator of further mathematical structure. The object exported is not merely the original vector; it is the structure produced by the declared generative rule.
Seed Example D — Parameter Seed in Gradient Descent
Optimization Seed · Generative update · Gradient export condition

Minimize \[ J(\theta)=(\theta-3)^2. \] Its derivative is \[ J'(\theta)=2(\theta-3). \] Choose step size \[ \alpha=\frac14 \] and Seed state \[ S_0=\theta_0=0. \]

The update is \[ \theta_{n+1} = \theta_n - \alpha J'(\theta_n). \]

\[ \theta_1 = 0-\frac14(-6) = 1.5, \] \[ \theta_2 = 1.5-\frac14(-3) = 2.25, \] \[ \theta_3 = 2.25-\frac14(-1.5) = 2.625, \] \[ \theta_4 = 2.625-\frac14(-0.75) = 2.8125. \]

If export requires \[ |J'(\theta_n)|<0.5, \] then at \(\theta_4\) \[ |J'(\theta_4)| = |2(2.8125-3)| = 0.375<0.5. \]

The generative Seed state may now export \[ R=2.8125 \] to a receiving parameter Branch whose tolerance accepts it.

9. Roots in Different Mathematical Instances

Root is a downstream role. The same BM idea can therefore appear in very different native mathematics.

Root Instance A — Scalar Controller Command
Scalar Response → actuator Root

Response: \[ R=6. \] Receiver: \[ A_U=[-10,10]. \] Since \[ 6\in[-10,10], \] the scalar may function as a Root for that actuator Interface.

Root Instance B — Vector State Estimate
Vector Response → navigation Root

Suppose an estimator produces \[ R= \widehat x = \begin{pmatrix} 120\\ 45\\ 8\\ -1 \end{pmatrix}, \] interpreted as planar position and velocity.

A navigation receiver requires: \[ \widehat x\in\mathbb R^4, \qquad \|\widehat v\|\le20. \] Here \[ \|\widehat v\| = \sqrt{8^2+(-1)^2} = \sqrt{65} \approx8.06<20. \] If the remaining covariance and unit Passports also pass, the vector Response can function as a Root for route planning.

Root Instance C — Positive-Definite Covariance Matrix
Matrix Response → estimator Root

Let \[ R=P= \begin{pmatrix} 2&0.5\\ 0.5&1 \end{pmatrix}. \] A receiving estimator requires a symmetric positive-definite covariance.

Symmetry is immediate. For a \(2\times2\) symmetric matrix, positivity can be checked by leading principal minors: \[ 2>0, \] and \[ \det P = 2(1)-0.5^2 = 1.75>0. \]

Therefore \(P\) is positive definite and can pass this structural Root gate.

Root Instance D — A Function Exported into an Integration Branch
Function Response → calculus Root

Suppose a previous Tree produces \[ R=f(x)=x^2 \] on \([0,1]\). A receiving integration Branch requires \[ f\in C([0,1]). \] Since \(x^2\) is continuous there, the function is admissible.

It can now participate in \[ \int_0^1x^2\,dx = \left[\frac{x^3}{3}\right]_0^1 = \frac13. \]

The Root here is a function, not a scalar.

Root Instance E — Probability Distribution Exported into a Decision Model
Distribution Response → probabilistic decision Root

Suppose the Response is a discrete posterior \[ R= (0.1,0.7,0.2). \] A receiving probability Branch requires \[ p_i\ge0 \quad\text{and}\quad \sum_i p_i=1. \]

\[ 0.1+0.7+0.2=1. \]

The distribution passes the normalization gate and can lawfully enter a decision calculation such as expected loss.

Root Instance F — One Response, Two Receivers, Two Outcomes
Root status is Interface-relative

Let \[ R=8. \] Receiver \(A\) accepts \[ [0,10], \] but receiver \(B\) accepts \[ [0,5]. \]

\[ 8\in[0,10], \qquad 8\notin[0,5]. \]

So the same Response can be a Root for \(A\) and not a Root for \(B\). Root status is not a permanent badge attached to the number.

10. One Example With Branches, Leaves, a Tree, a Seed, a Response, and a Root

Integrated Teaching Example — Calibrating a Thermal Controller
Major BM structural roles in one calculation

We will keep the native mathematics deliberately manageable so that the BM roles can be seen clearly.

Step 1 — Branches

Let the problem contain:

  • \(B_T\): measured temperature;
  • \(B_\star\): target temperature;
  • \(B_K\): controller gain;
  • \(B_u\): controller command;
  • \(B_{\mathrm{safe}}\): admissible command interval.

Use \[ T=90, \qquad T_\star=100. \]

Step 2 — Interaction and Leaf

The temperature-target Interaction extracts the error: \[ L_e=T_\star-T=100-90=10. \]

The error is a Leaf because it is information extracted from the declared Interaction between the target and measured-temperature Branches.

Step 3 — Seed

Suppose the controller gain is not directly accepted. It is generated through a calibration process. Begin with \[ S_0=K_0=0.2. \] Let a simple calibration objective be \[ J(K)=(K-0.6)^2 \] and update \[ K_{n+1} = K_n-\frac14J'(K_n). \]

Since \[ J'(K)=2(K-0.6), \] we obtain

\[ K_1 = 0.2-\frac14(-0.8) = 0.4, \] \[ K_2 = 0.4-\frac14(-0.4) = 0.5, \] \[ K_3 = 0.5-\frac14(-0.2) = 0.55. \]

If the Seed export condition is \[ |J'(K)|\le0.1, \] then \[ |J'(0.55)| = |2(-0.05)| = 0.1. \] The gain Seed has reached its export condition.

Step 4 — Use the generated value with the error Leaf

The controller Interaction is \[ u=K L_e. \] Using \[ K=0.55, \qquad L_e=10, \] gives

\[ u=(0.55)(10)=5.5. \]

The command value can be extracted as a new Leaf: \[ L_u=5.5. \]

Step 5 — Tree

\[ (B_T,B_\star) \xrightarrow{\mathcal I_e} L_e \] \[ S_0 \xrightarrow{G} S_1 \xrightarrow{G} S_2 \xrightarrow{G} K_{\mathrm{export}} \] \[ (K_{\mathrm{export}},L_e) \xrightarrow{\mathcal I_u} L_u. \]

The Tree is the organized structure containing both the error branch of the calculation and the gain-generation branch, together with their later Interaction.

Step 6 — Response

If the Tree's requested output is the controller command, then \[ R=5.5. \]

Step 7 — Root gate

Let the actuator accept commands only in \[ A_u=[0,6]. \] Then \[ 5.5\in[0,6]. \] If the remaining type, unit, and safety Passports are satisfied, the Response may function as a Root for the actuator calculation.

Step 8 — What each role did

Branches Carried temperature, target, gain, command, and safety data.
Interaction Combined Branches to compute error and command.
Leaves Exposed the error \(L_e\) and command \(L_u\).
Seed Generated the controller gain until an export condition was met.
Tree Organized the parallel gain-generation and error calculations and their merge.
Response The requested output \(R=5.5\).
Root The Response after downstream actuator admissibility was verified.
Why this is not just renaming arithmetic: the arithmetic is ordinary. BM is recording which mathematical objects are allowed to participate, how information is generated and extracted, how independent parts of the calculation meet, and when a result is actually allowed to enter the next mathematical context.

11. The Same BM Roles Across Different Mathematics

BM roles are structural rather than domain-specific. A Branch in probability does not need to look like a Branch in geometry; a Root in numerical analysis does not need to look like a Root in control. What remains stable is the role played in the organized mathematics.

12. Level 0 — One Branch

Example 0A — A Temperature Branch
Complexity Level 0 · Branch · Admissibility

Let a mathematical problem contain a temperature variable measured on the Kelvin scale.

\[ X_T=\mathbb R, \qquad A_T=[0,\infty). \]

A compact Branch record may be written

\[ B_T= \left( \mathsf S_T, \tau_T, X_T, A_T, \mathcal L_T, \mathcal O_T, \mathcal P_T \right), \]

with one possible interpretation:

Field Value
\(\mathsf S_T\) real scalar / physical-quantity sector
\(\tau_T\) absolute temperature
\(X_T\) \(\mathbb R\)
\(A_T\) \([0,\infty)\)
\(\mathcal L_T\) declared unit and admissibility law
\(\mathcal O_T\) allowed temperature operations used by the problem
\(\mathcal P_T\) downstream requirements, initially empty
Admissibility check. \(T=300\text{ K}\) is admissible. \(T=-20\text{ K}\) is not an admissible state of this Branch.

Nothing here requires a Tree, Root, stochastic kernel, or large Network. BM stays small because the problem is small.

Example 0B — Same Carrier, Different Branch
Complexity Level 0 · Type distinction · Failure case

Consider two scalar Branches with the same carrier:

\[ X_T=\mathbb R, \qquad X_P=\mathbb R. \]

One represents temperature and one represents pressure. Equality of the underlying carrier does not make them the same mathematical role:

\[ \tau_T\neq\tau_P. \]

Therefore the assignment

\[ 300\text{ K}=300\text{ Pa} \]

is not authorized merely because both numerical values belong to \(\mathbb R\).

BM point: carrier equality is weaker than typed mathematical compatibility.
Example 0C — A Vector-State Branch with a Geometric Admissible Set
Complexity Level 0 · Vector carrier · Explicit admissibility calculation

Let a planar position state be \[ x=(x_1,x_2)\in\mathbb R^2. \] Suppose the problem permits positions only inside a disk of radius \(5\).

\[ B_{\mathrm{pos}} = \left( \mathsf S_{\mathrm{Euclid}}, \tau_{\mathrm{position}}, \mathbb R^2, A_{\mathrm{pos}}, \mathcal L, \mathcal O, \mathcal P \right), \] \[ A_{\mathrm{pos}} = \left\{ x\in\mathbb R^2: x_1^2+x_2^2\le25 \right\}. \]
Candidate state 1 Take \(x=(3,4)\). Then \[ 3^2+4^2=9+16=25. \] Therefore \(x\in A_{\mathrm{pos}}\).
Candidate state 2 Take \(y=(4,4)\). Then \[ 4^2+4^2=16+16=32>25. \] Therefore \(y\notin A_{\mathrm{pos}}\).

Same carrier, same coordinate format, different admissibility result. The admissible set is part of the Branch.

Example 0D — A Function-Space Branch
Complexity Level 0 · Infinite-dimensional carrier · Regularity requirement

A Branch need not carry a finite-dimensional vector. Let

\[ X_f=C^1([0,1]), \] \[ A_f= \left\{ f\in C^1([0,1]): f(0)=0,\; \|f'\|_\infty\le2 \right\}. \]
Test \(f(x)=x^2\) \[ f(0)=0, \qquad f'(x)=2x, \qquad \|f'\|_\infty=2. \] Hence \(f\in A_f\).
Test \(g(x)=\sqrt{x}\) \(g\) is continuous on \([0,1]\), but \[ g'(x)=\frac{1}{2\sqrt{x}} \] is not finite at \(x=0\). Thus \(g\notin C^1([0,1])\), so \(g\notin A_f\).
BM can carry function-space regularity in the Branch declaration instead of treating every state as an untyped numerical vector.
Example 0E — A Symmetric Positive-Definite Matrix Branch
Complexity Level 0 · Matrix carrier · Structural law

Let \[ X_M=\mathbb R^{2\times2}, \] but require the admissible matrices to be symmetric positive definite:

\[ A_M= \{M=M^\top:\lambda_{\min}(M)>0\}. \]
Matrix \(A\) \[ A= \begin{pmatrix} 2&1\\ 1&2 \end{pmatrix}. \] Its eigenvalues satisfy \[ \det(A-\lambda I) =(2-\lambda)^2-1 =\lambda^2-4\lambda+3, \] so \[ \lambda\in\{1,3\}. \] Both are positive. Therefore \(A\in A_M\).
Matrix \(B\) \[ B= \begin{pmatrix} 1&2\\ 2&1 \end{pmatrix}. \] Its characteristic polynomial is \[ (1-\lambda)^2-4 =\lambda^2-2\lambda-3, \] giving \[ \lambda\in\{-1,3\}. \] Since one eigenvalue is negative, \(B\notin A_M\).

Merely storing four real numbers is insufficient to describe the Branch. Symmetry and positivity are native structural obligations.

Example 0F — A Directed-Acyclic-Graph Branch
Complexity Level 0 · Discrete structure · Non-numerical carrier

Let \(X_G\) be finite directed graphs and define \[ A_G=\{G\in X_G:G\text{ is acyclic}\}. \]

Graph 1 Edges \[ a\to b,\qquad b\to c. \] There is no directed path returning to its starting vertex, so the graph is admissible.
Graph 2 Add \[ c\to a. \] Then \[ a\to b\to c\to a \] is a directed cycle. The graph leaves the admissible set.

This shows why a Branch is not synonymous with a vector space. The carrier and its laws may be discrete and combinatorial.

13. Level 1 — One Lawful Transformation

Example 1A — Celsius to Fahrenheit
Complexity Level 1 · Transformation · Operation · Interface

Let \(B_C\) represent temperature in degrees Celsius and \(B_F\) represent temperature in degrees Fahrenheit.

\[ f:B_C\to B_F, \qquad f(c)=\frac95c+32. \]

If \(c=20\), then

\[ f(20)=68. \]
Operation audit
  • source type declared: Celsius temperature;
  • target type declared: Fahrenheit temperature;
  • formula defined on the intended domain;
  • units are transformed rather than silently relabeled;
  • the target receives a Fahrenheit value.

The conversion formula itself functions as an Interface between the two representations.

Example 1B — A Writable but Unlawful Map
Complexity Level 1 · Type failure

The function

\[ q(c)=c \]

is a perfectly valid real function, but if it is presented as a Celsius-to-Fahrenheit conversion, it violates the declared Interface. For example,

\[ 20^\circ\mathrm C\not\equiv20^\circ\mathrm F. \]

BM distinguishes formula existence from lawful typed use.

Example 1C — A Partial Square-Root Operation
Complexity Level 1 · Domain restriction · Candidate rejection

Let \[ f:\mathbb R_{\ge0}\to\mathbb R_{\ge0}, \qquad f(x)=\sqrt{x}. \]

Input \(x=9\) \[ 9\in\mathbb R_{\ge0}, \qquad f(9)=3. \] Source admissibility and target admissibility both hold.
Input \(x=-1\) \[ -1\notin\mathbb R_{\ge0}. \] The proposed real-valued Operation is not defined on this input.
Writing the symbol \(\sqrt{-1}\) does not make this a lawful real Branch transformation. One would need to change the mathematical sector and target type.
Example 1D — Matrix Observation Map
Complexity Level 1 · Linear transformation · Shown multiplication

Let the state Branch be \(\mathbb R^2\) and the observation Branch be \(\mathbb R\). Define

\[ H= \begin{pmatrix} 2&-1 \end{pmatrix}, \qquad y=Hx. \]

For \[ x= \begin{pmatrix} 3\\4 \end{pmatrix}, \] the shown work is

\[ y = \begin{pmatrix} 2&-1 \end{pmatrix} \begin{pmatrix} 3\\4 \end{pmatrix} = 2(3)-1(4) = 6-4 = 2. \]

The map is lawful as a linear observation map. Whether it is sufficient for a later Task is a separate Passport question.

Example 1E — Normalization Has a Missing Point
Complexity Level 1 · Partial Operation · Domain discovered from formula

Define \[ N(v)=\frac{v}{\|v\|}. \] It is tempting to write \[ N:\mathbb R^n\to S^{n-1}, \] but that overstates the domain.

Nonzero input For \(v=(3,4)\), \[ \|v\|=5, \qquad N(v)=\left(\frac35,\frac45\right). \]
Zero input For \(v=0\), \[ \|v\|=0, \] so division by \(\|v\|\) is undefined.
\[ \boxed{ N:\mathbb R^n\setminus\{0\}\to S^{n-1}. } \]

BM keeps the corrected domain as part of the Operation instead of allowing the notation to silently totalize it.

Example 1F — Differential Operator Between Function-Space Branches
Complexity Level 1 · Operator semantics · Regularity

Let \[ D:C^1([0,1])\to C^0([0,1]), \qquad Df=f'. \]

Valid input For \[ f(x)=x^3, \] \[ Df(x)=3x^2\in C^0([0,1]). \]
Invalid source object If the source Branch requires \(C^1\) regularity, then \(g(x)=|x-\tfrac12|\) is not admissible because its derivative fails to exist at \(x=\tfrac12\).

The same “transformation” idea therefore covers operators whose legality depends on function-space structure, not only scalar formulas.

14. Level 2 — Interaction and Leaf Extraction

Example 2A — Electrical Power from Voltage and Current
Complexity Level 2 · Interaction · Leaf

Let

\[ B_V:\text{voltage}, \qquad B_I:\text{current}. \]

Their lawful Interaction is

\[ \mathcal I_{VI}: A_V\times A_I\to Z, \qquad \mathcal I_{VI}(V,I)=(V,I,VI). \]

The Interaction result stores more than one quantity. A Leaf extraction map selects the power component:

\[ \ell_P:Z\to\mathbb R, \qquad \ell_P(V,I,VI)=VI. \]

Hence

\[ P= \ell_P\!\left( \mathcal I_{VI}(V,I) \right) =VI. \]

If \(V=12\text{ V}\) and \(I=3\text{ A}\), then \[ P=36\text{ W}. \] The derived value becomes a BM Leaf only because its originating Interaction and extraction map have been declared. A derived scalar floating elsewhere in a calculation is not automatically a Leaf.

Example 2B — Branches Retain Their Own Roles During Interaction
Complexity Level 2 · Branch interaction use

In the preceding example, voltage and current are not merged into one undifferentiated number space merely because multiplication is defined.

\[ B_V\neq B_I, \qquad \mathcal I_{VI}(B_V,B_I) \leadsto P. \]

Their types remain available to determine which operation is being performed and what the resulting quantity means.

Example 2C — Mass and Acceleration Produce Force
Complexity Level 2 · Two Branches · Unit-sensitive Interaction

Let \[ B_m:\text{mass in kg}, \qquad B_a:\text{acceleration in m/s}^2. \] Define

\[ \mathcal I_F(m,a)=ma. \]
For \[ m=4\text{ kg}, \qquad a=3\text{ m/s}^2, \] \[ F=ma =(4)(3) =12\text{ kg m/s}^2 =12\text{ N}. \]

The numerical multiplication \(4\times3=12\) is only part of the Interaction. The Branch types determine the physical quantity carried by the result.

Example 2D — Vector Interaction with Multiple Leaves
Complexity Level 2 · One Interaction · Several extracted quantities

Let \[ a=(1,0), \qquad b=(1,1). \] Construct an Interaction record

\[ \mathcal I(a,b) = \left( a\cdot b, \|a\|, \|b\| \right). \]
\[ a\cdot b=1(1)+0(1)=1, \] \[ \|a\|=1, \qquad \|b\|=\sqrt{1^2+1^2}=\sqrt2. \]

A Leaf may extract the cosine of the included angle:

\[ \lambda_\theta = \frac{a\cdot b}{\|a\|\|b\|} = \frac1{\sqrt2}. \]

Hence \[ \theta=\arccos\left(\frac1{\sqrt2}\right)=\frac\pi4. \]

If either vector is zero, the angle Leaf is undefined because \(\|a\|\|b\|=0\). The dot-product Leaf may still exist. Different Leaves can therefore have different admissible domains.
Example 2E — Bayesian Interaction and Posterior Leaf
Complexity Level 2 · Probability Branches · Normalization

Let \(H\) denote a hypothesis and \(D\) observed data. Suppose

\[ P(H)=0.2, \qquad P(D\mid H)=0.9, \qquad P(D\mid H^c)=0.1. \]
Unnormalized positive-hypothesis weight \[ w_H=P(D\mid H)P(H)=0.9(0.2)=0.18. \]
Unnormalized alternative weight \[ w_{H^c}=P(D\mid H^c)P(H^c)=0.1(0.8)=0.08. \]
Evidence normalization \[ P(D)=0.18+0.08=0.26. \]
Posterior Leaf \[ P(H\mid D) = \frac{0.18}{0.26} = \frac9{13} \approx0.6923. \]

BM does not replace Bayes' theorem. It can represent the prior, likelihood, evidence normalization, and posterior as distinct typed participants and extracted information.

Example 2F — Matrix–Vector Interaction with Dimension Failure
Complexity Level 2 · Algebraic compatibility

Let \[ A= \begin{pmatrix} 1&2\\ 0&1 \end{pmatrix}, \qquad x= \begin{pmatrix} 3\\4 \end{pmatrix}. \]

\[ Ax = \begin{pmatrix} 1(3)+2(4)\\ 0(3)+1(4) \end{pmatrix} = \begin{pmatrix} 11\\4 \end{pmatrix}. \]

If instead \(x\in\mathbb R^3\), the same \(2\times2\) matrix cannot multiply it. The Interaction fails before any numerical computation because the dimensions are incompatible.

15. Level 3 — Passport, Fibres, and Task Sufficiency

Example 3A — A Lossy Sensor
Complexity Level 3 · Passport · Fibre · Task

Suppose the true state is

\[ x=(T,H)\in X, \]

where \(T\) is temperature and \(H\) is humidity. A sensor reports only temperature:

\[ r:X\to\mathbb R, \qquad r(T,H)=T. \]

The fibre above an observed temperature \(t\) is

\[ r^{-1}(t)= \{(t,H):H\text{ admissible}\}. \]

Humidity distinctions have therefore been removed by the representation.

Example 3B — One Task Survives; Another Fails
Complexity Level 3 · Task-relative information

Consider two downstream Tasks:

\[ T_1(T,H)= \begin{cases} 1,&T>30,\\ 0,&T\le30, \end{cases} \]

and

\[ T_2(T,H)=H. \]

If \[ r(T,H)=r(T',H'), \] then \(T=T'\), so \[ T_1(T,H)=T_1(T',H'). \] The representation is exactly sufficient for \(T_1\).

But the same observation may correspond to different humidity values:

\[ r(25,40)=r(25,90)=25, \]

while

\[ T_2(25,40)\neq T_2(25,90). \]

The representation is not sufficient for \(T_2\).

Passport consequence. If later mathematics requires humidity, the Passport cannot permit the reduction \((T,H)\mapsto T\) without an additional retained humidity channel or an explicitly acceptable approximation.
Example 3C — Passport Violation Set
Complexity Level 3 · Explicit failure witness

Let the source Passport predicate require humidity availability:

\[ P_X(T,H)=1. \]

Let the reduced representation contain no humidity field, so the receiving Passport test fails:

\[ P_Y(r(T,H))=0. \]

The Passport-defect set is then

\[ \mathfrak D_{r,P} = \{(T,H)\in A_X: P_X(T,H)=1,\; P_Y(r(T,H))=0\}. \]

Here \(\mathfrak D_{r,P}\neq\varnothing\), so exact Passport preservation fails.

Example 3D — Approximate Sufficiency
Complexity Level 3 · Approximation

Suppose a Task requires humidity only to tolerance \(\varepsilon=5\%\). A compressed representation may store a quantized humidity \(\widehat H\) satisfying

\[ |H-\widehat H|\le5. \]

Exact recoverability may fail while a task-relative approximate criterion succeeds. This is a different claim and must not be relabeled as exact sufficiency.

Example 3E — Exact Fibre Audit on a Finite State Space
Complexity Level 3 · Every fibre shown explicitly

Let \[ X=\{a,b,c,d\} \] and define an observation

\[ r(a)=r(b)=0, \qquad r(c)=r(d)=1. \]

Therefore the fibres are

\[ r^{-1}(0)=\{a,b\}, \qquad r^{-1}(1)=\{c,d\}. \]

Define

\[ T_1(a)=T_1(b)=7, \qquad T_1(c)=T_1(d)=9. \]

\(T_1\) is constant on every fibre, so it factors through \(r\):

\[ \widetilde T_1(0)=7, \qquad \widetilde T_1(1)=9, \] \[ T_1=\widetilde T_1\circ r. \]

Now define

\[ T_2(a)=0, \qquad T_2(b)=1. \]

Since \(a\) and \(b\) share one observation but have different Task values, \(T_2\) cannot factor through \(r\).

Example 3F — Quantization Error Carried as a Passport Tolerance
Complexity Level 3 · Approximate retention · Explicit error bound

Let \[ r(x)=\operatorname{round}(x) \] and suppose the Task is \[ T(x)=2x. \]

Rounding to the nearest integer satisfies \[ |x-r(x)|\le\frac12. \]

Propagate the representation error into the Task \[ |T(x)-T(r(x))| = |2x-2r(x)| = 2|x-r(x)| \le1. \]

Thus the representation is not exact, but it is sufficient for a Task tolerance of \(1\) or larger.

Numerical instance If \(x=3.37\), \[ r(x)=3, \qquad T(x)=6.74, \qquad T(r(x))=6, \] so \[ |6.74-6|=0.74\le1. \]
Example 3G — One Representation, Two Simultaneous Tasks
Complexity Level 3 · Joint Passport requirement

Let the state be \[ x=(T,H,P), \] representing temperature, humidity, and pressure. Suppose the representation keeps \[ r(x)=(T,H). \]

Task \(A\) asks whether \(T>30\), while Task \(B\) asks whether \(H>80\). Both factor through \(r\).

Add Task \(C(x)=P\). Now the same representation is insufficient for the joint Task tuple

\[ \mathcal T(x)= \bigl( 1_{T>30}, 1_{H>80}, P \bigr). \]

The Passport required for \(\mathcal T\) must preserve pressure even though Tasks \(A\) and \(B\) do not need it.

Example 3H — Serial Reduction Can Preserve One Task and Destroy Another
Complexity Level 3 · Information monotonicity

Let an integer state \(n\in\mathbb Z\) first be represented by

\[ r_1(n)= \bigl( \operatorname{sgn}(n), n\bmod2 \bigr), \]

and then reduced again to parity:

\[ r_2(s,p)=p. \]

The composite is \[ (r_2\circ r_1)(n)=n\bmod2. \]

Parity Task \[ T_{\mathrm{parity}}(n)=n\bmod2 \] survives both stages.
Sign Task \[ T_{\mathrm{sign}}(n)=\operatorname{sgn}(n) \] is available after \(r_1\) but not after \(r_2\circ r_1\). For example, \[ (r_2\circ r_1)(3) = (r_2\circ r_1)(-3) =1, \] but \[ \operatorname{sgn}(3)\neq\operatorname{sgn}(-3). \]

16. Level 4 — Composition and Interface Failure

Example 4A — Three Lawful Operations
Complexity Level 4 · Composition · Typed Path

Consider

\[ B_C \xrightarrow{f} B_K \xrightarrow{g} B_E, \]

where

\[ f(c)=c+273.15 \]

converts Celsius to Kelvin and

\[ g(T)=k_B T \]

maps absolute temperature to the thermal energy scale \(E=k_BT\).

The typed path is meaningful because the output of \(f\) is exactly the kind of input required by \(g\).

\[ (g\circ f)(c) = k_B(c+273.15). \]
Example 4B — Individually Valid Formulas, Invalid Chain
Complexity Level 4 · Interface defect

Replace \(f\) by an identity-number map

\[ \widehat f(c)=c \]

while still pretending its output is Kelvin. Algebraically,

\[ g(\widehat f(c))=k_Bc \]

is writable. But for \(c=0^\circ\mathrm C\),

\[ k_B(0) \neq k_B(273.15). \]

The problem is not multiplication. The Interface falsely retyped a Celsius number as an absolute temperature.

Obstruction: the intermediate object does not satisfy the receiving Branch's semantic and admissibility requirements.
Repair: restore the lawful conversion \[ f(c)=c+273.15. \] The chain is then re-audited.
Minimal repair question: if no other defect exists, replacing only the bad Interface is sufficient. Rebuilding unrelated Branches would not be minimal.
Example 4C — Composition Shrinks the Usable Domain
Complexity Level 4 · Partial composition · Exact domain calculation

Let \[ f:[0,\infty)\to[0,\infty), \qquad f(x)=\sqrt{x}, \] and \[ g:(0,\infty)\to\mathbb R, \qquad g(y)=\log y. \]

Although \(f\) is defined at \(x=0\), the composite is not. The composition domain is

\[ D_{g\circ f} = \{x\ge0:f(x)>0\} = (0,\infty). \]
At \(x=4\) \[ (g\circ f)(4) = \log(\sqrt4) = \log2. \]
At \(x=0\) \[ f(0)=0, \] but \(0\notin D_g\). Therefore \(g(f(0))\) is undefined.
Example 4D — A Lawful Linear Chain that Violates a Norm Passport
Complexity Level 4 · Local legality vs global preservation

Define

\[ A:\mathbb R^2\to\mathbb R^3, \qquad A(x,y)=(x,y,0), \] \[ B:\mathbb R^3\to\mathbb R^2, \qquad B(u,v,w)=(2u,v). \]

Both are lawful linear maps. Their composite is

\[ (B\circ A)(x,y)=(2x,y). \]

Suppose the Passport requires Euclidean norm preservation.

Source norm \[ \|(x,y)\|^2=x^2+y^2. \]
Composite norm \[ \|(2x,y)\|^2=4x^2+y^2. \]

These are equal only when \(x=0\). Thus the maps are linear and type-compatible, but the composite does not satisfy the declared norm Passport on the full domain.

Example 4E — A Hidden Singularity Appears After Translation
Complexity Level 4 · Domain pullback

Let \[ f(x)=x-1, \qquad g(y)=\frac1y. \]

Then \[ (g\circ f)(x)=\frac1{x-1}. \]

Since \(g\) requires \(y\neq0\), the composite requires \[ f(x)\neq0 \iff x-1\neq0 \iff x\neq1. \]

BM's composition audit explicitly pulls the downstream domain requirement back through the upstream map.

Example 4F — Sample Values Without Sample Time Are Insufficient for a Derivative
Complexity Level 4 · Interface information · Hidden metadata

Let a continuous signal be sampled as \[ x_0=10, \qquad x_1=14. \] A downstream finite-difference Operation wants

\[ \dot x\approx \frac{x_1-x_0}{\Delta t}. \]

If \(\Delta t=2\text{ s}\), \[ \dot x\approx\frac{4}{2}=2\text{ units/s}. \] If \(\Delta t=0.5\text{ s}\), \[ \dot x\approx\frac{4}{0.5}=8\text{ units/s}. \]

The pair \((10,14)\) alone does not determine the derivative estimate. Sample spacing is Interface/Passport information required by the downstream Operation.

17. Level 5 — Parallel Paths and Coherence

Example 5A — Two Routes to Kelvin
Complexity Level 5 · Parallel paths · Coherence

Route \(p\) converts Celsius directly to Kelvin:

\[ F_p(c)=c+273.15. \]

Route \(q\) converts Celsius to Fahrenheit and then Fahrenheit to Kelvin:

\[ c \xrightarrow{f} \frac95c+32 \xrightarrow{g} \frac59(F-32)+273.15. \]

Therefore

\[ F_q(c) = \frac59 \left( \frac95c+32-32 \right) +273.15 = c+273.15. \]

Hence

\[ F_p(c)=F_q(c) \]

on the shared domain.

The parallel-path defect

\[ \Delta_{p,q} = \{c:F_p(c)\neq F_q(c)\} \]

is empty.

Example 5B — Numerical Coherence Instead of Exact Equality
Complexity Level 5 · Sector-correct equivalence

Suppose one path is evaluated in high precision and another path is rounded to the nearest \(0.1\text{ K}\). Exact equality may no longer be the correct requirement.

Define

\[ a\simeq_\varepsilon b \iff |a-b|\le\varepsilon. \]

Then coherence becomes

\[ F_p(c)\simeq_\varepsilon F_q(c). \]

BM therefore requires the destination notion of equality or equivalence to be declared rather than assuming literal identity in every sector.

Example 5C — From Pairwise Paths to Higher Coherence
Complexity Level 5 · Higher compatibility

With three representations \(B_1,B_2,B_3\), pairwise conversions may form a cycle:

\[ B_1 \xrightarrow{F_{12}} B_2 \xrightarrow{F_{23}} B_3 \xrightarrow{F_{31}} B_1. \]

Pairwise maps being individually lawful does not automatically prove cycle consistency. One may additionally require

\[ F_{31}\circ F_{23}\circ F_{12} \simeq \operatorname{id}_{B_1} \]

on the declared admissible domain. This is a higher compatibility obligation generated by the Network, not by any one local arrow alone.

Example 5D — Basis Change Must Close
Complexity Level 5 · Inverse path · Exact matrix audit

Let \[ P= \begin{pmatrix} 1&1\\ 0&1 \end{pmatrix}, \qquad P^{-1}= \begin{pmatrix} 1&-1\\ 0&1 \end{pmatrix}. \]

For \[ x= \begin{pmatrix} 2\\3 \end{pmatrix}, \] transform to the new coordinates:

\[ y=Px = \begin{pmatrix} 1&1\\ 0&1 \end{pmatrix} \begin{pmatrix} 2\\3 \end{pmatrix} = \begin{pmatrix} 5\\3 \end{pmatrix}. \]

Transform back:

\[ P^{-1}y = \begin{pmatrix} 1&-1\\ 0&1 \end{pmatrix} \begin{pmatrix} 5\\3 \end{pmatrix} = \begin{pmatrix} 2\\3 \end{pmatrix} =x. \]

The cycle defect is zero for this exact pair of inverse maps.

Example 5E — Three Unit Paths to the Same Speed
Complexity Level 5 · Multi-route numerical agreement

Start with \[ v=90\text{ km/h}. \]

Direct path: km/h → m/s \[ 90\frac{\text{km}}{\text h} \cdot \frac{1000\text{ m}}{1\text{ km}} \cdot \frac{1\text{ h}}{3600\text{ s}} = 25\text{ m/s}. \]
Path through miles per hour Using \(1\text{ mile}=1.609344\text{ km}\), \[ 90\text{ km/h} \approx55.9234\text{ mph}. \] Then using \(1\text{ mph}=0.44704\text{ m/s}\), \[ 55.9234(0.44704) \approx25.0000\text{ m/s}. \]

Exact definitions of the conversion constants make the paths mathematically coherent; displayed decimal rounding introduces only numerical presentation error.

Example 5F — Calibration Loop Exposes an Offset Defect
Complexity Level 5 · Cycle residual

Suppose instrument \(A\) maps to instrument \(B\) by \[ F_{AB}(x)=2x+1, \] while the claimed reverse calibration is \[ F_{BA}(y)=\frac{y-0.8}{2}. \]

Compose the loop:

\[ (F_{BA}\circ F_{AB})(x) = \frac{(2x+1)-0.8}{2} = x+0.1. \]

Therefore the cycle does not return the original value: \[ \delta(x) = (F_{BA}\circ F_{AB})(x)-x = 0.1. \]

Each formula is individually well-defined. The defect appears only when the Network requires the round-trip path to represent identity.
Example 5G — Coherence Is Tested Only Where Both Paths Exist
Complexity Level 5 · Shared-domain requirement

Let \[ F_p(x)=\sqrt{x}, \qquad D_p=[0,\infty), \] and \[ F_q(x)=\frac{x}{\sqrt{x}}, \qquad D_q=(0,\infty). \]

For \(x>0\), \[ F_q(x)=\sqrt{x}=F_p(x). \] But \(F_q\) is undefined at \(x=0\).

\[ D_p\cap D_q=(0,\infty). \]

The correct coherence statement is equality on the shared domain, not an unsupported claim that both paths are globally identical.

18. Level 6 — Response, Root, Export, and Re-entry

Example 6A — Tree Produces a Response
Complexity Level 6 · Tree · Response

Let a small thermal-control Tree combine

  • a temperature Branch \(B_T\),
  • a target Branch \(B_\star\),
  • an error Interaction, and
  • a controller Operation.
\[ e=T_\star-T, \qquad u=K_pe. \]

The organized computation produces a Response

\[ R=u. \]

Producing \(u\) does not yet establish that \(u\) is admissible for every downstream actuator.

Example 6B — When a Response Becomes a Root
Complexity Level 6 · Root decision

Suppose the receiving actuator requires

\[ A_U=[-10,10]. \]

If the controller produces

\[ R=6, \]

and all required Passport and Interface conditions are satisfied, the Response is admissible for downstream use:

\[ R \in A_U. \]

In this role,

\[ \boxed{ \text{Root} = \text{Response} + \text{verified downstream admissibility}. } \]

If instead \(R=15\), the Response exists but is not yet a lawful Root for this actuator.

Example 6C — Re-entry into New Mathematics
Complexity Level 6 · Export · Re-entry

Let the accepted controller output be exported into an actuator model:

\[ u \longmapsto \dot x = Ax+Bu. \]

Re-entry requires more than carrying the number \(u\) across the boundary. The receiving dynamical system must verify:

  • input dimension;
  • units;
  • actuator bounds;

\[ \partial_tu+(u\cdot\nabla)u = -\nabla p+\nu\Delta u+f, \qquad \nabla\cdot u=0. \]

Take the \(L^2\) inner product with \(u\) and integrate over \(\Omega\):

\[ \int_\Omega u\cdot\partial_tu\,dx + \int_\Omega u\cdot(u\cdot\nabla)u\,dx = -\int_\Omega u\cdot\nabla p\,dx + \nu\int_\Omega u\cdot\Delta u\,dx + \int_\Omega f\cdot u\,dx. \]

Time-derivative term

\[ \int_\Omega u\cdot\partial_tu\,dx = \frac12\frac{d}{dt}\int_\Omega|u|^2\,dx. \]

Define the kinetic-energy Leaf \[ L_E=E(t)=\frac12\int_\Omega|u|^2\,dx. \]

Convective term

Since \[ u\cdot(u\cdot\nabla)u = (u\cdot\nabla)\frac{|u|^2}{2}, \] periodicity and \(\nabla\cdot u=0\) give

\[ \int_\Omega (u\cdot\nabla)\frac{|u|^2}{2}\,dx = \int_\Omega\nabla\cdot\left(u\frac{|u|^2}{2}\right)dx - \int_\Omega\frac{|u|^2}{2}\nabla\cdot u\,dx =0. \]

Pressure term

\[ \int_\Omega u\cdot\nabla p\,dx = \int_\Omega\nabla\cdot(pu)\,dx - \int_\Omega p\nabla\cdot u\,dx =0. \]

Viscous term

\[ \int_\Omega u\cdot\Delta u\,dx = -\int_\Omega|\nabla u|^2\,dx. \]

Define the dissipation Leaf \[ L_D=D(t)=\nu\int_\Omega|\nabla u|^2\,dx. \]

Forcing term

Define \[ L_F=F(t)=\int_\Omega f\cdot u\,dx. \]

Derived energy Response

\[ \boxed{\frac{dE}{dt}=-D+F.} \]
\[ B_u\longrightarrow\begin{cases}L_E\\L_D\end{cases}, \qquad (B_f,B_u)\longrightarrow L_F, \] \[ (L_E,L_D,L_F) \xrightarrow{\text{energy balance}} \frac{dE}{dt}. \]

If a later Task asks only whether total energy is increasing, the sign of \(-D+F\) may be sufficient. If it asks how that change was produced, the forcing and dissipation Leaves must remain distinct.

Example 9A.2 — Vorticity and Enstrophy Expose a Different Leaf Family
Research-scale PDE · Curl Branch · Stretching Leaf · Viscous Leaf

Define vorticity \[ \omega=\nabla\times u. \] For incompressible three-dimensional flow, taking curl gives

\[ \partial_t\omega +(u\cdot\nabla)\omega = (\omega\cdot\nabla)u +\nu\Delta\omega +\nabla\times f. \]

Multiply by \(\omega\) and integrate over a periodic domain. Under the same smoothness, periodicity, and incompressibility assumptions, the transport term vanishes and integration by parts gives

\[ \frac12\frac{d}{dt}\int_\Omega|\omega|^2\,dx = \int_\Omega\omega\cdot(\omega\cdot\nabla)u\,dx - \nu\int_\Omega|\nabla\omega|^2\,dx + \int_\Omega\omega\cdot(\nabla\times f)\,dx. \]

The calculation exposes the Leaves

\[ L_\Omega=\frac12\int_\Omega|\omega|^2\,dx, \] \[ L_{\rm stretch} = \int_\Omega\omega\cdot(\omega\cdot\nabla)u\,dx, \] \[ L_{\nu\omega} = \nu\int_\Omega|\nabla\omega|^2\,dx, \] \[ L_{\omega f} = \int_\Omega\omega\cdot(\nabla\times f)\,dx. \]

Therefore \[ \boxed{ \frac{dL_\Omega}{dt} = L_{\rm stretch}-L_{\nu\omega}+L_{\omega f}. } \]

Why this differs from the energy Tree Energy and enstrophy are both derived from the velocity state, but they answer different questions. An energy-only representation can lose distinctions that matter to vorticity stretching.
Example 9A.3 — A Coarse Spectral Passport Can Preserve Energy and Lose Phase
Research-scale PDE · Fourier Branch · Information loss · Task dependence

Let a Fourier representation retain only modal magnitudes \[ r(\widehat u)=\{|\widehat u(k)|\}_k \] while discarding phases.

The modal-energy Leaves \(|\widehat u(k)|^2\) remain available, so a spectral energy sum \[ \sum_k|\widehat u(k)|^2 \] remains recoverable, with the conventional normalization fixed by the chosen Fourier convention.

Nonlinear Fourier interactions depend on products of mode amplitudes with their phase relations. Schematically, a triadic contribution contains terms of the form

\[ \widehat u(p)\,\widehat u(q), \qquad p+q=k. \]

Two velocity fields can therefore share the same magnitude-only observation while producing different phase-sensitive nonlinear transfer information.

\[ \widehat u \xrightarrow{\text{magnitude-only reduction}} \{|\widehat u(k)|\} \] \[ \begin{cases} \text{energy Task: recoverable from magnitudes},\\ \text{phase-sensitive transfer Task: generally not recoverable}. \end{cases} \]

This is a research-scale Passport example: the required distinctions are determined by the downstream Task, not by how detailed the reduced data appears.

Example 9B — Quantum Information Configuration
Complexity Level 9 · Operator sector · Measurement · Distinguishability

Consider two qubit states \[ \rho_0=|0\rangle\langle0| = \begin{pmatrix} 1&0\\ 0&0 \end{pmatrix}, \] \[ \rho_+=|+\rangle\langle+| = \frac12 \begin{pmatrix} 1&1\\ 1&1 \end{pmatrix}. \]

A computational-basis measurement has effects \[ E_0=|0\rangle\langle0|, \qquad E_1=|1\rangle\langle1|. \]

Observation from \(\rho_0\) \[ P(0\mid\rho_0) = \operatorname{Tr}(E_0\rho_0) =1. \]
Observation from \(\rho_+\) \[ P(0\mid\rho_+) = \operatorname{Tr}(E_0\rho_+) =\frac12. \]

The measurement Branch exports a classical probability law, not the density matrix itself. A downstream Task that needs phase coherence cannot reconstruct it from one computational-basis outcome.

A BM configuration can distinguish:

  • density-operator Branch;
  • quantum-channel Branch;
  • POVM/measurement Branch;
  • classical observation Branch;
  • Task-specific distinguishability Passport.

Operator theory and quantum probability remain the native mathematics; BM coordinates their interfaces and retained distinctions.

Example 9C — Closed-Loop Gauge Observable on a Lattice
Complexity Level 9 · Group-valued links · Gauge transformation · Invariant Leaf
Scope. This is a finite lattice-gauge calculation. The four-dimensional Yang–Mills existence and mass-gap problem remains open.

Let an oriented link \(x\to y\) carry \[ U_{xy}\in SU(N). \] Under a local gauge transformation,

\[ U_{xy} \mapsto G_xU_{xy}G_y^{-1}. \]

Around a closed plaquette \[ x_1\to x_2\to x_3\to x_4\to x_1, \] define

\[ U_p = U_{12}U_{23}U_{34}U_{41}. \]

Transform every link:

\[ U_p \mapsto (G_1U_{12}G_2^{-1}) (G_2U_{23}G_3^{-1}) (G_3U_{34}G_4^{-1}) (G_4U_{41}G_1^{-1}). \] Adjacent factors cancel: \[ G_2^{-1}G_2 = G_3^{-1}G_3 = G_4^{-1}G_4 =I, \] leaving \[ U_p\mapsto G_1U_pG_1^{-1}. \]

Taking the trace, \[ \operatorname{Tr}(G_1U_pG_1^{-1}) = \operatorname{Tr}(U_p). \]

Therefore the Wilson-loop-style Leaf \[ W_p=\operatorname{Tr}(U_p) \] is gauge invariant.

BM can track link Branches, group-valued Operations, local gauge Interfaces, loop composition, and invariant Leaves while the group theory supplies the actual proof.

Example 9D — Electromagnetic Field to Material Response to Detector Output
Complexity Level 9 · Field theory · Constitutive interface · Observation

In a simple linear isotropic medium, \[ D=\varepsilon E, \qquad B=\mu H. \] Electromagnetic energy flux is represented by the Poynting vector

\[ S=E\times H. \]

A detector may report a time-averaged scalar response proportional to incident intensity:

\[ Y = \alpha \frac1{\Delta t} \int_{t_0}^{t_0+\Delta t} S(t)\cdot n\,dt. \]

The participating Branches may include:

  • field \(E\);
  • field \(H\);
  • material parameters \(\varepsilon,\mu\);
  • surface normal \(n\);
  • integration window \(\Delta t\);
  • detector calibration \(\alpha\);
  • reported observation \(Y\).

Removing \(\Delta t\), changing the constitutive regime, or replacing vector flux by an unqualified scalar can make the later detector calculation ambiguous or invalid. BM's job is to retain those Interfaces explicitly.

Example 10B — Multiple Simultaneous Defects
Complexity Level 10 · Nontrivial repair

Suppose a control Network simultaneously contains:

  1. a sensor with excessive uncertainty;
  2. a Celsius/Kelvin Interface error;
  3. a controller output exceeding actuator bounds; and
  4. two estimator paths that disagree beyond tolerance.

The configuration may be represented as having a defect record

\[ \mathfrak D(\mathcal X) = \left( D_{\mathrm{obs}}, D_{\mathrm{unit}}, D_{\mathrm{act}}, D_{\mathrm{coh}} \right). \]

A proposed repair

\[ \rho: \mathcal X \longmapsto \mathcal X' \]

is successful only if the required defect components vanish or fall inside declared tolerances after re-audit.

\[ \mathfrak D(\mathcal X') \in A_{\mathfrak D}. \]

This is the kind of situation where the BM organization is meant to become more valuable as structural complexity increases.

Example 10C — Worked Type Failure: Same Number, Wrong Quantity
Complexity Level 10 · Type defect · Numerical trap

Suppose a law expects an absolute temperature: \[ E=k_BT. \] A source sends the number \[ 25 \] meaning \(25^\circ\mathrm C\), but the receiving Branch interprets it as \(25\text{ K}\).

Incorrect computation \[ E_{\mathrm{bad}}=25k_B. \]
Correct conversion \[ T=25+273.15=298.15\text{ K}. \]
Correct computation \[ E_{\mathrm{good}}=298.15k_B. \]

The ratio is \[ \frac{E_{\mathrm{bad}}}{E_{\mathrm{good}}} = \frac{25}{298.15} \approx0.08385. \] The formulas were valid; the Interface type was wrong.

Example 10D — Worked False Quotient
Complexity Level 10 · Equivalence not compatible with addition

On \(\mathbb R\), define \[ x\sim y \iff |x|=|y|. \] Then \[ 1\sim-1. \]

Try to define addition of equivalence classes by \[ [x]+[y]=[x+y]. \]

Choose representatives \(1,1\) \[ [1]+[1] \leadsto [2]. \]
Choose equivalent representatives \(-1,1\) Since \(-1\sim1\), the same class pair would also allow \[ [-1]+[1] \leadsto [0]. \]

But \[ [2]\neq[0] \] because \(|2|\neq|0|\). Therefore addition is not well-defined on this quotient.

This is exactly the kind of failure the structured-quotient gate is designed to expose.
Example 10E — Worked Quantifier Failure
Complexity Level 10 · Separate witnesses do not imply joint feasibility

Let the admissible action set be \[ U=\{a,b\}. \] Task 1 accepts only \[ P_1=\{a\}, \] while Task 2 accepts only \[ P_2=\{b\}. \]

Individually, \[ P_1\neq\varnothing, \qquad P_2\neq\varnothing. \] So the statements “there exists an action satisfying Task 1” and “there exists an action satisfying Task 2” are both true.

But \[ P_1\cap P_2 = \varnothing. \]

Hence there is no single action satisfying both simultaneously. The error comes from changing \[ (\exists u_1)(\exists u_2) \] into an unsupported shared witness \[ \exists u. \]

Example 10F — Worked Stochastic-to-Deterministic Collapse Failure
Complexity Level 10 · Expectation does not commute with a nonlinear Task

Let a random output satisfy \[ P(Y=0)=\frac12, \qquad P(Y=2)=\frac12. \]

Its mean is \[ \mathbb E[Y] = \frac12(0)+\frac12(2) =1. \]

Let the downstream Task be \[ g(y)=y^2. \]

Correct stochastic calculation \[ \mathbb E[g(Y)] = \frac12(0^2)+\frac12(2^2) = 2. \]
Incorrect deterministic collapse Replace the distribution by its mean first: \[ g(\mathbb E[Y]) = g(1) = 1. \]

Therefore \[ \mathbb E[g(Y)] \neq g(\mathbb E[Y]). \] A stochastic Branch cannot generally be replaced by its mean when later mathematics is nonlinear.

Example 10G — Repair Order Matters
Complexity Level 10 · Multiple defects · Dependency-aware repair

Suppose a chain has two defects:

  1. temperature is mislabeled Celsius as Kelvin;
  2. the resulting controller command exceeds actuator limits.

If the saturation repair is applied first, it may clip a command generated from the wrong temperature. The result can become numerically admissible while still being based on an invalid upstream state.

Correct repair order First repair the unit Interface: \[ T_K=T_C+273.15. \]
Recompute downstream command Evaluate the controller again using the corrected state.
Then apply actuator repair if still needed \[ u_{\mathrm{safe}} = \operatorname{clip}_{A_U}(u). \]

BM therefore treats repair as an operation on a dependency structure, not as a bag of independent fixes.

Several BM roles can be carried by the same underlying mathematical object, so the safest way to classify an object is by its origin and downstream use.

28. Governing Example Principle

\[ \boxed{ \text{Do not add complexity to display complexity.} } \]
\[ \boxed{ \text{Add structure exactly when the mathematics creates a new obligation.} } \]

In a small problem, BM should remain small. In a large problem, the same vocabulary can coordinate distinct carriers, laws, semantic sectors, paths, Passports, constraints, observations, and receiving interfaces without collapsing them into one kind of mathematics.

The examples are arranged so that every increase in BM structure corresponds to an increase in an actual mathematical obligation.
