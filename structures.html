Core Structures

Branch

Core object

A typed mathematical carrier of information, distinctions, structure, and lawful mathematical behavior.

Interaction

Core object

A lawful joint mathematical action or relation between participating Branches.

Leaf

Core object

Mathematical information extracted from an interaction between Branches.

Tree

Core object

An organized structure of Branches and Interactions that produces a mathematical response.

Response

Core object

A law-valued output produced by a Tree or associated lawful structure.

Root

Active structural object

A resulting mathematical response or structure capable of participating in further lawful attachment, rebranching, or response.

Passport

Active structural object

A formal carrier of distinctions, observations, admissibility conditions, compatibility requirements, and other information required across a mathematical interface.

Architectural Structures

Operation

A typed lawful transformation acting on one or more mathematical objects under stated input, output, and admissibility conditions.

Configuration

A specified mathematical state containing the active Branches, Interactions, Passports, Roots, Operations, and associated structural data required for a BM construction.

Interface

A typed boundary or compatibility structure through which mathematical objects may lawfully interact, transform, export, or re-enter.

Network

A structured collection of connected Branches, Interactions, Roots, Passports, and operations whose relations are tracked explicitly.

Structural Processes

Composition

Lawful combination of compatible mathematical objects or operations.

Realization

Construction or instantiation of a mathematical object satisfying its required structure and admissibility conditions.

Export

Lawful transfer of a mathematical result or structure from one compatible mathematical context into another.

Re-entry

Lawful return of a transformed, exported, or derived object into a compatible mathematical structure for further use.

Registry Status
